pfb 的 decomp-01 用了 partition / disjoint / cover 三个词，它们确实来自格论里"分区格"的最表层。但格论真正深的地方——非分配性、M3/N5 最小反例、子模格的结构——我们一点没用上。这个"浅"是刻意的：空间直觉（拼回去看漏、两两看重叠）比代数判据更适合 LLM 执行，S0→S1 Δ=+0.019 ≈ 噪声也印证了把分解"代数化"不带来质量提升。

## 1. 格是什么（30 秒版）

**格 = 一个集合 + 两个运算 ∧（meet，取小/交）和 ∨（join，取大/并），满足交换律、结合律、幂等律、吸收律。**

不用记定义。你只需要记住：**任何"有大小关系且任意两个元素都有最大下界和最小上界"的东西都是格。**

最熟悉的例子：整数集 ℤ 配 ≤ 关系。任意两个整数 a, b：
- meet(a,b) = min(a,b)
- join(a,b) = max(a,b)

这就是一个格。ℤ 没什么特别，但它是个合格的起点。

### 偏序 vs 全序

全序：任意两个元素都能比大小（比如实数）。
偏序：有些元素之间"不可比"（比如二维向量 (1,0) 和 (0,1)，谁也不"小于"谁）。

格论主要研究的是偏序情况——全序太简单了，没什么好研究的。

## 2. 幂集格：你的第一个真·格

设 X = {a, b}（就两个元素）。X 的所有子集构成一个集合 P(X)：

```
P({a,b}) = { ∅, {a}, {b}, {a,b} }
```

按"包含关系 ⊆"排起来，画出来长这样：

```
        {a,b}          ← top（全集）
       /    \
     {a}    {b}       ← 中间层
       \    /
         ∅             ← bottom（空集）
```

这是一个 **4 元格的 Hasse 图**（Hasse 图 = 偏序关系的阶梯图，上面的元素"压着"下面的，边表示直接覆盖关系，没有省略号的那种传递边）。

在这个格上：
- **∧（meet）** = 集合交集 A ∩ B（两个集合的"最大公共部分"）
- **∨（join）** = 集合并集 A ∪ B（两个集合的"最小共同超集"）

验证一下：{a} ∨ {b} = {a,b}（最小共同超集），{a} ∧ {b} = ∅（最大公共部分）。✓

**关键性质：幂集格是分配格。** 什么意思？下面马上说。

## 3. 分配律：格论的核心问题

### 3.1 什么是分配律

在普通算术里，乘法对加法分配：a·(b+c) = a·b + a·c。

格论里有两个运算 ∧ 和 ∨，所以有两条分配律：

**∧ 对 ∨ 分配：**
```
A ∧ (B ∨ C) = (A ∧ B) ∨ (A ∧ C)
```

**∨ 对 ∧ 分配：**
```
A ∨ (B ∧ C) = (A ∨ B) ∧ (A ∨ C)
```

在布尔代数（开关电路、逻辑门）里这两条都成立。在幂集格里也成立（因为就是普通的集合交并）。

**但不是所有格都满足分配律。** 这是格论的核心发现之一。

### 3.2 用幂集格验证分配律（你应该自己能算）

取 X = {a, b, c}，P(X) 有 8 个元素。随便挑三个：
- A = {a}
- B = {b}
- C = {a, c}

左边：A ∧ (B ∨ C) = {a} ∩ ({b} ∪ {a,c}) = {a} ∩ {a,b,c} = **{a}**

右边：(A ∧ B) ∨ (A ∧ C) = ({a}∩{b}) ∪ ({a}∩{a,c}) = ∅ ∪ {a} = **{a}**

相等。✓（你可以换别的三元组再试，永远相等。）

## 4. M3 和 N5：最小的非分配格

### 4.1 为什么需要"最小反例"

如果一个格不满足分配律，它一定含有某个"坏结构"。格论的一个经典定理（Birkhoff, 1947）说：

> **一个有限格是分配格 ⟺ 它不含 M3 或 N5 作为子格。**

换句话说，M3 和 N5 是"非分配性的最小原子"——任何非分配格都至少含其中一个。就像群论里"非阿贝尔群一定含 S3 的子结构"一样（不完全准确，但精神类似）。

所以理解 M3 和 N5 = 理解非分配性的全部本质。

### 4.2 M3（钻石格 / Diamond）

M3 有 5 个元素：1 个顶、1 个底、3 个中间元素，每个中间元素都在顶和底之间。

```
        1              ← top
      / | \
     a  b  c           ← 三个"原子"（atom = 紧挨着 bottom 的元素）
      \ | /
        0              ← bottom
```

**名字来源：** 看起来像字母 M 加一条竖线（或者像钻石/菱形），所以叫 M3（3 个原子）。

**验证 M3 不是分配格：**

取 A = a, B = b, C = c（三个中间元素）。

左边：A ∧ (B ∨ C)
- B ∨ C = b ∨ c = **1**（top，因为 b 和 c 的最小共同上界就是顶）
- A ∧ 1 = a ∧ 1 = **a**

右边：(A ∧ B) ∨ (A ∧ C)
- A ∧ B = a ∧ b = **0**（bottom，因为 a 和 b 的最大公共下界就是底）
- A ∧ C = a ∧ c = **0**
- 0 ∨ 0 = **0**

**左边 = a ≠ 0 = 右边。** 分配律断了。✗

**直观理解：** a、b、c 三个"方向"互相独立，任意两个的"交集"是空的（0），但 b 和 c 的"并"已经膨胀到整个顶 1，再跟 a 取交还是 a。分配律期望"先并再交 = 先交再并"，但这里"先并"把信息撑大了，"先交"却什么也没留下。

### 4.3 N5（五元链加一个分支）

N5 也有 5 个元素，但形状不同：一条 3 层的链，旁边多挂一个元素。

```
        1              ← top
        |
        d              ← 链条上的中间元素
       / \
      b   c            ← b 在链条上，c 是"旁支"
       \ /
        0              ← bottom
```

更标准的画法（注意 c 只跟 0 和 1 相连，d 在 b 上方）：

```
        1
        |\
        | c
        |  \
        d   \
        |    \
        b
        |
        0
```

即：0 < b < d < 1 是一条链，另外 0 < c < 1（c 与 b、d 不可比）。

**验证 N5 不是分配格：**

取 A = b, B = c, C = d。

左边：A ∧ (B ∨ C)
- B ∨ C = c ∨ d = **1**（c 和 d 的最小共同上界是顶）
- A ∧ 1 = b ∧ 1 = **b**

右边：(A ∧ B) ∨ (A ∧ C)
- A ∧ B = b ∧ c = **0**（b 和 c 的最大公共下界是底）
- A ∧ C = b ∧ d = **b**（b 在 d 下面，所以最大公共下界是 b）
- 0 ∨ b = **b**

嗯，这次相等了。换一组：A = c, B = b, C = d。

左边：A ∧ (B ∨ C)
- B ∨ C = b ∨ d = **d**（b 在 d 下面，最小共同上界是 d）
- A ∧ d = c ∧ d = **0**（c 和 d 不可比，最大公共下界是底）

右边：(A ∧ B) ∨ (A ∧ C)
- A ∧ B = c ∧ b = **0**
- A ∧ C = c ∧ d = **0**
- 0 ∨ 0 = **0**

这次也相等……再换：A = d, B = b, C = c。

左边：A ∧ (B ∨ C)
- B ∨ C = b ∨ c = **1**
- A ∧ 1 = d ∧ 1 = **d**

右边：(A ∧ B) ∨ (A ∧ C)
- A ∧ B = d ∧ b = **b**
- A ∧ C = d ∧ c = **0**
- b ∨ 0 = **b**

**左边 = d ≠ b = 右边。** 分配律断了。✗

### 4.4 M3 vs N5 的区别（一张表）

| | M3 | N5 |
|---|---|---|
| 形状 | 对称的钻石 | 不对称的链+旁支 |
| 对称性 | 完全对称（三个原子等价） | 不对称（c 是"外来者"） |
| 分配律断法 | "先并"膨胀到顶，"先交"归零 | "先并"沿链爬，"先交"停在低处 |
| 出现场景 | 三个独立方向的子空间 | 层级结构里混入一个跨层元素 |

**记忆口诀：** M3 是"三兄弟谁也不服谁"，N5 是"排队时有人插队"。

## 5. 子模格为什么是非分配的

### 5.1 先说清楚"子模格"是什么

**模（module）** = 抽象代数里的线性空间推广（向量空间的广义版本，把域换成环）。

**子模格 L(M)** = 模 M 的所有子模，按包含关系排成的格。meet = 子模的交，join = 子模的和（sum，不是直和）。

**核心事实：子模格几乎总是非分配的。**

最简单的例子：取 M = ℤ₂ × ℤ₂（二维向量空间 over GF(2)，4 个元素：0, e₁, e₂, e₁+e₂）。它的子空间只有 4 个：

```
{0}  <  span(e₁)  <  M
{0}  <  span(e₂)  <  M
{0}  <  span(e₁+e₂)  <  M
```

等等——这其实就是 M3！三个 1 维子空间（原子）+ 顶 + 底。

**所以 ℤ₂ × ℤ₂ 的子空间格 = M3 = 非分配格。** 这是最小的非分配子模格。

### 5.2 为什么子模格天然非分配

根本原因：**子模的"和"（join）不像集合的"并"那么守规矩。**

- 集合并：A ∪ B 就是"把 A 和 B 的元素放在一起"，很直观。
- 子模和：A + B = {a + b : a ∈ A, b ∈ B}，是"所有可能的线性组合"。

这个"膨胀"效应正是 M3 里"B ∨ C = 1"的原因：两个 1 维子空间的和可以是整个 2 维空间。分配律期望"交和并可交换顺序"，但子模的"可"（和）会制造出新的元素，打破交换性。

**物理类比：** 两个偏振方向的光束（e₁ 和 e₂），单独看各是一个 1 维"子空间"，但叠加后产生整个 2 维偏振态空间。你没法说"先叠加再投影 = 先投影再叠加"——量子力学里这不是比喻，是真的不成立（非对易算符）。

### 5.3 什么时候子模格是分配的？

有一个精确判据（Graver & Seidel, 1988）：

> **L(M) 是分配格 ⟺ M 是"分配模"（distributive module）**

分配模的条件相当苛刻：M 必须同构于某些特定结构的直和。大部分自然出现的模（比如 ℤ 作为 ℤ-模的子理想格）都不是分配的。

**具体例子：ℤ 的理想格。**

ℤ 的理想就是 nℤ（n 的倍数集）。按包含关系排：

```
... ⊂ 6ℤ ⊂ 3ℤ ⊂ ℤ
... ⊂ 6ℤ ⊂ 2ℤ ⊂ ℤ
```

这个格是 **分配格**（因为 ℤ 是主理想整环，理想格同构于正整数按整除关系排成的格，而整除格是分配的）。

但换一个环：R = k[x,y]（二元多项式环）。理想 (x) 和 (y) 的交是 (xy)，和是 (x,y)。取第三个理想 (x+y)：

- (x) ∧ ((y) ∨ (x+y)) = (x) ∩ (x,y,x+y) = (x) ∩ (x,y) = (x)
- ((x) ∧ (y)) ∨ ((x) ∧ (x+y)) = (xy) ∩ ... 

算了，这个例子手算容易出错。重点是：**多元多项式环的理想格通常非分配**，含 M3 或 N5 子格。

## 6. 回到 pfb：我们借了什么，没借什么

### 6.1 decomp-01 实际用到的格论概念

| 术语 | 格论出处 | pfb 里的用法 | 深度 |
|------|---------|------------|------|
| partition（分区） | 分区格 Πₙ 的元素 | "把问题拆成正交维度" | 表层词汇 |
| disjoint（不相交） | 分区的定义条件 | "两两看重叠" | 表层词汇 |
| cover（覆盖） | 分区的定义条件 | "拼回去看有没有漏" | 表层词汇 |

**分区格 Πₙ** = 集合 {1,...,n} 的所有划分方式，按"精粗度"排成的格。Π₃（3 元素的分区格）有 5 个元素，形状恰好是 **N5**！

```
{{1},{2},{3}}          ← 最细（全散）
    /    \
{{1,2},{3}}  {{1,3},{2}}   ← 中间层
    \    /
   {{1,2,3}}             ← 最粗（全合）
```

等等，Π₃ 其实有 5 个元素但形状不是标准 N5（它是 N5 的变体，叫 "pentagon lattice" 也行）。关键是：**分区格本身是非分配格**（n ≥ 3 时含 M3 子格）。

### 6.2 我们没用的深层结构

| 格论概念 | 内容 | pfb 是否用到 |
|---------|------|------------|
| 分配律 | A∧(B∨C) = (A∧B)∨(A∧C) | ❌ 完全没提 |
| M3 / N5 反例 | 最小非分配格 | ❌ 完全没提 |
| 子模格的非分配性 | 子模和的膨胀效应 | ❌ 完全没提 |
| 格同态 / 格嵌入 | 格之间的结构保持映射 | ❌ 完全没提 |
| Birkhoff 表示定理 | 每个有限分配格 ≅ 某幂集格的子格 | ❌ 完全没提 |

**关系总结：表面词汇借用，深度为零。** 我们用了 partition/disjoint/cover 这三个词的*空间直觉*（拼图、重叠、覆盖），但没有引入格论的任何代数结构。decomp-01 里明确写着"禁止用代数式判据替代这两个检查"——这是设计决策，不是遗漏。

### 6.3 为什么"浅"是 feature 不是 bug

**原因一：LLM 擅长空间直觉，不擅长代数推理。**

"把所有子节点的范围加起来，能不能完整覆盖原来那个节点的范围？"——这是一个视觉/空间任务，LLM 做得不错。

"A ∧ (B ∨ C) = (A ∧ B) ∨ (A ∧ C) 在此分解中是否成立？"——这是一个代数验证任务，LLM 大概率会硬编一个"成立"的答案而不真正验证（decomp-01 原文："那会诱导模型为了凑出表达式而硬编，看起来完成了检查，实际覆盖没覆盖它自己都不知道"）。

**原因二：实验数据支持。**

stage-ablation 的 Per-Level Delta 表（scoring.md）：

| Transition | Mean Prev | Mean Cur | Δ | Sign |
|------------|-----------|----------|---|------|
| S0→S1 | 0.556 | 0.575 | **+0.019** | + |
| S1→S5 | 0.575 | 0.791 | +0.216 | + |

S0 = 裸 01 阶段（无 decomp 模块），S1 = 01 + decomp-01 五步法。Δ = +0.019，n=6/arm，judge 为同源 27b（self-judge，绝对值只作相对比较）。

**解读：** +0.019 在这个量级下 ≈ 噪声（n=6 的标准误远大于 0.019；sign test 7/7/1，p=1.0，不显著）。也就是说，加了 decomp-01 的五步法（包括 partition/disjoint/cover 检查）相比裸流程，**没有统计显著的质量提升**。

但这不意味着 decomp-01 没用——它的价值在**过程可见性**（拼接覆盖图可审计）和**缺口标注覆盖率**（M4 维度），不在总分。如果把分解检查"代数化"（要求验证分配律、找 M3/N5 子格），预期效果会更差：LLM 会花 token 在形式操作上而不是实质覆盖判断上。

**原因三：正确的抽象层次。**

decomp-01 要解决的实际问题是："分解有没有漏？有没有重叠？" 这个问题的自然语言表述（拼回去看漏、两两看重叠）已经足够精确，不需要格论的形式化。格论的价值在于**证明定理**（比如"任何非分配格含 M3 或 N5"），不在于**指导 LLM 做分解检查**。

类比：你用尺子量桌子长度，不需要知道欧几里得几何的第五公设。尺子够用就行。

## 7. 如果你还想深入（可选路径）

1. **从 M3/N5 到一般非分配格：** 读 Birkhoff《Lattice Theory》第 4 章（1948，有 Dover 平装本，便宜）。重点：§4.3 分配格特征化，§4.4 有限分配格的 Birkhoff 表示。

2. **子模格的现代应用：** 子模格的非分配性在**亚模函数优化**（submodular function optimization）里有直接对应——亚模函数的"边际递减"性质正好对应子模格的非分配结构。ML 里的 facility location、sensor placement 问题都落在这。

3. **格论与范畴论：** 格是 (∧, ∨)-半格，也是 Lawvere-Tierney topos 里的 Heyting algebra 特例。如果走这条线，建议先读 Mac Lane《Categories for the Working Mathematician》前 4 章。

4. **pfb 相关：** 如果未来要做"分解质量的自动验证"，M3/N5 检测可以作为**离线审计工具**（人跑，不给 LLM 跑）：把 LLM 产出的分解树编码成格，程序检测是否含 M3/N5 子格，含则标记"该分解存在结构性重叠风险"。但这是审计层的事，不该进 prompt。
