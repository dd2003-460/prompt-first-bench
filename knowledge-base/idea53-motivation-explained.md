## 1. 一句话结论

为什么用信息族而非占比/消融：瓶颈判断是由**交互项**决定的组合函数。T5000 上 FP16 等速率时只占负载的 30%（70/30 工况），施加速率后却占 63% 的时间（50/50 时为 80%）。继承线性假设的度量——占比、固定上下文下的消融——会系统性低估交互项；信息论量不要求线性假设，能把"浅层已知后还剩多少"单独隔离出来。

## 2. H(D|S) 大白话

**浅层 S**：假设所有 rate=1，则时间占比正比于负载占比 f_i，瓶颈 = argmax f_i。相当于"只看占比、不看硬件"。

**深层 D**：施加真实速率 t_i = f_i/rate_i，瓶颈 = argmax t_i。相当于"把硬件规格代进方程"。

**H(D|S)**：浅层判断已知之后，瓶颈判断还剩多少会变。熵链式 H(D) = H(D|S) + I(S;D) 把深层的总信息切成两块：I(S;D) 是深层从浅层"继承"的部分（浅层已经知道的），H(D|S) 是深层"新增"的部分——这才是要给深层节点记的账。

两个可解释分量（大白话分数）：
- flip = P(S≠D)：方向修正，瓶颈类型翻转的比例（四平台实测 43–56%）
- shift = E|share_D − share_S|：粒度修正，时间占比的平均移动量（实测 0.17–0.23）

H(D|S) 是这两个量的信息论严格形式（实测 0.71–0.77 bits，四平台 × 40,000 个工作负载）。负控制：把所有速率设为 1 时 H(D|S) 精确为 0，排除"深层只是转发浅层"。

## 3. Fisher 项大白话（重点节）

读者痛点：互信息不是要靠大量样本估计吗，为什么这里能手算？

**闭式**：小高斯扰动 δ~N(0,σ²) 下，扰动与判断之间的互信息有二阶展开 I(δ;D) ≈ ½σ²F（F 是 Fisher 信息）。探针里写作 I₂ = ½c²(1−pᵀRp)，c=ασβ，R 为扰动相关阵；R=I 时退化为 ½c²(1−Σp²)。这是信息几何的标准结论：分布族的曲率在操作点处决定小扰动携带多少信息。

**为什么不用样本**：F 从模型导数（敏感性）算出——这里 d log t_i / d log rate_k = −α[i=k]，对角闭式——不是从样本统计估计。区别是"从方程读出曲率" vs "从数据拟合曲率"。所以不依赖大数据、不需要训练、不需要标注。

**(1−pᵀRp) = 瓶颈分布的模糊度**：p 是软判断分布 softmax(β·log t)。分布平坦（各分量份额接近）→ 1−pᵀRp 大 → 信息多：小扰动就能挪动排名，判断真依赖细节。某分量垄断（p→one-hot）→ 1−pᵀRp→0 → 信息 0：排名锁死，扰动无效。物理图像：操作点离决策边界越远，扰动携带的信息越少。

**概率从哪来**：p 由声明的先验代入模型得到——负载份额 f_i 从 Dirichlet(1,1,1,1) 均匀采样。这是声明的先验，不是测出来的频率。四平台是四次独立测量（每平台一套速率向量），不是池化平均。

**不成立的用法**：拿少量样本估计 MI（拟合分布再算熵）——那是教科书坑，闭式没做这事。闭式只用模型解析结构 + 声明先验；采样只出现在 MC 负控制里（验证闭式与模拟一致，H1 判据 34/41 配置 <2%）。

**边界声明**：Fisher 闭式在 toy 脚本/探针里（additive-tree-perturbation.py P3、corrnoise 探针 I₂）；论文头条量是 H(D|S)+flip/shift。两者同族——都是"可闭式算的信息增量"，Fisher 项是其小扰动版本。

## 4. 前瞻：位数性价比视角（2026-11-26 讨论，D 提出）

**问题**：信息族回答"判断里有多少信息"，但没回答"花多少比特买这些判断值不值"。节点得分 = Δperf / ΔL：每花一位数（码长）换来多少性能/判断质量的移动。

**率失真的反过来问**：经典率失真问"给定码长 L，保真度上限多少"；这里反过来——给定判断质量的移动 Δperf，最少要花多少码长 ΔL？

**位数和概率是同一个东西**：码长 L(x) = −log₂p(x)。声明一个概率 = 声明一个码长。但码表可审计：你可以声明一张码表而不声明一个分布——码表是显式的、逐符号可检查的对象，分布是隐式的。这把"声明先验"从黑箱变成白箱工件。

**加性树是锚点 regime**：t = Σ f_i/rate_i 下，ΔL = 子项参数的码长（声明 rate_i、f_i 各花几位），Δperf = 代入后 argmax 翻转 / 时间占比移动。两边都闭式，可以做负控制（平坦速率 → Δperf = 0，精确零）。一般情形（非线性聚合、相关扰动）当推广处理，锚点先行。

## 5. 与状态机的接口

该比值给分解树的停止规则一个可计算版本：最优候选节点的期望 Δperf/ΔL 超过阈值就继续拆，否则停。这替掉了"感觉差不多该停了"的软判断——停止规则变成一次闭式比较，可预注册、可负控制。

候选维度种子库（本地缓存）治维度盲区：候选节点从已验证的维度库里取种子，新维度进库前先在锚点 regime 上跑一遍负控制。盲区不再是"没想到这个维度"，而是"这个维度没通过种子库准入"。
