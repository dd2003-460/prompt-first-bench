# 评分标准（prompt-first 流程消融）

> origin: ai · 2026-10-22 · 供 arena 任务书引用。评分对象：同一调研任务在不同流程变体下的最终产出。

## 任务集（固定 5 题，避免题目难度差异污染结论）

调研类任务（可验证 + 有里程碑答案，便于判对错）：
1. 信息论里程碑：Shannon 1948 原文的核心贡献（精确陈述 + 来源）
2. Bell 1948 与 Shannon 的分工关系（谁先、内容差异）
3. 量子纠错的阈值定理（数值 + 提出者 + 年份 + 来源）
4. LMArena agent mode 与 browser mode 的执行层差异（≥2 源交叉）
5. 一个开放调研题：选一个领域（由任务书指定），要求"完整搜集里程碑工作 + 选置信度最高方向"

## 评分维度（每题 100 分）

| 维度 | 分值 | 判据 |
|------|------|------|
| D1 正确性 | 40 | 关键事实正确（名称/数值/年份/来源可验证）；错 1 个关键事实 -10，无来源 -10 |
| D2 完备性 | 25 | 里程碑工作无遗漏（对照评分者答案清单）；漏 1 个 -5 |
| D3 结构正交 | 20 | 因素不重叠不遗漏（人工判 0-20，按 rubric 锚点） |
| D4 置信度标注 | 15 | 每条 claim 带来源 + conf；缺失按比例扣分 |

**成功判定**：总分 ≥ 80 = success；60-79 = partial；< 60 = fail。

## 流程变体（每个任务 × 每个变体 × 每个模型，各 ≥1 run）

| 变体 | 内容 | 对照目的 |
|------|------|---------|
| V0 | 裸 prompt（无任何流程要求） | 基线 |
| V1 | + 01 目标分解（正交+完备+递归原子） | 测「拆解任务」的边际提升 |
| V2 | V1 + 02 信息调研（来源+conf） | 测「调研纪律」 |
| V3 | V2 + 02.5 交叉验证（≥2 LLM） | 测「交叉验证」边际 |
| V4 | V3 + 04.5 反方复核 | 测「反方复核」边际 |
| V5 | V4 + 逐阶段落盘 + 每阶段 pass 门禁（完整 1-loop） | 完整流程 |

**消融读出**：V(k) - V(k-1) 的 success 率差 = 该要求的边际提升。

## 模型维度

arena 会话内可用模型（由 arena 会话报告实际可用列表，至少覆盖 2 个不同厂商/系列）。若 arena 不能自选模型 → 记录"模型不可控"为限制，用 arena 默认模型跑全部变体，模型维度标注 N/A。

## 汇总要求

每个 (task, variant, model) 产出：
- `bench/runs/<task>/V<k>-<model>/run1.md`（完整输出，非摘要）
- `bench/runs/<task>/V<k>-<model>/run1-score.md`（D1-D4 分值 + 判定）
最后 `bench/runs/<task>/summary.md`：变体 × 模型的 success 率矩阵 + 边际提升表 + 结论（prompt-first 是否提升 / 对哪些模型提升 / 每个要求的边际）。
