## 核心：pfb 是什么

pfb 不是六个串行关卡，是一条**逼近"压缩-解压往返无损不动点"的流程**。每阶段是这个不动点求解的一个环节：

- 分解 = 压缩（选基 + 定阶）
- 取证 = 获取 likelihood（贝叶斯的证据输入）
- 校验 = 信度 + 效度
- 展开 = 解压
- 执行 = 时间方向的解压（预言→验证）
- 复核 = 往返无损检查（D∘C=恒等？）

**阶段间是乘性耦合，不是加性独立。** 证据：pfb 的 repair_stage 机制——04.5 发现证据不足→回退 02，一环断裂整体失效、必须回退修那一环。若是加性的（各阶段独立贡献），一环断了只损失一部分，不必回退。所以 pfb 的有效性 = 分解质量 × 证据质量 × 执行质量，任何一环=0 整体=0（木桶/链条，不是累加）。

## 六环节（逐个精细化：角色 / 输入输出 / 判据 / 缺口 / repair）

### 01 分解 = 压缩（选基 + 定阶）
- **角色**：把目标压成"主项+逐级修正"的展开（级数展开）。选基=选分解维度，定阶=定展开到第几级。
- **输入**：原始目标。**输出**：分解树（加性分叉）+ 空缺清单 + 02 研究入口。
- **判据**：正交（子项不重叠）+ 完备（覆盖目标）+ 叶子原子（不能再分）。
- **缺口**：
  ① 没有"当前基正交完备吗"的显式检查 → 不正交/不完备时无换挡信号（压缩环入口缺失）。
  ② 分解树纯加性，不支持乘性（因子分解：整体=A×B，A、B 各自展开）。
  ③ 隐含"选域"第①步（校验公理范围）但未成显式环节。
- **repair**：分解不完整 → 01（重新压缩）。

### 02 信息搜集 = 获取 likelihood（贝叶斯证据输入）
- **角色**：为 01 空缺填证据。证据质量决定贝叶斯更新方向。
- **输入**：01 空缺清单。**输出**：带来源/时间戳的证据集 + 暂定结论 + 未解决空缺。
- **判据**：每条主张有来源 URL+时间戳；关键主张≥2 独立来源；易变事实近 7 天。
- **缺口**：
  ① 只要求"搜到"，没要求"质量分级"。一手（教科书/原始论文/官方规格）vs 二手（转述/营销/博客）应分开标——二手是噪声，带偏更新方向。
  ② 低质量信息压不动（压缩比低）→ 陷执行模式 → "做多想少"的根因之一。
- **repair**：证据不足/矛盾 → 02（补证据）。

### 02.5 交叉核验 = 信度 + 效度校验
- **角色**：双重校验。**信度**=内部自洽（同一主张多来源一致吗）；**效度**=外部有效（来源本身准确/独立/客观吗）。
- **输入**：02 证据集。**输出**：证据边界（哪些可信、哪些存疑、矛盾在哪）。
- **判据**：矛盾有解释（不是"基本一致"）；对核验方结论做过至少一轮主动质疑（对抗核验）。
- **缺口**：
  ① 这里其实是"选域"第①②步（校验公理范围 + 迁移仍成立条件），但没用选域语言显式化。
  ② 效度（来源准确独立客观）现在混在"独立来源"里，没单列为判据。
- **repair**：资料够但核验表达不全 → 02.5；需补资料 → 02。

### 03 行动分解 = 解压（压缩态→可执行步骤）
- **角色**：把 02.5 的压缩态（证据边界）展开成可执行步骤序列。这是"解压"——从压缩模型展开到具体动作。
- **输入**：02.5 证据边界。**输出**：步骤序列（每步输入/动作/依赖/产出/验收）+ 并行标注 + 替代路径。
- **判据**：每步原子+可验证+owner 标注；依赖无循环；不依赖未核验事实。
- **缺口**：
  ① 解压是单向的（压缩态→步骤），没有"解压回来对得上压缩态吗"的回检。
- **repair**：依赖未核验事实 → 02/02.5。

### 04 执行 = 时间方向的解压（预言→验证）
- **角色**：把 03 步骤展开到"未来"（执行），对照验收。这是预言力——从压缩态展开到时间方向，看预测准不准。
- **输入**：03 步骤序列。**输出**：执行记录（命令/文件/输出/失败）+ 逐项验收对照。
- **判据**：声明完成的有实际结果；逐项对照验收；失败诚实保留。
- **缺口**：
  ① 执行层循环防护（重试≤2、卡住≤3轮）是行为判据，没有结构判据（为什么卡住=分解不正交/不完备？）。
- **repair**：前提/事实有问题 → 02/03；执行本身 → 04。

### 04.5 最终复核 = 往返无损检查（D∘C=恒等？）
- **角色**：全流程的往返无损校验。从原始目标压缩（01）→展开（03/04）→回到结论，检查"解压回来的东西对得上原始目标吗"。
- **输入**：全过程（01 空缺/02 证据/03 行动/04 结果）。**输出**：结论依据链 + 薄弱点 + 未完成项 + 残余风险 + 下一步。
- **判据**：结论不超证据范围；完整链条可追溯；反方检查（找反例）。
- **缺口**：
  ① 这里是"选域"第③步（实验新条件）的自然位置，但现在只"列残余风险"，没有"是否发现新适用条件→要不要换基"的判断。
- **repair**：影响结论的缺口 → 真正需要修复的阶段。

## 三结构性缺口（D 发现，汇总）

1. **压缩环缺失**：整条链假设现有理论够用。缺"当前基正交完备吗"的检查。入口在 01（不正交→压缩合并；不完备→先加项补充，基内盖不住才换基），出口在 04.5（发现新条件→换基）。
2. **选域三步不成显式环节**：①校验范围（01 隐含/02.5）②迁移条件（02.5）③实验新条件（04.5）。现在散在三处，没有"什么时候跑这三步"的信号。
3. **01 分解树纯加性**：阶段间已是乘性（repair 机制），但 01 树内部纯分叉，不支持因子分解（整体=A×B）。
4. **regime 突变检测缺失**（D 2026-11-25 指出）：贝叶斯更新假设平稳性（所有证据同分布）。渐进稳定=平稳 regime 内后验收敛；但数据结构突变时旧证据编码旧 regime 规律，结合历史不是加噪是**系统性偏差**（旧数据越多拉偏越厉害，后验惯性越大）。04.5 需第三检查：历史证据是否突然全部失效？是→丢弃旧压缩重新选域（回 01），不是回 02 补证据。这是"换基"的第二种触发条件（第一种=分解不完备基内盖不住）。

## gear-shift 信号（换挡判据）

把"连续 N 轮无进展"（行为判据）升级为**结构判据**：

- 分解不正交（两个子项说同一件事）→ 压缩合并
- 分解不完备 → 分两档（D 2026-11-24 修正）：
  - **可补充**（现有基内还有没用的基函数）→ 加项补充，不换基（优先）
  - **不可补充**（现有基完全盖不住，缺口不在基张成的空间内）→ 引入新理论（换基，最后手段）
- 执行卡住（重试≥2/同错≥2）→ 退一步查分解结构（行为判据做兜底）
- 发现新适用条件（04.5）→ 换基 / 跑选域三步
- 历史证据突然全部失效（regime 突变，04.5 检查）→ 丢弃旧压缩，回 01 重新选域（不是回 02 补证据）

## 数据质量门（02 过滤器）

- 一手证据（教科书/原始论文/官方规格）= 有效 likelihood，权重高
- 二手转述（营销/博客/转述）= 噪声，标"未核验"，不进关键主张
- 判据：压不动（压缩比低）的信息 = 不值得压 = 噪声，不进压缩态

## 咒语：先压后展

"先压后展"（4 字）是 pfb 的触发词。

**作用**：切换心智模式——执行模式（直接上手）→ 研究模式（先理解再展开）。

**为什么 4 个字够**：pfb 6 阶段 = 压缩（01 分解 + 02 取证 + 02.5 校验）→ 展开（03 行动分解 + 04 执行）→ 复核（04.5 往返无损）。"先压后展"是这个结构的 4 字压缩。咒语是**开关**（让 AI 知道该走 pfb 而不是直接上手），不是**流程**（流程在 pfb/loop/*.md）。

**触发方式**：
- D 说"先压后展：[任务]" → 进 pfb 模式，走 6 阶段
- 执行中卡住（重试≥2 / 同错≥2 / 分解不正交 / 不完备）→ think-trigger 自动注入"先压后展"
- 加强版："先压后展，正交完备吗？"（带结构判据）

**进入 pfb 模式后**：
1. 读 pfb/loop/*.md（6 阶段 SOP）
2. 按 01→02→02.5→03→04→04.5 执行
3. 每步先问"对不对"（结构判据：正交完备 / 独立来源 / 矛盾解释 / 验收对照 / 往返无损），再问"怎么做"（执行细节）

**稳定性保证**：咒语不依赖上下文。AI 看到"先压后展"就知道进入 pfb 模式（前提：pfb/CLAUDE.md 注册了触发词定义）。think-trigger 自动注入时，AI 不需要 D 手动说——stop_hook 检测到卡住条件后注入"先压后展：退一步，正交完备吗？"。

## 待 D 确认

- "正交完备冗余校验"精确含义：正交完备作**判据**（检查分解对不对）vs 冗余字典 over-complete basis 作**压缩手段**（允许多余基函数换取更稀疏表示）。本文暂按前者（判据）处理。
- "渐进稳定"指哪个：贝叶斯后验随证据累积收敛（证据固定、更新稳定）vs 条件空间本身探索渐进（每轮才知道条件空间多一点结构）。后者自举问题更严重（连"在什么空间搜索"都在变），难度差一个量级。
