## 1. 结论速览（按日历后端情景分流）

决定性因素不是价格，而是**贵司的日历后端到底是一套还是两套**。证据显示：**Microsoft 365 与 Google 两家都不提供彼此之间的原生双向日历打通**（S48），Microsoft 不支持 CalDAV 开放标准（S49 + S50），而 Google 官方的 GWSMO 工具"是让 Outlook 变成 Google 的客户端，而不是 M365 日历与 Google 日历之间的桥"（S48），且**从 Outlook 地址簿添加的会议室根本不会同步过去**（S47）。

| 情景 | 实际含义 | 推荐方案 | 年度成本 | 备选 |
|------|----------|----------|----------|------|
| **S-M365** | 只有 Microsoft 365 一套后端；"Google Calendar"只是个别员工的个人日历偏好 | **M365 房间邮箱 + Microsoft Places（原生）** | **¥0 增量** | Skedda APAC Starter（治理层）¥7,936 · Whatspot ¥2,004–2,405 |
| **S-Google** | 只有 Google Workspace 一套后端；Outlook 只是客户端 | **Google Workspace 日历资源（原生）** + Windows 用户用 GWSMO/浏览器 | **¥0 增量**（受 U1 限制） | Skedda APAC Starter ¥7,936 · Joan ¥4,088（软件） |
| **D-双栈** | Google Workspace 与 Microsoft 365 **同时在用** | **Skedda（EMEA/APAC Starter）** 作为中立预约层，双向同步两套日历 | **¥7,936/年（占预算 39.7%）** | Joan ¥4,088（软件，员工经 Outlook/Google 预订不计费）· Envoy $5/资源/月（**平台费未公开**）· Whatspot ¥2,004–2,405（证据较弱） |

**门禁联动（可选项）**：若需要，优先在 **Skedda × Kisi**（S19 + S27 的 Zapier 工作流示例"预约开始 → Kisi 开门"）或 **Envoy ×（Kisi / Openpath-Alta / Brivo / Genea / Rhombus）**（S19/S24/S34）中选择。⚠️ **国内门禁品牌与上述海外平台的兼容性无任何可核验证据（U16）**，若贵司门禁为国内品牌，请把门禁联动当作"需 POC 验证项"，不要当作已具备能力。

## 2. 推荐方案详述

### 情景 D（双栈并存）→ 推荐：Skedda EMEA/APAC「Starter」

| 项目 | 内容 | 来源 |
|------|------|------|
| 定价 | **$99/月**，年付，**含 15 个空间**，**不限用户与预订数** | S1（官方定价页，2026-10-28 抓取） |
| 年度成本 | **$1,188 ≈ ¥7,936**（1 USD = 6.68）→ 占预算 **39.7%** | 本地计算，`outputs/T7.1-cost-model.json` |
| 三端 | Web 为主；另有 iOS/Android App、Teams/Slack 内嵌 | S28、S10 |
| 双日历 | 声称与 Microsoft 365 与 Google Workspace **原生双向同步**（Skedda 建的预约出现在 Outlook/Google；Outlook 侧的预订也能占用 Skedda 空间） | S10（厂商）+ S28（独立第三方）→ **证据强度中等，必须试用验证** |
| 治理能力 | 预约规则引擎、交互式平面图、6 种签到方式（二维码/Wi-Fi/邮件/App/平板/Logitech 面板）、利用率看板 | S18/S19（Skedda 自营内容，**对自家能力不单独采信**，仅作功能清单参考） |
| 门禁 | 与 Kisi 集成 | S19 + S27 |
| 采购方式 | **无自助结算入口**，所有档位按钮均为 "Talk to Sales" | S1 |

**为什么是它**：在"双栈并存"约束下，唯一能同时对接两套后端的办法是引入中立层（02.5 §四B-2）；而在本次核验到公开价格的中立层里，Skedda 是**唯一一个"按档位含空间额度 + 不限用户"**的方案——30 人团队用它，成本不随人头增长，3 间房与 15 间房同价。

**必须在下单前做掉的事**（否则结论可能翻车）：
1. 向销售确认**中国大陆适用哪一区价目**（U8/DA-6）——美加价目会把预算占到 99.8%；
2. 确认**双向日历同步是否属于基础档**、是否存在额外收费的 "Integrations Pack"（U7/X4：第三方资料称集成包另收费，**官方定价页未列此项**）；
3. 试用期内跑通闭环：**Google 侧建会 → 会议室被占用 → Outlook 侧可见**，反向再跑一遍。

### 情景 S-M365 → 推荐：M365 房间邮箱 + Microsoft Places（零增量成本）

- **微软官方明确**："预订会议室与工位池**不需要任何额外许可证**"，且 Places Finder / Explorer 现已对所有用户免费（S2，官方文档当日抓取）。
- 房间/设备邮箱 50 GB 以内**不需要许可证，$0**（S45）。
- **需要付费的只有两件事**：会议室/工位的 **autorelease（无人到场自动释放）** 与 **占用分析**，需 Microsoft Teams Shared Space License（S2）。该许可证价格第三方称 $8.55/月、覆盖"4 桌 + 1 空间"（S43）——**此价格非微软官方页，未核验（U11）**。
- Room Finder 仍是 Outlook 与 Teams 日历中的默认体验（S2）→ 三端通过 Outlook 客户端 + Web 自然满足。

### 情景 S-Google → 推荐：Google Workspace 日历资源（零增量成本，带 1 个未核验点）

- Google 官方管理员帮助确认：Admin console → Directory → Buildings and resources 可创建楼宇与会议室资源，用户在日历中搜索并预订，可设容量/楼层/设备特性；最多 10,000 个楼宇（S3，官方页当日抓取）。
- ⚠️ **未核验（U1）**：抓取到的官方页**未说明**资源日历的版本门槛与计费，因此**不能断言"所有 Workspace 版本零增量成本"**，只能说"管理员可创建资源日历"。
- Windows 侧若坚持用 Outlook 客户端：GWSMO 仍在维护（v4.3.99.0，2026-07）但**仅支持 Windows + 经典 Outlook**，不支持 macOS / 新版 Outlook / Web / 移动端（S46/S47/S48），且**从 Outlook 地址簿添加的会议室不会同步，必须在 Google 日历里订房**（S47）→ **macOS 用户只能走浏览器或 Outlook for Mac 的 OAuth 账户方式**。
