## r2 交叉验证结论（DeepSeek + ChatGPT，web-llm/cross-check-r2.json）
- **共识 3 点**：① M1×M5 指标相关（加权重复奖励同一行为）② 缺结果/终态验证（过程分可能掩盖任务失败）③ 权重与基线缺校准证据（89.2→92.7 的精确性是虚假精度，应称"内部过程指标综合分"）
- **分歧 1 点**：新指标做加权项（DeepSeek 的 M7 溯源率）vs 硬门槛（ChatGPT 的 Task Success Rate gate）→ **裁决：按硬门槛口径落地**
- **采纳 M7（gate，非加权项）**：Verification Traceability Rate = 声称成功步骤中可追溯到 transcript 外不可伪造锚点（可执行测试返回值/外部 API 真实状态/独立 fs diff）的比例；外部锚点数据：Trust Layer（arXiv 2610.07274）108 任务仅 22.6% 同时通过「得分有据、声称属实、跨次稳定」四项检查
- **下轮待办（防忘）**：① 权重校准（两两相关性 + 多次运行方差）② M7 gate 实现进 loop 工件 ③ n≥3 run 消除 n=1 自评折损 ④ 终态效度判定接入（ls-remote/push 回执类锚点已具备）
