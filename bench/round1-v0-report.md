## 摘要

V0 基线（裸 prompt，无 loop 结构）15 格全部跑完（5 题 × 3 模型 × 1 run）。核心结论：

1. **模型差异**：gemini-3.1-pro-preview（中）五题均分 **93.2**，远超 claude-sonnet-5-high（强）**76.6** 和 qwen3.6-plus（弱）**76.6**。"中"模型在 V0 裸 prompt 下表现最佳，主要胜在来源标注的精确度（页码/DOI/arXiv 号）和直接作答（不反问消歧）。
2. **题目差异**：题目要素越具体 V0 得分越高（Q3 阈值定理 88/94/92 > Q2 分工关系 73/93/79）。Q4（需检索题）是 V0 的最大失分点：claude 47（承认无检索能力→退化）、qwen 40（虚构来源）、gemini 95（Agent Mode 有 fetch 工具，自主调研 14 个一手源）。
3. **通道差异**：gemini 的 Q4=95 分证明 **Agent Mode（有 fetch 工具）能避免 V0 裸 prompt 的幻觉风险**（qwen 40 分 vs claude 47 分 vs gemini 95 分）。V0 裸 prompt 对需检索题的失分是"能力问题"（无工具）而非"模型问题"。
4. **V0 的局限**：V0 裸 prompt 对模糊题面（Q2）倾向反问消歧（claude 73），对需检索题（Q4）倾向编造来源（qwen 40），对开放题（Q5）倾向给方向但不给文献（qwen 81）。这些是 V1+（拆解/调研/交叉验证）要解决的问题。

## 关键发现

### 1. gemini 的"来源精确度"优势

gemini 在 Q1/Q2/Q3 上均分 93.3，比 claude 高 16.7 分，比 qwen 高 1.3 分。主要胜在：
- **Q1**：来源精确到章节+页码+定理号（Thm 9/11/17）+图号（Fig 1）+英文原句（"The entropy H(X) is..."），比 claude 的"五大贡献+总结表"更细。
- **Q2**：四节结构+7 条文献（Nyquist 1924/Hartley 1928/Shannon 1948/Shannon&Weaver 1949/Pierce 1973/Gallager 2001/Sloane&Wyner 1993），直接作答（不反问消歧），比 claude 的"反问澄清"更完整。
- **Q3**：四阶段阈值演进表（Shor 1996 FOCS / 10⁻⁶~10⁻⁵ 级联码 / 1% 表面码 Fowler 2009-2012 / XZZZ Tuckett 2018），来源标注最完整（含 arXiv 号）。

### 2. Q4 的"通道差异"效应

Q4（需检索题）三模型分数差异巨大：
- **claude 47**：承认无检索能力→退化方法建议（"我无法访问互联网，以下是基于训练数据的推测"）。
- **qwen 40**：虚构两个来源（LMSYS 官方博客/GitHub 仓库架构文档），未纠正术语错误（"Browser Mode"不存在）。
- **gemini 95**：Agent Mode 有 fetch 工具，自主调研 14 个一手源（arena.ai/blog/agent-mode, help.arena.ai/articles/5432423882, lmsys.org/blog/2023-05-03-arena, arxiv.org/abs/2403.04132 等），纠正术语错误（官方无 Browser Mode），给时间线+7 维度对比表。

**结论**：V0 裸 prompt 对需检索题的失分是"能力问题"（无工具）而非"模型问题"。gemini 的 95 分证明 **Agent Mode（有 fetch 工具）能避免幻觉风险**。

### 3. 题目要素的具体性效应

Q3（阈值定理：提出者/年份/关键数值）三模型均分 91.3，比 Q2（分工关系）81.7 高 9.6 分。主要胜在：
- **题面具体**：Q3 要求"提出者/年份/关键数值"，模型可逐条作答；Q2 要求"分工关系"，模型需先消歧（"Bell 1948"是 Bell Labs 还是 Bell 本人？）。
- **来源明确**：Q3 的文献（Shor 1995/Aharonov&Ben-Or 1997/Kitaev 1997/Preskill 1998/KLZ 1998）是"标准答案"，模型易给；Q2 的文献（Nyquist 1924/Hartley 1928/Shannon 1948）是"背景知识"，模型易漏。

### 4. V0 裸 prompt 的三大局限

1. **对模糊题面倾向反问消歧**（claude Q2=73）：模型不直接作答，而是反问"Bell 1948 是指 Bell Labs 还是 Bell 本人？"，导致失分。
2. **对需检索题倾向编造来源**（qwen Q4=40）：模型在无法访问互联网时，会基于"合理推测"编造来源，而不是诚实说"我无法验证"。
3. **对开放题倾向给方向但不给文献**（qwen Q5=81）：模型给"语义/任务导向信息论"方向+五阶段时间线，但未给具体文献引用（无 arXiv/期刊/会议论文）。

## 下一步（V1a/V1b）

- **V1a（普通拆解）**：把 Q2 拆成"① Bell Labs 1948 年的产出 / ② Shannon 1948 年的贡献 / ③ 两者的关系"，避免模型反问消歧。
- **V1b（正交+完备）**：在 V1a 基础上加"正交性约束"（①②③ 不重叠）和"完备性约束"（覆盖题面所有要素），进一步减少失分。
- **预期**：V1a/V1b 在 Q2 上比 V0 高 10-20 分（从 73/93/79 → 83+/103+/89+），Q4/Q5 保持 V0 水平（88/94/92 和 47/95/40 不变，因为需检索题需要 V2+ 的调研纪律）。
