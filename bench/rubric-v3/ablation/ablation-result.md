# rubric-v3 O3 权重消融实验结果

> 数据来源：8 个 C0 run 原文；gold tree 与 run 文件未修改。命中证据为 run 原文连续片段，矩阵逐项通过“证据存在且长度≤40字”校验。
> **节点数不一致**：任务书及 gold-tree.md 开头称 35 节点，但 gold 文件可枚举的唯一节点 ID 只有 31 个。矩阵覆盖全部 31 个真实 ID；未杜撰另 4 个 ID。所有分数按可核验的 31 节点作分母，因而不能冒称完成了 35-ID 评分。
> 实验基线：当前分支合入输入后的 commit `8ee73de`；文件均来自 `bench/rubric-v3/ablation/`。

## 方法与权重

- **W0**：所有节点权重 1。
- **W1**：按 `w=1+4×SHARE(parent(v))`；根 N-0 权重 1。缺父节点 SHARE 的 N-5.1–N-5.3 采用中性权重 1，缺值与处理已写入 `prior-estimates.json`。
- **W2**：`w=1+min(−log₂(p̃), log₂(1/0.01))`。`p̃` 是 judge 对无 gold 模型在父上下文提出该拆分的先验概率；逐节点理由与 W2 weight 写在 `prior-estimates.json`。根节点无父上下文，p̃=null、权重1。
- **O3**：`Σ(wᵥ·hᵥ)/Σwᵥ`，分母为全部 31 个实际可识别节点。W0/W1/W2 总权重分别为 **31.000、83.828、104.153925**。
- 每个 `h=1` 有原文证据；`h=0` 的 evidence 为 null。

## 3. 权重改变排序的案例

- **run2 vs run6**：W0 差 `+0.0000`（两对均打平）；W1 差 `-0.0371`、W2 差 `-0.0261`。
  - `run2` 独有命中：N-1.1.1, N-1.2.2, N-3.1.2, N-5, N-5.1；`run6` 独有命中：N-3, N-3.1, N-3.2, N-3.2.4, N-4。
  - 解释：分数差不是新增命中数量造成，而是两侧命中落在不同节点权重。例如 N-4 在 W1 为根下一层（权重 5），N-3.2.4 的 W2 权重为 4.837；二者均由 run6 命中而 run2 未命中，因而 run6 得分更高。所有差异可从两个 JSON 按公式复算。
- **run3 vs run7**：W0 差 `+0.0000`（两者均 13/31）；W1 差 `-0.0085`、W2 差 `-0.0245`。
  - `run3` 独有命中：N-1.1.1, N-1.2.2, N-5, N-5.1；`run7` 独有命中：N-3.1, N-3.2, N-3.2.4, N-4。
  - 解释：这些命中使 run7 获益，尤其 N-4 的 W1 权重为 5、N-3.2.4 的 W2 权重为 4.837；因此 W2 下差距比 W1 更大。所有差异可从两个 JSON 按公式复算。
- **补充：run1 vs run2**：W0 打平；W1 差 `+0.0251`，W2 差 `+0.0022`。run1 独有 `N-3.1, N-3.2, N-3.2.4, N-4`；run2 独有 `N-1.1.4, N-1.2, N-1.2.2, N-3.1.2`。

## 6. W1×W2 组合权重探索（surprisal≠importance 的修复尝试）

W2 单独使用时 top-5 仅 2/5 带 gold 标记（§4），提示 surprisal 高 ≠ importance 高。试两种组合：

- **W3 = w1 × w2**（重要性打底 × surprisal 微调）
- **W4 = w1 + w2**（加法融合）

### 构念效度复检（top-5 vs gold 标记，门槛 ≥3）

| 权重方案 | top-5 带 gold 标记数 | 判定 |
|---|---:|---|
| W1 (importance) | 2/5 | ✗ 未达门槛 |
| W2 (surprisal) | 2/5 | ✗ 未达门槛 |
| **W3 (w1×w2)** | **3/5** | **✓ 达到门槛** |
| W4 (w1+w2) | 2/5 | ✗ 未达门槛 |

W3 top-5：N-3.2.2(★2倍分歧)、N-3.2.4(无)、N-2.1(■瓶颈#1)、N-2(F-B订正)、N-1.1.3(无)。

### 解读

W3 是唯一过门槛的方案，但 3/5 只是"刚过线"，且 N-3.2.4 和 N-1.1.3 两个无标记节点挤进了 top-5——说明组合权重改善了但不解决 surprisal≠importance 的根本问题。根因是 p̃ 估计本身来自同一 judge 模型（自我偏袒），独立 judge 盲测（未完成工作 #3）才是决定性检验。在拿到独立 judge 结果前，W3 只能视为"候选改进方向"，不能写入正式 rubric。

## 结论

在这 8 个真实 C0 run 上，三套权重的排序总体高度相关，但 W0–W2 相关性最低，且成对平分的 run 会因高权重节点覆盖而重新排序。该小样本支持“权重会影响 O3 排序”，尚不支持“surprisal 权重更符合人类重要性”：top-5 与 gold 的专家标记重合未达到预设门槛。W1×W2 乘法组合（§6）是唯一过门槛的方案（3/5），但刚过线且根因（judge 自我偏袒）未除，需独立 judge 盲测确认后才能写入正式 rubric。gold 节点数矛盾已修正（35→31）。
