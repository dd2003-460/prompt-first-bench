## 4. 负面结果声明

1. **W0 构念效度指标退化**：flat 权重下所有节点权重相等，global top5_gold 和 goldmeanrank 均无意义（完全平局）。W0 作为 baseline 的价值在于 run 排序（O3 分数），不在于节点级构念效度。这不是"计算错误"而是"指标不适用"。

2. **W1 构念效度高度 tie-sensitive**：goldmeanrank 范围 [9.60, 13.40] 意味着"W1 构念效度最差"这一结论部分依赖于 tie-breaking 规则。在 id tie-break 下 W1=11.2（最差），但在最优 tie-break 下可达 9.6（接近 W2 的 9.2）。更准确的表述是"W1 的构念效度评估对 tie-breaking 规则敏感，不宜单独作为定稿依据"。

3. **new W3 top5_gold tie-sensitive**：当前报告的 1/5 依赖于 id tie-break（N-1 < N-2 alphabetically）。若采用其他 tie-break 规则，值可能为 2/5。"new W3 否决构念效度"的结论需要带"在 id tie-break 下"的限定语，或者改用 tie-robust 指标（goldmeanrank 范围 [8.40, 8.60] 更窄）。

4. **Per-run 口径下无 run 过线**：所有 scheme×judge 组合的 per-run top5_gold max=2，无一达 ≥3。这与 global 口径（orig W3=3/5）形成对比，说明"过线"与否强烈依赖于聚合口径（global vs per-run）。

5. **语义级重判不可机判**：arena 语义重判（P5）和 O1 深度分的"有实质内容"判据（finding #21）本质上是语义判断，无法写成 assert 脚本。这类判定只能靠多 judge 交叉或人工复核，不属于机判化候选。

6. **κ 值计算本身不可机判**：κ 的计算需要两个 judge 的独立打分，而独立打分的执行质量（是否真的独立、是否真的换位）无法通过断言脚本验证。断言脚本只能验证"回执文件存在且格式正确"，不能验证"打分过程合规"。
