## 0. 根节点

**C = 每验收通过任务的**风险调整**成本（美元/任务）**

```
C = (capex/H + P_kW×elec + capex·r_risk/8760) / (3600/T × S × p)

r_risk = 年化故障/换件率（非标件、退役件不为 0）
H      = 摊销小时（受厂商支持期限约束，不一定等于 3 年）
```

`r_risk` 与 `H` 是 V0 口径里没有的两项，但在这个候选集里它们是**决定性的**：一块 $260 的 P40 之所以便宜，恰恰因为它的 `H` 只剩 1.7 年（驱动 2028 年中停更）且 `r_risk` 高；一块 $3,900 的改装 4090 之所以便宜，是因为它把 `r_risk` 转移给了你。**不把这两项算进去，等于默认所有硬件都能无故障用满 3 年**，那只对零售有保卡成立。

题面未给、本 run 声明：前缀 60.5K / 新输入 3.5K / 输出 0.5K；W(Q4_K_M)=17.1 GB；KV(q8_0@64K)=2.0 GB/流；电价 40.49 円/kWh ÷ 150 = $0.270/kWh；p=0.90。

### 1.1 分区推导

画像里三条约束各自指向一个渠道属性：②成本约束 → 「一次性 capex 还是持续 opex」；③可用性约束 → 「有没有保修、坏了自己能不能修」；①负载特征 → 「显存与带宽的绝对下限」（用于判断某个渠道里有没有合格件）。据此得到四个分区：

| 分区 | 渠道属性 | 风险结构 | 默认先验？ |
|---|---|---|---|
| **a 零售新卡** | 一手零售，3 年保修 | r=0，H=3 年 | ✅ 默认 |

### 1.6 非默认候选的三问（逐条必答）

**c1 · 改装 RTX 4090 48GB**
- ① **生态**：CUDA 完整、驱动走标准 GeForce 分支，llama.cpp/vLLM 直接可跑——这是它唯一比"换架构"友好的地方。但**固件非官方**，部分用户报告较原版慢（hardware-corner 2025 提到可能存在 BIOS 限制）。
- ② **经济**：$3,750–4,100，比同性能的 L40S（$7,000–9,000）便宜一半，比 A100 80G 便宜 40%。**它是本表唯一「$4,000 档拿到 48 GB + CUDA + 千 GB/s」的东西**。
- ③ **实测瓶颈**：**不是算力，是可靠性**。改装服务商自报 ~2% 失效率，行业报道与 Reddit 讨论普遍质疑长期 24×7 稳定性（改焊颗粒、散热、PCB 改动）。本 run 把它折成 `r_risk = 2%/年` 进成本式；若实际是 8%/年，它的成本从 1.549m 涨到 2.35m，直接跌出前三。

**c2 · 双改装 4090 48GB（96 GB）**
- ① 生态同上；多卡还多一层 PCIe 拆分与 BIOS 配置的实操风险。
- ② $7,800–8,200 拿 96 GB，与 RTX PRO 6000（$8,565 发布价）几乎同价 —— **但后者有保修**。这是本题最尖锐的一处性价比对峙。
- ③ 瓶颈：**风险叠加**。两张独立改装件的联合故障率 ≈ 4%/年，且**坏一张就整套停摆**（TP=2 不能降级运行）。本 run 用 `r_risk=4%/年`。

**d1 · 云 GPU 租用**
- ① 生态最佳（同一批 CUDA 卡，不用运维）。
- ② $0.22–0.50/h，无 capex。按单流 34 t/s、8 并发折算 ≈ 340 任务/h → **$1.03m/任务 → 1.14m/验收**，与「买一张 3090」（1.175m）基本打平。
- ③ 瓶颈：**数据与控制权，不是性能**。且题面明确要求「本地跑」。本 run 只把它当**成本基准线**，不当候选。

**d2 · 既有工作站加一张卡**
- ① 生态无差异，但受限于既有主板 PCIe 通道、电源余量、机箱长度（3090 是三槽卡）。
- ② 增量 $1,200–1,600（省 $700–1,000 平台费），是**全表最低的入场成本**。
- ③ 瓶颈：**上限锁死**。加一张 24 GB 卡后显存闸仍是 2（S=1），与「从零买 1×3090」性能完全一样，只是便宜 $800。它不改变结论，只改变「已经有机器的你」的边际决策。

## 4. 瓶颈

**BOTTLENECK: N-2.2.2 速度闸（⌊单流 tok/s ÷ 20⌋）**

打分：N-2.2 = 0.53×0.65×3.0 = **1.03**；N-1.1 = 0.36×0.58×4.5 = 0.94；N-2.1 = 0.53×0.35×7.4 = 1.37；N-1.3 = 0.36×0.16×∞（但绝对额只有 $0.01–0.04/h，离群）。

按裸分，**T（单任务耗时）反而最高（1.37）**——这在本候选集里是对的，因为 P40 的 prefill 只有 90 t/s，T 被拉到 66 秒。但 P40 全军覆没的方式不是「成本高」，而是「单流过不了 20 t/s」。把「不可行」的候选剔掉后再看，剩下的合格者里 T 的分布是 8.9–24.4 s（BOUND 2.7×），乘积降到 0.50，**于是速度闸重新成为第一**。

所以我把瓶颈判在速度闸，理由有两条：

1. **它决定了「谁能参赛」，而不是「谁更快」**。本候选集 12 个里，1×P40 直接被它判死，2×P40 擦线，其余 8 个全都因为它的取值（1 或 2 或 3）而分成三档。**这是一条离散的、不可用钱绕过的门槛**：A6000（$4,100、48 GB）与 2×3090（$3,900、48 GB）显存完全一样，价格几乎一样，唯一差别就是前者单流 26.9（S=1）、后者 59.5（S=2）——**成本因此差 1.8×**。钱在这里买不到速度闸的通过权，只有带宽能。
2. **它是唯一「加钱也几乎买不到」的因子**。想提 S，要么加带宽（加卡，capex 线性涨），要么降 KV（软件工作，几乎免费）。而 S 每 +1，成本降 30–50%。**性价比最高的动作不是买东西，是把 KV 从 q8 压到 q4**（2.0 → 1.1 GB/流，24 GB 卡的显存闸从 2 变 5；虽然本例里速度闸仍然先触发，但在 48 GB 卡上会真正确实生效）。

**为什么不是「风险折价」**：它的 BOUND 数学上是无穷（0 → 4%），但绝对额只有 $0.01–0.04/h，占 c_hour 的 3–9%。它是**次要修正项**，不是瓶颈。

## 7. 矛盾清单（D2：逐条声明边界类型）

**X1 · Tesla P40 值不值：$239 的 24 GB vs 「买它就是浪费钱」**
- 源 A：gpudojo（2026-08）「$9.96/GB，最好的 24 GB 性价比」；runaihome（2026-08）「$260 买 24 GB，无出其右」。
- 源 B：openclawdc（2026-08）「只适合折腾党，日常主力应买 3090」；同文给实测：7B Q4 40–45 t/s、14B Q4 约 16 t/s。
- **更可信**：两者不冲突——A 说的是「$/GB」，B 说的是「$/(tok/s)」。**本题用后者**（题面问的是每任务成本，不是每 GB 成本），因此采信 B。P40 在 27B Q4 上 66 s/任务，是全表最慢。
- **边界类型：① 数学/理论边界** —— 到此为止因为 `tok/s ≤ 347 GB/s ÷ 17.1 GB = 20.3`，这是 roofline 不等式，软件优化不可突破；要过 20 tok/s 必须 ≥2 张，而 TP 折扣又把收益吃掉一半。

**X2 · 改装 4090 48GB：$3,400–4,100 的性价比 vs 「2% 失效率、无保、非官方固件」**
- 源 A：millionminer（2026-05）「$3,750–4,100，27B FP16 已验证，约 2% 失效率」；tweaktown「中国 $3,400 含一体水冷」；Reddit（2026-07）「eBay $3,500」。
- 源 B：hardware-corner（2025）「部分用户报告比原版慢，可能有 BIOS 限制」；acczio/Reddit 讨论「长期 24×7 稳定性存疑」。
- **更可信**：价格采信 A（多源、含渠道）；可靠性采信 B 的**方向**（即 r_risk 不为 0），但具体数值无人给，只能用 A 的 2% 作下限。
- **边界类型：③ 信息边界** —— 缺 24×7 长跑失效率。`research_required: 改装卡在 64K 常驻负载下 30 天连续运行的故障率；获取路径 = 买 3 张做 30 天烤机，或找改装商的 RMA 统计。`

## 9. 交付

- **最优：1×A100 80GB（二手 $5,000–6,500），0.370×10⁻³ $/验收任务**；第二是**双改装 4090 48GB（0.600m）**，第三 RTX PRO 6000（0.874m）。
- **D1 按采购口径切分区的真实收益**：它把一个 V0 根本不会考虑的候选（改装件）推到了第二名，同时暴露了一个反直觉事实——**$9.96/GB 的 Tesla P40 是全表最贵的方案**（3.9m，因为它慢到 prefill 就吃掉 34 秒）。
- **风险调整是本 run 相对 V0 唯一新增的成本项**，也是唯一能翻转前两名的参数：改装件 `r_risk` 从 2% 升到 8%，冠军立即易主为 RTX PRO 6000。**当候选集里出现非标件时，「可靠性」从软性描述变成了硬数字。**
- **该先测的三件事**：①改装件 30 天烤机失效率；②p 通过率；③A100 撑 3 条 64K 流的显存水位。
- **一句话**：本题的答案在「$4,000–6,500 这个档位里，谁能同时给出 ≥2 条 20 tok/s 的流」——A100 80G 靠 80 GB 显存与 2 TB/s 带宽同时满足；改装 4090-48GB 用一半的钱做到了，代价是把可靠性风险从 0 挪到了 2–8%/年。
