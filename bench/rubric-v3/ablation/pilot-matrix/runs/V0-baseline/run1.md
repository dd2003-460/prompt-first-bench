## 0. 根节点与口径先定死

**根节点 N-1：每「验收通过」任务的成本 C（美元/任务）**

选它不选「哪块卡最好」，因为题面问的是「每完成一个任务的成本最低」，硬件只是决策变量。
一次任务可能做错重做，所以分母要是**验收通过的任务数**，不是尝试数：

```
C = c_hour / (Q_attempt × p)        c_hour = 每小时持有成本（资本摊销 + 电费）
                                     Q_attempt = 每小时尝试任务数 = 3600/T × S
                                     T = 单任务耗时（prefill + decode）
                                     S = 并发流数（受 ≥20 tok/s/流 与显存双重限制）
                                     p = 一次通过率（<1，做错重做）
```

题面**没有**给缓存命中比、没有给候选清单、没有给精度。这几处必须自己声明假设并做敏感性——V0 题面缺 D1/D2 段，这是它和 V1 的结构差别，我在这里显式补上：

- 假设 A1（缓存比）：64K 里 60K 是长期不变的前缀（可缓存复用），3.5K 是本任务新输入，0.5K 是输出。→ prefill 只需算 3.5K，decode 只需算 0.5K。
- 假设 A2（精度）：主口径 Q4_K_M（17.1 GB），并列对照 Q8_0（29 GB）。
- 假设 A3（摊销）：3 年 24×7 = 26,280 h 满摊；若只在上班时段用（8h/天），c_hour 的资本项要 ×3，见 §4 敏感性。
- 假设 A4（电价）：机器在东京，按东京电力 従量電灯B 第 3 档 40.49 円/kWh（含税），150 円/USD → **0.270 USD/kWh**。这个值比常见「$0.10/kWh」贵 2.7×，会直接改写瓶颈结论（见 §2）。

## 2. 瓶颈

**BOTTLENECK: N-1.2.2 并发流数 S**

理由（Amdahl 判据 SHARE × BOUND）：

- N-1.1.2 电费：0.42 × 0.64 × 2.6 = **0.70**
- N-1.1.1 资本摊销：0.42 × 0.36 × 7.2 = **1.09**（但 7.2× 的 BOUND 里，8,000 美元的 A100 高价位是离群值；在「可行候选」内实际只有 2.4×）
- N-1.2.2 并发流数：0.48 × 0.66 × 3.0 = **0.95**
- N-1.2.1 单任务耗时：0.48 × 0.34 × 1.6 = 0.26
- N-1.3 通过率：0.10 × 1.18 = 0.12

按裸数字，资本摊销（1.09）略高于并发流数（0.95）。但**这是本 run 最关键的一次判断**：资本摊销的高 BOUND 有 87% 来自「A100 贵 8 倍」，而 A100 之所以贵还能入选，恰恰是因为它能把 S 做到 3——同一个因子被数了两遍。剥掉这层重复计算后，真正支配结论的是 **S（并发流数）**：

1. 单流 20 tok/s 门槛在 4 张卡上**单流全部达标**（26.2–38.4），所以「卡够不够快」根本不是问题；
2. 但 decode 是带宽共享型：批处理几乎不提升总吞吐（权重每步只读一遍，S 条流分摊），所以 **S_max ≈ ⌊总吞吐 / 20⌋**——20 tok/s 这条硬约束直接变成了「一台机器能塞几条流」的上限，而 S 又是 $/h 的分母；
3. 实测把这条推到极端：5090 有 1,792 GB/s（理论比 3090 快 1.9×）、32 GB 显存（显存闸能放 2 条流），但 64K 下单流只有 26.2 tok/s，**S 只能取 1**，于是它比 3090 贵 2.1×——带宽账面最高的一张卡，在这个任务画像下最差。
4. 反过来，2×3090 的 S 是 3 而不是 1，同样两张卡的成本只涨 1.6×，$/任务直接降到 0.85m——**结论对 S 的敏感度远高于对卡价、电价的敏感度**（§4 敏感性表：S 从 3→1，C 涨 2.4×；卡价 ±30%，C 只动 ±11%）。

所以瓶颈写 N-1.2.2，并指明它由两个更底层的量共同决定：**η 有效带宽系数**（决定带宽闸）与 **KV_per_stream**（决定显存闸）。这两者都不是「买更贵的卡」能解决的，是软件栈（量化 kernel、KV 量化、PagedAttention 块大小）问题。

**停止判定**：N-2.3（家用回路功率）不设独立节点——按 350–1,150 W 全部落在 1,500 W 以内，判定为恒真约束，不入树；若上 4 卡 3090（1,400 W+）则逼近上限，需单列。

## 7. 一句话交付

在 Q4_K_M + 64K + ≥20 tok/s/流 的画像下，**$/验收任务的前四名挤在 25% 区间内，真正的分水岭是「一台机器能同时塞几条流」而不是买哪张卡**：把 S 从 1 抬到 3（2×3090 或 A100 80G）能把成本砍到 0.89–0.94m；账面带宽最高的 5090 因为 64K 下实测单流只有 26.2 t/s，S 被迫锁在 1，反而最贵（2.19m）。东京第 3 档电价 0.270 USD/kWh 让电费占到 c_hour 的 64%，是第一顺位的连续敏感项，但它不翻排序；翻排序的只有 S 这个整数跳变。
