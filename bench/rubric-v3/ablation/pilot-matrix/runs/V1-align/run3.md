## 0. 根节点

**C = 每完成一个「验收通过」任务的成本（USD/任务）**

题面把模型规模（27B）、上下文（64K）、单流下限（20 tok/s）都钉死了，**唯一没钉死的是权重精度**——题面明说「不指定候选硬件列表和权重精度，由 subagent 自行调研」。而 27B 在四个精度档下分别是 **54 / 28 / 17.1 / 13.2 GiB**，这直接把候选硬件的**显存介质**变成了决定项：能装下 54 GiB 的只有 HBM 服务器卡和 LPDDR 统一内存；能装下 17.1 GiB 的可以是任何 GDDR 卡。

但真正让「介质」成为主轴的不是容量，是**带宽**。因为本任务的 decode 每生成 1 个 token 要把 `权重 + 64K KV` 完整读一遍：

```
每 token 读量 = W(精度档) + 5.0 GiB(KV)        ← 22.1 GiB（Q4 口径）
单流上限 = 介质带宽 ÷ 22.1 GiB
跨 20 tok/s 需 442 GB/s · 跨 40 需 884 · 跨 60 需 1,326 · 跨 80 需 1,768
```

**这四条线恰好把四种显存介质分在了不同的档位上**：LPDDR5X（215–1,200）大多在 442 以下或勉强过第一档；GDDR6/6X（347–1,008）过第一档、个别过第二档；GDDR7（1,792）过第三档；HBM（1,555–3,350）过第三到第五档。这就是本 run 选「按显存介质切」的理由——**它不是按卡型分类，而是按「每 token 能读多快」这个物理量分类**。

### 0.1 统一口径

| 量 | 取值 |
|---|---|
| 权重 W（27B，Q4_K_M 基准档） | 17.1 GiB |
| 单会话 64K KV（fp8） | 5.0 GiB（80 KB/token） |
| CUDA graph/激活 | 1.5 GiB |
| `slots` | ⌊(VRAM − 18.6)/5.0⌋ |
| `S` | min(slots, ⌊单流/20⌋) |
| `T` | 3500/prefill + 500/单流（前缀命中） |
| `C` | (capex/26280 + P_kW×0.270) ÷ (3600/T × S × 0.90) |
| p | 0.90（Q4_K_M 基准；精度对 p 的影响见 §7 与 X3） |

## 1. D1 · 候选集四分区

### 1.1 分区推导依据

按**显存物理介质**四切。这一刀之所以合法，是因为题面的性能约束（20 tok/s/流）经 `带宽 ÷ 22.1 GiB` 换算后，**恰好是按介质分层而不是按容量分层**：

| 分区 | 介质 | 带宽范围 | 能跨到第几档（20/40/60/80） | 归属逻辑 |
|---|---|---|---|---|
| **a GDDR6/6X（含 GDDR5 遗留）** | 分立 GDDR，128–384 bit | 347–1,008 GB/s | 第 1 档为主，个别第 2 档 | 2016–2022 世代的主力 |
| **b GDDR7** | 分立 GDDR7，512 bit | 1,792 GB/s | 第 3 档 | 2025 起的消费/工作站旗舰 |
| **c HBM2/HBM2e/HBM3** | 堆叠 HBM，4096+ bit | 1,555–3,350 GB/s | 第 3–5 档 | 数据中心卡 |
| **d LPDDR5X 统一内存** | SoC 共享池 | 215–1,200 GB/s | 第 0–2 档 | 整机 SoC（Apple / GB10 / Strix） |

**互斥**：一个 SKU 只有一种显存介质（R9700 是 GDDR6 → a；M5 Ultra 是 LPDDR5X → d）。**穷尽**：任何加速器的显存必属这四类之一（无其他量产介质）。✅

**与前两次分区的关系**：a/b/c/d 不再按「卡的类型」或「买法」分，而是按**介质本身的物理带宽上限**分——同一分区里的卡可以价格差 30 倍（P40 $260 vs L40S $7,500），这正是这一刀想要暴露的：**同介质内部的差异是价格，跨介质的差异是能力**。

## 5. 瓶颈

**BOTTLENECK: N-2.2.2「速度闸」——具体是 `⌊介质带宽 ÷ 442 GB/s⌋` 这个由显存介质直接决定的整数。**

打分：N-2.2 = 0.54×0.81×5.0 = **2.19**；N-1.1 = 0.36×0.66×107.7 = **25.6**。裸分 N-1.1 压倒性，但它 107.7× 的区间几乎全部来自 **H100（$28,000）与 P40（$260）这两个极端点**——而这两个点一个被价格拖死（0.571m 只排第 4）、一个被带宽判死（0.077/h 却做不出合格任务）。把「不合格者」和「极端贵者」都剔除后，capex 收敛到 $1,399–7,500（BOUND 5.4），乘积 1.28，低于 2.19。

三条结构论据：

1. **S 是台阶函数，而台阶由介质决定**：`S = ⌊带宽/442⌋`。GDDR5 卡在 0（347 < 442），GDDR6/6X 卡在 1（768–1,008），GDDR7 卡在 2–3（1,792），HBM 在 2–5（1,555–3,350），LPDDR5X 分裂成 0（215–273）和 2（1,200）。**同一个「LPDDR5X」标签下，Strix Halo（0）与 M5 Ultra（2）差了整整两档**——这说明介质名称不决定成败，**介质内部堆了多少带宽才决定**。
2. **它解释了「贵卡为什么不一定输」**：H100 单价是 3090 的 20 倍，但带宽是 3.8 倍，S 从 1 到 4，$/任务只贵 1.5 倍（0.571m vs 1.039m）。**在台阶结构里，跨档带来的收益可以吃掉 10 倍的价格差。**
3. **它也解释了「便宜卡为什么不一定赢」**：P40 的 $/h 是全表最低（0.077），但因为 347 GB/s 跨不过第一档，**它连一个合格任务的分子都进不去**。这是本 run 最干净的反例：**成本的分母（S）比分子（$/h）更能决定结果。**

**瓶颈的下一层**：介质的成本效率是**倒挂**的。每 $1 买到的带宽：P40 1,367 / 3090 685 / 5090 612 / A100-40 549 / A6000 303 / A100-80 305 / M5U 224 / L40S 118 / PRO 115 / H100 73 / Spark 60。**排序几乎与「能否用」完全相反**——最便宜的带宽最没用，最贵的带宽最有用。**这是本题最重要的一条经济学观察：带宽的边际价值是阶跃的，所以按 $/带宽 排序会系统性地推荐错的卡。**

**五条要点**

1. **HBM 组包揽前三（0.307 / 0.320 / 0.571m）**。不是因为它们快，而是因为它们**同时具备「跨多档的带宽」与「够用的 slots」**——这是介质决定的，不是价格决定的。
2. **A100 40GB 只比 80GB 贵 4% 的成本（0.320 vs 0.307），售价却便宜 55%**。80 GB 多出来的 8 个 slots **一个都用不上**（速度闸只给 3）。**在本题里，A100 40GB 是 80GB 的 96% 性能、45% 价格**——这是全表最值得记的一条。

**OPEN**
- **O1「能不能靠 FP8 把 A100 40G 的 S 提到 3？」** → **① 数学/理论边界**：FP8 权重 28 GiB + KV 5 + 开销 1.5 = 34.5 < 40，装得下 1 个会话；但 FP8 **不改变带宽**，S 仍被 `1,555/442 = 2` 卡住。到此为止因为 decode 是带宽函数而非精度函数。
- **O2「HBM 的带宽能不能租？」** → **② 实操边界**：云租 A100 $1.20–1.85/h，本任务每任务成本 ≈ 0.6–0.9m，比自建贵 2–3 倍（未计入本文，因为题面要求「本地」）。到此为止因为 Z = 长期租约/预留实例合同。
- **O3「LPDDR5X 能不能堆到 442 GB/s 以上又不贵？」** → **① 数学/理论边界**：LPDDR5X 单颗 8533 MT/s × 256 bit ≈ 273 GB/s，要 442 需 384 bit 以上或双通道堆叠；Spark 已经是 273。到此为止因为**封装位宽是硬约束**（要更宽就得更大的 SoC 封装，成本跳到 HBM 区间）。
- **O4「把 27B 换成 MoE 能不能绕开带宽墙？」** → **② 实操边界**：题面指定 27B 规模，换 MoE 是换模型不是换硬件；且 MoE 激活参数少，带宽需求降但显存需求升。到此为止因为超出选型范围（Z = 质量评估）。

## 10. 交付

- **最优：A100 80GB 二手，$0.307×10⁻³/验收任务**；次优 **A100 40GB（0.320m，价格只有 45%）**、RTX 5090（0.512m）、H100 PCIe（0.571m）。
- **本 run 的判据**：**显存介质决定台阶，台阶决定成本**。`S = min(slots, ⌊带宽/442⌋)`，而 ⌊带宽/442⌋ 完全由介质决定：GDDR5 → 0 档（不合格）、GDDR6/6X → 1 档、GDDR7 → 2–3 档、HBM → 2–5 档、LPDDR5X → 分裂在 0 档与 2 档之间。
- **最重要的经济学观察**：**每美元带宽的排序与可用性几乎完全相反**（P40 1,367 → H100 73）。因为带宽的价值是**阶跃的**，按 $/带宽 选卡会系统性地推荐「便宜但跨不过门槛」的方案。**买带宽要买「够跨档」的，不是「最便宜的」。**
- **最实用的一条**：**A100 40GB 是本画像下的甜点**——它比 80GB 便宜 55%，性能只差 4%，因为 80GB 多出来的 8 个 slots 在速度闸（3）面前全是死的。**如果你确定只跑 27B/64K 这一类负载，40GB 版是理性选择。**
- **三个反直觉**：① $3,000 的 5090 与 $28,000 的 H100 在 $/任务上只差 10%；② 同为 1,792 GB/s 的两张 GDDR7 卡，$/任务差 35%（过供）；③ 「统一内存」在 2026 年的带宽跨度是 5.6 倍（215–1,200），这个词已经不代表任何性能水平。
- **该先测的三件事**：① 精度档 → 通过率（决定该买 40GB 还是 80GB）；② 各机 64K 深度单流（决定速度闸）；③ H100 二手实价（决定它第 2 还是第 4）。
- **一句话**：这道题真正的自变量是**显存介质的带宽**，因为 20 tok/s 的硬约束换算下来就是「每 token 能读 22 GiB 的速度」——**HBM 与 GDDR7 能跨档，GDDR6 只能守一档，GDDR5 与低端 LPDDR5X 连门都进不去**。
