## 3. D1/D2 主效应与 sham 对照

设计说明：7 变体是 D1×D2 的**非正交**组合（无「有 D1+无 D2 且非 sham」之外的均衡重复），主效应为边际均值差，只能作方向性证据。

### D1（候选集构造规则）
- 有规则组 (B,C,E,G) 均值 34.79 vs 无规则组 (A,D) 30.92 → 边际 Δ = +3.88（精确值 +3.875）
- **sham 对照 (F，D1 位置放等长中性占位块) = 34.67** → 占位块自身效应（vs 无规则组）= +3.75
- **净 D1 效应（扣占位块，以 F 为锚点）= B−F = +2.67 —— 在噪声带（pooled SD ±3.96）内，不显著**〔RV3G9 勘误 r183：原稿写 ≈+0.12，系「有规则组均值(B,C,E,G)=34.79 − F=34.67」的组均值口径——B 本身是组内成员，该口径系统性压扁净效应；干净配对值 B−F=+2.67 才是净效应估计。两种口径都不显著，定性结论不变〕

解读：加一段"怎么构造候选集"的文字本身没有可测增益；真正起作用的是**执行后果**——见 §4 的 O1 通道。V-sham(F) 的高分说明：只要答卷实际挖出了低先验候选（O1 拿分），prompt 里有没有那段规则文字无关紧要。但注意 F 组 SD=2.88（双判 pool 6 值口径；merged 3 值口径为 3.21）〔RV3G9 勘误 r183：标注口径〕，占位块条件下执行一致性更差。

### D2（边界类型声明）
- 有声明组 (B,C,D,F) 均值 35.83 vs 无声明组 (A,E,G) 30.78 → 边际 Δ = **+5.06（精确值 +5.056），超出噪声带，方向稳健**
- 机制定位在 P4 维度：P4-E2_boundary_type（边界类型声明条目）在有 D2 的变体中全拿满分 2×6/12，无 D2 的 A/E/G 三组全为 0；P4 总分均值：有 D2 组 6.0/6，无 D2 组 **3.11/6**（E/G 靠 P4-E1 终止注记和 P4-E3 可行动路径拿到部分分）〔RV3G9 勘误 r183 澄清：此处 3.11/6 是 P4 **整维**均值（含 E1/E3 部分分），非 P4-E2 条目值——P4-E2 本身是严格二分（有 D2 组 12/12 满分 vs 无 D2 组 0/12）。机制定位在 P4-E2 条目成立，但引用时应区分「条目值」与「维度均值」两种口径〕
- D2 的 sham 对照 (G，D2 位置占位块) = 33.17，介于两组之间且 P4 仍只拿到 4.0 → **占位块部分替代了声明的功能**（等长文本让模型"意识到这里该写点什么"），但没补满。D2 效应比 D1 更"真"，但 sham 污染使其上限估计偏保守。

## 4. O1 通道：增益的实际传导路径

O1-E3_depth_eligible（低先验候选深度达标：1–3 个低先验候选→2 分）是唯一与 D1 指令直接挂钩的计分条目。实测：

- V0 组 O1 仅 1.67/6（候选集基本全是默认先验：RTX 3090/A100/5090/M5 Ultra 这类 14+/21 高频项）
- 所有含 D1 或含 D2 的变体 O1 跳到 4.0–6.0/6〔RV3G9 勘误 r183：原写 3.67–6.0，下界应为 C 组均值 4.0；另 F 组 per-run 含一个 0/6 outlier（run3），占位块条件下执行方差大〕
- **V-sham(F) 也拿到均值 3.67/6**（per-run：5/6、6/6、0/6）〔RV3G9 勘误 r183：原句未标 per-run，易误读为稳定高分；实际 run3 双判一致给 0/6，占位块条件下执行不稳定〕—— 对比基准 V0 均值 1.67/6（per-run：0/0/5），占位块条件下模型仍自发挖出部分低先验候选，只是不稳定（per-run SD 大）

结论链：**D1 规则 → 答卷实际列出更多低先验候选 → O1 得分 → 总分**。规则文字本身（sham 对照）贡献 ≈0；效应全部经由行为改变传导。这与 pilot 9-run 的观察一致（pilot 中 D1 效应同样集中在 O1 通道）。

## 6. 与 pilot 的对照

pilot（9 run = 3 变体 × 3）排序：V1-full > V1-align > V0-baseline（详见 kappa-results-corrected.json）。正式矩阵（21 run = 7 变体 × 3）扩展后：

- **头部关系保持**：V1-full(37.33) > V1-align(35.17)，且 V2-nocoverage(36.17) 插入两者之间——pilot 未测的"无候选集规则但有边界声明"变体表现意外地强，说明 **D2 单独就能拿走大部分增益**（§3）。
- **V0 垫底关系保持**：25.67，与第二名差距 7.5 分（≈1.9× pooled SD），pilot 中同向。
- 新增信息：D1 净效应被 sham 对照打掉（≈0），pilot 阶段因无 sham 变体无法区分"规则文字效应"与"行为改变效应"——这是正式矩阵 7 变体设计相对 pilot 的核心增量价值。

## 7. 局限与后续

1. **同判官限定**（§开头限定语）：所有 Δ 是同一 agent 双口径下的模式证据。解锁真实 IRR 需 G1b family_check（非 Qwen 家族 judge 重跑 21 份）。
2. **非正交设计**：D1/D2 主效应是边际均值差，无交互项的干净估计；若要交互效应需补「有 D1+无 D2+非 sham」的重复（当前 E 组承担此格但 n=3）。
3. **sham 污染**：等长占位块本身携带 +3.75（D1 位置）/部分功能替代（D2 位置）的效应，净效应估计依赖 sham 锚点质量；F 组 SD=2.88 提示占位块条件执行不稳定。
4. **O3 天花板**：5 条 0 命中 claim 压低了所有变体的 O3 得分，若 gold 树修订（prefill 路径二选一），O3 维度需重算。
5. **盲评泄漏已修复**（r180b）：任务书内嵌映射表已移除；本批评分由两裁判忽略该表完成，但严格意义上盲态已被破坏过一次，后续批次须用修复后的任务书模板。


## 8. 预注册统计检验执行（RV3G9 · r183）

按 DRAFT §3.3 (R-11) 预注册方案执行：4 主对比 × 7 维 = 28 项配对置换检验（10⁴ sign-flips）+ Holm-Bonferroni 全族校正；敏感性 Wilcoxon（多组 |d|=0 不适用）。**结果：0/28 维度检验、0/4 复合总分检验 Holm 后显著**（最小原始 p=0.2528——n=3 下置换检验分辨率上限，结构性 underpowered，非效应不存在）。

效应量（judge-merged pairs, dz）：V1-full vs V0：outcome Δ=+0.360 (dz=1.55) / process Δ=+0.343 (dz=10.68) / total38 Δ=+11.67 (dz=2.86)；V1-full vs V-sham：total38 Δ=+2.67 (dz=0.92)。MDE 反推要求 n≥8（总分对比）至 n≥139（O1 单维），本轮 n=3 只够方向性证据。

机制复核：P4-E2 双判一致二分（有 D2 组 B/C/D/F 全 2/2，无 D2 组 A/E/G 全 0/2）——D2 机制定位成立。O1 通道为最大单维增益源（Δ(B-A)=+4.33/6）。

完整数字与勘误记录：`formal-stats-results.json`（同目录）。

EOF
