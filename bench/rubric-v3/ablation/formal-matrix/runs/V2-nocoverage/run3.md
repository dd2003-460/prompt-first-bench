## 0. 根节点

**C = 每完成一个验收通过任务的成本 [USD/任务]**

本轮换一个切法：不讲「哪张卡」，先算清题面对硬件提了**两个互不相干的硬指标**，再把候选放进一张二维表。

```
C = c_hour ÷ (3600 ÷ T × S × p)
```

口径：W=17.1 GB；KV=5.0 GiB@64K；开销 1.5 GiB；H=26,280 h；p=0.90；电价 0.270 USD/kWh。

**两条硬指标**

| 指标 | 由来 | 门槛 |
|---|---|---|
| **装得下** | 27B Q4 (17.1) + 64K KV (5.0) + 开销 (1.5) = **18.6 GiB 底盘** | VRAM ≥ 18.6；每多 1 个并发流再要 5.0 |
| **跑得快** | 每 token 读 ~22.1 GiB → 20 t/s 需 **442 GB/s**；受实现效率打折，实需 ~550–880 | 带宽 ≥ 442（名义） |

**这两条线就是分解树第一刀**：它们分别对应 `S` 的两个闸（容量闸 / 速度闸），且**互不替代**——一条不满足，另一条再高也没用。

```
├── B task/h                                     SHARE 0.51  BOUND 7.9x（103–1,066）
│   ├── B1 T = 3500/prefill + 500/decode         SHARE 0.17  BOUND 2.6x
│   └── B2 S = min(容量闸, 速度闸)                 SHARE 0.83  BOUND 4.0x
│       ├── B2.1 容量闸 ⌊(VRAM−18.6)/5.0⌋          区间 −1–21（← 象限 B/A）
│       └── B2.2 速度闸 ⌊decode/20⌋                区间 0–3（← 象限 C/A）
└── C p = 0.90                                   SHARE 0.10  BOUND 1.18x
```

份额：0.39+0.51+0.10 = 1.00 ✅；A1 0.62+A2 0.38 = 1.00 ✅；B1 0.17+B2 0.83 = 1.00 ✅。

**B2.1 与 B2.2 的耦合声明**：两支都进 `min`，**会改变结论**——象限 B 的机器有 5–21 个容量槽却只有 0–1 个速度档，槽位全是死的；象限 C 反过来，1 个槽配 1–2 档，槽位是硬约束。

## 4. 瓶颈

**BOTTLENECK: B2.2「速度闸」——即 `⌊decode ÷ 20⌋`。它是象限 B 全军覆没与象限 A 分层的唯一原因。**

打分：B2 = 0.51 × 0.83 × 4.0 = **1.69**；A1 = 0.39 × 0.62 × 5.6 = **1.35**。B2 更高。

四条结构论据：

1. **象限 A/B 的差别不在容量**：A6000 的 48 GB 与 A100 40G 的 40 GB 只差 8 GB，**但 768 vs 1,555 GB/s 让 S 从 2 掉到 1**，成本反过来贵 3.6 倍（1.621m vs 0.454m）。**象限 B 的 5 个候选，两个速度闸为 0、三个为 1，没有一个是 2。**
2. **象限 C 的差别不在带宽**：3090 的 936 GB/s 只比 1,555 少 40%，`S` 却从 2 掉到 1——因为 24 GB 装不下第 2 条流的 5 GiB。**容量闸在这两个卡上是真约束**，但在象限 B 上全是废闸。
3. **它是「贵卡不一定赢」的唯一机制**：5090 的 capex 是 3090 的 2.37 倍、带宽 1.91 倍，**但 26.2 t/s 让它连 1 个速度档都勉强**，成本反而贵 2.26 倍。
4. **它是 V100 生死线的唯一变量**：18.0 与 22.5 之间没有中间态（`⌊18/20⌋=0` vs `⌊22.5/20⌋=1`），**这是一条断崖**。

**瓶颈的下一层**：`⌊decode/20⌋` 的分母是「每 token 读 22.1 GiB」，而 22.1 里的 **5.0 GiB 是 KV**。**KV 占了每 token 读量的 23%**。如果能把 KV 压到 2.5 GiB（FP8 KV），每 token 读量降到 19.6，同样的带宽能多出 12.8% 的 decode——**V100 的 18.0 会变成 20.3，刚好跨过门槛**。这一条把「量化格式」从模型问题变成了硬件选型问题。

## 6. 矛盾清单

**X1 · V100 32GB 在 27B 上到底多快：98.8 / 32 / 22.4 三个数**
- 源 A：miyagadget（2026-09-10）「Qwen 3.6 at **98.8 tok/s**，1.6× Faster Than M1 Max」——但标题里写明是 **MoE 35B**。
- 源 B：aliteq（2026-07-31）「V100 SXM2 16GB + 4080，Qwen3.6-27B **Q5_K_M** 约 **32 t/s**，prompt processing 133–160 t/s」——**这是两块卡合跑，27B 权重主要在 4080 上**。
- 源 C：本 run 的带宽推算：900 ÷ 22.1 × 0.55 = **22.4 t/s**（dense 27B Q4、64K、单卡）。
- **三个数不可比，且我判断 A、B 都不适用于本题**：A 是 MoE（每 token 只读激活专家，读量远小于 22.1 GiB）；B 是混合双卡且 prompt processing 只有 133–160（说明 27B 主体在 4080 上、V100 只出了 16 GB 显存）。**采信 C 的 22.4 作为上限**，并把实测值视为 15–22 的区间。
- **边界类型：③ 信息边界** —— `research_required: V100 32GB 单卡、dense 27B Q4_K_M、64K 深度、llama.cpp 源码编译（Volta 已被预编译版移除，见源 A）；路径 = 自测 llama-bench -d 60000`。

**X2 · A100 80GB 的带宽：1,935 还是 2,039**
- 源 A：highvramhardwarewatch（2026-10-25）表格：「A100 80GB PCIe：HBM2e、**1,935 GB/s**、300 W；A100 40/80 SXM：**2,039 GB/s**、400 W」。
- 源 B：itcreations 产品页把 2,039 直接标在「A100 SXM GPU 40GB and 80GB」标题下，易被误读为通用值；theaicipher 同时列了 1,935 与 2,039 两个数。
- **更可信：A**（唯一把「PIe vs SXM」与功耗 300/400 W 对上的源）。**采信 1,935。**
- **影响**：S 不变（两者都 ≥3 档），**结论不动**——但这条错误若发生在临界卡上会直接改名次，所以必须记。
- **边界类型：③ 信息边界** —— `research_required: 目标 SKU 的 datasheet；路径 = NVIDIA 官方 product brief`。

**X3 · 「大显存能不能兑现」两派**
- 源 A：gpudojo 对 V100 32GB 的定位「32GB usable」+ miyagadget 的「131k Context on a Single Card」——**容量是卖点**。
- 源 B：本 run 的算式：V100 的 32 GB 给 2 个容量槽，但速度闸 0，**两槽全废**。
- **两者不冲突，是口径不同**：长上下文能力（装得下 131K）与并发吞吐（多条流同时跑）是两个指标。**本题约束的是后者。**
- **边界类型：① 数学/理论边界** —— `S = min(容量, 速度)`；速度闸为 0 时容量项的偏导为 0。到此为止因为这就是 `min` 的定义。

**X4 · 16 GB 卡能不能跑 27B**
- 源 A：compute-market（2026）「RTX 5080：13B–30B 参数模型的最佳性价比」——暗示能跑 27B。
- 源 B：本 run 的算式：27B Q4 权重 17.1 GB > 16 GB，**连权重都装不下**；加上 64K KV 的 18.6 GiB 底盘，差 2.6 GiB。
- **采信 B**：源 A 的「30B」是**更低量化（Q3/IQ2）或无 64K 上下文**的口径。**16 GB 在本画像下不合格。**
- **边界类型：① 数学/理论边界** —— 17.1 > 16 是硬不等式，不是调优问题。

## 8. 交付

- **最优：1×A100 80GB PCIe（$7,400 二手），0.403×10⁻³ $/验收任务**；次优 **A100 40GB（0.454m，价格 51%）**、RTX PRO 6000（0.830m）。
- **本 run 的判据**：先算清两条硬线（**18.6 GiB 底盘 / 442 GB/s**），候选就自动落进四个象限，**而同象限内几乎同名次**——A 象限包揽前五，B 象限全在 1.6m 以上，C 象限 1.1m 级，D 象限直接不合格。
- **最有价值的一条**：**V100 32GB（$975）是一条断崖**。它是本轮唯一一个「差 2 t/s 就从出局变成第 4 名」的候选——带宽 900 GB/s 除以 22.1 GiB 得 22.4 的名义上限。**如果实测 ≥20 t/s，「$975 的老卡打败 $4,149 的 5090」就是本题最反直觉的答案。**
- **第二有价值的一条**：**KV 是每 token 读量的 23%**。把 KV 从 5.0 GiB 压到 2.5 GiB，能让 V100 从 18.0 跨到 20.3——**量化格式因此从「模型问题」变成「硬件选型问题」**。
- **该先测的三件事**：①V100 单卡 27B Q4 @64K（源码编译，预编译版已弃 Volta）；②各机的 64K 深度单流；③5090 的实现效率。
- **一句话**：这道题的两个门槛只差 2 倍，**大部分候选不是「性价比差」，而是连门槛都过不了**。
