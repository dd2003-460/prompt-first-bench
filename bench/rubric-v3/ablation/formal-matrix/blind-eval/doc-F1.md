## 1. 根节点与口径

**C = 每完成一个验收通过任务的成本 [USD/任务]**

```
C = c_hour ÷ (3600 ÷ T × S × p)
c_hour = capex/H + P_kW × 0.270
S = min( ⌊(VRAM − 18.6)/5.0⌋ , ⌊decode/20⌋ )
```

W(Q4_K_M 27B)=17.1 GB；64K KV=5.0 GiB（80 KB/token）；开销 1.5 GiB；H=26,280 h；p=0.90；电价 0.270 USD/kWh（東京 40.49 円÷150）；T=3500/prefill+500/decode。

## 5. 瓶颈

**BOTTLENECK: A1「资本摊销 capex/H」——具体是**「买错档位」的代价**，而不是「买贵」的代价。**

打分：A1 = 0.42 × 0.63 × 11.5 = **3.04**；B2 = 0.48 × 0.83 × 3.0 = **1.20**；A2 = 0.42 × 0.37 × 2.8 = 0.43。

A1 的 11.5× 区间是本矩阵里最宽的一支，但它**并不能线性传导到 C**：

| capex 比 | S 比 | C 比 | 说明 |
|---|---|---|---|
| H100 / A100-80 = 3.88× | 3 / 3 = 1.0 | **2.71×** | 贵 3.88 倍，只换来 1.09 倍的产能 |
| A100-80 / 3090 = 2.96× | 3 / 1 = 3.0 | **0.31×** | 贵 2.96 倍，换来 3.0 倍产能 |
| 5090 / 3090 = 1.66× | 1 / 1 = 1.0 | **1.96×** | 贵 1.66 倍，产能一模一样 |

**A1 只有在能推动 S 上台阶时才算瓶颈；推不动时，它纯粹是浪费。** 所以真正的瓶颈是 **A1 与 B2 的「咬合」**——而 B2 是那个把 A1 变成产能的转换器。

**三条论据**：

1. **H100 是本表最贵的一台，也是「买错档位」最贵的例子**：它的带宽只比 A100 高 5%（2,039 vs 1,935），`S` 同为 3，**$/任务贵 2.71 倍**。**多付的 $21,300 换来了 1.09 倍的吞吐。**
2. **3090 的价格在 2026 年 8–10 月涨了 50–70%**（8 月 clustermelt 报 $800–1,200；10 月 gpudojo 报中位 $1,804）。**这一涨直接把它从 1.12m 推到 1.29m，让原本第 3 名的它掉到第 4 名、被 4090 反超。** 这是本 run 唯一一个「价格变动改了名次」的地方。
3. **DGX Spark 是「A1 与 B2 脱钩」的极端**：$4,699 买 128 GB，`S=0`——**capex 一分钱都没转化成产能**。

## 7. 矛盾清单

**X1 · RTX 3090 在 2026 年 8 月到 10 月之间涨了 50–70%**
- 源 A：clustermelt（2026-08-01）「$800–1,200」。
- 源 B：gpudojo（2026-10-30）「最低挂牌 $1,300、卖家加权中位 **$1,804**、中间 50% $1,699–1,996、83 条挂牌」。
- **更可信：B**（有 83 条样本、卖家加权、明确时间戳）。A 是 8 月的区间估计，且未说明样本量。**采信 $1,804。**
- **对结论的影响**：3090 从 1.12m 涨到 1.29m，**被 4090 反超**。价格变动直接改名次，这在本题里很罕见。
- **边界类型：③ 信息边界** —— `research_required: 2026-11 月的成交分布（本轮只查到 10-30 的截面）；路径 = gpudojo 每周更新`。

**X2 · H100 PCIe 到底值多少钱：$28,000 / $32,000 / $13,000–16,500**
- 源 A：gpudojo（2026-10-09）「eBay $28,000、Newegg $29,500」；caladansemi（2026-09-09）「美区 PCIe 询问价 $28,000–32,399，中位 $32,000（仅 3 条）」。
- 源 B：clusterbid（Q2 2026）「H100 PCIe 当前残值 **$13,000–16,500**，年折旧 24–27%」。
- **更可信：A 对「现在付多少」，B 对「值多少」**。两者差 2 倍的原因是**挂牌价 ≠ 成交价**（caladansemi 自己说「美区只有 3 条挂牌，是很薄的市场」）。
- **采信 $28,000（A）做基准，$15,000（B）做敏感性**。
- **边界类型：③ 信息边界** —— `research_required: H100 PCIe 的实际成交价；路径 = 投标记录或经销商报价单`。

**X3 · 服务器卡的「带宽优势」能不能兑现**
- 源 A：规格对照（topcpu 2026-10）「H100 SXM5 3,350 GB/s vs PCIe 2,039 GB/s」，PCIe 版带宽高 A100 5%。
- 源 B：本 run 的换算：H100 的 S 与 A100 相同（都是 3），**因为 `⌊decode/20⌋` 在 64.8 与 69.2 上都是 3**。
- **两者不冲突，是「连续量」与「整数闸」的差别**：H100 的 69.2 比 A100 的 64.8 高 6.8%，但**在 `S` 上被取整抹平**。**采信 B 对本题。**
- **边界类型：① 数学/理论边界** —— `S` 是整数，`⌊69.2/20⌋ = ⌊64.8/20⌋ = 3` 是取整的性质，到此为止。

**X4 · 「DGX Spark 的 128 GB 能跑 27B 长上下文」**
- 源 A：pyshine（2026-10-01）「128 GB 统一内存，NVFP4 34 t/s」。
- 源 B：harrisoldroyd（2026-07-11）「Gemma3-27B Q4 10.83 t/s」。
- **采信 B**（dense 27B Q4 的常规口径；A 的 34 t/s 大概率是更小模型或投机解码）。**S=0，不合格。**
- **边界类型：③ 信息边界** —— `research_required: Spark 上 Qwen 级 27B Q4、64K、无投机解码；路径 = 官方 playbook 复现`。

**OPEN**
- **O1「H100 会不会因为 FP8 而获得更多槽位」** → **① 数学/理论边界**：FP8 KV 把 5.0 GiB 压到 2.5，容量闸从 12 升到 23，但**速度闸仍是 3**（`S = min`）。到此为止因为 `min` 的性质。
- **O2「3090 涨价是不是暂时的」** → **③ 信息边界**：10 月的 $1,804 中位是 8 月的 1.5–2.2 倍，可能是 AI 需求或挖矿残余。`research_required: 2026-Q4 的月度趋势；路径 = 连续 3 个月的成交中位`。
- **O3「DGX Spark 的 273 GB/s 能不能靠 NVFP4 提升」** → **② 实操边界**：NVFP4 改的是计算精度，不改每 token 要读的字节数（除非权重也量化——那是模型侧）。到此为止因为 CPU 侧没有可用工具链（Z = 官方 playbook）。
- **O4「H100 有没有更便宜的 SXM 版」** → **① 数学/理论边界**：SXM 模块 $14,000–19,550 确实更便宜，但**需要 HGX 主板**（$8,000+）与专用机箱，整机成本反而更高。到此为止因为平台成本已超过卡价差。

## 9. 交付

- **最优：1×A100 80GB（$7,400），0.403×10⁻³ $/验收任务**；其余全部 ≥ 1.09m，**差 2.7 倍**。
- **本 run 的判据**：`S` 是整数闸，**capex 只有在推动 S 上台阶时才算数**。H100 贵 3.88 倍只换 1.09 倍产能（2.71 倍差），而 A100 贵 2.96 倍换 3.0 倍产能（0.31 倍差）。
- **两个价格事实比结论更重要**：①**RTX 3090 在 2026 年 8→10 月从 $800–1,200 涨到中位 $1,804**，直接掉了名次；②**H100 的挂牌价（$28,000）与残值模型（$13,000–16,500）差 2 倍**。
- **最反直觉的一条**：**H100 的带宽优势（+5%）在 `⌊decode/20⌋` 上被完全抹平**——69.2 与 64.8 都取整成 3。**规格书上的领先，落在整数闸上是 0。**
- **该先测的三件事**：①各机 64K 单流；②3090 的成交价趋势（决定它与 4090 的名次）；③H100 的真实成交价。
