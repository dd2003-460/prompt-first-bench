## 0. 根节点

**C = 每完成一个验收通过任务的成本 [USD/任务]**

口径：W=17.1 GB；KV=5.0 GiB@64K（80 KB/token）；开销 1.5 GiB → 底盘 18.6 GiB；H=26,280 h；p=0.90；电价 0.270 USD/kWh；T=3500/prefill+500/decode。

**本 run 的切法：从「已经有什么」出发，算边际成本，而不是从「有什么可买」出发算总价。**

这个切法的合法性来自题面本身——它只说「我要在本地跑」，**没说现在是零基础**。而「从零开始」与「已有一台主机只差一张卡」在本题里差得极大：

| 起点 | 付出 | 3090 的真实门槛 |
|---|---|---|
| 零基础 | 卡 + 全套平台（主板/CPU/内存/电源/机箱） | $1,750 |
| 已有 ATX 主机 | 只加卡 | **$1,050** |

**平台 $700 占 3090 总价的 40%，占 A100 的 9.5%**——所以「起点」这件事对便宜的卡影响巨大、对贵的卡几乎无感。**这是本 run 最重要的一个结构性事实。**

## 2. 分解树

```
C 每验收任务成本 [$/任务]                          SHARE 1.00  BOUND 12.6x
├── A c_hour [$/h]                               SHARE 0.34  BOUND 2.6x
│   ├── A1 capex / H                             SHARE 0.58  BOUND 4.2x
│   │   ├── A1a 卡的成交价                        leaf 可查（$505–4,149）
│   │   ├── A1b **平台是否已持有**（本题的最大分野）   leaf 二分：$0 或 $700
│   │   └── A1c 寿命 H = 26,280 h                leaf 可定
│   └── A2 电费 P × 0.270                        SHARE 0.42  BOUND 3.1x（0.18–0.68 kW）
├── B task/h                                     SHARE 0.56  BOUND 8.0x（100–1,066）
│   ├── B1 T [s]                                 SHARE 0.19  BOUND 3.6x（9.1–32.6）
│   └── B2 S = min(容量闸, 速度闸)                 SHARE 0.81  BOUND 4.0x
└── C p = 0.90                                   SHARE 0.10  BOUND 1.18x
```

份额：0.34+0.56+0.10 = 1.00 ✅；A1 0.58+A2 0.42 = 1.00 ✅；B1 0.19+B2 0.81 = 1.00 ✅。

**A1b 的分野**：只加卡时，电费占 c_hour 的比例从 37% 升到 55%——**平台一旦免费，剩下的就全是卡钱与电费**，这会把「便宜但费电」的卡往下推、把「贵但省电」的卡往上推。

## 4. 瓶颈

**BOTTLENECK: A1b「平台是否已持有」× B2「速度闸」的组合，而其中**A1b 是本 run 独有的、影响最大的那一支**。**

打分：A1b = 0.34 × 0.58 × **∞**（其取值是 0 或 700，是一个二值开关，不是连续区间）；B2 = 0.56 × 0.81 × 4.0 = **1.81**；A1a = 0.34 × 0.58 × 8.2 = **1.62**。

按「同一张卡的两种起点」比较：

| 卡 | 零基础 | 已有主机 | 起点带来的降幅 |
|---|---|---|---|
| 3090 | 1.119m | **0.848m** | **−24%** |
| 4090 | 1.198m | **0.953m** | **−20%** |
| A100-80 | 0.403m | **0.219m** | **−46%** |

**三条结论**：

1. **起点能改变名次**：零基础下 3090（1.119m）与 4090（1.198m）差 7%，**已有主机下两者差 12% 且顺序不变，但相对 A100 的差距从 2.8 倍缩到 3.9 倍**——因为 A100 的平台占比最小，**平台的免费化对便宜卡是雪中送炭、对贵卡是锦上添花**。
2. **A100 摊薄平台的能力最强**，所以「已有服务器空槽」这个起点让它从 0.403m 掉到 0.219m（−46%），成为全表唯一进入 0.2m 档的方案。
3. **但真正决定能不能用的仍是 B2**：13 个候选里 **9 个的 S 由速度闸或双闸失效**（5080、5060 Ti、P100 容量不足；V100 速度 0；A5000、A6000、M5 Max、M5 Ultra、5090 只有 1 档）。

**瓶颈的下一层**：**速度闸的分母是「每 token 读 22.1 GiB」，其中 5.0 GiB 是 KV**。而 KV 的量与「并发流数」成正比——**S 越大，KV 越大，每 token 读越多，速度越慢**。这是一个负反馈：**本题的 S 上限本质上由「带宽 ÷ (权重 + S×5.0)」这个隐式方程解出，而不是由显存除一下**。用带宽写出来：

```
decode(S) ≈ 带宽 × 效率 ÷ (17.1 + 1.5 + 5.0×S)
要求 decode(S) ≥ 20  ⟹  S ≤ (带宽×效率/20 − 18.6)/5.0
```

**对 3090（936 × 0.80 = 749 GB/s 有效）：S ≤ (749/20 − 18.6)/5.0 = 3.77**——理论上能跑 3 条！而按显存算只有 1.08 条。**这说明 3090 的真实上限是显存（1 条），不是带宽；而 A100-80 的真实上限是带宽（3 条），不是显存（12 条）。** 两者的瓶颈在**不同的闸**上，这正是「瓶颈必须指名哪一支」的意义。

## 6. 矛盾清单

- 源 A：gpuprix（2026-10-03）「PNY 二手 $2,430」。

**X3 · 「已有主机只加卡」是不是合法的口径**
- 源 A：runaihome（2026-09-14）把「二手 3090 ~$1,050」作为「一切都能塞进 24 GB 时的答案」——**只讲卡价，不讲平台**。

## 7. 黑盒

| # | 项 | 影响 | 区间 | 怎么量 |
|---|---|---|---|---|
| B1 | p 通过率 | C | 0.85–0.97 | 100 条真实任务判分 |
| B2 | 各机 64K 单流 decode | B2（全部结论） | 3–64.8 t/s | llama-bench -d 60000 |
| B3 | 「已有主机」的真实比例 | 结论选哪个分区 | — | 无法测量，只能给出两个答案 |
| B4 | V100-32 单卡实测 | 出局 or 0.976m | 15–22.5 t/s | 源码编译自测 |
| B5 | Mac 的 Metal 效率 | M5 Max 合不合格 | 0.63–0.83 | 同上 |

**OPEN**
- **O1「3090 理论上能跑 3 条流，为什么实际只跑 1 条」**：用带宽方程解出 S ≤ 3.77，但显存只有 1.08 槽。**结论是显存在卡它。** 那能不能把第 2、3 条的 KV 放到主机内存？PCIe 4.0 ×16 是 32 GB/s，一段 5 GiB 的 KV 每 token 要读一遍 → 5 GiB ÷ 32 GB/s = 0.16 s，**单是搬 KV 就掉到 6 t/s**。**所以不行，这条到此为止。**
- **O2「能不能用 FP8 KV 把 A100 的 S 从 3 拉到 4」**：KV 从 5.0 降到 2.5 GiB，容量闸从 12 升到 15，但速度闸上界变成 (1,935×0.78/20 − 16.1)/2.5 ≈ 23.7 → 仍受 `⌊decode/20⌋` 的整数限制，**实际 S 由 decode 决定，而 decode 会因读量变小而升到 74 t/s → 3 档**。**没变。** 到此为止。
- **O3「已有 Mac 的人怎么办」**：Apple Silicon 不支持 eGPU（无驱动），只能整机换。**这是硬事实，没有折中方案。**
- **O4「P100 为什么这么慢」**：Pascal 无 Tensor Core、FP16 只有 1:64 速率，flash-attention 的 kernel 在 sm_60 上退化成逐元素计算。**这个我知道原因，但没法在本题里救它。**

## 8. 交付

- **最优（已有服务器空槽）：1×A100 80GB 二手卡 $4,000 → 0.219×10⁻³ $/验收任务**——全表唯一进 0.2m 档的方案。
- **最优（零基础）：1×A100 80GB 整机 $7,400 → 0.403m**。
- **最优（已有 ATX 主机）：RTX 3090 $1,050 → 0.848m**——比零基础便宜 24%。
- **本 run 的判据**：**平台 $700 对便宜卡是 40% 的成本、对贵的卡是 9.5%**，所以「你已经有什么」比「你想买什么」更能决定 $/任务。**同一张 A100 在两个起点上差 46%。**
- **最反直觉的一条**：**3090 的瓶颈是显存（1 条流），A100-80 的瓶颈是带宽（3 条流）**——用带宽方程 `S ≤ (带宽×效率/20 − 18.6)/5.0` 算，3090 理论上能跑 3.77 条，实际被 24 GB 卡在 1.08 条。**两张卡的瓶颈在不同的闸上**，所以「升级哪一项」的答案完全不同。
- **最实用的一条**：**如果你已经有一台 750 W 的 ATX 主机，$1,050 的 3090 就是本题的性价比答案**；如果你没有，先别买——$700 的平台费会吃掉它 24% 的优势。
- **该先测的三件事**：①各机 64K 单流（S 上限）；②V100 单卡（决定它是不是第 5）；③Mac 的 Metal 效率（决定 M5 Max 是不是直接出局）。
