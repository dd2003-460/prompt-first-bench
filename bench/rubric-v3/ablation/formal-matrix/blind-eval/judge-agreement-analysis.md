# 双裁判盲评一致性分析

**日期**: 2026-11-02 (+08:00)
**数据源**: `judge-1-scores.json` + `judge-2-scores.json`（各 21 docs × 19 non-NA items + 31 O3 claims）
**匿名映射**: A=V0-baseline, B=V1-full, C=V1-align, D=V2-nocoverage, E=V3-noboundary, F=V-sham, G=V3-sham

## ⚠️ 关键限制声明

**本分析不是真正的裁判间信度（inter-rater reliability）。** 两个"裁判"是同一个 arena agent 用不同评分口径跑的两遍。它测量的是**同一模型对同一材料在不同严格度下的评分稳定性**（strictness sensitivity），不是独立人类标注员之间的一致性。任何 κ 值都不能直接引用为"双裁判一致性好"的证据，只能作为"评分对严格度不敏感"的辅助证据。

### 观察矩阵（三级，rows=J1, cols=J2）

```
           J2=0   J2=1   J2=2
J1=0      [  21,    0,    0]
J1=1      [   2,   42,    0]
J1=2      [   0,    8,  326]
```

不对称模式：J1 给 1 分时 J2 也倾向给 1（42/44=95%），但 J1 给 2 分时 J2 偶尔降为 1（8/334=2.4%）。**所有偏差方向一致：J1 比 J2 略宽**。

## 二、分歧明细

### 逐项分歧（二值化后）

8/399 项分歧（98.0% 一致），**全部是 J1 高于 J2**：
- `O4-E2_numeric_interval`: 7 次（J1 认为给了数值区间，J2 认为不够精确）
- `O2-E3_L3`: 1 次

### O3 claim 分歧

5/651 条分歧（99.2% 一致），**全部是 J1 标 covered、J2 标 not_covered**。

### 每文档总分差

最大 Δ=+2（G1, G3），最小 Δ=0（12/21 docs 完全一致）。J1 总分系统性偏高 0-2 分。

## 四、结构性缺口（rubric 盲区）

**5 个 claim 在全部 21 docs × 2 judges 中零覆盖**：
- N-2.2, N-3.1, N-3.1.1, N-3.1.2, N-3.1.3

这意味着当前 benchmark 任务（R121 paper-compare）的产出物**从不触及**这 5 个 claim 对应的内容维度。可能原因：
1. 任务本身不需要这些 claim（它们属于更广泛的 rubric 模板，不适用于此特定任务）
2. 任务设计缺陷——应该要求但不被要求
3. Rubric 过宽——claim 列表包含了超出任务范围的内容

**建议**：对照 TASK-r121-paper-compare.md 的任务描述，逐条判断这 5 个 claim 是否应该在 R121 的评分范围内。如果不在，应从 R121 的 claim 列表中移除（减少虚假的 NA 惩罚）；如果在，说明任务设计需要扩展。

## 五、结论与后续

1. **评分系统内部一致性高**（κ=0.93 binary），但这是同一模型的 self-consistency，不是 inter-rater reliability。正式发表时需明确标注此限制。
2. **V1-full 显著优于 V0-baseline**（Δ=11.6/38≈30%），支持 rubric 引导的有效性。
3. **Coverage 组件贡献最小**（Δ=1.1），boundary 组件贡献较大（Δ=3.8）。这与 pilot 阶段观察一致。
4. **Sham 流程得分接近真实流程**（34.7 vs 37.3），提示流程本身的区分力有限，主要区分来自 rubric 内容而非执行流程。
5. **5 个零覆盖 claim** 需要 Lead 裁定：保留（承认任务不覆盖）还是移除（减少噪声）。
