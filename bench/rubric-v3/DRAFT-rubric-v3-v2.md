## 0. 设计原则（先读这个）

1. **outcome 和 process 分开报，不合成总分**。过程好结果差 = 执行 bug；过程差结果好 = 运气或任务太简单。合在一起互相抵消，消融测不出东西。（与 T8-C3 的 M8-truth/M8-cover 拆分逻辑一致。）
2. **所有分数对比 baseline 才有意义**。baseline = 无引导 prompt（C9-plain 档）或开源框架 prompt（AutoGen/LangGraph/ReWOO 档）。单看绝对分不判显著性。
3. **深度 > 广度**。挖到 L3 深层矛盾 1 个 > 表面 trade-off 5 个（权重体现见 §1 预注册权重表）。
4. **【v2 改写 · R-02】每个维度拆 3-6 个 yes/no 条目，维度分 = 条目通过数 / 条目数（0-1 连续量）**。条目判据必须机械可判（judge 照表打二值分，不留自由裁量空间）；κ 在**条目层（二值）**计算——原「0/1/2 三档」制被 v1 §1 自身推翻（O1 无界 / O2 含 0.5 / O3 倍率 / 仅 O4 真三档，B6），废弃。judge 校准门禁沿用 C3 v3 的 R5（换位双判 + κ≥0.6 + 长度去偏），评分前不过门禁不开评。
5. **【v2 新增 · R-02】权重与总分公式在本文件预注册写死**（见 §1 末「Outcome 总分」与 §2 末「Process 总分」），不留「满分另定」。任何开跑后改权重 = post-hoc，禁止。

## 1. Outcome 层（结果标准）—— 看 pipeline 终态产出

### O1 候选集覆盖度【v2 重写 · R-01：拆账 + 二值条目化】

**测什么（v2 收窄）**：最终产出的候选集是否覆盖了「非默认可行区间」（低模型先验候选）——**只计覆盖行为，不判语义正确性**（B1 拆账：同一证据不得同时进 O1 与 O3；O3 专管 gold 命中，O1 专管「有没有去找非直觉候选并留下可定位证据」）。

**计分结构（每候选 3 条 yes/no 条目，二值 0/1）**：

| 条目 | 判据（judge 机械判定） |
|------|------------------------|
| E1 纳入 | 该候选出现在最终候选集中（按名称/型号可定位） |
| E2 三项检查证据 | 该候选名下同时存在 ①≥1 个可定位来源引用（URL/文档路径/API 回执）②≥1 个数值（价格/吞吐/规格等）③≥1 句约束判断（该候选在何条件下可行/不可行/成为瓶颈）——缺一该候选 E2=0 |
| E3 深度计入资格 | 该候选是「低先验候选」（定义：不在被测者未受引导时的默认候选先验内，由 judge 对照 V0 同题产出判定）且本 run 计入深度分的低先验候选数 ≤3（**预注册封顶，写死不放开**） |

**维度分**：O1 = （全部低先验候选的 E1+E2+E3 通过数）/（3 × 低先验候选数）。无低先验候选 → O1 = 0（覆盖行为缺失，不是 NA）。

**防刷分机械判据（四条，run 级门禁，违反则该 run O1 记 0 并标原因）**【v2 新增 · #20/#21】：
1. 档位区分度：同题重复 run 的候选集 Jaccard < 0.9，且相邻档候选集不得几乎相同（双口径兜底——AUDIT-report 未展开定义，**需人工裁决**，见 revision-log M5）；
2. 维度定义带时间戳且早于任何候选名出现（防事后补维度）；
3. 候选集规模 ≥3 档中含中间档（不得只有「全有/全无」两极）；
4. 证据密度下限：每候选 ≥1 URL + ≥1 数值 + ≥1 约束判断（= E2 的 run 级汇总），低于阈值标「形式合规实质不足」，该 run O1 上限 0.5。

**为什么单独计分**：decomp gold 树已证明 V100×8 能进前二（0.697 ¢/task，仅次于 3090×4），且电价 ≥0.26 $/kWh 时翻转第一——但 C0 run 的候选集是模型自搜出来的，没有 prompt 机制保证覆盖。这是系统性的选择偏差：模型先验偏向新卡，"常见候选"五个字不够。

**baseline 预期**：无引导 prompt 在 O1 上大概率 0-1 条目通过率（靠模型先验），这是本维度最可能产生显著 Δ 的地方。

### O2 矛盾挖掘深度【v2 框架化 · R-02 横切；条目内容待 batch2 R-12】

把 v1 的层级加权（L1 0.5 / L2 1 / L3 2 个/项 + min(2,Σ) 封顶）改为条目制。v2 先用现判据二值化直译过渡：

| 条目 | 判据（二值） |
|------|--------------|
| E1 | 产出中存在 ≥1 个 L1 表面 trade-off（两具名候选/属性方向相反取值，片段可定位） |
| E2 | 产出中存在 ≥1 个 L2 机制矛盾（≥2 变量联合约束下不可同时满足，片段可定位） |
| E3 | 产出中存在 ≥1 个 L3 深层矛盾（需领域知识/实测的机制级矛盾，片段可定位） |
| E4 | 每个已列矛盾均标注 已解/未解 + 验证路径（缺任一则该条 E4=0） |

**维度分**：O2 = 通过条目数 / 4。

> `[batch2: R-12]` 层级必要条件机械化（L1/L2/L3 各给「产出内可定位的必要条件」）+ 层级主导计分（取消「深度>广度」被封顶取消的问题）+ gold 命中正交化（gold 命中仅作附加标签不计分，「gold 未覆盖的新深层发现」改正式计分项）——本 goal 不实施，占位防误用。

### O3 gold 覆盖度（outcome 主分）【v2 加宣称前置条件 · R-06】

**测什么**：终态产出是否命中该域 gold 树的节点，按意外性加权（v3.1 · 信息论调研定稿）。

- **权重公式**：w_v = 1 + min(−log₂ p̃_v, log₂(1/ε))，O3 = Σ_{v∈G*} w_v·h_v / Σ_{v∈G*} w_v
  - p̃_v = 冻结协议下多模型盲生成时该拆分（相对其父上下文）的出现率——"模型发现率"，不是工程师真实 prior（未经人工校准不得这么叫）
  - ε=0.01 为待验证试点值 → 权重上限 ≈ 8；不用无界 surprisal，不用 1/P，不叠乘深度
  - 直觉保留：常见拆分 P≈1 → w≈1；反直觉拆分 P 小 → w 大。旧的 L4×2/L5×2/L6×3 固定倍数废弃，由 p̃ 实测替代
- **`[batch2: R-13]` 已提前落地**（RV3G6-o3-claim-list，2026-10-30）：O3 命中判据 = 原子 claim 清单实质内容包含（`o3-claim-list.md` §2/§3/§4）；R-13 剩余部分（claim 级独立重判执行）导出 queue RV3G6-o3-claim-rejudge——见 revision-log-batch1.md R-13 条目（范围切割说明）
- **先验获取协议**（离线一次，冻结后不再动）：≥3 个 LLM 服务在相同 prompt 下盲生成分解树（不给 gold），按语义类统计每个候选拆分的出现频率，p̃=(k+0.5)/(N+1) 平滑；少量领域工程师盲提试验做外部效度校准和语义匹配裁决
- **命中判据【v2 修订 · R-13 提前落地】**：judge 拿产出逐节点对照 `o3-claim-list.md` §2 的原子 claim 清单，判**实质内容包含**（该节点 claim 描述的结构/机制/方向是否出现在产出中，错误方向的覆盖不算命中），不再以节点 ID 匹配为判据（AUDIT finding #13：run 自带编号体系与 gold 编号系统性错配，ID 判据双向失效）。多判者聚合按 `o3-claim-list.md` §4（N=3、≥2/3 一致即 h_v=1）；新旧判据一致性按 `o3-claim-list.md` §3 映射一致性指标报告（口径声明缺失的引用无效）
- **黑盒标注是能力不是缺陷**：显式标"我不知道+区间+怎么测"的叶子正常计分，漏标才是错
- **【v2 新增 · R-06】状态声明：surprisal 加权（w2）当前为 experimental**——p̃ 双源偏差（零命中高估 + 保守下界效应）在同族双 judge 下未被消除（AUDIT-report G2 F2），W3/W4 组合方案不进正式公式直至异源 judge 重测。主公式 = W1 importance（唯一无 p̃ 依赖方案）；构念效度主判据 = gold mean rank（gmr，预注册 tie-break 见 AUDIT-report §3.2/§8，过线阈值待 RV3G3-goldrank-threshold-proof 正式论证，**论证前不得写死**）。

#### 宣称前置条件（硬条款 · 对外引用 O3 构念效度数字前必读）【v2 新增 · R-06，原文引自 AUDIT-report §6】

> 本文引用的 O3 构念效度数字（gold mean rank / top-10 计数 / top-5 计数）**均为「相对 Lead-gold」的度量**：gold 树由单一作者构建，rubric 题面补丁与该 gold 答案结构同构，故「命中 gold」与「被题面引导写出 gold 形状」在当前设计下不可区分；且全部 p̃ 估计来自**同族双 judge**（qwen3.8-27b 底座，上下文独立但非家族独立），p̃ 层的系统性偏差（零命中高估 + 保守下界效应）未被消除。**在以下二者之一闭环前，这些数字不得作为 rubric-v3 有效性的独立证据对外宣称**：(i) 双 gold——由未参与 pfb 的第三方/异族模型独立构建同域 gold，报两 gold 命中差值作为同源偏置上界；(ii) 异源第三 judge（queue 项 R5.2-third-scorer）完成 p̃ 重估 + 构念效度复测。

- 构念效度：top-5 gold 计数 ≥3/5 判据已废弃（对 p̃ 来源二元翻转 3/5↔1/5 + per-run 口径无 run 过线 max=2 + 超几何基线 P(X≥3)=1.99% 极严判据，AUDIT-report §3.1）；改用 gmr（连续量，扰动最小）
- 机判防护：w2 公式逐节点断言 `ablation/scripts/assert-w2-formula.py`（C4）+ W0-W4 分数复算断言 `ablation/scripts/assert-w3w4-recompute.py`（C3），冻结数据篡改即 FAIL

## 3. 实验设计（怎么跑出这些分数）

### 3.1 域选择

第一格沿用 decomp 27B 硬件域（gold 现成、baseline 分数现成可直接复用 L1 的 C9-plain/AutoGen 数据做冷启动对照），但题面升级为 **rubric-v3 版**（见 §4 候选集扩展）。第二格选一个 gold 需新建的域（建议：推理基础设施选型或科研方法论，T17 已有半成品），测 gold 覆盖度在新域上的可构建性。

## 4. 候选集扩展指令（prompt 补丁）【v2 重写 · R-03：去方向暗示】

**问题诊断**（保留 v1 原文，属事实陈述非指令）：C0 题面写"常见的候选硬件"，模型自搜出来的集合是 {3090, A100, L40S, M2U, V100×8}——V100 进了但纯属运气（run 间不稳定），P100/T4/2080Ti/1080Ti 这类"有社区优化+保值性好+性价比可能更高"的卡系统性缺席。原因：模型先验 = 发布会记忆，老卡的社区生态（kernel 支持演进、量化路径、二手行情）不在先验里，不主动搜就不知道。

### 4.1 主补丁（V1 使用 · 去锚点版）

**设计变更声明（B3/B11）**：v1 补丁含「发布 ≥5 年」具体年代锚点 + 「保值性好/性价比可能更高」价值断言 + 指向特定卡型生态的三问——这三处构成**答案注射**（题面泄漏了评估框架的方向，Pr2/Pr3 因此自证）。v2 补丁只做两件事：(i) 强制**分区饱和搜索结构**（把覆盖度从模型先验变成流程义务）；(ii) 要求**每个候选留下可定位证据**（供 O1 二值条目机械判定）。分区边界与准入属性由**任务画像**定义，题面不给具体年代/价格阈值/卡型示例。

```
【候选集构造规则】（硬性，不许跳过）
1. 候选集不许直接枚举。先按以下四个分区各自搜索，再合并：
   分区 a/b/c/d 的边界由任务画像推导（任务画像 = 本题给出的负载特征、
   成本约束、可用性约束的完整集合），每个分区写明推导依据。
   分区划分须覆盖「模型默认先验会自然想到的候选」与「默认先验之外
   仍可能可行的候选」两类，后者不得少于前者的一半数量。
2. 每个分区至少给出 2 个候选，附搜索证据（来源+日期）。
   某分区确实搜不到合格候选，写明搜了什么、为什么没有，不许静默跳过。
3. 每个「默认先验之外」的候选必须额外回答三问（由你按任务画像实例化
   具体指标，题面不指定指标名）：
   ① 生态成熟度：该候选支撑目标工作负载的技术栈现状如何？
   ② 经济状况：该候选当前的获取成本处于什么水平（相对其他候选）？
   ③ 实测瓶颈：别用规格书名义值，找实测数据定位它在本任务画像下的
      真实瓶颈。
4. 搜索预算：候选集构造阶段的搜索次数不设上限，
   直到每个分区都有 ≥2 个带证据的候选或显式的"无合格候选"声明。
```

**设计逻辑（v2 版）**：
- 「四分区强制搜索 + 分区边界由任务画像推导」把覆盖度从模型先验变成流程义务，且不预设哪个区间是非默认的（v1 的「老马区」标签本身就是方向暗示，删除）
- 「默认先验之外的候选不得少于一半数量」是**数量义务**而非**价值判断**——它不告诉模型哪些候选好，只要求覆盖宽度（M4 修正：这是 V1 保留的倾向成分的最小化形态；V1-align 连这条也去掉，见 4.2）
- 「搜索预算不设上限直到分区饱和」直接响应"增加搜索预算"：不是给固定 N 次搜索，而是给**停止条件**（分区饱和或显式空声明），这符合 pfb 停止条件表的既有范式
- 「不许静默跳过」对应 M8-cover 的逻辑：遗漏要可见，不能当不存在
- 三问域无关占位（M4）：题面只规定**问什么类别**（生态/经济/实测），不规定**用什么指标**——指标实例化是被测者的工作，也是 O1-E2「三项检查证据」条目的判定对象

### 4.2 V1-align 对照组补丁（纯结构版 · B3 处置）

与 4.1 的差异（逐处）：
1. 删除「后者不得少于前者的一半数量」句（数量义务 = 残余倾向提示，V1-align 剥离）；
2. 分区 a/b/c/d 的边界描述改为纯占位：「分区 a/b/c/d 由任务画像推导（四个互斥且并集覆盖全部可行候选的划分），每个分区写明推导依据」——不出现「默认先验」字样（该字样本身引导被测者思考先验盲区）；

其余（四分区结构 / 每分区 ≥2 带证据 / 不许静默跳过 / 搜索停止条件）与 4.1 逐字相同。
