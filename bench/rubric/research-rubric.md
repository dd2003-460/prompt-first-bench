# 研究能力评分维度 D5

> origin: ai · 2026-10-23 · **定稿（round3 定稿修订）** · 路径 D 第二步产物
> 适用题库：`bench/tasks/research-questions.md`（BrowseComp 10 / GAIA L2-3 10 / HLE 10）
> 适用对照：V0（裸 prompt）vs V4（正交+完备+交叉验证+反方复核），各 ≥2 runs

## 0. 与现有 D1-D4 的关系

`rubric/scoring.md` 现有维度（每题 100 分）：D1 正确性 40 / D2 完备性 25 / D3 结构正交 20 / D4 置信度标注 15。

**D5 定位为「加分维度」（bonus），不是独立计 100 的维度**，理由：
1. D1-D4 已覆盖「答对 + 答全 + 结构 + 来源」，是合格线；
2. 研究能力 bench 要测的增量是 **prompt 没给出的新结论**——D1-D4 的满分产出（忠实照 prompt 答对）可以新结论为零，D5 专门捕捉这一层；
3. 加分制不扰动现有 V0-V5 消融的 success 判定（≥80 线不变），另出「研究分」供对照读出。

**总分规则（定稿）**：
- 基础分 = D1+D2+D3+D4，0-100，判定线不变（≥80 success / 60-79 partial / <60 fail）。
- 研究分 R = 基础分 + D5_bonus，D5_bonus ∈ [0, +20]。
- 报告时两个数都报（基础分用于消融对齐，研究分用于研究能力排名）；success 判定只看基础分，**避免 D5 把答错答案的 run 拉过线**。
- 负向项（假新/伪新）从基础分扣（计入 D1/D4），可能使基础分 <60 而判 fail——新结论是加分，不是保底。

## 1. D5 定义：新结论（New Conclusions）

**新结论 = 模型最终产出中、prompt 题面与附件均未给出、且为真（可验证）的独立研究性陈述。**

三条同时满足才算一条：
- (a) **新**：prompt（题面+附件+变体流程指令）中不含该信息，也不是题面的同义改写/直接摘抄；
- (b) **真**：可被评分者用独立来源验证为真（web/文献/计算复核）；不可验证的猜测不计分；
- (c) **独立**：与同一产出中其他已计分新结论不重复（同一事实的不同表述只计 1 次）。

**不算新结论的**：
- 答对参考解本身（那是 D1 的活）；
- 流程性陈述（"我拆成了 3 个子任务""我交叉验证了 2 个来源"）——那是流程证据，进 D4/结构证据，不进 D5；
- 常识级背景（"Shannon 1948 年发表"这类无检索也能说的）——需达到"非检索不可得"或"需跨源综合"级别；
- 被评分者验证为假的（假新结论 = 扣分项，见 §3）。

## 2. 「新」的判定细则（定稿修订新增）

**(a) 新 = 相对题面与参考解的增量**，具体判法：
1. 评分者手边放两样参照物：**prompt 全文**（题面+附件+变体流程指令）与 **`bench/tasks/research-questions.md` 中该题的参考解**；
2. 产出中的陈述若能在上述两处**逐字或同义**找到 → 不算新（答对参考解本身归 D1）；
3. 答对参考解的**路径上的中间事实**（如 BrowseComp 多跳检索中的中间实体）：仅当模型明确陈述且该中间事实本身不在题面/参考解中时，按「单源可得」级计入新结论；若中间事实只是解题必经步骤而未形成独立陈述，不重复计；
4. 常识级背景：评分者凭训练知识即可复述、无需检索的陈述不算新；判不准时按「需检索才确认」处理（宽松计入，但级别只能给「单源可得」）。

**(b) 真 = 可核验来源 + 抽查**，具体判法：
1. 每条候选新结论，评分者用独立来源（web/文献/计算复核）验证；
2. **抽查规则（定稿修订新增）**：评分者对每个 run 的候选新结论**至少独立核验 ≥1 条**（URL 可达/文献编号可查/数据出处可复核）；若抽查的条目来源核验失败且无法用其他独立来源补证 → 该条不计分（按不可验证处理，不判假）；
3. 模型在产出中**给出来源线索（URL/文献编号/数据出处）的候选**，核验成本最低、优先抽查；未给来源线索的候选需要评分者自行检索验证，成本高，验证通过仍计分（级别不因此降档）；
4. 模型**把猜测伪装成已验证结论**（陈述语气为确定 + 评分者验证为假）→ 假新结论，进 §3 负向项。

**(c) 独立**：同一事实的不同表述（换序/换单位/换措辞）只计 1 次；评分者合并后再判档。

## 3. 负向项（从基础分扣，不在 D5 内）

- **假新结论**：模型标成"新发现"但评分者验证为假的陈述 → 每条 -10（基础分扣，计入 D1 正确性错误）；
- **伪新**：把题面已有信息包装成新结论 → 每条 -5（D4 置信度/诚实性，虚报）；
- **不可验证不判罚**：无法验证（非假）的猜测不计 D5 也不扣分，但要求模型按 D4 标注 confidence，未标注按 D4 规则扣。

## 4. 计分（D5_bonus，0-20，五档锚点，定稿修订：4 档→5 档）

> 修订说明：草稿为 4 档（0/+5/+10/+15/+20，标号 0-4 实为 5 行但语义分 4 级），与「0/25/50/75/100 五档锚点」要求对齐，现明确为 5 档，每档给出**可操作判据**（满足任一行即可落该档，就高不就低）：

| 档 | 分值 | 锚点判据（满足任一） |
|---|---|---|
| 0 | 0 | 无新结论；或仅复述 prompt/题面/参考解/常识级背景（无一条满足 §2 三条件） |
| 1 | +5 | ≥1 条新结论，全部为「单源可得」级（一次检索即得；如补充一个题面没问的相关事实），且无跨源综合 |
| 2 | +10 | ≥2 条新结论（允许单源可得混合）；或 ≥1 条「跨源综合」级（需 ≥2 源拼接/推断/换算才得出） |
| 3 | +15 | ≥3 条新结论且 ≥1 条跨源综合；或 ≥2 条跨源综合 |
| 4 | +20 | ≥3 条新结论且 ≥2 条跨源综合；或含 ≥1 条「题面外方向」级结论（题面没要求、但对该研究问题有实质推进：参考解的边界条件/反例/后续发展/新变量/开放问题） |

**级别判定**（评分者用，§2 已给判法）：
- 单源可得：任意一个可靠来源单独就能查到；
- 跨源综合：需要 ≥2 个来源的信息拼接、换算或推断；
- 题面外方向：超出题面所问，指向该研究问题的新维度（新变量/反例/适用边界/开放问题）。

**数量封顶**：每条新结论只按其贡献的最高档计 1 次，不逐条累加超过 +20。

## 5. 评分流程（盲评）

1. 评分者先按 D1-D4 独立打分（不看 D5）；
2. 从产出中抽取候选新结论清单（模型自己标注的"新发现"段 + 评分者自行发现题面外陈述）；
3. 逐条按 §2 判 (a)(b)(c) + 判级别（**每 run 至少独立核验 ≥1 条来源**）；
4. 按 §4 档表给 D5_bonus，按 §3 记负向项；
5. 两名独立评分者分歧 >1 档时仲裁并留痕（沿用 FINAL-VERIFY.md 盲评协议）。

## 6. 读法（消融对照）

- 主读出：V4 vs V0 的**研究分 R** 差（配对，模型内），以及 D5_bonus 档分布差；
- 辅读出：D5 与基础分的相关性（研究分高的 run 是否基础分也高）；
- 限制：30 题 ×2 runs 小样本，只做方向性结论，不做强显著性（同 FINAL-VERIFY.md 口径）。

## 7. 待 round3/4 验证的开放问题（定稿修订：原 §6 顺延为 §7，状态更新）

1. +20 加分上限是否合适（会不会让 V4 研究分虚高而基础分低）→ round3 试跑后看 D5 与基础分相关性再定；
2. "题面外方向"档是否应单独设分（现在合并在 +20 里）；
3. BrowseComp 题答案本身就是多步检索产物，"新结论"与"答对路径上的中间事实"边界 → 已在 §2(4) 给出初判规则（中间事实形成独立陈述才计），round3 实例校准；
