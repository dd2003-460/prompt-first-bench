# 研究能力评分维度 D5 草稿

> origin: ai · 2026-10-23 · **草稿·待 round3 验证** · 路径 D 第二步产物
> 适用题库：`bench/tasks/research-questions.md`（BrowseComp 10 / GAIA L2-3 10 / HLE 10）
> 适用对照：V0（裸 prompt）vs V4（正交+完备+交叉验证+反方复核），各 ≥2 runs

## 0. 与现有 D1-D4 的关系

`rubric/scoring.md` 现有维度（每题 100 分）：D1 正确性 40 / D2 完备性 25 / D3 结构正交 20 / D4 置信度标注 15。

**D5 定位为「加分维度」（bonus），不是独立计 100 的维度**，理由：
1. D1-D4 已覆盖「答对 + 答全 + 结构 + 来源」，是合格线；
2. 研究能力 bench 要测的增量是 **prompt 没给出的新结论**——D1-D4 的满分产出（忠实照 prompt 答对）可以新结论为零，D5 专门捕捉这一层；
3. 加分制不扰动现有 V0-V5 消融的 success 判定（≥80 线不变），另出「研究分」供对照读出。

**总分规则（draft）**：
- 基础分 = D1+D2+D3+D4，0-100，判定线不变（≥80 success / 60-79 partial / <60 fail）。
- 研究分 R = 基础分 + D5_bonus，D5_bonus ∈ [0, +20]。
- 报告时两个数都报（基础分用于消融对齐，研究分用于研究能力排名）；success 判定只看基础分，**避免 D5 把答错答案的 run 拉过线**。

## 1. D5 定义：新结论（New Conclusions）

**新结论 = 模型最终产出中、prompt 题面与附件均未给出、且为真（可验证）的独立研究性陈述。**

三条同时满足才算一条：
- (a) **新**：prompt（题面+附件+变体流程指令）中不含该信息，也不是题面的同义改写/直接摘抄；
- (b) **真**：可被评分者用独立来源验证为真（web/文献/计算复核）；不可验证的猜测不计分；
- (c) **独立**：与同一产出中其他已计分新结论不重复（同一事实的不同表述只计 1 次）。

**不算新结论的**：
- 答对参考解本身（那是 D1 的活）；
- 流程性陈述（"我拆成了 3 个子任务""我交叉验证了 2 个来源"）——那是流程证据，进 D4/结构证据，不进 D5；
- 常识级背景（"Shannon 1948 年发表"这类无检索也能说的）——需达到"非检索不可得"或"需跨源综合"级别；
- 被评分者验证为假的（假新结论 = 扣分项，见 §3）。

## 2. 计分（D5_bonus，0-20）

| 档 | 分值 | 锚点 |
|---|---|---|
| 0 | 0 | 无新结论；或仅复述 prompt/题面/常见背景 |
| 1 | +5 | 1 条新结论，且为"单源可得"级别（一次检索即得，如补充一个题面没问的相关事实） |
| 2 | +10 | 2 条新结论；或 1 条"跨源综合"级别（需 ≥2 源拼接/推断才得出的结论，如从两个数据集推出题面没问的量） |
| 3 | +15 | 3 条新结论且至少 1 条跨源综合；或 2 条跨源综合 |
| 4 | +20 | ≥3 条新结论且 ≥2 条跨源综合；或含 1 条"题面外方向"级结论（题面没要求、但对该研究问题有实质推进的发现，如指出参考解的边界条件/反例/后续发展） |

**级别判定**（评分者用）：
- 单源可得：任意一个可靠来源单独就能查到；
- 跨源综合：需要 ≥2 个来源的信息拼接、换算或推断；
- 题面外方向：超出题面所问，指向该研究问题的新维度（新变量/反例/适用边界/开放问题）。

**数量封顶**：每条新结论只按其贡献的最高档计 1 次，不逐条累加超过 +20。

## 3. 负向项（从基础分扣，不在 D5 内）

- **假新结论**：模型标成"新发现"但评分者验证为假的陈述 → 每条 -10（基础分扣，计入 D1 正确性错误）；
- **伪新**：把题面已有信息包装成新结论 → 每条 -5（D4 置信度/诚实性，虚报）；
- **不可验证不判罚**：无法验证（非假）的猜测不计 D5 也不扣分，但要求模型按 D4 标注 confidence，未标注按 D4 规则扣。

## 4. 评分流程（盲评）

1. 评分者先按 D1-D4 独立打分（不看 D5）；
2. 从产出中抽取候选新结论清单（模型自己标注的"新发现"段 + 评分者自行发现题面外陈述）；
3. 逐条验证 (a)(b)(c) + 判级别；
4. 按 §2 档表给 D5_bonus，按 §3 记负向项；
5. 两名独立评分者分歧 >1 档时仲裁并留痕（沿用 FINAL-VERIFY.md 盲评协议）。

## 5. 读法（消融对照）

- 主读出：V4 vs V0 的**研究分 R** 差（配对，模型内），以及 D5_bonus 档分布差；
- 辅读出：D5 与基础分的相关性（研究分高的 run 是否基础分也高）；
- 限制：30 题 ×2 runs 小样本，只做方向性结论，不做强显著性（同 FINAL-VERIFY.md 口径）。

## 6. 待 round3 验证的开放问题

1. +20 加分上限是否合适（会不会让 V4 研究分虚高而基础分低）→ round3 看 D5 与基础分相关性后定；
2. "题面外方向"档是否应单独设分（现在合并在 +20 里）；
3. BrowseComp 题答案本身就是多步检索产物，"新结论"与"答对路径上的中间事实"边界需 round3 实例校准；
4. 是否要求模型在产出中显式标注"新结论"段（方便抽取 vs 诱导表演）→ round3 试两种 prompt 各跑 5 题。
