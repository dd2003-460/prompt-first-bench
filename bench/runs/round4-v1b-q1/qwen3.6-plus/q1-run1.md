# 基于分解骨架的最终调研答案

## 文献对象（F1）

- Shannon, C. E. (1948). "A Mathematical Theory of Communication." *Bell System Technical Journal*, 27(3), 379–423（Part I，1948-07）；27(4), 623–656（Part II，1948-10）。**[待研究假设 G1]**
- 重印版：Shannon (2001), *BSTJ* 80(1), 5–21（页码不同，引用勿混用）。
- 公开全文（待核验 G4）：https://cm.bell-labs.com/cm/ms/what/shannonday/shannon1948.pdf

## 核心贡献逐项（F2）

1. **通用通信系统模型**（F2.1）：信源→编码→信道→解码→受信者五段式，与具体物理实现无关；区分两类误差（Type A 传输错误 / Type B 映射选择不当）与两类改进（改进编码 vs 改进传输）。论文骨架，后续定量结果均建立其上。
   来源：Part I §1–§5（章节号 **[待研究假设 G2]**）。

2. **信息熵的定义**（F2.2）：H = −Σ pᵢ log pᵢ（底数 2，单位 bit）；与联合熵、条件熵 H(X|Y)、互信息 I(X;Y)=H(X)−H(X|Y) 构成体系；熵 = 信源不确定性/平均信息量的度量，也是无损压缩极限。
   来源：Part I §6（**[待研究假设 G2]**）。

3. **无噪编码定理**（F2.2）：存在编码使平均码长 L 满足 H ≤ L < H + 1/n（n 为分块长度）；熵是无损压缩平均码长的下确界。
   来源：Part I §9, Theorem 9（**[待研究假设 G2]**）。

4. **信道容量定义**（F2.3）：离散无噪记忆信道 C = max I(X;Y)（bit/信道符号）；连续高斯信道的容量公式 C = W log₂(1 + P/N) **严格出自 1949 续篇**（Shannon, "Communication in the Presence of Noise", BSTJ 28:45–64, 1949），1948 篇对应为连续信道的定性/极限处理——**[待研究假设 G3，归属判断 conf 中高]**。
   来源：Part II §12–§13（**[待研究假设 G2]**）。

5. **噪声信道编码定理**（F2.3）：R < C 时存在编码使平均译码错误概率趋于 0；R > C 时不存在。信息论核心存在性结果。
   来源：Part II §11, Theorem 11（**[待研究假设 G2]**）。

6. **英语熵/冗余估计**（F2.4）：英语字母级熵约 4.1–4.7 bit/字母，按词级条件概率修正到约 **1.5 bit/字母**（**[待研究假设 G5]**）；冗余度约 50%；冗余是理解消歧与纠错的基础。
   来源：Part I §7（**[待研究假设 G2]**）。

7. **易混点澄清**（F2.5）：
   - 率失真函数（rate-distortion）的系统定义属 1959（Shannon, "Rate Distortion Theory"），**不是** 1948 篇贡献；
   - "C = W log₂(1+P/N)" 严格归属 1949；
   - 典型序列/随机编码的存在性论证（1948 Part II §13–§15）是噪声信道编码定理的证明方法，属贡献 5 的证明细节而非独立定理。
