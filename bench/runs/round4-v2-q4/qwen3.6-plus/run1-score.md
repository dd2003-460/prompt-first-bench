**注**：对照 V0 Q4 的 claude 47 分卷（Direct 通道、模型自述"没有可靠的检索工具"）：其失分主因不是"没工具做检索"本身，而是**裸 prompt 未要求声明工具缺失→模型退化为"你该去哪查"的方法建议**，一个可计分事实都没产出。V2 prompt 的"无工具必须明确声明+用训练知识完成"条款正好堵死该退化路径——本卷即为证据（同通道同模型，产出从 0 事实 → 7 条带 conf 的 claim）。若 arena 解封后可补 claude/gemini 直连 run，可进一步验证该判定。

## 判定

**80/100 = success（压线）**。V0→V2 在 Q4×qwen 本地通道：40 → 80（+40，fail→success）。注意：n=1、评审为执行者单评（探索性），且 V2 流程增益部分来自执行者自身知识水平（模型 = 评分者同模型），存在自评偏倚风险；正式结论需 arena 通道补 run + 盲评。
