- → **构念错配成立**：top-5 W3 判据实际测量的是「judge 认为罕见的节点」，gold 判据要求的是「理论瓶颈/订正节点」，两个构念的重叠度本身未验证。

### F4 · 判据层 — 超几何严格度量化

n=31、k=5（gold）、抽 r=5（top-5）：E[X] = 5×5/31 = 0.806；P(X≥3) = [C(5,3)C(26,2)+C(5,4)C(26,1)+C(5,5)]/C(31,5) = [10×325+5×26+1]/169911 = 3536/169911 ≈ **1.99%**。

- 即随机权重下 top-5 命中 ≥3 gold 的概率约 **1.99%**（精确值 0.019899，超几何 n=31,k=5,r=5）——判据设计上是「极严」的，3/5（旧 judge）本身就接近显著边缘，1/5（新 judge）落在 P(X≤1)≈82.7% 区间内。
- 双 judge top-5 diff：old {N-3.2.2, N-3.2.4, N-2.1, N-2, N-1.1.3} → new {N-4, N-1.1.3, N-5, N-3.2.4, N-2}；进出 3 席（N-3.2.2/N-2.1 出，N-4/N-5 进），gold 计数 3→1 完全由这 3 席交换决定。
- N-4 进 top-1 的原因：p̃ 0.42→0.25 → w2 2.2515→3.0（w1=5.0 满值不变，w3 = 5.0×3.0 = 15.0 登顶）。新 judge 把 N-4 判得更罕见，恰好把它推上第一。这是「碰巧修正对了方向」（N-4 确实是 gold），说明偏差并非单向有害，但不可依赖。

## 暂定结论（供 02.5 对抗核验）

1. **F1 公式层排除**（62/62 精确一致）。
2. **F2 p̃ 估计层是主根因**：新 judge 的保守下界效应（零命中节点抬 p̃≥0.3）直接制造了 top-5 中的 2 个非 gold 席位（N-1/N-2），同时把 2 个 gold（N-3.2.2/N-2.1）挤出 top-5。
3. **F3 gold 标注层存在独立的结构性问题**：gold 口径（瓶颈/订正）与 W3 测量的构念（罕见度）不等价，即使 p̃ 完美无偏，top-5≥3/5 判据也不保证通过——这是判据设计问题，不是数据问题。
4. **F4 判据极严**（随机基线 2.08%）：单 judge 的 3/5 或 1/5 都不足以定论，需要第三 judge（R5.2-third-scorer）或改判据（如 top-10 口径 / AUC 口径）。
