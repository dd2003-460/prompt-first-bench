## 攻击 1 — 「PASS 是空转：98/98 全过 = 没查出任何问题，goal 白做」

**驳回**。验证链补环本身就是产出：TASK-ablation Step 1 的 verbatim 硬约束此前**从未被机判过**（o3-claim-list §3.2 只查了数值泄漏方向），r141 又把它确立为新 rejudge 数据的 schema 硬约束——标准不对称（新数据受检、旧数据免检）在 M1 identity 锚点与 FM-2 分母上构成未排除风险。本 goal 把该风险从「无证据排除」变为「exit 0 实证排除」。另附真实负面发现（27 不可复现）。同 r130/r131 先例：PASS + SIGNAL/发现 ≠ 空转。

## 攻击 2 — 「连续子串检查太宽松：允许取半句/跨标点拼接片段，不满足『句子』语义」

**部分成立（已预注册）**。X1 已显式登记：「句子」→「连续子串」是从严机判化选择中的**较宽一侧**（比整句边界宽松，只禁改写与拼接；比「任意字符集重排」严格）。语义相关性（evidence 是否支持该 node 命中）本就不可机判（01 §3 不做的事第 1 条），机器层只能保证出处真实性。若成璐要求整句边界对齐，属口径升级 → 需新 goal 改判定语义，不在本 goal 静默收紧。

## 攻击 3 — 「C4 只在 C2 FAIL 时触发 = 逻辑漏洞：evidence 同时存在于所属 run 和其他 run 时，无法区分 judge 抄的是哪个 run」

**驳回（按 X2 预注册）**。C2 PASS 意味着 evidence 确实出自所属 run——即使其他 run 也写了相同短句（11 组合法重复，如「3090=350W」各 run 独立推导得出），归属所属 run 完全成立，不存在张冠李戴事实。张冠李戴的定义就是「出处错误」——出处正确时诊断无对象。全局唯一性检查会把 11 组合法 cell 全部误报，X2 已预先排除该实现。

## 攻击 4 — 「V1 口径锁定是事后合理化：三个口径都不等于 27，你挑了对自己最方便的那个」

**驳回**。V1 锁定理由在 02 F3 + 02.5 X3 中**先于实跑**预注册：(a) 与仓库内既有 assert-o3-claim-list.py 同源——脚本间双源漂移比「哪个口径更接近 27」危害更大（同一数字两个脚本算出两个值会摧毁回归基线可信度）；(b) V1 是最严黑名单（token 必须出自节点自身行）。且关键事实：**没有任何口径能复现 27**——「挑方便的」不成立，因为 27 在所有候选里都不存在。勘误候选照导，处置权在成璐。

## 攻击 5 — 「mutation test 用脚本副本 + 路径替换，测的不是交付物本体」

**驳回（附注记）**。副本与交付物逐字节一致（read_text 后仅替换一行 HIT_MATRIX 常量），测毕删除；四场景断言均针对 stdout 关键行 + exit code。首版 /tmp 放置因 parents[4] 深度不足 IndexError——已在 04 A3 如实记录为脚手架问题并修复（同深度放置）。残余风险：HIT_MATRIX 那一行的替换本身若写错会测偏——但替换目标字符串在文件中唯一（grep 可证），且 M1-M4 的 FAIL/SIGNAL 行内容各不相同，互相交叉印证。

## 攻击 6 — 「C3 阈值 40 是拍脑袋：TASK-ablation 原文『≤40字』的『字』是汉字还是字符？」

**部分成立（已预注册）**。「字」vs「字符」歧义真实存在——本实现用 Python `len()`（Unicode 码点数），对纯中文文本 1 字 = 1 码点，对含 ASCII 的混合文本（如「decode ≥ 20 tok/s」）1 汉字 < 1 码点不等价于 1 字。但 C3 定位是 **SIGNAL 非门禁**（01 §2 预注册：惯例超界留人工裁量），且 live data max len=38 零触发——该歧义在当前面**无实际影响**，仅在变异/未来数据 >40 码点时才显现，届时 SIGNAL 由人裁定即可。若需精确「汉字计字」口径 → 新 goal。

## 攻击 7 — 「h 值非法分支（h∉{0,1}）返回 FAIL 但未在 01 阶段 C1-C5 表中预注册」

**驳回（防御性设计披露）**。该分支处理的是**结构损坏**（JSON 层面 h 字段非法），不是判定语义——03 预注册规则 5 已声明「结构损坏 fail-loud」。live data 中 h 全为 0/1（F2 统计 98+150=248 全覆盖），该分支当前面不可达，与 C3/C5 同属防御性代码。01 表覆盖的是判定语义空间，结构完整性检查属脚本健壮性范畴，两者分层合理。

## 攻击 8 — 「A4 说『27 是巧合非溯源线索』（run1/N-3.2.1 evidence 含 token 27）——这是 circular reasoning：你在用失实数字解释失实数字」

**驳回**。该注记的本意恰相反：排除一个**看似诱人实则无效**的溯源假说（「27 来自某条含 27 的 evidence」）。三口径枚举（13/34/35）+ 差异来源抽样已穷尽落盘口径空间，27 无对应口径——注记只是防止读者把 V1 清单里的 '27' token 误读为「找到了 27 的来源」。逻辑方向是**证伪**而非循环论证。
