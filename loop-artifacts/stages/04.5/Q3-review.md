## 8. 反方复核（挑战结论）

### 挑战 1："自托管比 API 便宜 5-8 倍"是否忽略了人力成本？

**反方论证**：自托管需运维工程师（薪资 $50k-100k/年），分摊到 token 成本可能翻倍。

**回应**：
- Gold Q3 口径："只算框架带来的增量成本差异；`c_hour` 常数项在排名中抵消" —— **框架选型不含人力**
- 运维成本 N-4 作为**次级 tie-breaker**，仅在吞吐差 <10% 时生效
- 若纳入人力：假设 1 FTE $80k/yr = $9.13/hr，分摊到 3.24M tok/hr = $0.0028/1k_tok，**仍远低于 API $0.63-0.90/1k_tok**
- **结论不变**：自托管在规模化时成本优势压倒性

### 挑战 2：SGLang 首选是否过度依赖单一博客的 ITL p99 数据？

**反方论证**：ttlab 单一来源，测试条件未完全标注，可能不具备普适性。

**回应**：
- 执行日志已标注"量化弱、定性强"，敏感性分析显示 **+5% 增益即为 SGLang/vLLM 分水岭**
- 机制支撑：RadixAttention + cache-aware scheduling 理论上在高并发/前缀复用场景优于 vLLM 的 PagedAttention + 普通调度
- **决策规则已内化不确定性**：增益 ≤5% 时自动回退 vLLM，**无盲目押注风险**

### 挑战 3：题面"固定 GPU RTX 3090×4"是否意味着硬件已采购（沉没成本），决策应只看边际电力成本？

**反方论证**：若硬件已买，`c_hour` 仅含电力 $0.15/hr，自托管优势更大；若未买，需含折旧。

**回应**：
- 执行日志提供**双视角**：边际成本（决策相关，$0.40/hr）与全包成本（报告绝对值，$0.80/hr）
- 两视角下**排名一致**，自托管均远优于 API
- **决策稳健性不依赖折旧会计选择**
