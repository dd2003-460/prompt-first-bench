## 反方质询（逐条对 02 暂定结论）

### Q1 · 「形式一致率 100%」是否虚高——S1 只查了 h=1，漏判方向完全没覆盖？
**攻击**：抽检 75 cell 里 40 个是 h=0，但 S1 只对 35 个 h=1 做 evidence 核验。h=0 cell 没有 evidence 可查（政策就是 null），所以「一致率 100%」实际只覆盖了命中方向。如果某个 run 系统性漏判（该 hit 的没 hit），S1 一个都抓不到。拿这个数当「一致率」交付有误导性。
**回应**：成立，这是 S1 口径的固有边界而非执行缺陷。修正表述：交付物中明确写「**形式一致率仅覆盖 h=1 方向（evidence 锚点有效率 35/35）**；h=0 方向（漏判）无法用逐字核验覆盖，需语义级重判」。同时补充一个间接证据缓解：8run 全量 hr 分布（0/8 到 8/8 连续存在，31 节点中 13 个非零命中）说明矩阵不是「全 0 或全 1」的退化形态——但这不能替代逐 cell 的漏判检查。最终口径：形式一致率（h=1 方向）= 100%，语义一致率 = unverified，两者分开陈述不合并。

### Q2 · ρ=0.456 < 0.5 触发 LOW-CORR，但 n=30 且 p̃ 是离散粗粒度值（0.015/0.03/0.05…），相关弱是否只是分辨率伪影？
**攻击**：p̃ 取值集中在少数几个档位（大量 0.5/0.55/0.6/0.65），hr 也只有 9 个可能值（k/8）。两个低基数变量的 Spearman 天然被并列秩压低，0.456 可能不代表「系统性偏差」，只代表「双方都是粗刻度」。
**回应**：部分成立。两点核查：(a) 即便只看「方向一致性」——p̃ 高低排序 vs hr 高低排序的逆序对比例，ρ=0.456 对应的 Kendall τ 约 0.36，仍低于「无信息」直觉预期；(b) 更强的证据不在相关系数而在 **S3 二项式红旗**：N-1（p̃=0.45, 0/8）和 N-5.3（p̃=0.05, 8/8）这种单节点级别的统计不自洽，不受分辨率伪影影响——单个节点的先验与 8 次观测差了两个数量级的概率。修正：LOW-CORR 信号降级为「提示性」（受粗刻度限制），矛盾清单 C1 的证据主体改为 S3 的三个红旗节点 + ρ 作为旁证。

### Q3 · C4「W3 判据对 p̃ 敏感」算不算 G1 的矛盾？会不会越界抢了 G2 的活？
**攻击**：任务书 G1 的「矛盾」指 8 run 之间、hit-matrix 与 prior-estimates 之间的判定矛盾。C4 说的是「换 judge 后 top-5 翻转」，那是构念效度问题，是 G2 的任务书范围。G1 列 C4 是越界。
**回应**：部分成立，边界需要划清。保留 C4 的理由：它的**事实层**（同一 hit-matrix 下双 judge top-5 diff = 3 席交换，gold 计数 3→1）是 G1 的 F3c 信号直接产出的观测，属于「prior-estimates 与 blindtest 的内部一致性」审计范围——这正是任务书 G1 第三项「hit-matrix 与 prior-estimates 的内部一致性」的字面要求。**解释层**（为什么翻转、根因在哪）才是 G2 的，G1 只做移交不做解剖。修正：C4 条目限定为「一致性观测 + 移交声明」，不写根因判断。
