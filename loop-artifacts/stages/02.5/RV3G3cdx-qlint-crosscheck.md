## X2 裁定 — (c) 分段数下限：**按状态位分派，不按区分派**

独立复核发现 02 S5 漏检：低 pipe 行不止存在于「已完成」区——新导出候选区 L37/L40/L41/L42/L43/L46/L47/L48/L49/L50/L51 共 11 行 pipe ≤ 1，待办区 L17-L20 型简写行 4 行在已完成区。**若规则按「区」定下限（已完成 ≥1 / 其他 ≥2），当前 main 直接 11 行 FAIL——lint 首跑即红，工具失去基线意义。**

复核这 15 行原文后确认共同特征：**全部是 `[x]` 完成行且结果注记用 `—`（em dash）或分号承载而非 `|`**（如 L17 `- [x] R5.2-evidence-packet (2026-10-30, r102: baff4b3) — 模板 v2 + packet v2...`）。而所有 `[ ]` 未完成行（11 行）pipe 全部 ≥ 2，`[~]` 行（3 行）pipe 全部 = 2。

裁定：**(c) 判据 = 「短名 token 非空（剥 `~~` 后）+ 行体含至少一个分隔符（`|` 或 ` — `）」**。即「可解析即过、不可解析才 FAIL」最小规则（01 降级条款 (c) 原话），不引入 pipe 计数下限。理由：(i) 历史合法变体实证存在（r102c 父版本 + 当前 15 行 em-dash 行），任何固定 pipe 下限都会误报存量；(ii) (c) 的目标是防「行格式崩坏到无法提出短名」（未来 append 事故），不是统一排版——排版统一超出本 goal 范围，导出候选。

## X4 裁定 — 短名 token 提取：**剥 `~~` 前后缀**
