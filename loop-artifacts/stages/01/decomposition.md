# 01 目标分解：prompt-first 是否提升成功率/质量

## 交付目标
以可复核公开证据回答 Q1–Q3；如证据不能识别因果或边际效应，给出可运行的对照实验设计。输出核心报告 `bench/verify/FINAL-VERIFY.md`。

## 正交覆盖分解
1. **总体因果效应（Q1）**：裸 prompt 与显式任务拆解之间，最终成功率/质量的差异。叶项：任务类型/难度、模型、样本数及随机性、拆解介入位置、执行器/工具环境、终点指标。研究入口：比较带与不带分解的同任务同模型实验；搜 arXiv `LLM task decomposition direct baseline success rate`。
2. **要求的边际效应（Q2）**：拆解形式；正交/完备检查；来源交叉验证；逐阶段落盘与门禁；反方复核。它们是不同干预，不可由“有 planner 的系统整体更强”相互替代。逐项消融是识别方法。入口：搜索 ablation/task decomposition/plan-and-execute 与框架源码。
3. **模型调节效应（Q3）**：模型能力等级 × 流程变体交互。需事先固定强/中/弱操作定义与模型，避免事后贴标签；跨模型系统结论只可作为线索。
4. **证据质量与偏差**：同行评审/预印本、基线同条件、样本和统计量、任务分布、框架工程混杂；GitHub 框架证明“有这种机制”，不证明效果。

## 已知 / 可推导 / 空缺
- 已知（任务书）：Rubric 18分制、success ≥80；固定五题任务集见 `rubric/scoring.md`；每条件 runs≥3；内部 C0 与 C9-plain 小样本只作待检验假设。
- 可推导：公开基准中的 planner + executor 或任务分解常与工具、训练、反馈、专用执行器一起变化，通常无法归因于提示词拆解本身。
- 待研究：同条件直接对照的效应量；正交完备与逐条要求的独立效应；模型强弱交互；公开论文适用范围。
