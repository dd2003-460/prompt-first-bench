## Q1：GPU

- 目标：在同一模型和负载下比较 H100 SXM 80GB 与 H100 PCIe 80GB 的条件化表现/成本，而不是将互联带宽当成单卡 token 吞吐。
- 冻结示例候选：SXM 与 PCIe（源于仓库实际存在的近似 Q1 题面；厂商具体支持及数字待研究）。
- 正交研究入口：① HBM 容量和速率；② 同精度、同稀疏口径的算力；③ 多卡互联；④ 供电与租用成本。硬件规格是输入，真实 workload、带宽利用率、互联开销和报价是独立缺口；成本和电力不得重复计费。
- 将每个方向递归到可核验的最小数值/假设；根可排序标量应明确公式、单位、候选口径和约束；不把理论峰值称作真实实测。
- 首查厂商原始 datasheet、云 GPU 明码价格；再找独立技术资料或报价验证高影响项。缺失时给 [GAP]，不填造数据。

## Q3：API 供应商

- 目标：相同模型、请求量与 token 口径下，排序服务费用，并明确上下文、质量、延迟、安全、地区和 SLO 的可行性边界。
- 待核验的候选冻结集：Groq、Together AI、Fireworks AI，优先选择三方都提供的相同开源模型（例如 Llama 3.3 70B Instruct，是否在售须查）；若不存在可比 SKU，显式记录变更原因并另定可比候选，不能偷偷更换。
- 正交研究入口：① 输入 token 计费；② 输出 token 计费；③ 请求规模/上下文及有效输出；④ 服务约束（速率、可用性、隐私）与业务 SLO。缓存/批处理优惠不能重复计算；不同模型质量不假设等价。
- 先查三家实时公开定价和模型文档，再找独立价格汇总核对；明确相同模型、版本、价格单位、促销/批量/缓存、地区和观察时间。
