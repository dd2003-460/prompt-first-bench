## 1. 目标与交付物

**任务**：为 30 人研发团队选一套团队文件协作/网盘方案；预算 ≤¥30,000/年；需支持 Web + macOS + Windows 客户端；核心需求 = 文档版本管理 + 细粒度权限控制；离线可用为加分项。产出可交付的选型报告（推荐方案 + 备选 + 淘汰理由 + 成本明细）。

**必须交付（缺一即半成品）**：

| # | 交付件 | 验收形态 |
|---|--------|----------|
| D1 | 推荐方案 ×1 | 产品/方案名 + 计价模型 + 年度成本 + 满足约束的逐条证据 |
| D2 | 备选方案 ≥2 | 分层（不同取舍：成本优先 / 能力优先 / 自主可控优先） |
| D3 | 淘汰理由 | 对冻结候选集内每一类/每一个被考察对象给出淘汰或保留理由，可追溯到硬约束 |
| D4 | 成本明细 | 年度 TCO（人民币），含计价单位、档位、隐藏费用（存储超额/带宽/运维工时）、汇率处理说明 |
| D5 | 证据链 | 每条关键主张带来源 URL/路径 + 快照时间戳，或显式「存在性断言-未核验」（修订②） |

**不交付（出域，见 00 §2）**：办公套件替代、代码托管、IM 平台整体选型。

## 4. 因素分解（正交顶层因素）

| # | 因素 | 边界 | 覆盖的目标部分 |
|---|------|------|----------------|
| F1 | 候选类别枚举与冻结 | 类别级（不是产品级）；冻结后增删须 02 登记（修订①） | D3 的可追溯基础 |
| F2 | 功能合规（版本管理/权限/三端/离线） | 每个被考察对象逐项判定，格子非空 | D1/D2 的筛选 |
| F3 | 成本模型与 TCO | 计价维度（人头/存储/混合）× 档位 × 隐藏费用；自托管含工时 | D4 |
| F4 | 数据主权与迁移成本 | 导出能力、锁定风险、切换成本（影响"自主可控"备选层） | D2 分层依据 |
| F5 | 部署与运维负担 | SaaS=零运维 vs 自托管=服务器+备份+升级+安全补丁 | D2 分层依据 + D4 工时项 |
| F6 | 证据链完整性 | 每主张带来源或显式降级（修订②）；矛盾进 02.5 X 清单 | D5 + M8 计分基础 |

**正交性检查**：F2（能不能用）/ F3（多少钱）/ F4（走不走得掉）/ F5（维护多累）四者独立影响决策，互不重叠；F1/F6 为流程元因素。✅

## 6. 候选集冻结声明（修订①·防漂移）

**冻结集合 C1–C5（类别级，2026-10-30 冻结）**：

| # | 类别 | 定义边界 | 示例对象（待 02 核验，非承诺） |
|---|------|----------|-------------------------------|
| C1 | 综合协同套件内置网盘 | IM/办公套件捆绑的文件模块，不单卖 | 飞书云文档/云空间、钉钉钉盘、企业微信微盘、Google Drive（Workspace）、OneDrive（M365） |
| C2 | 专业 SaaS 网盘/协作 | 独立产品，按人头/存储计价 | Dropbox Business、Box、坚果云 Team、iCloud for Business（存疑）、pCloudy Business |
| C3 | 开源自托管网盘 | 免费软件 + 自备服务器 | Nextcloud、ownCloud、Seafile、FileRun（商业内核?存疑）、Pydio |
| C4 | 轻量文件同步/共享 | 弱版本管理，主打同步/分享 | Syncthing、Resilio Sync、WeTransfer 类（大概率命中排除规则，留作对照） |
| C5 | 文档协作型（版本管理强项） | 以文档为中心而非文件为中心 | Notion、Confluence（Atlassian）、语雀、腾讯文档 |

| # | 排除 | 理由 |
|---|------|------|

| X3 | 起售即定制报价且无任何公开价格锚点的企业存储 | 命中 T7.1 X4 排除规则（价格不可核验 → 不作成本结论）；若有公开锚点则保留在 C2/C3 内核验 |
