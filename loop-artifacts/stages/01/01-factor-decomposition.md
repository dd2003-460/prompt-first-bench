## 1. 顶层因素（正交且覆盖完整）

「性价比最高的硬件系统」= 在**约束**下，从**候选集**中选出一个在**软件可行**前提下、**性能/成本**比值最优、且**风险**可接受、并匹配**负载需求**的系统。据此拆成 7 个互相正交、合起来完整覆盖的顶层因素：

| ID | 因素 | 定义（边界） | 正交性说明 | 优先级 |
|---|---|---|---|---|
| F1 | 负载需求 | 模型 + 使用场景对硬件提出的要求（与具体硬件无关） | 只描述「需要什么」，不涉及「有什么/花多少」 | 高 |
| F2 | 候选硬件供给 | 2026-10 中国大陆可得的硬件类别与对象（选项空间） | 只描述「有什么可选」，不评价价格/性能 | 高 |
| F3 | 成本 | 采购总价 + 价格形成机制与波动风险 | 只描述「花多少钱」，独立于性能维度 | 高 |
| F4 | 性能 | 实际推理能力（容量/带宽/算力/实测吞吐） | 只描述「多快多大」，独立于价格维度 | 高 |
| F5 | 软件生态与兼容性 | 能否真正跑起来、跑得好（框架/量化/长上下文/并发/驱动） | 可行性门禁，独立于价格与裸性能 | 高 |
| F6 | 可靠性与风险 | 供应/质量/技术/容量/退出风险 | 对 F3/F4 的不确定性修正，独立维度 | 中 |
| F7 | 决策框架与硬约束 | 如何定义与权衡性价比 + 不可违背的约束 | 元层：组合 F3/F4/F6 做决策，并施加红线 | 高 |

**覆盖核对**：性价比 = F4/F3（比值），受 F5 门禁（跑不起来则性价比无意义）、被 F6 修正（风险抬高有效成本/压低有效性能）、 targeting F1（不匹配需求则无效）、从 F2 中选择、由 F7 裁决。7 因素合起来完整覆盖目标，且两两正交（需求/选项/价格/性能/可行性/风险/裁决规则）。

## 3. 条件三分区

### 【人类已提供条件】（来自任务背景，未核验者标注「传闻级」）
- **H1** 时点 = 2026-10，地域 = 中国大陆市场。
- **H2** 用户已有一台 Mac 在跑 MLX 27B，约 30 tok/s。（具体 Mac 型号/内存/带宽未说明 → 见 G8）
- **H3** 真实负载 = 长上下文 30K–226K + solo + 中并发（≤8）。
- **H4** 基准模型 = Qwen3.8-27B（参数量 27B；架构细节未提供 → G1）。
- **H5**（传闻级，未核验）NVIDIA 消费卡因 GDDR7 显存涨价 + 10 月停产传闻被渠道炒高；RTX 5090 32G 据称从 ¥3.5 万炒到 ¥5.4 万水货价。
- **H6**（传闻级，未核验）Apple 于 2026-09 发布 M5 Max / M5 Ultra Mac Studio；M5 Max 最高 128GB 统一内存 / 614GB/s。
- **H7** 目标 = 性价比最高（「性价比」的量化定义未给 → G7）。

> 说明：H5/H6 是「人类提供的信息」，但其事实内容仍属**待验证假设**，本阶段不将其当作已知事实，仅作为种子假设进入 F3/F2 并挂到 G3/G4。

### 【可推导条件】（从 H1–H7 + 领域常识推导，不引入新事实）
- **D1** 27B 权重占用随量化精度近似变化：FP16≈54 GB、INT8≈27 GB、INT4≈14–17 GB。（算术推导；若 Qwen3.8 为 MoE 或非常规结构则需修正 → 依赖 G1）
- **D2** 显存总需求 = 权重 + KV cache + 激活 + 余量；KV cache ∝ 上下文 × 并发 × 层数 × KV heads。（公式可推导，系数依赖 G1）
- **D3** 226K 上下文 × 8 并发的 KV cache 将远超单张 24 GB 卡 → 「长上下文+大并发」与「小显存单卡」存在结构性张力。（定性可推导）
- **D4** LLM 推理中 decode 受显存带宽限制、prefill 受算力限制。（领域常识，具体数值待 G2/G5）
- **D5** 性价比 = 性能/成本，需同时取得 F4（性能）与 F3（成本）才可排序。（定义推导）
- **D6** 用户已有 Mac 且跑 MLX → Apple 路线存在「零迁移成本」隐含优势。（从 H2 推导）
