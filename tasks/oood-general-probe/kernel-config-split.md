# 核/配置/超参三层分离 — 剥离版核实验设计
> 起源: D 2026-11-27「能不能把非 general 的部分完全去掉」。
> 判断: "去掉"→"隔离"。域味两面性(偏置 vs 功能提示)读代码判不了, 只能三臂 2×2 测。
> 架构: 核层(纯控制流+域中性 prompt+默认超参) / 配置层(域特定示例, 可插拔) / 超参层(域标定, 核给默认)。
> 对应 D 选域/精化两阶段: 核=精化控制流(不变), 配置=选域产物(可变域)。

## 1. 为什么"完全去掉"做不到
域味焊在三处, 剥离难度递增:
1. **prompt 示例**(core-purity-audit A/B 级): 能删/改——硬件公式清单、"最优选择"框架、stochastic 例子
2. **prompt 框架假设**: 能改——P1H_INDEX L306「最优选择」预设决策/优化结构, 解释型/点估计型题会被带偏
3. **超参标定**(ObjectiveConfig): 难剥离——contribution_threshold=0.10 / max_kids_per_parent=8 / gain_threshold=0.50 全在硬件域上调过, 删了(改域中性默认)伤域内性能
结论: 核能变纯(1+2 剥到配置层), 但超参层保留"核默认+域覆盖"机制, 不是硬删。

## 2. 剥离 diff 规格(基于 core-purity-audit §3, 生成 S1 剥离版 prompt)
S1 = S0 原版 prompt 应用以下 5 处替换(其余一字不改, 保证单变量):
1. s5_state_machine.py L1565-1597 合成段: 「如 TCO 公式、roofline 公式、KV Cache 计算、故障损耗项、利用率分解等」→「如本题域内的关键公式与数值链」; 「如不同 head_dim 取值」→「如同一参数在不同节点的取值」
2. EDGE_TYPE_PROMPT L358-360: stochastic 例子「温度采样、量化噪声、batch 组成波动 / 推理稳定性←temp 采样」→「传感器噪声、队列波动、环境扰动 / 系统稳定性←同一噪声源」
3. P1H_INDEX L306: 「不同时间跨度与口径下最优选择」→「题目所问的结论/答案(决策/解释/点估计/规划皆可)」
4. P3_VERIFY L194: 「容量、比率、价格、复杂度、带宽」→「数值、比率、参数、约束量」
5. 各 L1 变体 L34 类: 「具体硬件参数」→「具体参数/数值」
超参层: S1 沿用 S0 默认超参(不域覆盖), 保证剥离只动 prompt 不动超参(单变量)。

## 4. 判决判据(预注册, 2×2 四格)
记分: 每臂每域用同 gold 判据(气象=机制覆盖/衰减速率/主导项; 硬件=Q9 既有 rubric 40 节点版)。
- **域味=污染**: S1域外 > S0域外 且 S1域内 ≥ S0域内 → 剥离正确, 域味纯有害
- **域味=域适配配置(最理想)**: S1域内 < S0域内 但 S1域外 > S0域外 → 核本来就 general, 域味是可插拔配置, 三层分离架构成立
- **域味=功能(核不 general)**: S1域外 < S0域外 且 S1域内 < S0域内 → 核离不开域味, 当前核不 general, 需重设计
- **inconclusive**: 混合/差距<噪声(单 rep 无 CI)→ 每格加到 3 rep 再判
附加: 所有臂记 LLM 调用数/token(供 C/E 计算匹配对照, 见 oood-battery-spec §1)。
