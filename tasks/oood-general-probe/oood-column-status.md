- **剥离域味未伤 OOD 表现**: S1 仍 4/4 机制覆盖(=S0=基线), L1=5 健康(3-7 带内, 无硬件模板漂移), 自发产出"机制谱系→量化速率→主导项→强度调制→环境调制→黑盒"正确分解
- 定量 claim S1(44) < S0(64), 但 S1 调用更少(151<161)且快 38%(1344<2163s) → 非"剥离变差", 更可能是 S0 多跑了 800s 堆出更多叶子
- **OOD 列结论: S1 OOD ≥ S0 OOD**(覆盖持平, 结构健康, 无退化) → 域味在 OOD 上**不是负资产**

## 待 K3(硬件域内 S0/S1/B) 补齐 2×2 右列
- 若 S1 HW ≈ S0 HW → 域味 = **无害配置**(可隔离保留, kernel general 成立)
- 若 S1 HW < S0 HW 但 S1 OOD ≥ S0 OOD → 域味 = **域适配配置**(最理想: kernel general + 域味只在域内有功能)
- 若 S1 HW < S0 HW 且 S1 OOD < S0 OOD → 域味 = **功能性**(kernel 不 general, 需重设计)
- 当前证据方向: OOD 列已排除"负资产", 倾向"无害/域适配配置"
