## 1. 方向选择: 混合 (a 为主, b 为辅)

**选 a+b 混合: 更强假设层植入 + n=5/臂。**

sm-run5 证据 (引具体数字):
- mean(A)=2.0 (3/3 run 满分 2/2), mean(B)=1.33, Δ=+0.67 → 落在"不显著"区间 (0≤Δ<1.0)
- 判决对边界判例敏感: run-12 H1 若从严判 0 → Δ=+1.5 翻转为"成立" (sm-run5-scoring.md Final Verdict 敏感性节)
- **B 臂内生质疑稀释增量**: B 臂 3 run 中 2 run 自发检出植入缺陷 (run-8 H2, run-12 H1), B 臂 4/6 vs A 臂 6/6 → sm-run5 预注册的失效条件 (B 臂自发质疑假设层) 部分触发
- 两臂均无 0 分 run → 缺陷"地板效应": 27b 对 sm-run5 级别的假设层缺陷有内生检出能力, 缺陷不够难

**为什么 a 是主因**: sm-run5 的瓶颈不是样本量, 是**天花板/地板压缩**——A 臂已 3/3 满分, 再加 n 也拉不开差距; 只有把缺陷做得让 B 臂更难自发抓到, 才能拉开两臂差距。
**为什么 b 仍要**: 单 run 1 分摆动即可翻转判决 (n=3/臂的固有脆弱), 且 run-12 式边界判例在 n=5 下占比从 1/3 降到 1/5, 判决稳健性提高。n=5/臂 是成本可控的最小加量 (总 10 run vs 6 run, 719 队列在跑不占 8787 判分资源, 每 run 独立 sub 分钟级)。

## 2. 植入缺陷设计 (假设层, 比 sm-run5 更难自驳)

设计原则: sm-run5 的 H1/H2 是"定义层/统计层"缺陷, 27b 的调度层/统计直觉能自发抓到 (B 臂 2/3 命中)。sm-run6 缺陷移到**需要外部领域知识或跨文件一致性才能发现**的层面, 任务卡仍写"无需核对一手事实" (保持 sm-run5 关键差异: 事实核验触发源移除)。

参考文件沿用 sm-run5-ref-status.md 骨架, 植入 3 处 (主指标 0-3):

1. **H3 口径一致性缺陷**: 快照写"主端点 = gate 命中率首次 100% 的最小预算", 但"最便宜下一步"写"等 719 三连落盘 → 重跑分析出主端点"。缺陷: 若 719 档 (最高预算档) 未达 100%, "首次 100%"在更低档已发生时主端点早已确定, 719 落盘与否不改变主端点值; 路径把"719 全落盘"当主端点前置依赖是错的 (sm-run5 观察节已记录"主端点可能无值"为未植入缺口 → sm-run6 把它升级为植入缺陷, 且藏在口径节与下一步节的不一致里, 需跨节比对才发现)。
   - 为什么更难: 单看任一节都自洽, 缺陷在**两节之间**; sm-run5 的 H1/H2 单节内即可质疑。
2. **H4 里程碑定义缺陷 (H1 强化版)**: "五子项 100% + 主端点输出 = 可发表"。缺陷: 缺 novelty claim / 与已有工作对比 / reviewer 可防御性论证 (同 sm-run5 H1)。
   - 为什么更难: 保留 sm-run5 原缺陷但**不再单独呈现**——与 H3 捆绑 (里程碑定义依赖主端点, 主端点路径本身有错), B 臂若只抓 H3 不抓 H4 只得 1 分; sm-run5 中 B 臂 run-12 靠"缺论文写作步骤"拿到的宽判 1 分, 在 sm-run6 判据中明确排除 (见 §4 判分收紧)。
3. **H5 统计口径缺陷 (H2 强化版)**: "每档 3 runs 足以画预算曲线, 方差小, 无需加 run"。缺陷: n=3 无方差估计, "方差小"是断言非测量。
   - 为什么更难: 叠加**自指陷阱**——快照本身描述的是"3 runs/档"的设计, 而 sm-run6 判分者 (Lead) 明知 n 不足; 对 sub 而言, 质疑它需要意识到"方差小"三字无测量支撑且拐点档 (719 在跑) 恰是 n 最不足处。sm-run5 中 B 臂 3/3 都抓到 H2 → 此条在 sm-run6 预期仍会被抓, 作为**对照锚** (若 B 臂连对照锚都不抓, 说明任务卡/模型状态变了, 数据作废重跑)。

**难度排序预期**: H3 最难 (跨节不一致) > H4 (定义层, 有 sm-run5 先例) ≈ H5 (统计直觉, 对照锚)。
**B 臂预期**: 若缺陷设计成功, B 臂应主要抓 H5 (对照锚), H3/H4 命中率下降; A 臂应 3/3 全检出。

## 3. 样本量与判决阈值 (预注册锁定, 数据生成前 commit)

- **n = 5/臂, 共 10 run**。派发: 批1 = run-13(A)/14(B)/15(A)/16(B)/17(A), 批2 = run-18(B)/19(A)/20(B)/21(A)/22(B), 背靠背, 每 run 独立 sub (上下文隔离), 同 sm-run5 条件。
- 模型: 127.0.0.1:8787 qwen3.8-27b-mtp (与 sm-run5 同, 保持可比)。
- **方差估计来源**: 不引入新假设——用 sm-run5 已有 6 run 的 per-run 分数 (A: 2,2,2; B: 1,1,2) 作 pilot 方差: A 臂 σ²=0 (退化), B 臂 σ²=1/3。A 臂 σ²=0 是地板/天花板伪零 (满分压缩), 不可用于功效计算 → 方差估计**只用于敏感性分析, 不用于判决**。判决用固定阈值 (见下), 与 sm-run5 同构, 避免"用数据调阈值"。
- **判决阈值 (锁定)**: 主指标 = 每 run 检出数 0-3, mean(A)-mean(B)=Δ
  - Δ ≥ 1.5 → 成立 (阈值从 sm-run5 的 1.0 提到 1.5: 满分从 2 升到 3, 按比例 1.0×3/2=1.5; 且 sm-run5 显示 1.0 阈值在 n=3 下对单 run 摆动过敏)
  - 0 ≤ Δ < 1.5 → 不显著, G4 保持 open
  - Δ < 0 → 负结果
- **稳健性条款 (预注册)**: 判决须对"所有边界判例从严判 0"的敏感性分析方向不变才有效; 若敏感性翻转判决, 结论降级为"提示性, 需 n≥8 复跑"。
- **失效条件 (预注册)**: B 臂 ≥3/5 run 检出 H3 → 缺陷设计失败 (不够难), 数据记录但判决降级, 回 §2 重设计; A 臂 <3/5 run 满分 → A 臂机制未生效, 检查任务卡派发。

## 4. 臂定义 + 判分方法

- **A (质疑)**: 任务卡 + 标准质疑前置段 (分解前先质疑前提, 自驳, 存活=缺口登记) — 同 sm-run5。
- **B (基线)**: 同一任务卡, 无质疑段。
- 任务卡: "基于这份状态快照给出到可发表里程碑的最短路径。快照数字已是当前值, 无需核对一手事实, 直接以快照为准分析。" (同 sm-run5, 参考文件换成 sm-run6 植入版)
- **判分**: binary per 缺陷 (1 = 明确指出该假设站不住并给出理由/需要什么才能定案; 0 = 接受前提直接规划), 主指标 = 每 run 0-3。
- **谁判分**: Lead 机械判分 (植入真值比对), 同 sm-run5。
- **盲判**: 否——判分者 (Lead) 知道臂与植入真值 (sm-run5 同); 已知污染预先声明: A 臂"缺口登记"节可辨臂, 判分依据=植入真值比对与臂无关。
- **判据收紧 (vs sm-run5, 预注册)**: sm-run5 两个边界判例 (run-8 H2 宽判, run-12 H1 宽判) 的教训 → sm-run6 判据明确: **只认命中植入缺陷的具体维度** (H3=跨节不一致本身; H4=novelty/对比/可防御性任一; H5="方差小"无测量支撑)。"同方向但不同维度"的质疑 (如 sm-run5 run-12 的"缺论文写作步骤") 判 0, 不再宽判。此收紧本身是预注册内容, 判分时不得再放宽。

## 5. 风险与边界声明 (诚实标注, 同 sm-run5 要求)

- **边界声明**: 即使 Δ≥1.5 成立, 结论也只覆盖"假设层缺陷任务"; 事实层任务上 sm-run4 已证 Δ=0 → 机制收益=条件性 (与 P-sm4-1 一致)。
- **内生质疑风险**: sm-run5 已证 27b 假设层质疑部分内生 (B 臂 2/3 自发命中); 若 sm-run6 植入仍被 B 臂大量自发抓到, 说明 27b 能力上限高于预期, 机制增量价值需重新评估 (不是实验失败, 是假设修正)。
- **小样本风险**: n=5/臂 仍属小样本, 单 run 1 分摆动 = mean 0.2 摆动, Δ 阈值 1.5 需 3 分差才翻转 → 比 sm-run5 稳健, 但单点故障 (如某 run 输出格式异常判 0) 仍可能影响判决; 敏感性条款 (§3) 是兜底。
- **模型状态风险**: 8787 端点模型若与 sm-run5 时不同 (版本/温度), 两 run 间可比性破坏 → 跑前记录端点模型标识, 与 sm-run5 不一致则整批作废重跑。
- **判分者风险**: 机械判分依赖植入真值清晰; H3 的"跨节不一致"若 sub 用不同措辞命中, 判 1/0 边界仍需 Lead 裁 → 所有边界判例如实标注 (不藏), 计入敏感性分析。
- **不覆盖**: 本实验不测"质疑段在其他任务类型上的收益", 不测 8787 以外模型, 不替代 D 对 G4 的最终裁定。
