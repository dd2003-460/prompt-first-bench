## 核心命题（一条规则导出全部）

无损性不是一个度量，是**一个压缩态 C 在两个方向上的往返误差**：

```
        向后（复现）              向前（预言）
  现象 X ──压缩C──▶ 压缩态 M ──解压D──▶ 重建链 X'     （d(X,X') 小 = 复现无损）
                          │
                          └──展开D'──▶ 新预言 P₁..Pₙ  （P 命中 held-out = 预言无损）
```

D 说"唯一完整复现"与"预言质量"是**等价说法**——因为二者是同一个不动点 D∘C=恒等 的两个投影：
- **唯一** = 解压单射（一个压缩态只展开成一条链）→ 复现方向
- **完整** = 解压满射（压缩态不含未表达的信息）→ 复现方向
- **预言质量** = 不动点外推到未观测区的误差 → 预言方向

所以**可操作化 = 把"往返误差"落成两个正交数字**，不多不少：

| 数字 | 测什么 | 怎么算 | 对应 D 原话 |
|---|---|---|---|
| **复现误差** ε_rep | 压缩态能否唯一还原推理链 | 从 M 重建链 X'，与真实链 X 做**结构对齐**（步骤序列的编辑距离/子树匹配，非逐字） | "唯一完整复现整个链路" |
| **预言命中率** ε_pred | 压缩态能否外推新现象 | 从 M 推 N 条 held-out 预言，命中率 = 命中数/N | "预言质量" |

**压缩强度** = len(M)/len(X)（字符或 token 比）——第三个量，正交于前两个：ε 测**保真**，压缩比测**强度**。D 00:33(5)"general 就是更好的压缩描述"= 压缩比越小越 general。

三者合成**理解度**三元组 `(压缩比, ε_rep, ε_pred)`：
- 好理解 = 压缩比小 ∧ ε_rep 小 ∧ ε_pred 高
- 只 ε_pred 高 = 过拟合的插值器（背答案，没压缩）
- 只压缩比小 = 空压缩（D 01:26 警惕的"推不出可检验预言"）
- 只 ε_rep 小 = 复述机（没外推力）

## 为什么是"结构对齐"不是逐字比对

D 00:33(4) 强调"唯一"——但唯一指的是**推理链的逻辑结构唯一**，不是措辞唯一。同一机制可有多种表述（D 自己 01:04 把"选域"精确化成三步，措辞全换但结构同）。所以 ε_rep 必须在**机制层**比（步骤的角色序列：假设→校验→迁移→实验→演绎→预言），不在表层文本比。判据：两步结构对齐当且仅当它们承担相同的**信息流角色**（输入什么、产出什么、被哪一步依赖）。
