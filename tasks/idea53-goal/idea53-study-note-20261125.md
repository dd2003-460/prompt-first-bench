## §0 一分钟版本

**这套东西在说什么**：把一个判断（"这个任务快不快"）写成一棵加性树——总延迟 = 各叶子延迟之和，每个叶子延迟 = 工作量/速率^α。然后问：如果某个速率被扰动（±σ），判断（哪个叶子最慢/整体快慢排名）会不会翻转？

**得到的**：翻转概率有闭式解（Φ 函数），信息增益有二阶级数闭式（Fisher 形式），而且 σ=0 时精确归零（负控制）。

**为什么这比"跑实验数翻转次数"强**：闭式解 = 可以**预言**哪些判断在扰动下会翻转，不用真的去跑。这是"judge 加速"的接口：闭式判据说"不会翻"的判断，机械放行；说"会翻"的，才送 LLM judge 复核。

**核心张力（D 的直觉所在）**：整套闭式解依赖两个条件——① 弹性矩阵对角（扰动一个节点只影响自己）② 结构是树（无环）。这两个条件一破，闭式解就死了。所以"推广空间"的形状 = 在这两个条件附近能走多远。

## §1 数学骨架（学习起点）

### 1.1 从加性树到对角弹性

```
T = Σᵢ tᵢ                      总延迟 = 叶子延迟之和（加性）
tᵢ = fᵢ / rateᵢ^α              叶子延迟 = 工作量 / 速率^α
log tᵢ = log fᵢ − α·log rateᵢ  取对数：加性变线性
∂log tᵢ/∂log rateₖ = −α·1[i=k]  弹性矩阵 = 纯对角 ← 一切的源头
```

**关键认知**：对角性不是假设，是**结构**给的——加性树里叶子之间没有交互项，所以 log 空间里微扰不传播。这是整个闭式解的根基，也是 D① 戳中的地方（乘性结构若也可分解，对角性仍在；真正杀对角性的是**耦合**，不是拓扑）。

### 1.2 三个命题

| 命题 | 内容 | 依赖 |
|------|------|------|
| P1 | 翻转概率 P(flip) = Φ(−m/(ασ√2))，m = 两最大叶对数间距 | 对角 + 高斯扰动 |
| P2 | "深层主导"三口径（翻转率/信息量/修正）互不一致 | 无（恒真，纯逻辑） |
| P3 | 软判断 softmax(β·log t) 下信息增益 I₂ = ½(αβσ)²(1−EΣpᵢ²)，Fisher 形式 | 对角 + 二阶展开 |

### 1.3 有效域（新稿自证边界）

- **αβσ ≤ 0.4**：二阶级数的收敛域。超过后 I₂ 不再是好的近似。
- **β→∞**：硬 argmax 极限，级数必死（softmax 变 one-hot，Fisher 信息发散/退化）。
- **σ=0**：精确归零（负控制，flat-rate 实验验证 = 0，不是 ≈0）。

**学习要点**：这三条边界不是缺陷，是**资产**——审稿人问"什么时候失效"，答案已经写在论文里。大多数论文死于没划边界。

### 1.4 计算练习（D 要求"我需要计算"）

1. **手算 P1**：取 m=1.0, α=1, σ=0.5 → P(flip)=Φ(−1/(0.5·√2))=Φ(−1.414)≈0.0786。对照 `modules/F-theory/research/idea53-theory-flip.json` 的枚举值，误差应在 MC 标准误内。
2. **画相图**：横轴 m/(ασ)，纵轴 P(flip)，标出 0.5/0.1/0.01 三条线。这条曲线就是"判断鲁棒性"的标尺。
3. **I₂ 的 β 扫描**：固定 ασ=0.2，扫 β∈[0.1, 10]，画 I₂(β)。β→∞ 端看它怎么死——这就是 D④ 说的"相变"的雏形。
4. **非对角玩具**（为 G8 轴B 热身）：加一个交互项 t₁₂ = c·rate₁·rate₂，重新算弹性矩阵，看它变成什么样，P1 还能不能写闭式（预期：不能，但能写上下界）。

## §4 空白探测（D 的核心问题：现有成果没覆盖的是什么）

**我的判断（conf 0.6，待调研校准）**：

| 区域 | 覆盖状态（预判） | 依据 |
|------|------------------|------|
| 加性树上的扰动理论 | 大概率已有（可靠性/决策树稳定性） | 两个成熟领域都在做"扰动下结构稳定性" |
| 翻转概率闭式解（Φ 形式） | **可能空白**——现有工作多给渐近/数值，少给精确闭式 | 待调研验证 |
| 信息增益二阶级数（Fisher 形式）用于判断评分 | **大概率空白**——Fisher 信息用于判断评分的应用没见 | 待调研验证 |
| 精确零负控制（σ=0 精确归零）作为方法论 | **空白**——这是工程习惯不是理论贡献，但写成方法论就是贡献 | 逻辑判断 |
| 乘性可分解结构的对应物 | 排队论有 product-form，但**没人接翻转/评分** | D① 直觉，待核验 |
| 场论/RG 层面的节点打分 | **大概率空白** | D② 直觉，待核验 |

**一句话**：单点（翻转闭式/信息级数）可能是空白，但每个单点的邻居都不远——**真正的空白是"把这些邻居串成一个判断评分理论"这件事本身**。这就是"可站在其上"的定位：不发明新砖，发明新墙。
