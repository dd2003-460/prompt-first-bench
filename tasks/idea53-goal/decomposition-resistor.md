## 目标
把 #53 claim 从「一维 rate 对比」推广到「两三层树 + 串联电阻瓶颈网络」：深层节点的信息贡献 = 它把「瓶颈在哪一段」判对了多少。闭式计算，不跑实验、不用 judge。

## 模型（Lead 已定口径，subagent 照此执行）
- **树**：2 层。根 → 层1（3 分支）→ 层2（每分支 2 子节点）。共 1+3+6 = 10 节点。
- **电阻**：每节点标量 r_i > 0（抽象阻力）。从 4 硬件 spec 算：计算延迟 = FLOPs/TFLOPS，内存延迟 = bytes/bandwidth。取两者较大者为该节点 r_i。
- **瓶颈判定**：串联路径占比最大的段。B = argmax_i (r_i / Σ_j r_j)，i 在层2 的 6 个节点上。
- **浅层模型 S**：只看层1 聚合，假设层2 各 rate 相等 → 瓶颈判定粒度 = 层1（3 候选）。
- **深层模型 D**：看到层2 真实 rate → 瓶颈判定粒度 = 层2（6 候选，具体哪段）。
- **信息增益**：I(D; B | S) = H(B|S) − H(B|S,D)。B = 瓶颈位置（离散变量）。这是「深层节点对瓶颈判定的增量信息贡献」的闭式量。

## 分解树（正交子项）
1. **电阻赋值**：4 硬件 spec × workload 先验 → 每节点 r_i
2. **瓶颈判定**：闭式算 B（浅层粒度 vs 深层粒度）
3. **信息增益**：闭式算 I(D;B|S)（离散熵，bits）
4. **对照臂**：
   - flat：层2 rate 全相等 → I 应 = 0（负对照，解转发平凡性）
   - 置换：随机打乱层2 rate（N 次）→ I 应显著下降（解同义反复）
5. **general 性**：跨 4 spec 复现，I 随 rate-ratio 结构增大
6. **落盘**：脚本 + 结果 JSON + 一行结论
