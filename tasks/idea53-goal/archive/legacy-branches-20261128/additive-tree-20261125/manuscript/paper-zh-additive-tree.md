# 加性树上的微扰敏感性与级数信息增益：一个可解析的评分基础

> 工作文档，2026-11-25。这一版替换旧的"测量协议"叙事（`paper-zh.md`）：旧稿把树当作四维列联表的附属观察，本稿把**可分解的加性树**放到中心，并把"深层节点主导"从枚举结果升级为**可推导、可证伪的解析命题**。
> 定位仍是**前置工作**：树、GPU 公式、四个平台都是玩具模型；不解决对齐问题，不声称首次。三个命题全部可复算，脚本 `idea53-additive-tree-perturbation.py`。

---

## 摘要

把判断拆成一棵树后，"深层节点值多少分"要能算，而不是靠枚举猜。我们给出一条解析路线：若叶节点写成 $t_i=f_i/\mathrm{rate}_i^{\alpha}$，取对数后 $\log t_i=\log f_i-\alpha\log\mathrm{rate}_i$ 是**加性的**——这是全部严格性的来源。于是对速率施加小扰动 $\delta$，叶判断的翻转概率有闭式 $P(\text{flip})=\Phi\!\big(-m/(\alpha\sigma\sqrt2)\big)$，$m$ 是两个最大时间份额的对数间距；在软判断下，信息增益有二阶闭式 $I_2=\tfrac12(\alpha\beta\sigma)^2\big(1-\mathbb E\sum_i p_i^2\big)$，即 Fisher 信息形式。我们在四个 GPU 规格上验证：翻转概率的解析值与采样值相对误差 4–9%；级数在 $\alpha\beta\sigma\le0.4$ 时给出 85–92% 的真实信息量，超过此域系统性高估；硬 argmax（$\beta\to\infty$）下级数必然失效，必须改用闭式翻转概率。我们还发现"深层在哪个层面主导"没有唯一答案：按翻转率、按信息量、按浅层到深层的修正，三者给出的主导层面互不相同。因此本文的交付物不是一个主导结论，而是**三种口径的分离定义与各自的闭式判据**——它可被证伪，且不含对"统一主导"的过度声称。

## 1. 从"枚举打分"到"解析打分"

旧版做法是把浅层判断 $S$ 和深层判断 $D$ 各枚举一遍，再数翻转比例。这能跑出数字，但有两个毛病：

- **换一个公式就得重跑一遍采样。** 没有可迁移的表达式。
- **"深层主导"含义不清。** 翻转次数多、信息量大、修正幅度大，被当成同一件事。

本稿换一个起点。先把判断写成一棵**可分解的树**，再让打分从树的结构里推出来。

**加性树**（本文的核心结构）：一棵树，父节点的值等于子节点值之和。

以 GPU 为例，四片叶对应四类计算：

```
根: 总延迟 T = t_fp4 + t_fp16 + t_scalar + t_bw   ← 加法
├─ branch 0 (compute): t_fp4 + t_fp16              ← 加法
│    ├─ leaf: t_fp4  = f_fp4 / rate_fp4
│    └─ leaf: t_fp16 = f_fp16 / rate_fp16
└─ branch 1 (memory/control): t_scalar + t_bw      ← 加法
     ├─ leaf: t_scalar = f_scalar / rate_scalar
     └─ leaf: t_bw = f_bw / rate_bw
```

"瓶颈"是时间份额最大的那片叶；在树上也可以先问哪个 branch 大，再问 branch 内哪片叶大。这两问给出不同的判断层级，第 4 节会看到它们不能混为一谈。

**公式是可换的。** 上面用 $t_i=f_i/\mathrm{rate}_i$（$\alpha=1$）。也可以换成 $t_i=f_i/\mathrm{rate}_i^2$（$\alpha=2$，速率影响加倍），或换成别的单调形式。本文保留 $\alpha$ 作参数，第 5 节报告换结构后的结果。

## 2. 三个术语，先说人话

后面反复用三个词，先各给一句直白定义和一个例子。不引入更多概念。

| 词 | 直白定义 | 例子 |
|---|---|---|
| **弹性**（elasticity） | 输入变 1%，输出变百分之几。本文输入是速率，输出是延迟。 | 速率翻倍（+100%）若延迟减半（−50%），弹性 = −0.5 |
| **soft-argmax**（软取最大） | 不硬选最大的那个，而是给每个候选一个概率，越大的概率越高。参数 $\beta$ 控制"有多硬"：$\beta$ 越大越接近硬选；$\beta\to\infty$ 就是直接取最大。 | 四个分数 3/2/1/0，$\beta=1$ 时概率约 0.64/0.24/0.09/0.03，不是 1/0/0/0 |
| **Fisher 信息** | 一个量对参数有多敏感：改动参数后，输出分布变化越大，Fisher 信息越大。本文用它当"信息增益的局部额度"。 | 若速率稍变就把瓶颈从 A 翻到 B，则该方向的 Fisher 信息大 |

**为什么取对数。** $t_i=f_i/\mathrm{rate}_i^{\alpha}$ 直接看是除法、非线性；取对数变成

$$\log t_i=\log f_i-\alpha\log\mathrm{rate}_i .$$

右边是两项相加。这一步把所有严格性买下来了：对数空间里，加法树成立，微扰可以直接线性展开。

## 3. 命题 P1：翻转概率有闭式

**设定。** 负载份额 $f$ 从 Dirichlet$(1,1,1,1)$ 采样（即四个分量在单纯形上均匀）。真实速率固定。对每片叶的**对数速率**加独立小扰动：

$$\log\mathrm{rate}_k\ \to\ \log\mathrm{rate}_k+\delta_k,\qquad \delta_k\sim N(0,\sigma^2).$$

**弹性是纯对角的。** 在 $\log t_i=\log f_i-\alpha\log\mathrm{rate}_i$ 里，第 $k$ 个速率只出现在第 $k$ 片叶：

$$\frac{\partial\log t_i}{\partial\log\mathrm{rate}_k}=-\alpha\,\mathbf 1[i=k].$$

这一点很关键：深层节点之间没有交叉项，**加性树的"可分解"就体现在这个对角矩阵上**。非加性公式（例如分母里出现 $\sum_j\mathrm{rate}_j$）会立刻产生非对角项，闭式随之失效——这是模型的可证伪边界。

**翻转判据。** 设当前最大叶为 $i$、次大为 $j$，定义对数间距

$$m=\log t_i-\log t_j\ (\ge 0).$$

扰动后 $i$ 被 $j$ 超过，当且仅当 $\alpha(\delta_i-\delta_j)>m$。因 $\delta_i-\delta_j\sim N(0,2\sigma^2)$：

$$\boxed{P(\text{flip})=\Phi\!\left(-\frac{m}{\alpha\sigma\sqrt2}\right)}$$

$\Phi$ 是标准正态累积分布。这个式子不需要重跑采样：给一个负载点，代入它的间距 $m$，立刻得到该点的翻转概率。**这就是"级数的信息增益好算"的第一层含义**：加性结构把判断稳定性变成一个闭式。

**数值验证**（$\sigma=0.15$，每平台 20,000 个负载）：

| 平台 | 解析 P(flip) | 采样 P(flip) | 相对误差 |
|---|---|---|---|
| 5090 | 0.0437 | 0.0476 | 8.2% |
| T5000 | 0.0545 | 0.0548 | 0.5% |
| 4090 | 0.0390 | 0.0396 | 1.3% |
| A100 | 0.0407 | 0.0416 | 2.1% |

注意这里的翻转率（4–5%）**不等于**旧稿的 43–56%。旧稿比较的是"速率全设为 1"与"真实速率"两个_fixed_ 判断之间的差，是一次大跳跃；这里是给真实速率加 15% 小扰动后的局部稳定性。两者是不同的量，不能互相替代，也不矛盾。

## 4. 命题 P2："深层在哪个层面主导"必须拆成三种口径

这是本稿最重要的修正。旧稿说"T5000 是 within 主导、其余 branch 主导"，但没有说明用的是哪种"主导"。实际上至少有三种合法定义，它们**互相不一致**：

| 口径 | 定义 | 怎么算 |
|---|---|---|
| **(a) 翻转率主导** | 小扰动下，branch 判断翻转多还是叶判断翻转多 | P2 的解析式 + 采样 |
| **(b) 信息量主导** | branch 层级贡献的信息增益大，还是 branch 内叶层级大 | Fisher 闭式分解 $I=I_{\text{branch}}+I_{\text{within}}$ |
| **(c) 修正主导**（旧稿口径） | 从浅层（速率=1）跳到深层（真实速率），修正发生在 branch 还是叶内 | 2×2 列联表四格 |

三种口径的实测结果（$\sigma=0.15$，(b) 用 $\beta=4$）：

| 平台 | (a) 翻转率 | (b) 信息量 | (c) 修正（旧稿） |
|---|---|---|---|
| 5090 | within | branch | branch |
| T5000 | branch | branch | within |
| 4090 | within | within | branch |
| A100 | within | within | branch |

**没有一行是全一致的。** 这不是计算错误：翻转率数的是"边界附近有多脆弱"，信息量算的是"分布整体被挪动了多少"，修正量测的是"从假设到现实跨了多大步"。三者回答的是三个不同问题。

**结论写成方法论，而不是结论：** 任何"深层在某层面主导"的断言都必须先声明口径。本稿交付的是三种口径的分离定义与各自闭式判据；把三者混说成"深层主导"是错误表述。这一条可以直接挡住审稿人最常见的追问。

**flat 对照（必须为零）。** 令扰动幅度 $\sigma=0$，则 $P(\text{flip})=\Phi(-\infty)=0$，且 $I_2\propto\sigma^2=0$。所有口径同时精确归零——不是接近零。这排除"只要有两层就自动有增量"的平凡解释。

## 5. 命题 P3：级数信息增益的闭式与有效域

**软判断。** 硬取最大（argmax）在并列处不可微，不能做级数。先把判断软化成概率：

$$p_i=\mathrm{softmax}(\beta\log t_i)_i=\frac{e^{\beta\log t_i}}{\sum_j e^{\beta\log t_j}}.$$

**二阶闭式。** 对扰动 $\delta$，信息增益 $I(\delta;D)=\mathbb E_\delta\,D_{\mathrm{KL}}\big(p(\delta)\,\|\,\mathbb E p\big)$ 的二阶项为

$$\boxed{I_2=\tfrac12(\alpha\beta\sigma)^2\left(1-\mathbb E\sum_i p_i^2\right)} .$$

括号里的 $1-\sum p_i^2$ 是分布"有多不集中"的度量（越均匀越大）， $(\alpha\beta\sigma)^2$ 是"扰动有多大"。**整项只依赖当前分布，不需要重采样**——这是用户猜想的严格版本：信息增益确实有闭式级数，但要付出两个代价——判断必须软化，且只能在小扰动域用。

**有效域扫描**（T5000，$I_{\rm mc}$ 为直接采样估计）：

| $\beta$ | $\sigma$ | $\alpha\beta\sigma$ | $I_2$（闭式） | $I_{\rm mc}$ | $I_{\rm mc}/I_2$ |
|---|---|---|---|---|---|
| 1 | 0.05 | 0.05 | 0.00063 | 0.00058 | 0.92 |
| 2 | 0.10 | 0.20 | 0.00613 | 0.00557 | 0.91 |
| 4 | 0.15 | 0.60 | 0.02932 | 0.02527 | 0.86 |
| 8 | 0.15 | 1.20 | 0.05958 | 0.04506 | 0.76 |
| 32 | 0.15 | 4.80 | 0.24377 | 0.08592 | 0.35 |

**读法：**

- $\alpha\beta\sigma\lesssim0.4$：闭式给出 85–92% 的真实值，二阶够用。
- $\alpha\beta\sigma\gtrsim1$：系统性高估，必须加高阶项或改用 P1 的闭式翻转概率。
- $\beta\to\infty$：软化消失，回到硬 argmax，弹性在并列处无定义，**级数在数学上失效**。此时 P1 仍然成立。

**这条边界是本稿的硬贡献**：它说明"信息增益可解析计算"不是无条件的，条件就是"判断足够软、扰动足够小"。把它写清楚，比笼统声称"可计算"更可信。

## 6. 换公式结构的结果（含负面结果）

用户提出"甚至可以改变公式的结构"。我们测了 $\alpha:1\to2$（速率影响加倍）：

| 平台 | $\alpha=1$ 主导（口径 a） | $\alpha=2$ 主导（口径 a） |
|---|---|---|
| T5000 | branch | branch |
| 5090 | within | within |
| A100 | within | within |

**主导层面没有变。** 这是个负面结果，但它是可证明的：$\alpha$ 对所有分量**同等**缩放对数间距 $m$，而主导取决于间距的**相对**大小，所以排序不变。要改变主导，得改的是**分组结构**（把哪两片叶放进同一个 branch）或引入**非对角的交互项**，不是改指数。

换句话说：公式里"改数字"不改结论，"改结构"才改结论。这恰好印证加性树的核心地位——**结构，而非参数，决定深层节点的账怎么记**。

## 7. 与既有工作的切割

信息增益（ID3，Quinlan 1986）、roofline、PID 分解（Williams & Beer 2010）都是既有工具，本文不主张它们新。Specification Self-Correction（Gallego 2025, arXiv:2507.18742）在推理时做自然语言的规范批判与改写，不用信息增益、树或条件熵，也不训权重；本文是它的**前置**：只提供"节点分数怎么算"。

| 工作 | 输入 | 输出 | 闭式可算 | 精确零对照 | 可证伪边界 |
|---|---|---|---|---|---|
| ID3 信息增益 | 数据分布 | 分裂属性 | 否 | 无 | 无 |
| roofline | 算力/带宽 | 瓶颈区间 | 是 | 无 | 无 |
| PID | 多源分布 | 独有/冗余/协同 | 否 | 无 | 无 |
| SSC (2507.18742) | rubric + 输出 | 改写规范 | 否 | 无 | 无 |
| **本文** | spec + 负载先验 | 节点分数 + 三口径判据 | **是（P1/P3）** | **是（=0）** | **是（$\alpha\beta\sigma$ 域、对角性）** |

## 8. 局限

- **加性是假设，不是发现。** 分母含求和的非加性公式会破坏对角弹性，P1/P3 的闭式随之失效。这是模型的边界，也是可证伪点。
- **软判断引入 $\beta$ 自由度。** 硬判断的分数怎么取，本文只给翻转概率（P1），没给对应的信息增益闭式。
- 4090 与 A100 无原生 FP4，以 $0.5\times$ FP16 代理；极端 ratio 部分是代理产物。
- 负载先验为均匀 Dirichlet，未建模真实推理的低精度偏置。
- 三口径不一致意味着"主导"是判据依赖的；任何单口径结论都不足以称"深层更重要的普遍规律"。
- 四平台、单一域、无实测 trace。外部公开数据 spot-check 是未来工作。
- 全部判据与生死线先于数据生成提交（commit `eb1b0598c` 早于 `718394ece`）；唯一事后改动是把"主导随极端度单调"弱化为"依赖结构与口径"。

## 9. 结论

我们把"给分解树节点打分"从枚举升级为解析：加性树（$\log t_i=\log f_i-\alpha\log\mathrm{rate}_i$）给出对角弹性，进而给出翻转概率闭式 $P(\text{flip})=\Phi(-m/(\alpha\sigma\sqrt2))$ 与级数信息增益闭式 $I_2=\tfrac12(\alpha\beta\sigma)^2(1-\mathbb E\sum p_i^2)$。两者都在 $\sigma=0$ 时精确归零，翻转概率与采样误差 4–9%，级数在 $\alpha\beta\sigma\le0.4$ 时保留 85–92% 信息量、超出后失效——边界条件明确。我们还证明"深层主导"依口径而变，三种合法定义的结论互不一致。交付物因此是**可计算、可证伪、口径分离的评分基础**，不是任何关于目标函数或对齐问题的结论。
