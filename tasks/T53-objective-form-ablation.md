## 0. 一句话

AI 的 hack 不是"被 prompt 骗了"，是 **prompt 定义了隐式优化器的损失函数**——目标的形式（公式/文字/可加量/定性描述）决定损失景观的形状，模型找到的"最短下降路径"就是 hack 方向。所以改目标形式 = 改损失函数 = 重定向 hack。这条链每一环都有本地证据，缺的是同实验内定量对照。

## 3. 消融设计（三臂，补 E3+E4 缺口）

### 臂定义（单变量：目标形式，其余全同）

| 臂 | 目标形式 | 实现 | 状态 |
|----|---------|------|------|
| F（formula） | 可测要素 + 显式组合公式 | P1_L1_SKELETON | d34 在跑（gpu 题） |
| T（text） | ≤80 字定性描述，禁公式 | P1_L1_TEXT | textarm 在跑（gpu 题） |
| M（minimal）[新增] | 只给"完整详尽准确"三个字，不给任何要素提示 | 需写 P1_L1_MINIMAL | 待建 |

M 臂的意义：F→T 只测"公式化程度"，M 臂把信息量也降下来，才能分离**形式效应**（同样的内容，写成公式 vs 文字）和**信息量效应**（给了多少要素提示）。没有 M，F/T 的差异无法归因。

### 测量指标（每臂 n≥3 同题，跨 ≥2 题域）

1. **结构健康度**：verified 率、quotient 率、gain 序列（#31 原口径）
2. **膨胀指标**：总节点数、每层 kₙ、同义变体率（dedup 前/后比值）← E2 的直接观测
3. **正交性代理**：有效正交维度数（embedding 聚类或 LLM-judge 两两正交判定，#33 选型待定）← E4 的核心
4. **真实质量**：最终答案对 G9 gold 维度集的覆盖率（不是 S_α 分数！防 Goodhart 套娃）← E5 的验证

### 预测（先写后跑，防事后合理化）

- P1: F 臂节点数 > T 臂（公式给出可加量 → 刷量路径短）— 基于 v17 先例
- P2: M 臂节点数最小但覆盖率也最低（信息不足 → 欠分解）
- P3: 若 F 臂同义变体率显著高于 T/M，则 E4 成立（hack = 最短描述路径），且 S_α β 项（冗余惩罚）应只对 F 臂有收益
- P4: 若三臂真实质量（gold 覆盖）无差异而结构指标有差异 → 证明结构指标本身是 Goodhart 代理，进一步支持 C 模块 Q5 的"漏 4 条"判断

### 成本估算

- F/T 各 1 题（gpu）已在跑，n=1；补 n=3 需每题再跑 2 次 × 2 臂 ≈ 4 个 run
- M 臂需新 prompt + 3 题 × 3 臂 = 至少 3 个新 run
- 单 run gpu 题 ~150 节点上限，按 d34 当前速率估 2-4h/run（凭记忆，未本轮实测 [待核验]）
- 总计 ~10-16 GPU-hours，本地 27b 可过夜跑完
