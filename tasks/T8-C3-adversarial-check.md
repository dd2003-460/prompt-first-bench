# T8-C3 对抗核验任务卡（arena 反方）

## 背景
T8 prompt 消融实验的 Part C3「定向 paired runs」方案已设计完成，需过对抗核验（红线 r29：所有 idea 必须严格找 arena 核验条件和有效性，且不能盲目相信核验判断，要反驳追问直到碰理论/信息瓶颈）。

## 待核验方案（C3 可执行方案）
**目标**：验证 top-k prompt 组件对 M8（形式真实性）的因果效应。top-k 由双证据链锁定（行为层 L1 消融 + 内部状态 C1 hidden-state 探针独立收敛）：{candidate-freeze, owner-tag, evidence-url}。

**配置矩阵**（每域 4 配置 × 2 run = 8 runs/域）：
- A-full：七阶段 prompt 全量（基线）
- B-nofreeze：删 candidate-freeze 组件（预期 M8 降幅最大）
- B-noowner：删 owner-tag 组件
- B-noevidence：删 evidence-url 组件
- 阳性对照 sanity：A-full 重复 2 run（测 run-to-run 方差）

**样本**：2 域（decomp 目标分解 + pfb 一个 pipeline 阶段）× 上述配置；每配置 ≥2 run 取均值。
**度量**：M8（独立 AI 裁决防自估偏差）+ M9（成本/轮次）+ C2 行为代理指标。
**判读**：B-noX 相对 A-full 的 ΔM8，若 |Δ| > 阳性对照方差 → 显著因果效应。

## 反方要找的漏洞（重点质询方向）
1. **补偿效应**：删掉一个组件后，模型可能用其他行为补偿（如删 freeze 后更激进地探索），导致 ΔM8 低估真实效应。如何控制？
2. **统计功效**：每配置仅 2 run，2 域共 4 观测点，能否支撑"显著因果效应"的判读？需要多少 run 才有足够 power？
3. **混淆变量**：A-full vs B-noX 之间除了目标组件还有别的差异吗（prompt 长度变化、上下文位置变化）？是否该用等长填充对照？
4. **M8 裁决可靠性**：独立 AI 裁决 M8 本身有噪声，这个噪声会不会淹没组件效应？
5. **top-k 选择偏差**：top-k 是用同一批数据（L1+C1）选的，再用同域数据验证 C3，是否存在选择-验证同源偏差？是否需要 hold-out 域？
6. **阳性对照设计**：只用 A-full 重复做方差估计，是否够？是否该加一个"已知无效组件"做阴性对照？
