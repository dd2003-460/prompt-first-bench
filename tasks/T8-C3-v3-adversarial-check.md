## 反方要找的漏洞（重点质询方向）
1. **R1 三道地板的有效性**：sham 地板用"等长中性文本替换"算出的偏离度当真地板——但 sham 文本本身也会改变语义（连贯无关文本 ≠ 无语义），地板值可能系统性偏高或偏低；Spearman(偏离度, 被删 token 数) 只有 4 个点（freeze/owner/evidence/sham），n=4 的相关系数统计上几乎无意义，>0.7 否决线是否形同虚设？z-score+CI 要求 ≥3 seed，但 C1 探针通道（llama.cpp :8099）本次暂缓——R1 实际可执行性存疑，v3 说"完全行为层自洽"与"R1 决定 C1 能否参与排序"是否矛盾？
2. **R4 全因子的功效**：8 配置 × 3 域 × 每域 ≥2 run ≈ 48 runs，但主分析要估 3 主效应 + 3 两两交互 + 1 三阶交互 = 7 个对比，每格仅 2 run 的配对差 d_i 方差多大？三阶交互在 n≈6 观测点下根本不可估——预注册里 δ 和 n 由 MDE 反推，但 MDE 依据是 L1 效应量（decomp 最简任务），外推到 pfb 一阶段是否成立？降级版"4 角点"（full/none/单删 freeze/sham）能支撑哪些结论、不能支撑哪些，有没有写死？
3. **R5 judge 校准的可操作性**：κ≥0.6 是双判一致性门槛，但 M8 是连续加权分（0-1），Cohen's κ 需要二分类化——怎么切分？切分点本身引入任意性。CALM 扰动 Robustness Rate 的阈值没给（多稳算稳？）。"裁决器模型 ≠ 被测生成模型"——可用异源模型清单是什么？如果只有 arena 免费通道，异源约束如何保证？校准集"覆盖全部配置"意味着校准阶段就要跑一遍 8 配置，成本翻倍，预算允许吗？
4. **M8-truth/M8-cover 联合判读的循环风险**：cover 的分母 = "任务输入预定义的核验机会集"——这个集合由谁定义、何时冻结？如果由 Lead 在跑之前定义，Lead 知道各配置预期行为，会不会把"该配置大概率会遗漏的条目"排除出机会集从而抬高 cover？机会集定义与盲法（去除配置标签）如何兼容？
5. **选择-验证隔离的实际执行**：hold-out 域"未参与 top-k 选择"——top-k 当初由 L1（decomp 域）+ C1（pfb 工件）选出，那 hold-out 域只能从第三类任务里找；现有资产里第三个域是什么？如果找不到合格的 hold-out 域，v3 说"明确结论仅限既定两域"——但这样整个外推性声明就没了，C3 的价值还剩多少？
6. **补偿效应的检测力**：B 组同时记录 C2 行为代理（候选集漂移次数等）用于判断"真没冻结还是换了方式冻结"——但 C2 指标本身没有信度验证（零成本直接算，没做过 inter-rater 检验），拿一个未验证的代理指标去做关键判读分支，站得住吗？
