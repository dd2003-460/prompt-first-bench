## 四、统一原则 (反局部最优 = 一个循环, 不是五个实例)
**压缩 → 预测(推可检验后果) → 接地(对真现实) → 修框架(非加细节) → 重复**

- 局部最优 = 只优化静态局部指标 + 只加细节不压缩 + 不对真现实
- 逃逸 = 每轮强制 (a)压缩 (b)对真现实
- 为什么是同一个问题: "陷局部" 和 "建不出优雅模型" 是同一失败的两侧 — 局部最优=优化静态局部指标的必然产物; 优雅模型=找到少数生成性变量而非背细节。两者都被"压缩+接地"解掉。
- 预言力(可检验, 防空压缩):
  ① 只优化静态指标(无接地)→OBJHACK 签名(jac 尾厚/rework 主导) [已观测: formula gt05=14]
  ② 加接地(真检索/真测量)→降同义打转升正交 [已观测: TOOL-POC 7/10; OBJHACK 锚点 info 0.61]
  ③ 复杂域最终压到少数自由参数 (GPU≈2-3: 算术强度/FLOPs/带宽=Roofline); 压不到 ~5 参数以下=陷局部
  ④ 首稿必过细(局部最优="全覆盖"), 自审步把它压下去; 压不动=机制缺失
  ⑤ 无接地时模型自称"实测/验证"(散文模拟签名); 接地真伪必须机器可检(数字↔tool_call 溯源), 不能信自报 [已观测: GPU 探针 C 臂"实测基准值"+search=0]
  ⑥ 自审 hook 的可检签名=否定结构数上升(排除错误解释), 不是参数数下降 [已观测: GPU 探针 B 臂 Δ否定=+6.3, Δfp≈0]
  ⑦ "简单 prompt 撬动思考"不成立且负作用: 强项域(27b 参数记忆覆盖)模型不缺触发, 自发就到 Roofline; 加"尽最大努力分解"反而诱导实例枚举(局部 frame) [已观测: D 臂 fp 30/30/48 > C 臂 27/27/31, 定性: 生成式关系 vs 实例计算表。caveat: temperature=0 致 ep1/ep2 逐字重复, 独立样本每臂仅 2, 单题强项域]
