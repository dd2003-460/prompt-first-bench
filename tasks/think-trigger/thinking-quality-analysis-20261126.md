回避最贵的阶段（验证=需要 ground truth）。

### 层 3：代价模型
J = Δ(思考质量) / (打断成本 + 检测成本)

- 检测成本：行为判据 ≈ 0（计数）；结构判据 ≈ 高 1-2 个数量级（读分解树+判正交/完备，是判断不是计数）
- 打断成本：F1 实证高频注入 J 为负（便签轰炸 = 覆盖↑、打断↑↑、Δ质量≈0）
- **Δ质量 = 注入文案质量决定**——T2b 自查型 0/3。
  T2c 3/3 的有效要素是**域由外部给定**（prereg_t2c L30 原话："路由（选域）由外部系统做，
  执行（域内推理）由模型做。T2c 验证的是执行半边"）。
  ⚠️ **本文件初稿犯了一个机制移植错误**：把"被告知域 3/3"写成"自声明域 3/3"，
  据此改了 stop_hook 文案（要求模型自产域声明）——自声明域落在 T2c 证据覆盖之外
  （介于 T2b 0/3 与 T2c 3/3 之间），已在文案中如实标注"待 P12 验证"。
  这个错误本身是 T1 该抓的模式：把实验结论从它被验证的条件外推到未验证的条件。

**当前系统 = 高检测覆盖 × 无效注入文案 = 高频打断 + 零质量增益。**
F1 便签轰炸是这个公式的定量表现。

### 层 4：统一形式
think-trigger ≡ 控制器：
```
检测(传感器) → 注入(控制信号) → 产出(被控量) → 验证(反馈)
```
当前状态 = **传感器过采样 + 控制信号幅值不足 + 反馈回路开着**：
- 传感器过采样：F1（PID 同步修了一半；深层问题=触发频率应与注入价值成反比）
- 控制信号幅值不足：T2b 0/3（自查型信号动不了 27b）
- 反馈回路开着：ledger 闭环率从未算 = 开环控制，传感器调得再准也没用

## 压缩

一条判据覆盖全部现象：**系统在优化可见活动量（检测覆盖/触发次数），不优化洞察密度（Δ质量/打断）。**
Goodhart 的机制版：把"触发次数"当目标，触发次数就涨（F1），洞察密度不动（T2b 文案）。
D 11-24 的判据（结构判据 > 行为模式）从压缩视角重述：**行为模式是症状的统计量，
分解结构是病因的解剖学**——检测症状的频率再高，也不改变病因。

## 判据瓶颈

flip（域身份）的 ground truth = D 指认的正确域。
- benchmark 会话可得（T2/T2b/T2c 有 gold 域）
- **生产会话不可得**（D 不在场指认域）

→ 生产只能测 form（shift/预言力/边界）→ form 可被 Goodhart（T2 臂B：form 5.67/6，flip=0）
→ **出路不是"找到生产 flip 的测法"，是让 flip 错误可见**：
  a. 选域外显化（T2c 证有效）：注入文案不要求模型自查域（无效），而是要求它**先声明域再选框架**——
     声明本身就是可见的 flip 代理（声明的域 vs 问题实际域，可人工/异族抽查）
  b. 产出可验证化：预言（如果X则Y）= 思考的压缩形式。好思考必能压成可证伪预言；
     压不成 = 没想透。ledger = 产出落点，闭环率 = 反馈信号
  c. 结构判据（D 11-24 L40）作高精度低频触发：分解不正交→压缩合并；不完备→引新理论。
     命中率低于行为判据，但每次命中带**具体修改指令**（不是泛泛"多想想"）
