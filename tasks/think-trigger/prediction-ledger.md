# 预言台账（prediction ledger）

# origin: ai · 2026-11-26 · D 质询"你有认真思考吗"的落地机制

## 为什么有这个文件
"认真思考"不可直接测量（reasoning 字符数是 proxy 指标，27b 思考本来就薄）。
可测量的代理 = **可证伪预言的闭环率**：提出"如果 X 则 Y"→ 到期核验 → 证实/证伪。
手比脑快的系统特征是：活动量大、预言数≈0（Goodhart：优化可见活动量，不优化洞察密度）。
本台账就是洞察密度的计数器。每轮结束可抽查：本轮新增几条预言？几条到期核验？

## 判据
- 合格预言 = 可证伪（说清什么结果算错）+ 带核验方法（哪个文件/哪次运行/哪个数字）
- 到期核验 = 写 证实/证伪/部分 + 证据（路径或数字）。证伪不是失败，是信息。
- 每周可算：闭环率 = 已核验 / 总数；证伪率单独看（全证实 = 预言太软，也要警惕）

- 新预言随手加（一行），不攒批——攒批 = 又变记账负担

- 每月看一次闭环率和证伪率，两个都低 = 预言太软或没在验证，改预言质量
