## 逐臂判读

### T2b 软锚点（生死线第 3 条命中：无效）
- D 机制域 0/3，混沌域 13-17 次/样本，与控制臂无实质差别
- **机制解释**：软锚点是"自查"型（"核对你是不是在正确的域"），自查预设模型能识别正确域——T2 已证明 27b 恰恰没有这个能力（选域/induction gap）。让它自查一个它感知不到的漂移 = 等于没查。
- 副产品：混沌域命中从 70 降到 46，说明软锚点有轻微抑制效应，但不足以翻转域。

### T2c 显式域声明（生死线第 1 条命中：有效）
- D 机制域 19-26 次/样本（landscape 7-9、非凸 4-8、loss 5-9、凸优化 1-3），混沌域降到 1-5
- **内容质检（防 prompt 回声）3/3 真推理**：
  - run1：NP-hard/#P-hard 复杂度论证（验证全局最小值 NP-hard、landscape 拓扑 #P-hard）+ 预言：Lipschitz 常数 L 随网络深度指数增长 → 需更小学习率（可测：不同深度网络梯度范数分布）
  - run2：Hessian O(n²)/O(n³) 不可行 + 非凸性局部/全局敏感性差异 + 3 条预言（CNN vs MLP Hessian 条件数、Hessian 负特征值比例随 epoch 下降、决策边界附近敏感性高 2 个数量级）
  - run3：反向传播 O(n) vs 全局行为预测 NP-hard 的区分 + 信息论限制 Ω(n²) 函数评估
- **新预言判据**（learn-to-think 验收）：以上预言均不在 D 原文（D 只说"敏感性这种动力学内容应该很容易计算吧，或者说算法的空间不像物理空间那样"），3/3 满足"≥1 个 D 原文没有的可检验预言"。

## 结论解释边界（prereg 先定死，防事后合理化）
1. **显式域声明 = 把"选域"从模型内部移到 prompt 外部**。有效只证明"27b 能在给定域内推理"，**不证明**"27b 能自主选域"——自主选域仍是 gap（T2 0/6、T2b 0/3 未变）。
2. **T5 调度器定位由此获得实证**：路由（选域）由外部系统做（路由器提供显式域声明），执行（域内推理）由模型做。T2c 验证执行半边可行；路由半边（27b 能否正确分类问题类型）仍是开放问题（T5 边界①）。
3. **n=3/臂**，方向性结论，统计力弱（与 T2 口径一致可比）。
4. **T1 生产文案的软锚点句（stop_hook.py L614"核对爬到的机制域是不是这个问题所在的域"）被 T2b 证伪**——应升级为显式域声明格式，但 T1 是通用触发器（不绑定具体域），域应由 T5 路由器按问题类型提供，不是硬编码进触发文案。

## 落点
1. **T5 ROUTING.md 加"域声明"列**：路由结果 = 流程 + 显式域声明（路由器不只选流程，还给域）。
2. **T1 触发文案**：软锚点句保留（无害）但标注"T2b 证明单独无效，域由路由器提供"。
3. **learn-to-think 验收**：T2c 3/3 满足"爬到机制层 + ≥1 个 D 原文没有的可检验预言"（域由外部注入的边界已标注）。
