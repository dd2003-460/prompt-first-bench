## 主指标 1：二元验收清单（8 项，全部派生自 D 题面原文）
每项判定必须引用输出原文片段作证据（可逐条人工复核）。

| # | 验收项（题面原文锚点） | 判定 |
|---|---|---|
| A1 | 容量下限：上下文窗口 ≥32K（"上下文窗口 ≥ 32K tokens 作为容量下限保留"） | 方案满足 or 否 |
| A2 | 精度论证：所选精度 + 质量损失可接受性论证（"必须论证所选精度的质量损失是否可接受"） | 有论证 or 仅声明 |
| A3 | 候选集完整：覆盖架构/代际/容量档位/价格区间，含消费级+数据中心级+非典型（"包括…非典型方案"） | 三类均覆盖 or 缺类 |
| A4 | 单卡 vs 多卡 TCO 对比（"评估单卡与多卡方案的 TCO 差异"） | 有实质对比 or 无 |
| A5 | 完整选卡方案：具体到型号+数量+精度+用途，非模糊建议（"给出性价比最优的完整选卡方案"） | 完整 or 不完整 |
| A6 | 无遗漏维度：讨论了题面未点名但影响决策的维度 ≥3 个（功耗/散热/软件栈/PCIe 拓扑/互联带宽/价格波动/二手市场等）（"确认没有遗漏任何影响决策的维度"） | ≥3 个 or <3 个 |
| A7 | 数字溯源：关键数字标注来源（刚查到 vs 凭记忆），不确定标 [待核验]（"每个关键数字标注来源…不确定的标 [待核验]"） | 有标注体系 or 无 |
| A8 | 条件性推荐：最终推荐带条件，无无条件排名（"最终推荐必须是条件性的"） | 条件性 or 无条件 |

得分 = 通过项数 / 8。

## 主指标 2：recall（B 臂专属，二值行为观察）
B 的 6 阶段输出中，呈现阶段特征结构的阶段数（01 正交分解 / 02.5 证据分级 / 04.5 条件性复核，任一可辨即计）/ 3。

## 防偏差措施
1. **盲评**：打分前抹去臂标签，6 份输出（A×3 + B×3）随机编号后逐份判 8 项，判完再揭标签。
2. **证据强制**：每项判定必须附输出原文引用（≤2 句），无引用 = 该项判不通过。
3. **judge 身份声明**：judge = Lead（异构模型，非 27b 同族）；二元判定 + 原文引用把主观空间压到最低，残余主观性在结果中如实标注。
4. 6 因子仅作描述性附录（若打分），不参与任何结论。

## 生死线（不变，判据换成主指标 1）
- B 均值 > A 均值 且 recall ≥2/3 → pfb 流程端到端有效
- recall 高但均值持平 → 纯结构无增益
- B ≤ A 或 recall <1/3 → 无效
