# T6 预注册：SOP 检查点效果（prompt 级代理）— 先于数据

## 问题
在显式域声明（T2c 已证有效）之上，加入 pfb SOP 的 4 个结构检查点
（正交完备 / 证据分级 / 域核对 / 往返无损），是否提升输出质量？
这是"harness/SOP 层是否有效"的最小可跑代理（完整 agent 级 A/B 需异族 judge，暂缓）。

## 臂
- 控制臂 = T2c 实验臂（FRONT + DECL，复用 raw_outputs_t2c.json 3 样本，不重跑）
- 实验臂 = 控制臂 + CHECKPOINT 块（下方原文），3 个新样本

CHECKPOINT 块（注入执行 prompt 末尾）：
"""
回答前先自查四点：
① 正交完备：问题分解是否正交且完备？
② 证据：用到的证据是一手（可直接观察/复现）还是二手（转述）？
③ 域：推理是否在声明的域内？
④ 往返无损：结论是否回应了原始问题（D 问的是什么，你解的是不是那个）？"""

## 模型/参数（与 T2/T2b/T2c 完全一致）
qwen3.8-27b-mtp @ 127.0.0.1:8787, temp 0.7, max_tokens 1024, 3 样本/臂

## 判据（看数据前锁定）
1. **新预言（主判据）**：样本含用声明域（优化/复杂性）概念推出的新断言，
   且不在 D 原文中、不是 prompt/检查点措辞的重述（防回声，同 T2c 内容 QC）。
2. **结构检查行为（次判据）**：样本显式执行了正交完备或往返无损检查
   （有分析性陈述，不是复述清单四项）。
3. **关键词（辅助，词表同 T2c）**：实验臂 D 机制域命中不低于控制臂（域不回退）。

## 生死线（看数据前锁定）
- **有效**：实验臂新预言 ≥2/3 且 结构检查行为 ≥1/3 且 D 机制域不回退
- **部分**：实验臂新预言 ≥2/3 但无结构检查行为（检查点惰性：无害也无益）
- **无效**：实验臂新预言 <2/3（检查点有害：分散注意力）

## 诚实边界
- prompt 级代理 ≠ 完整 SOP A/B；3 样本/臂，小样本
- judge = Lead 人工内容 QC（同族 judge 限制，同 T2c）
- **机制风险（预先声明）**：T2b 已证自查型指令对"识别正确域"无效（0/3）。
  实验臂的 ③域核对 可能是惰性的——预期如此，不构成反证；
  主假设针对整体检查点块（尤其 ④往返无损 + ①正交完备，这两项不依赖模型自知漂移）。
