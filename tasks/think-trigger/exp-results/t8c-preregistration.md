## 0. 假设与指标

**H1（备择）**：在 token 预算匹配（两臂同为 73728 completion tokens 上限）且题面无歧义（三歧义已消解）的条件下，
pfb 六阶段流程（Arm B'）在 **correctness** 上优于直接求解（Arm A'）。

**H0（原假设）**：两臂 correctness 无差异（p_B' = p_A'）。

**主指标 = correctness（三型判别）**，不是 coverage：
- 每样本一个标签 ∈ {A1, A2, A3, indeterminate}，由 J1 机械判别器
  （`correctness_layer_v0.py`，commits 92aa24a76→fb60263ac，selftest 11/11，无 LLM）给出。
  三型定义（`research/correctness-layer-design.md` §0/§3，①类）：
  - **A1 候选构建断点**：winner 卡型（V100）从未进入候选集（P_A1 = 1−C ≥ 0.7）。
  - **A2 候选集粒度断点**：V100 进了候选集，但 winner 配置（4×V100）从未被构造/评估（C2BP）。
  - **A3 排序/权重断点**：4×V100 被完整评估但排序垫底/未被选中（P_A3 = E1·R_low ≥ 0.5）。
  - **indeterminate**：都不命中——**含结论正确的情形**（winner 被评估且被选中时 R_low=0 → 不命中 A3）。
- **correctness 得分**：`score = 1[indeterminate] + 0[A1/A2/A3]`（三型=断点=错，indeterminate=未检出断点=对/无法判定）。
  注意 indeterminate 是「未检出断点」而非「确认正确」——报告时标注此口径，不夸大为 accuracy。
- **为什么不用 coverage**（已证陷阱）：J2 存量 17 条 Pearson(cov, CORR)=0.462（互补非冗余）；
  cov 最高样本 S5=0.389 恰是 A2 断点样本；cov 均值按 verdict 单调 A1 0.179 < A2 0.259 < A3 0.278
  （`research/joint-scores-20261125.md`，①类）——coverage 高 ≠ 结论对。

**次指标 = coverage（必要条件检查）**：judge_v1 cov 分数（frozen f6072397f）照算，
但只用于「B' 是否覆盖了 gold 结构」的必要条件核对（cov 低则 correctness 高分存疑），不进主判据。

## 1. token-matched 对照设计

**两臂同 token 预算上限 = 73728 completion tokens**（B' 臂 6 阶段 × 12288；2026-11-26 post-hoc 修复：原 24576 下 B' 臂 3/3 截断，根因=总预算 < 六阶段真实需求 69227）。

**基线来源（T8b 实测，`raw_outputs_t8b.json` meta + usage，①类本轮读）**：
- Arm A（直接求解，max 16384）：3 run completion tokens = 7015 / 13276 / 12819，
  均值 11037，全部自然 stop（未撞顶）。
- Arm B（六阶段，6×4096）：3 run 总 tokens = 23645 / 21466 / 22779，
  均值 22630，cap 利用率 87-96%（撞顶 2/3：B1/B2 final finish=length）。

**取哪条 run 做基线**：取 **B 臂截断态实测需求 69227** 向上取整到阶段对齐值 **73728**（=6×12288），
而不是 A 臂均值 11037——理由：① token-matched 的意义是「给直接求解臂同样的 token 预算」，
预算上限由 B 臂结构决定（6 阶段 × 4096 是 harness 的硬结构）；② 若按 A 臂均值 11037 设预算，
B 臂 6 阶段每阶段只有 ~1856 token，01 阶段连分解都写不完（T8a 已证 4096 截断 confound），
对照退化为「双截断」无信息量。

**两臂预算分配**：
- Arm A'（直接求解）：单次调用 `max_tokens=73728`。T8b A 臂自然收尾在 7K-13K，
  73728 下预期仍自然 stop（不截断）；若 stop 后实际用量 ≪ 73728，属正常（预算是上限不是配额），
  报告里同时记「预算」与「实际用量」。
- Arm B'（六阶段）：每阶段 `max_tokens=12288`，总预算上限 73728（同 T8b B 臂结构，阶段数不变）。

**匹配容差**：
- **预算层面（硬）**：两臂名义预算上限严格相等 = 73728，无容差（这是设计的定义）。
- **实际用量层面（软，只报告不判死刑）**：若 A' 实际用量均值 < B' 实际用量均值 × 0.5
  （即直接求解臂远未花完预算），报告中必须标注「预算匹配但用量失衡」，
  此时主判据（§3）照常执行，但结论置信度降一档（token 预算相等 ≠ token 用量相等，
  余量本身是流程差异的一部分，不强行消除）。
- **截断处理**：任一臂样本 finish_reason=length（撞顶截断）→ 该样本主指标判
  **indeterminate（截断）**，单独计数，不进三型分布比较（截断样本的 correctness 不可判）。
  若某臂截断样本 > 50%，该臂数据作废重跑（预算 73728 覆盖 B' 实测需求 69227，预期不发生；
  原 24576 下 B' 3/3 截断已证预算不足，post-hoc 修复见 t8c-posthoc-20261126.md）。

## 2. 样本量与 power analysis

**检验**：两臂 correctness 得分（§0 定义）构成 2×2 表，双侧 Fisher exact，α=0.05。
**效应量参考**：T8b 正向对照（0/6 → 1/1 收敛正确族，t8b_positive_control 实跑）指示
「题面对齐 gold 后模型可达 winner」，即 p_B'=1 是乐观上限；p_A' 未知（T8b A 臂 0/3 是
题面分叉下的值，T8c 题面消解后 A' 臂可能 >0）。

**python 实跑结论（本轮，二项+Fisher exact 精确计算，非手算）**：

| n/臂 | 双侧 p<0.05 的拒绝域（B' 有利方向，A'=A 臂错数, B'=B 臂对数） | 备注 |
|------|--------------------------------------------------------------|------|
| 3 | **空**（最极端 0/3 vs 3/3 也仅 p=0.100） | n=3 在任何真实效应下 power=0，无法拒绝 H0 |
| 4 | A0-B4 (p=0.0286) | 仅全对/全错分离可拒 |
| 6 | A0-B5 (0.0152), A0-B6 (0.0022), A1-B6 (0.0152) | |
| 9 | A0-B5 (0.0294) … A4-B9 (0.0294)，共 14 个格（含 A1-B8 0.0034） | 差 ≥5 格基本可拒 |
| 12 | A0-B5 (0.0373) … A7-B12 (0.0373) | |

**power 网格（双侧 Fisher α=0.05，精确计算）**：

| n/臂 | pA=0,pB=1 | pA=1/3,pB=1 | pA=0.5,pB=1 | pA=0.3,pB=0.7 |
|------|-----------|-------------|-------------|---------------|
| 3 | 0.000 | 0.000 | 0.000 | 0.000 |
| 4 | 1.000 | 0.198 | 0.062 | 0.058 |
| 6 | 1.000 | 0.351 | 0.109 | 0.085 |
| 9 | 1.000 | 0.855 | 0.500 | 0.261 |
| 12 | 1.000 | 0.981 | 0.806 | 0.389 |

**结论（n=?）**：
- **n=3/臂：power=0（α=0.05 双侧）**——2×2 表在 n=3 时无任何格子 p<0.05。
  n=3 只能作 **smoke**（可行性/退化检查），不能作显著性检验。
- **n=9/臂**：对乐观效应（pA=0,pB=1）power=1.000；对中等效应（pA=1/3,pB=1）
  power=0.855 ≥ 0.8 ✅；对弱效应（pA=0.3,pB=0.7）power 仅 0.261——弱效应需 n≈29/臂
  （27b 烧不起，接受为不可测）。即 **n=9/臂 能检出「B' 接近全对且 A' 错率 ≤1/3」的效应**。
- **决策规则（pre-commit，见 §4）**：先 n=3/臂 smoke → 出现分离迹象（B' ≥2/3 且 A' ≤1/3）
  → 扩到 **n=9/臂** 正式检验（拒绝域见上表 n=9 行）；smoke 无分离（两臂 0/3 或 1/3）
  → 停止，如实报告「该效应在 27b + 本题面下低于可测下限」，不硬烧。
- **成本**：n=9/臂，A' 实际 ~13K×9≈117K + B' 实际 ~69K×9≈621K，两臂 ~738K，27b 本地可承受（~数小时）。

## 3. 判据（可机械执行 · 先 commit 再跑）

**每样本机械量**（J1 判别器输出 + 断点深度）：
- 标签 ∈ {A1, A2, A3, indeterminate}（§0 定义，`correctness_layer_v0.py` 级联判定）。
- 得分 `s = 1[indeterminate] + 0[断点]`（0/1）。
- **断点深度** `d`：A1=1, A2=2, A3=3, indeterminate=4。依据：三型沿 gold 推理链
  的位置递增——A1 断在候选构建（最早）→ A2 断在 winner 配置构造 → A3 断在排序/权重
  （最晚，winner 已被完整评估）→ indeterminate 无断点（最深）。`d` 单调对齐 gold 链深度，
  是「推理链推进到哪一步」的机械代理。

**判据提案修正（对任务书「A1+A2 占比下降且 A3 占比上升？」的回答）**：
方向对但锚点错——A3 仍是错误型（winner 被评估但垫底），**A3 占比上升本身不是赢**，
只是「断点位置后移」（结构进步）。赢的锚点必须是 **indeterminate（无断点）占比上升**；
A1+A2→A3/indeterminate 的后移只作次级结构证据。故判据如下：

**「多阶段赢」= H1 成立，当且仅当三条全满足**（机械可执行，跑数前冻结）：
1. **W1（方向）**：`mean(s_B') > mean(s_A')`（B' 无断点率严格高于 A'）。
2. **W2（显著）**：2×2 表（断点/无断点 × 臂）双侧 Fisher exact p < 0.05。
   （n=3 时拒绝域为空——W2 只在 n=9 阶段执行；n=3 只记 W1 方向作 smoke 信号。）
3. **W3（结构，必要条件）**：`mean(d_B') > mean(d_A')`（B' 断点分布沿 gold 链后移）。
   防退化情形：两臂 indeterminate 率相同但 B' 断点更深——此时流程只保住了「走到评估」
   没保住「选对」，不算赢。

**「多阶段输/无效」**：W1 不满足（`mean(s_B') ≤ mean(s_A')`）→ H1 不成立，如实报告。
**「不可判」**：某臂截断样本 >50%（§1）→ 该臂作废；两臂 smoke 全断点（s 全 0）
→ 效应低于可测下限，停止并如实报告（不扩样硬烧）。
**次指标核对（不判胜负，只报告）**：coverage（judge_v1 cov）按臂汇总；
若 B' correctness 高但 cov 低 → 标注「correctness 与 coverage 背离，复核 judge 口径」。

## 4. 决策规则（smoke → 扩样，pre-commit）

**Stage 0（smoke，n=3/臂，先跑）**：
1. 跑 A'×3 + B'×3（各 73728 预算上限，§1）。
2. 机械检查（不过 → 修 harness/题面后重跑 smoke，不进入 Stage 1）：
   - 无退化：无复读/空输出/JSON 崩溃（同 T8b smoke 判据）。
   - 截断率 ≤ 50%/臂（§1）。
   - 三型判别器对 6 样本全部出标签（含 indeterminate），无异常抛出。
3. **smoke 分流（pre-commit 决策规则，不许事后改）**：
   - **分离迹象**：`s_B' ≥ 2/3 且 s_A' ≤ 1/3`（即 B' 多数无断点、A' 多数断点）
     → **扩样到 n=9/臂**（补跑 A'×6 + B'×6，共 9/臂），执行 §3 三判据（W1+W2+W3，
     Fisher 用 n=9 全表）。
   - **无分离**：两臂 s 均 ≤1/3（全断点/多数断点），或 B' ≤ A'（方向反）
     → **停止**。结论：「题面消解 + token 匹配下，27b 两臂 correctness 无分离信号
     （n=3 无检验力，n=9 前验 power 对弱效应 <0.3），效应低于可测下限」，
     落盘报告，不扩样（烧 27b 换不可检出的检验 = 浪费）。
   - **边界情形**：s_B'=2/3 且 s_A'=1/3 但三型分布显示 B' 全是 A3（断点后移但未选对）
     → 按 §3 W3 判「结构进步非赢」，同样停止扩样（W1 方向为正但 W3 为负 → 无效）。

**Stage 1（正式，n=9/臂，仅 smoke 分流为「分离迹象」时执行）**：
1. 补跑至 9/臂，全表 18 样本过 J1 判别器。
2. 执行 §3：W1（方向）+ W2（Fisher p<0.05，拒绝域见 §2 n=9 行）+ W3（深度后移）。
3. 三判据全过 → **H1 成立（多阶段赢）**，claim 限定为「27b + 本题面 + 73728 预算上限下
   correctness 优势」，不外推（单任务、单模型、单预算——推广需 ≥3 类任务，
   见 `prereg_t8c.md` 第 3 条，不在 T8c 范围内）。
4. W1 过 W2 不过（n=9 下方向对但不显著）→ 报告「方向性证据，检验力不足」，
   给观测 p 值与 95% CI，不 claim 显著。
5. 任何判据不过 → H1 不成立，如实报告（负结果同样是结果）。
