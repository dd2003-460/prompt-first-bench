# cc 评审 #2 — 规则注入 vs 示范注入 — 回答 — 2026-11-28

## Q1: 抽象规则 vs D 真实示范，哪个更可能改变内容层？
**结论：示范注入更可能改变内容层，但前提是把示范选成"内容载体"而非"形式载体"；纯规则注入对内容层的期望效应接近零。** conf: 0.7
依据：
- T2 已实证 27b 对形式注入响应强（5.67/6）而内容域偏移 100%——规则注入走的是"指令跟随"通道，27b 这条通道强；内容层走的是"知识检索+迁移"通道，这条通道是弱项，规则文本本身不携带域知识，只携带操作指令。
- 27b 的 in-context learning 机制：对 few-shot 主要学"输入→输出的映射模式"，示范里若含 D 的域内机制词与因果链，模型可把该模式迁移到同域任务；纯规则无映射模式可学，只能触发指令跟随。
- 风险：示范若选错（选了 D 的形式性思考而非内容性思考），会重演 T2——形式分再涨、域偏移照旧。示范的内容选择是成败关键，不是"有没有示范"。

## Q2: 最小可行示范样本规格 + token 预算
**结论：1 个示范、150-250 字中文（约 200-350 token）、选 D 的"质疑链/关键决策"类样本（含'我觉得X因为Y'+追问），不选论文推导。** conf: 0.6
- 数量：1 个足够。27b 对 few-shot 数量不敏感（1-3 个差异小于样本质量差异），且本实验单变量原则下 1 个示范是"最小可检测效应"；3 个示范把 token 预算吃掉且引入示范间风格噪声。
- 类型排序：质疑链 > 关键决策 > 论文推导。理由：质疑链天然含"域内机制词+因果方向+直觉锚点"，且短；论文推导太长且形式化重（会教形式不教内容）；关键决策次之（含取舍逻辑，与分解任务最贴近）。
- 结构要求：示范必须含 (a) 域内机制词 ≥3 个、(b) 一句'我觉得X因为Y'式直觉、(c) 一条追问链（≥2 步）。缺 (a) 的示范 = 形式示范，会重演 T2。
- token 挤压：P1_L1_SKELETON 现约 800 字 + 注入段 150 字；+250 字示范后总 prompt ~1200 字（<2k token），对 27b 上下文（32k+）远未到挤压点。真正挤压点在 P1H_INDEX（多轮累积 confirmed_block），示范只注 P1_L1_SKELETON 一处、不注 P1H_INDEX，可避免多轮 token 累积。

## Q3: 混合方案 vs 纯规则；M3 前能否加 V2 臂
**结论：混合（短规则+1 示范）理论上优于纯规则，但 M3 跑批前不建议加 V2 臂——先跑 M3（V0+V1），M4 判负或形式模仿时再上 V2。** conf: 0.75
- 理论排序：混合 ≥ 纯示范 > 纯规则。规则提供"操作指令"（何时自检），示范提供"内容锚点"（域内长什么样），两者正交互补；但这是假设，未实证。
- 不加 V2 的理由：(a) M3 已排满 8787 单实例串行队列（V1×3域×3reps + V0×2reps），加 V2 = 再 +9 臂，夜间跑不完，会拖垮 M4 判决时间线；(b) V1 结果本身是 V2 的先验——若 V1 已判正（align 提升），V2 边际价值低；若 V1 判负且是形式模仿，V2 的示范选择需要 T2/M3 的域偏移词表数据来选样本，现在选 = 盲选；(c) 预注册纪律：M2 设计卡已预注册 V1 判据，临时加臂稀释单变量性。
- 折中：M3 跑批期间（夜间），离线准备 V2 的示范样本（选 1 个 D 质疑链样本、按 Q2 规格裁剪），M4 判负时 V2 可立即上，零准备延迟。

## Q4: M3 判负时，示范注入插在判别树哪个位置？
**结论：插在"知识锚点探针"之后、"域条件化 V1.5"之前，作为探针的阳性分支动作；若探针阴性则跳过示范注入直接走能力缺口。** conf: 0.7
判别树（预注册：知识锚点探针 → 域条件化 → 能力缺口）：
- 知识锚点探针（~30min/臂）：测 27b 是否"知道"域内机制（直接问域内事实，不给任务上下文）。
  - 探针阳性（模型知道域知识，只是任务中没用上）→ **示范注入在此插入**：问题不是"不知道"而是"不会迁移"，示范提供迁移模板，预期有效。这是示范注入的最佳适用位置。
  - 探针阴性（模型根本不知道域知识）→ 示范注入无效（示范里 D 的域知识模型无法理解/迁移），跳过，直接走域条件化（把域知识显式喂入）或判能力缺口。
- 理由：示范注入治的是"迁移失败"，不治"知识缺失"。探针正好区分这两种失败模式，所以示范注入必须是探针的下游分支，不能插在探针之前（盲插 = 无法区分失败模式），也不能插在域条件化之后（域条件化已显式喂知识，示范的边际价值归零）。
