# 思考机制瓶颈定位: 触发层 (2026-11-28)

# origin: ai (Lead 综合, 基于 M4 判决 e6049ec0a + 红队三探针)

## 核心发现
M 线实验 (M3/M4 + 红队三探针) 精确定位了"让 AI 像 D 一样思考"的瓶颈:
- **不在认知层**: 模型知道该做什么 (元层注入后能说出"测错了层", redteam-inject v4)
- **不在工具层**: 模型有能力做 (给了检索通道, tooltest)
- **在触发层**: 模型不知道"在什么信号下决定去做" (tooltest: 零 [SEARCH:] 行)

现象: 习惯在、通道在、但触发器没接上。模型不会在"我还没查"这个状态上停下来真的去查。

## 三要素框架
思考机制落地 = 习惯 (prompt 可注入) × 信息 (记忆提供) × 触发 (agent 循环事件)

| 要素 | 作用 | 实现路径 | 当前状态 |
|---|---|---|---|
| 习惯 | 知道该做什么 | prompt 注入 | 已验证: 对象层无效 (M4 FAIL), 元层买到层次敏感度 (redteam v4) |
| 信息 | 知道有什么可查 | 记忆系统 (前人方案/成熟解) | 未实现 |
| 触发 | 知道什么时候该做 | agent 循环事件点火 | 未实现 (= D 的"矛盾触发思考机制") |

三者缺一: 只有习惯+信息没有触发 → 模型知道该查但不会去查 (tooltest 判负)。
只有触发没有信息 → 模型知道该查但不知道查什么 (无记忆)。
只有习惯没有触发 → 模型知道该做但不会在正确时机做 (M4 对象层 FAIL)。

## 触发器的实现路径
触发器需要外部事件点火, 不靠模型自觉。候选触发信号 (均可在 agent 循环里机械检测):
1. **矛盾**: 模型输出与已知事实/先前结论矛盾 (矛盾检测器)
2. **卡住**: 同一问题重试≥2 次或同错≥2 次 (stop_hook 已有)
3. **信息缺口**: 模型声称"不知道"/输出置信度低 (logprob 探针, 只做优先级排序不做触发, 避免循环论证)

这与 D 之前定的"矛盾触发思考机制"完全吻合: 思考机制的触发不靠模型自觉, 靠外部事件点火。M 线判决验证了这个方向判断——prompt 注入到头了, 下一步是 agent 循环。

## 负结果的正面价值
M 线的负结果 (对象层注入无效) 不是失败, 而是:
1. 排除了"prompt 注入就够了"的错误路径 (节省后续 GPU 时间)
2. 验证了 D 的方向判断 (思考机制需要 agent 循环, 不是 prompt)
3. 精确定位了瓶颈 (触发层), 为后续实现提供了清晰目标

可发表 claim: "AI 思考机制的瓶颈在触发层, 不在认知层或工具层" + "思考机制落地=习惯×信息×触发, 三者缺一"。
