# 到可发表里程碑的最短路径

可发表 = 五子项 100% + Q9 主端点（gate 命中率首次 100% 的最小预算）输出。
当前位置：①②③ 已收口；④ 12/15 落盘、最高档 3 连在跑（队列自动接力）；⑤ 除排序键裁决外全完成。

## 分步

1. **等最高档 3 连落盘（约 4–6h，队列 v2 自动接力，无需人工干预）**
   为什么在最短路径上：这是关键路径上唯一的串行硬依赖，墙钟下限由算力决定，没有任何动作能缩短它；队列已自动化，人工插手只会增加出错面。

2. **落盘后立即重跑分析脚本出主端点 → ④ 收口**
   为什么：这是把原始 run 转成主端点的唯一转换步骤，纯机械、分钟级；能做的时刻一到就做，不攒批、不等别人。

3. **报 D 裁排序键：A（post_acc×(150/n_realized) 预算惩罚复合分）vs B（纯 post_acc），附推荐项**
   为什么：⑤ 的唯一卡点是这一个决策，其余全部完成；带上推荐项让 D 一句话可裁，把人为依赖压到最小。

4. **D 裁完 → gold 冻结 → ⑤ 收口 → 里程碑达成**
   为什么：冻结是不可逆终步，必须在裁决之后，无可并行空间。

关键路径总时长 ≈ 第 1 步等待（4–6h）+ 第 3 步人为响应时间；第 2、4 步均为分钟级。

## 发现的缺口（共 4 个）

1. **D1 裁决是时间不可控的人为依赖**：无超时/代理规则，D 不在场则 ⑤ 无限期停摆，且它排在 ④ 收口之后、无人能代做。
2. **最高档 run 失败/队列卡死无预案**：任一 run rc≠0 或接力断链，主端点算不出；当前只写了"队列自动接力"，没有重跑或降级口径的后备路径。
3. **主端点可能不存在**：若各档命中率从未达 100%，"首次 100% 的最小预算"未定义；没有后备口径（取最大值/插值/改判据），需与 D 预先约定。
4. **主端点无精度口径**：每档仅 3 runs，"最小预算"这一离散事件估计无误差棒/置信区间声明；报数时若不附方差，claim 的可防御性打折。
