## 分步（每步为何在最短路）
1. 立即向 D 发出 D1 裁决请求（排序键 A: post_acc×(150/n_realized) 惩罚项 vs B: 纯 post_acc）

2. 等 719 档 3 runs 落盘（~4-6h，队列自动接力）
   为什么：④的主端点（gate 命中率首次 100% 的最小预算）需要 15 runs 全齐，719 档是唯一缺口；自动接力零人工成本，单 run ~1.5-2h 是硬件下限，压不动。
3. 重跑分析脚本出主端点 → ④ 收口
   为什么：脚本已存在、分钟级机械操作；主端点是"可发表"定义的必备件，缺它里程碑不成立。
4. D 裁决到达 → gold 冻结 → ⑤ 收口 → 五子项 100% + 主端点输出 = 里程碑达成
   为什么：⑤其余部分（题面冻结 / gold A/B 对照 / rubric 37 units）均已完，冻结是最后一步；若 D 在等待期已裁决（第 1 步），此步零耗时。
