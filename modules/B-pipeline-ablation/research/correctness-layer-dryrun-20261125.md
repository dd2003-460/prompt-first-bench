## 阈值敏感性分析（`--sensitivity`，量化 §3 标注的 A1/A2 理论边界）

设计文档 §3 诚实标注了"A1 与 A2 在 C2=0 且 C1e 接近 0.5 时有边界重叠，由判定优先级裁决"。这是"能机械区分"claim 的可防御性软肋——若重叠区在真实数据上会被踩到，claim 就站不住。本节用阈值扫描把它从"理论担忧"量化为"已测量的安全裕度"。

方法：对已知 3 条（gt），三维扫 TH_A1×TH_A3×C1e_th（TH_A1/TH_A3 各 0.4..1.0 步长 0.1，C1e_th ∈ {0.3,0.4,0.5,0.6,0.7}，共 245 体素），统计每条样本判定保持正确的体素占比 + 距默认阈值最近的翻转点。C1e_th 是 A1↔A2 的真正铰链（A2 要求 C1e≥c1e_th，A1 要求 C≤0.3），重点扫它。

```
arm_a[0]   gt=A1  稳定占比=100% (245/245) 全网格稳定
arm_a[2]   gt=A3  稳定占比=100% (245/245) 全网格稳定
arm_a[1]   gt=A2  稳定占比=71%  (175/245) 最近翻转@TH_A1=0.5/TH_A3=0.5/C1e_th=0.5→A1
sensitivity: ROBUST (已知样本过半阈值体素稳定)
```

**解读（把理论边界量化成安全裕度）**：
- **A1、A3 样本全网格 100% 稳定**：无论阈值怎么扫，arm_a[0] 恒判 A1、arm_a[2] 恒判 A3。这两型的判别信号（C1e=0 / E1=1.0+C=1.0）远离任何阈值边界，零裕度风险。
- **A2 样本 71% 稳定，最近翻转需 TH_A1 从 0.7 降到 0.5（0.2 偏移）**：arm_a[1] 的 C1e=1.0（3090 充分出现），距 A1 的 C≤0.3 边界有 0.7 的 C 空间裕度；只有在 TH_A1 大幅下调到 ≤0.5 时才会被误吞成 A1。默认 TH_A1=0.7 下，A2 的安全裕度 = 0.7−0.5 = **0.2 个阈值单位**，且该翻转方向是"保守归 A1"（宁可漏 A2 不误报 A2 为 A3），不产生危险误判。
- **结论**：§3 标注的 A1/A2 理论重叠点在真实数据上**未被踩到**——三条已知样本的 (C1e, C2, E1) 取值都远离重叠区（A1 型 C1e=0，A2 型 C1e=1.0，A3 型 E1=1.0）。判别对阈值扰动稳健，"能机械区分三型"的 claim 可防御。**残余风险**：若未来样本出现 C1e 恰在 0.5 附近（卡型仅边缘提及 2 次）的真 A2，会被保守归 A1——这是已知的、方向安全的（不产生 A3 误报），v1 标定 TH_A1 时可按此方向收紧。

## R 轴承重机制与假阳性边界（格式扰动压测，2026-11-25 补测）

对 A3 样本 arm_a[2] 做格式扰动压测，定位"A3 判定到底靠什么信号"，并压测其对输出格式的脆弱点：

| 扰动 | 预期 | 实际 | 含义 |
|---|---|---|---|
| 原文 | A3 | A3（E1rows=4, E1=1.0, R=1.0） | 基线 |
| `\|`→空格（保留行结构） | ? | A3（E1rows=4） | 表格符号非承重 |
| `\|`→换行（列拆行） | E1 掉→塌缩？ | **A3**（E1rows=2, E1 仍=1.0） | E1 2 行即 `min(n/2,1)` 饱和，无区分度 |
| 表格行压平为散文行 | ? | A3（E1rows=4） | 单元格同行关系非承重 |

**承重机制结论**：A3 判定的真正承重轴是 **R（散文强推荐行）**，不是 E1。E1 极易饱和（2 行即 1.0），只起"配置进过评估上下文"的开关作用；区分"评估过但垫底"vs"评估过且选中"的是 R_low（强推荐行是否含 4×3090）。

**假阳性边界（实测反例）**：构造一条**正确样本**——winner 被完整评估（E1=1.0）且被推荐，但推荐表述不含 STRONG_REC 关键词（"综上, 综合性价比来看, 建议优先部署 4×RTX 3090 方案。"）→ 层判 **A3**（R_low 默认 1.0）。即：**winner 被推荐但推荐语句无关键词 → 误判 A3**。对照组（推荐走关键词散文行 / 推荐埋表格含"最终推荐"字样）均正确判 indeterminate，确认是"无关键词"这一表述形态触发的，非评估证据问题。

**影响评估**：本批 7 样本的 winner 推荐全部走关键词行（arm_a[2] 四条强推荐行均不含 4×3090，方向正确）或表格含"最终推荐"，无此情形 → dry-run 3/3 结论不受影响。但这是**跨 run 推广前的必修项**：若后续 run 的模型习惯用无关键词散文做最终推荐，R 轴会把"正确样本"误报为 A3 断点（假阳性方向，会高估断点率）。v1 修法（设计文档 §2 轴 R）：E1>0 且无任何 STRONG_REC 行时，扫全文含 CFG4 的弱推荐语义行（建议/优先/部署/选择），命中 winner → R_low=0。
