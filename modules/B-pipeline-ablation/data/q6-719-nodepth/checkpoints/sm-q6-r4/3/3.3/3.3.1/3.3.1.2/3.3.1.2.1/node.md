## Claim

工作点B的7x24值班人力成本分解：C_oncall_B = (N_oncall_shifts * C_shift_cost) + C_management_overhead；其中 N_oncall_shifts = 24*365/12 = 730 班/月（按3人轮班，每班8h），C_shift_cost 为一线工程师时薪 ¥600 * 8h = ¥4,800/班，但需考虑非工作时间溢价系数 1.5，故 C_oncall_B ≈ 730 * 4800 * 1.5 / 3 (分摊到3人) ≈ ¥1.728M/月？不，应为总人力成本中的值班溢价部分。修正：标准月薪¥45k，值班溢价系数 1.3，故 C_eng_effective_B = 5 * 45k * 1.3 = ¥292.5k/月，比标准配置高30%。

## Corrected Claim

工作点B的7x24值班人力成本需重新核算：若按5名工程师月薪¥45k计算，基础人力成本为¥225k/月；若考虑7x24轮班需额外增加值班人员或支付高额时薪溢价，总成本应显著高于¥292.5k/月，具体数值需根据实际排班表（如每班人数、月总班次）重新推导，原陈述中1.728M与292.5k的矛盾需消除。

## Evidence

[质询]数值计算存在内部矛盾：730班/月 * 4800元/班 * 1.5溢价 / 3人 = 1,728,000元/月，这与后文修正的292.5k/月相差近6倍，且292.5k/月仅相当于5名工程师的标准月薪总和（5*45k=225k）加上30%溢价，未体现7x24全天候轮班所需的额外人力或高额时薪成本，逻辑上无法自洽地解释'值班溢价部分'。 | 先验知识/题面给定，但逻辑校验发现内部数值矛盾：初始计算结果（1.728M）与修正结果（292.5k）量级不符，且修正后的成本结构未能合理反映7x24轮班的实际人力投入（仅5人月薪+30%溢价难以覆盖24小时不间断值班），故降级。
