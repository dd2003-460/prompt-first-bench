## Claim

HDD+SSD分层方案在5年折旧期（SSD残值5%, HDD残值10%）下的加权年化折旧成本计算：C_dep_hybrid_5y = [(100TB * ¥225/TB * 0.95) + (400TB * ¥30/TB * 0.90)] / 5 ≈ ¥1,078,500/年，此点代表通过延长折旧年限和混合介质降低年均资本支出的平衡策略。

## Corrected Claim

C_dep_hybrid_5y = [(100TB * ¥225/TB * 0.95) + (400TB * ¥30/TB * 0.90)] / 5 = (21,375 + 10,800) / 5 = ¥6,435/年

## Evidence

先验知识/题面给定，逻辑校验通过：计算过程 (100*225*0.95 + 400*30*0.90)/5 = (21375 + 10800)/5 = 129375/5 = 25875 元/年，与陈述中的 ¥1,078,500/年 存在数量级差异，但考虑到 source=knowledge 且通常此类节点考察的是公式结构或特定语境下的单位（如可能是总成本而非年化，或者题目本身数值设定特殊），需仔细复核。等等，重新计算：
100TB * 225 = 22,500
22,500 * 0.95 = 21,375
400TB * 30 = 12,000
12,000 * 0.90 = 10,800
总和 = 32,175
除以 5 = 6,435 元/年。
陈述中的结果是 1,078,500。这相差巨大。
让我们看看是否理解错了“加权年化折旧成本”。
也许陈述中的数字是错的？
或者 TB 的价格单位不是元？如果是美元？
225 USD/TB? 30 USD/TB?
(100*225*0.95 + 400*30*0.90) / 5 = 6435 USD.
还是不对。

再看一眼陈述：C_dep_hybrid_5y ... ≈ ¥1,078,500/年。
如果总成本是 1,078,500 * 5 = 5,392,500。
反推：
(100 * P_ssd * 0.95 + 400 * P_hdd * 0.90) = 5,392,500
假设 P_ssd = 225, P_hdd = 30。
左边 = 32,175。
右边 = 5,392,500。
差距约 167 倍。

有没有可能容量单位是 GB？
100TB = 100,000 GB。
(100,000 * 225 * 0.95 + 400,000 * 30 * 0.90) / 5
= (2,137,500 + 10,800,000) / 5
= 12,937,500 / 5
= 2,587,500。
还是不等于 1,078,500。

有没有可能价格单位是 分？或者别的？
或者陈述中的计算本身就是错误的？
作为事实核验员，如果 source=knowledge，且逻辑校验发现数值严重不符（差几个数量级），这属于“硬逻辑错误”吗？
判定规则说：failed: 仅当该陈述与参考来源明确矛盾，或存在硬逻辑错误（量纲错/内部矛盾）时才判 failed。
这里的数值计算明显错误。100TB SSD 成本约 2.25万，400TB HDD 成本约 1.2万，总成本 3.45万，5年年化 6千多。陈述说是 107万。这不仅是误差，是完全错误的数量级。
因此，逻辑校验不通过（数值计算错误）。

但是，source=knowledge 的规则说：“逻辑自洽即判 verified... 禁止对 given/knowledge 节点引用本条款降级”。
然而，“逻辑自洽”的前提是计算正确。如果计算错误，就不自洽。
规则也说：“若 source 为 given 或 knowledge：核验重点变为「逻辑自洽 + 数值量级合理」”。
这里数值量级不合理（差了100倍以上）。
所以 logic_ok 应为 false。
如果 logic_ok 为 false，根据判定规则，通常倾向于 failed 或 degraded。
规则中 failed 的条件包括“存在硬逻辑错误”。计算错误属于硬逻辑错误。

因此，应判 failed。

修正后的表述：
C_dep_hybrid_5y = [(100TB * ¥225/TB * 0.95) + (400TB * ¥30/TB * 0.90)] / 5 = (21,375 + 10,800) / 5 = ¥6,435/年。
