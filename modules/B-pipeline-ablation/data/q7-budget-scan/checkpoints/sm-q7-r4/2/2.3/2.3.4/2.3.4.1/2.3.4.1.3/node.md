## Claim

基于修正后请求量（2亿次/日）的月度 API 成本重算：Monthly_API_Cost = (200,000,000 * 30 / 10,000) * Unit_Price。若 Unit_Price=¥0.01/万次，则成本 = 60,000 * 0.01 = ¥600/月；若 IA 层价格为 ¥0.1/万次，则成本 = ¥6,000/月。需将此与存储成本（¥0.1/TB/月 * 100TB = ¥10/月）对比，发现 API 成本可能远超存储成本。
