# N303: 云对象存储请求费用计算中，GET 请求单价为 $0.0004/1,000 requests，该参数适用于 AWS S3 标准存储层，GET 费用随读取对象数量线

## Claim

云对象存储请求费用计算中，GET 请求单价为 $0.0004/1,000 requests，该参数适用于 AWS S3 标准存储层，GET 费用随读取对象数量线性增长，与数据量成正比。

## Corrected Claim

AWS S3 标准存储层的 GET 请求单价通常为 $0.40/1,000 requests（具体价格因区域而异），GET 费用随请求次数线性增长，而非直接随数据量（字节数）成正比。

## Evidence

[质询]数值量级与口径混淆：AWS S3 标准存储（Standard）的 GET 请求单价通常为 $0.40/1,000 requests（即 $0.0004/1,000 是 $0.40 的 1/1000，或者混淆了 $0.0004 与 $0.40 的小数点位置，实际上 $0.0004/1,000 意味着每 100 万次请求仅 $0.4，远低于市场价；若指 $0.40/1,000，则陈述中的 $0.0004 数值错误）。此外，'与数据量成正比'表述不严谨，GET 费用主要与请求次数线性相关，而非直接随数据量（字节数）成正比（虽然通常读取大对象次数少，但费用模型是按次计费，非按字节计费）。 | 经验事实，逻辑自洽但缺来源支持；且数值 $0.0004/1,000 与 AWS S3 标准存储常见定价 $0.40/1,000 存在显著量级差异（相差 1000 倍），疑似小数点错误或单位混淆，无法确认为正确参数。
