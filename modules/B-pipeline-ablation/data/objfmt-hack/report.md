# OBJHACK 报告：目标函数形式 × hack 复现

# origin: ai
日期：2026-11-27 · spec: `spec.md` · 数据: `arms/*.json` + `hack-metrics.json`

## 问题
文字目标函数（高意图完备性）vs 其公式等价形式（低意图完备性），哪个更易被 hack？
复现 hack = 目标函数理解的操作性定义。

## 假设（预设判决句，防事后解释）
- H1: 公式臂 syn_sib_rate 更高 / info_density 更低 → 意图完备性决定 hack 性（坐实）
- H2: 两臂无分离（Δ<0.1）→ hack 由评分器/停止判据驱动，不是格式
- H3: 都不 hack → 预算 100 不够触发，加大预算重跑

## 判决
- **命中 H1（公式臂更易 hack），方向一致、分离清晰**：
  - 判别端点 = Jaccard 分布形状（预设修正：β 预过滤使 syn_sib 近零，见仪器 caveat）。
  - 公式臂两次 run 都出现同义变体对（gt05=1 和 14），文字臂两次都是 0 —— 零 vs 正，干净分离。
  - jac_max：文字 0.44/0.44 vs 公式 0.65/0.88（1.5-2 倍）；jac_p95：文字 0.15/0.29 vs 公式 0.33/0.53（~2 倍）。
  - info_density 方向一致但弱（0.50 vs 0.47）；rework 无干净方向（46/54 vs 70/35）——
    印证预设：判别力在分布形状，不在均值类端点。
- **解读**：公式目标（factors+composition，可机械优化、意图残缺）让模型在同义变体里打转
  （r2 有 14 对兄弟节点说同一句话），文字目标（保留"为什么"的终点描述）逼出更正交的分解。
  坐实 hack 性 ∝ 可优化性 × (1 − 意图完备性) 的行为侧证据。
- **hack 的形态**：这里是"软 hack"（冗余同义变体、正交维度塌缩），不是"硬 hack"
  （反向 gaming 评分指标）。复现的是意图残缺→同义打转这一支。
- caveat（n=2/臂、单题域、同模型自评风险）：
  - n=2/臂、单题域（GPU 选卡）；公式臂 run 间方差大（gt05 1 vs 14），文字臂也有（p95 0.15 vs 0.29）。
  - 同模型自评风险不涉及本实验（端点全机械计算：Jaccard/bge-m3 聚类，无 LLM 判分）。
  - 与 GPU paired 旧观察（text 臂 rework 更高）方向不一致：旧观察未控预算（公式臂自然只跑 53 节点），
    本实验预算固定 100 才是干净对照，以本实验为准。
- **仪器 caveat (2026-11-27 17:12, text 臂核出)**: syn_sib_rate 主端点结构性近零 — text 臂 252 兄弟对 Jaccard max=0.44/median=0.02, harness β 冗余惩罚在生成时预过滤同义节点, 幸存兄弟天然正交。两臂 syn_sib 都≈0 时 **不得判 H2**, 真因=harness 预过滤掩盖格式效应。判别力改看: ① Jaccard 分布形状 (formula 臂 max/p95 是否显著高) ② info_density ③ rework_density。

## 导出
- **对 ⑥ 思考触发分支**：4/4 runs 全 rework 停 + 公式臂同义打转（r1 rework=70 为四 run 最高）
  = "质疑→重做"循环的行为指纹。思考不接行动的根因假设获得行为侧支持：
  模型在"可机械优化的目标"下把预算花在重复而非探索。
- **对预算轴结论的补充**：预算买节点数不买正交质量（Q9 结论）在本实验复现——
  4/4 runs 都跑满 100 节点、全 rework 停，节点数相同但正交质量（info_density/jac 形状）
  由目标形式决定。
- **设计规则**：给 agent 设目标函数时，文字版（保留意图/为什么）优于公式等价版（只剩可优化项）；
  若必须用公式形式，需外挂意图锚点（如验收 gate 列表）补偿意图残缺。
