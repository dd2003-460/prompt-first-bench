## Claim

ARPU_min（每分钟每用户平均收入）的敏感性分析：若平台主要靠广告变现，ARPU_min = (年广告收入 / 365 / 24 / 60) / DAU_avg，假设年广告收入5亿元，则ARPU_min ≈ 0.0095元/分钟/用户；若包含会员订阅，ARPU_min可能提升至0.02元，导致每分钟损失从500元翻倍至1000元。
