## Claim

公有云 CDN 的 API 调用 成本：日均 2TB 下载量，假设 每 1000 请求 产生 1 次 API 调用（如 刷新 缓存/查询 状态），日均 请求量 为 200 万（基于 平均 对象 大小 1MB），则 日 API 调用 次数 = 200 万 / 1000 = 2000 次；阿里云 API 调用 单价 约为 0.01 元/次，故 日 API 成本 = 2000 × 0.01 元/次 = 20 元/天，月 API 成本 = 600 元/月。
