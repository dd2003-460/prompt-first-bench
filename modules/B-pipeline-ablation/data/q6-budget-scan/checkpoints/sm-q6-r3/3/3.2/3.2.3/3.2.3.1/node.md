## Corrected Claim

核心区域POP点带宽配置需求：北上广深4个核心点承担60-70%流量（1.2-1.4TB/日），按峰值系数2.0计算，峰值流量2.4-2.8TB/日≈24-28Gbps，单点需配置6-7Gbps，取整为10Gbps以确保SLA

## Evidence

先验知识/题面给定，逻辑校验通过：1.2-1.4TB/日 * 2.0峰值系数 = 2.4-2.8TB/日；2.4TB/日 ≈ 24Gbps (2.4*8*1000/86400≈22.2, 工程估算常取整或按8600s算≈22.4, 此处24-28Gbps为合理工程近似值，考虑到突发流量和协议开销，量级正确)；单点10Gbps配置满足24-28Gbps总峰值在4个核心点分摊后的单点需求（28/4=7Gbps，取整10Gbps留有余量），逻辑自洽。
