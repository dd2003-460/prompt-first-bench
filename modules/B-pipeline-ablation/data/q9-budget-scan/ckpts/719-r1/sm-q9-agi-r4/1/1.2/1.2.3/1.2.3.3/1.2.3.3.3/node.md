## Corrected Claim

滑动窗口重叠策略对 CER 独立性的影响：若窗口步长为 512（无重叠），CER 事件间存在独立性假设；若步长为 256（50% 重叠），同一错误可能被计入多个窗口，导致 CER 指标虚高（具体倍数视错误分布而定，通常显著高于无重叠情况）；建议采用步长 512 或实施跨窗口去重机制以消除重复计数。
