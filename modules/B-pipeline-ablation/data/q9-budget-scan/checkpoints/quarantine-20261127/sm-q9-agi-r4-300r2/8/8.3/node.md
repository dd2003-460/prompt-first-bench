## Claim

引用文献真实性校验通过 Crossref API 验证 DOI 的自动化流程中，单次查询延迟为 200-500ms，失败率（DOI 不存在或元数据不匹配）在模型生成的虚构引用中约为 15-20%；若连续 3 次校验失败，系统应标记该段落为‘高风险幻觉区’并强制调用外部搜索引擎进行二次验证，而非直接通过。

## Corrected Claim
