## 2. 矛盾裁决：GPU cov ~300 饱和 vs Q6 cov 719 仍涨

**矛盾原样**（S1 json 数字）：GPU 域 cov 300=0.358 (n=8) → 719=0.352 (n=3)，Δ=−0.006（平台/微降）；
Q6 域 cov 300=0.1377 (n=3) → 719=0.1667 (n=3)，Δ=+0.029（"仍在升"）。

**裁决：这是跨域口径差异，不是同域内饱和点矛盾；口径对齐后数据支持「饱和点是域属性（gold 覆盖空间的函数）」，conf 0.6。**

逐维度证据（落到具体档位数字）：

- **a) gold 规模差异（主因）**：GPU gold=36 units vs Q6 gold=46 units（k7 md L4 口径声明）。
  覆盖空间越大，cov 越难饱和。Q7 作为第三域佐证：cov 全 5 档单调升 0.1026→0.1667→0.1795→0.2564→0.3205，
  最大单段增益在 300→719（+0.0641），到 719 仍未见平台。三域方向一致：gold 空间大的域饱和晚。
- **b) n 与 CI（"仍在升"不成立，降级为"未证饱和"）**：Q6 719 档 n=3，且 S1 json 中 Q6 全档
  se/ci=null（无 per-rep 原始分，gap #4），Δ+0.029 的 CI 无法计算 → 统计上不能拒绝"已饱和"。
  旁证：719 nodepth 独立批 cov_mean=0.1956 vs 原批 0.1667（Δ+0.0289，n=3），方向一致但仍不足以
  建立显著性。对照 Q7（唯一可算 CI 的域）：300→719 cov Δ=+0.0641，CI=[−0.0681, +0.1963]（本卡按
  se=sqrt(0.0256²+0.017²) 重算），**CI 含 0**——即便增益最大的域，300→719 的 cov 增益在 n=3 下也不显著。
- **c) 实际节点数对齐（budget 是下界非上限）**：GPU 300 档 realized 节点 271-462（md L31-32，
  soft cap 下与 150 档重叠）；Q7 719 档 rep3 实际只跑到 604 节点（S1 json n_nodes）。
  两域"719 档"的实际计算量不可比，跨域按 budget 参数直接比饱和点本身就不成立。

**三选一结论**（原卡要求）：选 **「饱和点是域属性（gold 覆盖空间函数）」**，conf 0.6。
- 排除「普遍 ~300」：Q6/Q7 cov 在 719 方向均未回落（Q6 +0.029、Q7 +0.0641），与"普遍 300 饱和"矛盾。
- 排除「同域内矛盾」：GPU 域内两口径（池化 n=8 vs K7-only n=3）对"cov ~300 平台"判断一致（md L34），
  域内无矛盾；矛盾只出现在跨域比较，且由 gold 规模（36 vs 46）+ n（8 vs 3）+ 实际节点数错位三个口径差异解释。
- 限定：Q6「饱和点 >719」与「Q6 未饱和」在当前 n 下不可区分，表述为"未证饱和"，不做强断言。

## 3. Pareto 边界 + 推荐工作点

**各域最优档（三口径分开给）**：

| 域 | cov 最优档 | depth 最优档 | total 最优档 | 备注 |
|---|---|---|---|---|
| GPU | **300**（0.358 > 719 的 0.352） | 719（struct 0.933，但为 max_depth=5 机械台阶，非质量增益） | 719（0.643，但由 struct 台阶驱动） | cov 饱和 → 300 是质量拐点 |
| Q6 | **719**（0.1667，未证饱和） | 未测（struct/depth 全档缺失） | **719**（0.4833，但 300→719 每节点增益塌方，见下） | 300 有 rerun 复现证据 |
| Q7 | **719**（0.3205） | **719**（depth 1.0 触顶；300=0.867 已近顶） | **719**（0.6603，CI [0.6237, 0.6968]） | 唯一 CI 完整的域 |

**边际收益/成本（total 口径，每节点增益，本卡按 S1 json 数字重算）**：

| 域 | 150→300 Δtotal / 节点 | 300→719 Δtotal / 节点 | 塌方倍数 |
|---|---|---|---|
| GPU | +0.078 / 250 节点 = 0.00052 | +0.064 / 419 节点 = 0.000153 | 3.4× |
| Q6 | +0.0217 / 150 节点 = 0.000145 | +0.0181 / 419 节点 = 0.000043 | 3.4× |
| Q7 | +0.0718 / 150 节点 = 0.000479 | +0.0988 / 419 节点 = 0.000236 | 2.0× |

三域一致：**300→719 段的每节点边际收益较 150→300 段塌 2-3.4 倍**；GPU cov 在该段直接持平（Δ=−0.006）。
且 300→719 的增益在 n=3 下均不显著（Q7 total Δ CI=[−0.103, +0.300]，本卡按 se=sqrt(0.0461²+0.0085²) 重算，含 0）。

**跨域综合推荐工作点：budget = 300（单一明确），conf 0.6。**
理由一行：300 是三域共同拐点（GPU cov 饱和、Q6/Q7 每节点边际收益塌方 2-3.4×、Q7 depth 0.867 已近顶），
且是唯一有独立复现证据的档（Q6 300 rerun cache 隔离 0.4688 vs 原批 0.4652，Δ=+0.0036；GPU 300 档 n=8 为全域最大样本），
符合 goal 的"可靠性优先"；719 档多花 320 节点换不显著的边际增益，性价比拐点后塌方。

## 5. 口径限定（继承原卡 S3 要求）

- judge 族：judge_v1（qwen3.8-27b ×1，non-IRR）+ 域内 gold（gpu 36 units / q6 46 units）；
  total = 0.5*struct(depth/GOLD_DEPTH) + 0.5*cov(bge-m3 cosine≥0.70 命中 gold 单元比例)。
- n 口径：GPU 池化 n=3/8/8/8/3；Q6 n=3/档；Q7 n=3/档（t=4.303）。**n<8 的组功效不足**，
  跨域比较只比曲线形状不比 cov 绝对值（gold 规模不同，md L56）。
- max_nodes 是下界非上限：soft cap 下 realized 节点 GPU 300 档 271-462、Q7 719 档 rep3=604，
  预算参数 ≠ 实际计算量，跨域对齐必须用实际节点数。
- 已知混淆：Q6 原批 300/719 逐 rep 分数相同源于跨域 gold 匹配命中数少（非 cache 串内容，md L57-62）；
  metacog 轴与 cov 轴近乎独立（ρ≈0），"预算=覆盖度旋钮"只对 cov 轴成立，不泛化到整体研究质量。
