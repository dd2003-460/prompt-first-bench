# #53 因果测量 — 各层对根判定的信息贡献

# origin: ai
# 2026-11-24 · 直接计算 (非消融) · 复用 idea53-supply-bottleneck-enrichment.py 词表

## claim

LLM 研究树/推理树中，**深层节点对系统瓶颈判定（供给侧：SM 频率/指令吞吐/发射率/内存带宽/occupancy）的信息贡献更大**。非线性资源竞争系统下，浅层枚举无法确定哪个资源是瓶颈，瓶颈判定需要深层推理。

这是**因果测量**（信息论量），不是描述性 level 分布（后者已测：L4 富集三源显著 p<0.05，commit `0e866871c`）。

## 方法（直接计算，不消融不重跑）

- **根判定** = run 树根节点判定文本，或最终结论（answer 字段）：
  - ①rep-scan 无 answer → 根 = L1 节点 claim 拼接
  - ②t53b 有 answer → 根 = answer
  - ③stage-ablation 无 answer → 根 = L1 节点 claim 拼接
- **各层 L_k 信息贡献** = 该层节点对根判定的信息量。
- **度量（按优先级，n 不够降级）**：
  1. 首选 互信息 I(L_k; 根判定) — bge-m3 算各层节点文本与根判定文本相似度矩阵后算 MI（需联合分布，n 够才算）。
  2. 次选 条件熵降低 H(根)−H(根|L_k)。
  3. 降级 **贡献排名** = 各层供给侧瓶颈判定节点数 / 总瓶颈判定节点数（哪层贡献最大，不依赖 n 大，最稳健）。
- **供给侧词表** 复用 `idea53-supply-bottleneck-enrichment.py`（硬件供给词 ∧ 判定词），不重新定义。

|---|---|---|---|

## 结果

### 主度量（降级，最稳健）：贡献排名 — 各层供给侧瓶颈判定节点占比

| 层 | ①rep-scan | ②t53b | ③stage-ablation |
|---|---|---|---|
| L1 | 1.1% (8/736) | 0.6% (7/1082) | 1.0% (35/3473) |
| L2 | 7.5% (55) | 6.3% (68) | 11.5% (401) |
| L3 | 35.6% (262) | 26.9% (291) | 31.5% (1093) |
| **L4** | **55.8% (411)** | **66.2% (716)** | **47.5% (1651)** |
| L5 | — | — | 8.4% (293) |

**贡献最大层 = L4，三份数据源全部成立**（47.5%–66.2%）。瓶颈判定节点高度集中在深层 L4，浅层 L1 仅 0.6%–1.1%。这直接支持"深层 = 瓶颈判定层"的 claim。

### 次度量（首选/次选）：互信息 I(L_k; 根判定) + 条件熵降低（分类信息论量）

| 源 | n_trees | H(根) | 各层 I(L;根) (bits) |
|---|---|---|---|
| ①rep-scan | 15 | 0.390 | L1=0.252, L2=0.013, L3=0.000, L4=0.000 |
| ②t53b | 18 | 0.000 | 全 0（根判定恒定）|
| ③stage-ablation | 26 | 0.515 | L1=0.792, L2=0.000, L3=0.044, L4=0.083, L5=0.091 |

**⚠ 此度量 underpowered 且被根判定构造方式混淆，不作主结论：**
- **n_trees = 15/18/26 < 30** → 联合分布样本不足，MI 估计方差大（任务规则：n<30 直接降级）。
- **根判定由 L1 claim 拼接**（①③）→ L1 与根判定**构造上共变**，L1 的 MI 偏高是构造伪影，非"浅层贡献大"。
- **②t53b 根判定（answer）18 树全部含瓶颈判定语言** → 根恒定，H(根)=0，MI 全 0（无信息可传）。
- **bge-m3 连续相似度版**（任务首选）需对 27648 条文本编码，CPU 上 >45min 且 n_trees<30 同样 underpowered → 降级到本分类 MI + 贡献排名。

**结论：信息论高阶量（MI/条件熵）在本数据上 n 不足 + 根判定构造混淆，测不干净；稳健的因果证据来自贡献排名（度量3），它清楚显示 L4 贡献最大。**

## 边界与可信度

- **同族 judge（27b 评 27b）**：分数仅相对有效，绝对值不可信（系统性偏差被平均但不消除）。
- **level 口径不同**：三份源 L1–L4 / L1–L4 / L1–L5 口径不同，**不可合并比倍数**，同源自比。
- **轴陷阱**：run 树 level（judge 层）≠ gold 主干深度，本测量只测 run 树自身坐标系。
- **供给侧词是高频背景词**（~19% 节点命中），贡献占比天然比稀缺锚点弱，但 n 大时占比差异稳健。

## 一句话结论

**供给侧瓶颈判定节点在深层 L4 贡献最大（三源 47.5%–66.2%），浅层 L1 仅 0.6%–1.1% —— 直接支持"深层 = 瓶颈判定层"的 #53 核心 claim。高阶信息论量（MI/条件熵）因 n_trees<30 + 根判定构造混淆测不干净，主结论以贡献排名（降级度量，最稳健）为准。**
