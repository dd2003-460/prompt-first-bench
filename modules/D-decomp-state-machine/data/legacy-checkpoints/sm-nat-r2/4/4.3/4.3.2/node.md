在非均匀工作点下，热点对象（Top 10%）贡献了约 89.1% 的请求量，局部失效对整体命中率的影响显著。D_update 的修正应基于热点对象的加权失效概率，具体公式需确保量纲一致且符合命中率损失的物理定义（例如：D_update = Σ_{hot} p_i * (1 - H_i) / Σ_{all} p_i，其中 H_i 为局部命中率）。
