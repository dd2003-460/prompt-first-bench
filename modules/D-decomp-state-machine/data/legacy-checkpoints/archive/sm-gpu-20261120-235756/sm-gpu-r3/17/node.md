## Claim

候选硬件全集的完备性论证：在 Qwen3-27B 32K 上下文场景下，显存容量 < 24GB 的显卡（如 RTX 4080/5080）因无法容纳 FP8 权重 (27.18GB) 而被物理排除；显存 > 80GB 的显卡（如 H100 80GB, MI300X 192GB）因单卡 TCO 超过 $10,000 且性能收益边际递减（受限于单用户带宽瓶颈）而被标记为'非典型高成本备选'。最终候选集锁定为：24GB-48GB 消费/专业卡（RTX 4090/5090/6000 Ada）及 80GB 数据中心卡（A100/H100），该集合覆盖了从 $2,500 到 $15,000 的价格区间及 GDDR6/7/HBM 三种主要显存架构。
