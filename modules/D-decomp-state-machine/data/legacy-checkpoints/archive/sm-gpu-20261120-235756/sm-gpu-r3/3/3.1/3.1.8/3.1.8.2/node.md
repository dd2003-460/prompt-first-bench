## Claim

在典型 ATX 中塔机箱 (如 Fractal Design Meshify 2, $130) 中，RTX 4090 的 PCIe 插槽间距限制通常支持最大 240mm 或 280mm 冷排，若选择 360mm 冷排需全塔机箱 (如 Fractal Design Define 7, $200) 并可能牺牲硬盘位或风扇位；360mm 冷排 (如 Corsair H150i, $180) 相比 240mm 方案增加 $60 硬件成本和 $70 机箱升级成本，3 年摊销增加 $43.33/年，但散热效能提升约 15%，可将持续负载下的频率稳定性提高 1-2%，对长时推理任务 (24/7) 的 TCO 影响需结合故障率降低系数 (假设水冷故障率比风冷低 20%) 进行量化。
