## Corrected Claim

P_top10 = 0.45 的高集中度工作点意味着 LRU 缓存的小容量部分（如 5GB，约为 128GB 的 4%）可能覆盖显著比例的热点流量，但具体覆盖率及是否为边际收益最大点需结合具体访问分布模型（如 Zipf 指数）进一步验证，不能仅由 Top10 集中度直接得出 5GB 覆盖 45% 流量的结论。
