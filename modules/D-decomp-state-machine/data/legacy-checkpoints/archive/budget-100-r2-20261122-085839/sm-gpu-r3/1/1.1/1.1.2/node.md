## Corrected Claim

W4 量化下的额外显存开销：除权重本身（13.55 GB）外，W4A16 或 W4A8 方案需额外存储量化缩放因子（Scales/Zeros），通常每 128 或 256 个权重共享一个 FP16/FP8 缩放因子，增加约 1%-2% 的显存占用（约 0.14-0.27 GB）。
