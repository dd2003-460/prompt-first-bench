# N40: LFU字节命中率上界的量化计算：H_lfu = sum_{i in S_LFU} (request_rate_i * size_i) / total_bytes

- **status**: degraded
- **level**: L3
- **source**: knowledge
- **edge_type**: quotient
- **rework_count**: 1
- **parent_ids**: N11

## Claim

LFU字节命中率上界的量化计算：H_lfu = sum_{i in S_LFU} (request_rate_i * size_i) / total_bytes ≈ 0.92 * 0.7 ≈ 64%-68%，相比LRU的52%-55%，提升ΔH ≈ 10%-15个百分点，主要源于更精准地保留高频小对象。

## Corrected Claim

LFU字节命中率上界的量化计算：H_lfu ≈ 0.92 * 0.7 ≈ 64.4%，相比LRU的52%-55%，提升ΔH ≈ 9%-12个百分点。注意：LFU的优势取决于负载中高频对象的大小分布，若高频对象为大对象，LFU可能因缓存效率低而表现不佳。
