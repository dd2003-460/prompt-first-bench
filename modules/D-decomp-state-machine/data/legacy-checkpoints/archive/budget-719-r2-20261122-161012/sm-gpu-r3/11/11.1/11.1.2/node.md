## Corrected Claim

双 RTX 4090 方案的最小电源功率需求为 1200W (2x 450W GPU + 150W CPU + 100W 其他)，但考虑到峰值负载系数 1.2 及 PSU 效率曲线（80+ Gold 在 50-60% 负载效率最高），推荐选择 1600W 80+ Titanium 认证电源，其价格约为 $300-$450，相比 850W 电源增加 $150-$250 成本。
