## Corrected Claim

买家解释占比投影：在强算法干预条件下，买家解释占比 E_buyer = 0.40 + 0.10 * ξ_algo(t)，其置信度 C_buyer = 0.60 * exp(-0.3 * ξ_algo(t)^2)，当 |ξ_algo(t)| < 1 时，C_buyer ∈ [0.44, 0.60]。

## Evidence

先验知识/题面给定，逻辑校验通过：当 |ξ| < 1 时，ξ² < 1，故 -0.3 < -0.3ξ² < 0，exp(-0.3ξ²) ∈ (exp(-0.3), 1] ≈ (0.7408, 1]，C_buyer = 0.60 * exp(-0.3ξ²) ∈ (0.4445, 0.60]。题目声称 C_buyer ∈ [0.52, 0.60]，该区间是实际值域的子集（即若 C_buyer 在此范围内则成立，但实际值域更宽）。然而，通常此类陈述意指“在此条件下，C_buyer 的取值范围被限定在...”，若理解为“C_buyer 必然落在 [0.52, 0.60]”，则当 ξ 接近 ±1 时（如 ξ=0.9, ξ²=0.81, exp(-0.243)≈0.784, C≈0.47），C_buyer 会小于 0.52。因此，严格来说，陈述“C_buyer ∈ [0.52, 0.60]”作为 |ξ|<1 的必然结果是不准确的，因为存在 ξ 使得 C_buyer < 0.52。但是，考虑到 source=knowledge 且通常此类模型参数可能隐含 ξ 的有效范围或近似处理，或者题目本身定义如此。让我们重新检查计算：
ξ=1 -> C=0.6*exp(-0.3)=0.6*0.7408=0.4445.
ξ=0 -> C=0.6.
区间是 [0.4445, 0.60].
题目说 [0.52, 0.60].
0.52 对应 exp(-0.3ξ²) = 0.52/0.6 = 0.8667.
-0.3ξ² = ln(0.8667) ≈ -0.143.
ξ² ≈ 0.477.
ξ ≈ 0.69.
所以只有当 |ξ| < 0.69 时，C_buyer 才在 [0.52, 0.60]。
题目条件是 |ξ| < 1。
因此，陈述“当 |ξ| < 1 时，C_buyer ∈ [0.52, 0.60]”在数学上是**错误**的，因为存在反例（如 ξ=0.9）。

但是，根据【硬性约束】：source=knowledge 的节点，逻辑自洽即判 verified。这里逻辑**不自洽**（数学推导矛盾）。
规则说：“failed: 仅当该陈述与参考来源明确矛盾，或存在硬逻辑错误（量纲错/内部矛盾）时才判 failed。”
这里存在硬逻辑错误（数学区间包含关系错误）。
因此应判 failed。

修正：C_buyer ∈ [0.44, 0.60] 或类似更宽的范围。
