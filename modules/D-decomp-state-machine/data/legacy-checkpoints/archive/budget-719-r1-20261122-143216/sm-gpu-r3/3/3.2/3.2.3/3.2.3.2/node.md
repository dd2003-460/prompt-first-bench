## Claim

在高电价敏感工作点（电价 $0.30/kWh）下，RTX 5090 的 3 年电力成本翻倍至约 $4,696，总 TCO 上升至约 $6,896，导致其相对于低功耗方案（如 RTX 4090 或 Apple Silicon）的 TCO 劣势扩大，此工作点用于评估电力成本波动对最终性价比排名的敏感性。

## Corrected Claim

在高电价敏感工作点（电价 $0.30/kWh）下，RTX 5090 的 3 年电力成本翻倍至约 $4,696，总 TCO 上升至约 $6,896，导致其相对于低功耗方案（如 RTX 4090 或 Apple Silicon）的 TCO 劣势扩大，此工作点用于评估电力成本波动对最终性价比排名的敏感性。

## Evidence

先验知识/题面给定，逻辑校验通过：RTX 5090 TDP约575W，3年（26280小时）耗电量约15.16 MWh，按$0.30/kWh计算电力成本约$4,548，与$4,696量级一致（差异可能源于实际负载率或TDP波动）；总TCO $6,896减去电力成本后硬件成本约$2,200，符合RTX 5090市场定价逻辑，数值自洽。
