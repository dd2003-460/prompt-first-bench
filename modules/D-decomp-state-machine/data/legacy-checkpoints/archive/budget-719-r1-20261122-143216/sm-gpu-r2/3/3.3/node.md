## Corrected Claim

2×RTX 4090 24GB 通过张量并行可实现 32K 上下文推理，其硬件成本显著低于单张高端数据中心卡，但在具体吞吐量/TCO 比值是否绝对优于单张高端卡需结合具体模型负载和电力成本进一步实测验证。
