## Claim

GPU 间同步等待（Synchronization Barrier）：TP=4 要求 4 张 GPU 每层计算完成后同步。由于 GPU 计算时间存在微小差异（~5-10% 抖动），慢卡会等待快卡。实测中，同步等待导致整体吞吐下降 10-20%。4x 4090 TP=4 的有效吞吐 = 单卡理想吞吐 / 4 * (1 - 同步损耗率)。若同步损耗率为 15%，则有效吞吐 = 单卡 / 4 * 0.85 = 单卡 * 0.2125，即仅为单卡的 21.25%（而非理想 25%），与 '60-70% 效率' 的说法不符——此处 '60-70%' 应指相对于 TP=4 理想加速比 (4x) 的效率，即实际加速比 = 4 * 0.65 = 2.6x，而非绝对吞吐占比。

## Corrected Claim
