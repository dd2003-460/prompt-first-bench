## Claim

多卡 TP=4 下的计算延迟因并行度提升而降低：理想情况下计算延迟变为单卡的 1/4，即 ~67.5 μs/token。但实际受同步等待影响，总延迟 = max(计算时间, 通信时间) + 同步开销。由于通信时间 (17 μs) < 计算时间 (67.5 μs)，总延迟接近 67.5 μs + 同步开销。
