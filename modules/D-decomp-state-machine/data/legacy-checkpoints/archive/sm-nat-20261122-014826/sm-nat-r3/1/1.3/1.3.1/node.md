## Claim

基于 ρ=-0.3 的大小-热度相关性，Top-1% 对象 (r<1000) 的条件期望大小 E[Size|Top-1%] 的量化：E[Size|Top-1%] = E[Size] * (1 + ρ * (μ_heat/σ_heat - μ_size/σ_size))，需先计算热度秩与大小秩的相关系数转换，初步估计约为 0.9 * E[Size] = 9.9KB。

## Corrected Claim

基于 ρ=-0.3 的大小-热度相关性，Top-1% 对象的条件期望大小 E[Size|Top-1%] 不能通过简单公式 E[Size] * (1 + ρ * (μ_heat/σ_heat - μ_size/σ_size)) 直接计算。若假设线性关系，需使用回归方程 E[Size|Heat=h] = μ_size + ρ(σ_size/σ_heat)(h-μ_heat)，并代入 Top-1% 对应的热度阈值 h_99% 进行计算。初步估计约为 0.9 * E[Size] = 9.9KB 的结论缺乏严谨推导支持。
