## Claim

满足 450W 散热需求的机箱风道设计最小标准：需至少 3 个前置进风风扇（120mm/140mm，风量 >70 CFM each）和 2 个后置/顶部出风风扇，形成前进后出风道；若机箱风道设计不良（如进风不足），GPU 温度在 30 分钟内可上升 10-15°C，触发节流。
