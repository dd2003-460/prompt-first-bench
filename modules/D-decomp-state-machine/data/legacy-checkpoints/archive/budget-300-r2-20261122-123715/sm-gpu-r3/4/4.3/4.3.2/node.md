## Corrected Claim

1x L40S (48GB) 数据中心卡方案：显存容量 48GB 理论上可容纳 INT8 权重 (27GB) + 32K KV Cache (~18GB)，但激活值与框架开销可能导致显存紧张，需精细优化或降低并发；其 FP8 支持通常能保持较低量化损失（具体 PPL 增量视模型而定），采购成本 (~$8000-10000) 约为 2x 4090 (~$3200) 的 2.5-3 倍，需通过单卡稳定性与免多卡驱动复杂性来平衡 TCO。
