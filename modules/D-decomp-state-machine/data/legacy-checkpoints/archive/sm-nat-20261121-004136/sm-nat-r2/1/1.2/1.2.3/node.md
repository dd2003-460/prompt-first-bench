## Claim

在 β=0.9 的 Pareto 热度分布下，覆盖 90% 请求流量所需的最小对象数量 k_90 可通过求解 1 - (k_90/N)^0.1 = 0.9 得到，k_90 = N * (0.1)^(1/0.1) = 100,000 * 0.1^10 ≈ 0.1，即理论上仅需极少头部对象即可覆盖大部分流量，实际需结合最小频率阈值。

## Corrected Claim

在 β=0.9 的 Pareto 热度分布下，若 N=100,000，求解 1 - (k_90/N)^0.1 = 0.9 得到 k_90 = N * (0.1)^(1/0.1) = 100,000 * 10^-10 = 10^-5。由于 k_90 必须至少为 1，这意味着在如此陡峭的分布下，理论上仅需 1 个头部对象即可覆盖绝大部分（接近 100%）流量，实际部署中需结合最小频率阈值和长尾效应进行调整。
