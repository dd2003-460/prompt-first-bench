## Claim

单位 token 成本临界利用率 U_crit 计算：令 TCO_3090 / (T_3090 * U) = TCO_H100 / (T_H100 * U)。由于 TCO 包含固定成本（硬件+维护）和变动成本（电力），电力成本随利用率线性变化。设固定成本 F_3090 = $1,522.5 + $480 = $2,002.5，F_H100 = $20,400 + $90 = $20,490。变动成本系数 V_3090 = $1,684.35 / (50.15 * 3600 * 24 * 365 * 3) ≈ $0.0000114 /token，V_H100 = $1,506.53 / (60.99 * 3600 * 24 * 365 * 3) ≈ $0.0000108 /token。临界利用率 U_crit = (F_H100 - F_3090) / (V_3090 - V_H100) * T_total。由于 V 值极小且接近，主要差异在固定成本，U_crit 极低，意味着在几乎所有实际利用率下，3090 方案单位成本更低，除非 H100 吞吐量优势通过高并发放大（此处为单用户场景，不适用）。

## Corrected Claim

单位 token 成本临界利用率 U_crit 计算：令 TCO_3090 / (T_3090 * U) = TCO_H100 / (T_H100 * U)。由于 TCO 包含固定成本（硬件+维护）和变动成本（电力），电力成本随利用率线性变化。设固定成本 F_3090 = $2,002.5，F_H100 = $20,490。变动成本系数 V_3090 和 V_H100 需重新定义为单位时间单位吞吐量的成本，或修正公式为 U_crit = (F_H100 - F_3090) / (V_3090 * T_3090 - V_H100 * T_H100) 以确保量纲一致。由于 V 值极小且接近，主要差异在固定成本，U_crit 极低，意味着在几乎所有实际利用率下，3090 方案单位成本更低，除非 H100 吞吐量优势通过高并发放大（此处为单用户场景，不适用）。

## Evidence

[质询]公式推导存在量纲错误：U_crit 应为无量纲比率，但公式右侧乘以了 T_total（时间/吞吐量单位），导致量纲不一致；此外，临界利用率通常定义为固定成本差与变动成本差之比，不应包含总吞吐量 T_total 作为乘数，除非 T_total 被定义为特定归一化因子，但此处未明确定义，导致逻辑不自洽。 | 先验知识/题面给定，逻辑校验发现公式量纲错误（U_crit 应为无量纲，但公式含 T_total），且 V 值计算中分母包含时间单位，导致 V 单位非 $/token 而是 $/(token*时间) 或类似，与后续除法不匹配。
