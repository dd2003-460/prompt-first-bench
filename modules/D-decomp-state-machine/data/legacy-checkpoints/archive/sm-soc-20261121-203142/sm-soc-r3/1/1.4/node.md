## Claim

投影3（平台侧）：平台算法对‘高挂价+短周期’商品的曝光加权系数 W_exposure = 1 + α * (P_ask / P_market)，其中 α > 0 代表平台对高溢价商品的高点击率预期，导致即使未成交，高挂价商品在搜索排名中占据优势，缩短买家决策路径。

## Corrected Claim

部分平台算法可能对高溢价商品给予一定的曝光加权或特殊流量扶持，以匹配特定高净值用户群体，但具体加权系数及公式形式因平台、品类及算法版本而异，并非通用的线性公式 W_exposure = 1 + α * (P_ask / P_market)。
