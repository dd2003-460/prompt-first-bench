## Claim

更新率 λ 对缓存空间碎片化的影响机制：当对象更新时，LRU 将其移至栈顶，若对象大小不变则不产生碎片，但若更新伴随大小变化（如视频转码），则产生空间碎片；量化碎片率 Fragment_Rate = λ * E[|ΔS|/S]，其中 E[|ΔS|/S] 为平均相对大小变化率（CDN 场景下通常 <5%），因此碎片化对命中率的影响通常 <0.5%，可忽略不计。
