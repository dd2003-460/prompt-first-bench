## Corrected Claim

工作点2（中驻留/标准失效）：假设对象平均驻留时间 T_resident = 100 天，若失效率参数为 0.01/天，则 M_invalidation = 1 - exp(-0.01 * 100) = 1 - exp(-1) ≈ 0.632（约63.2%）；若 M_invalidation ≈ 0.00995（约1.0%），则对应的失效率参数应为 0.0001/天（即 1 - exp(-0.0001 * 100) ≈ 0.00995）。
