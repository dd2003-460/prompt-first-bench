## Corrected Claim

均价变化 ΔP_t 的构成拆解：ΔP_t = ΔP_mix + ΔP_negotiation，其中 ΔP_mix 为高溢价商品占比下降导致的结构性均价降低（假设高溢价商品原占 GMV 的 30%，占比降至 10% 时，混合均价下降约 -5%），ΔP_negotiation 为剩余商品因竞争加剧导致的议价空间扩大（假设 -2%~-5%），总和需符合 [-5%, -10%] 区间。
