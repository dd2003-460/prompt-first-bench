## Claim

搜索成本 S 对降价咨询率的非线性抑制作用：即使 ΔP > ΔP_crit，若买家的总搜索成本 S 过高，导致 U_buyer = V - P_new - S < 0，买家仍不会咨询。需计算临界价格 P_min = V - S，只有当 P_new < P_min 时，咨询率才显著上升。对于 60% 无咨询的卖家，需验证其 P_new 是否仍高于 P_min，若是，则“无咨询”并非因为 ΔP < ΔP_crit（噪音），而是因为 P_new 仍高于买家的保留价格（Reservation Price），需修正解释框架为“价格仍高于保留价格”而非“降价幅度不足”。
