## Claim

置信度上限 0.6 与 0.85 的设定依赖于假设检验的显著性水平 α（通常 0.05）和统计功效 Power（通常 0.8）；若 α 或 Power 改变，置信度区间需通过 Z-score 重新计算，公式为 Confidence = Φ(√n * β / σ)。

## Corrected Claim

置信度上限的设定依赖于显著性水平 α（通常 0.05）；统计功效 Power（通常 0.8）用于确定所需样本量 n，其关系近似为 n ≈ (Z_{1-α/2} + Z_{Power})² * σ² / β²。置信度本身通常固定为 1-α，不随 n 或 β 变化，而是区间宽度随 n 变化。

## Evidence

[质询]公式 Confidence = Φ(√n * β / σ) 在统计学上缺乏标准定义且量纲/逻辑存疑：置信度（Confidence Level）通常由显著性水平 α 决定（如 1-α），而非直接由样本量 n、效应量 β 和标准差 σ 通过正态分布函数 Φ 计算得出；该公式更像是将统计功效（Power）或 Z 分数误用为置信度，且未体现 α 与 Power 的联合约束关系。 | 先验知识/题面给定，逻辑校验未通过：置信度与显著性水平 α 直接相关，而公式中未包含 α，且 Φ(√n * β / σ) 通常关联于功效计算而非置信度定义，存在概念混淆。
