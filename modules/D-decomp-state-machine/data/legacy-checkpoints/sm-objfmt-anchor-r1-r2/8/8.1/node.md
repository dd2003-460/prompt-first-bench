## Claim

在无硬性延迟约束下，用户感知流畅度的阈值 ITL_threshold 定义为：当 Inter-Token Latency < 20ms 时，阅读速度跟上生成速度，主观体验为'即时'；当 20ms < ITL < 100ms 时，体验为'可接受'；当 ITL > 100ms 时，体验为'卡顿'。性价比排序中，只要 ITL < 100ms，TTFT 和 ITL 的具体数值差异对效用函数的边际贡献趋近于 0。

## Corrected Claim

在无硬性延迟约束下，通常认为较低的Inter-Token Latency（ITL）能提升用户感知流畅度。一般而言，ITL低于一定阈值（如几十毫秒）时体验较为流畅，超过较高阈值（如百毫秒级）时可能产生卡顿感。在ITL处于较低水平时，进一步降低ITL或优化TTFT对用户整体效用的边际提升可能相对有限，但具体阈值和效用曲线因应用场景和用户偏好而异。
