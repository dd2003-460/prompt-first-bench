## 正案例：结构化递归（任务自身词 → 正交拆 → 递归 → 原子）

目标（任务自身描述）: 求比值 R = A/B 的最小值。

- 第1层 — 拆任务自身词: R 由两个正交因素决定 → 分子 A、分母 B（R=A/B；A、B 独立，合起来完全定义 R）。
- 第2层 — 递归 A: A = X·Y（X、Y 正交，合完全决定 A）。
- 第3层 — 递归 X: X = X₁ + X₂（正交，合覆盖 X）；X₁、X₂ 不能再分解 → 原子。
- 第2层 — 递归 B: B = B₁·B₂；B₁、B₂ 原子。
- 停止: 叶子 {X₁, X₂, Y, B₁, B₂} 全部原子 → 分解完成。
- 结构特征: 每层拆"一个"因素；拆是正交+完整；先拆任务自身词（R→A,B），再递归；层级嵌套清晰（X 含 X₁, 不并列）。

## 负案例：扁平/凌乱（同一目标, 错误写法）

把 R 直接写成并列清单: [A 大小, B 大小, X, Y, X₁, X₂, 单调性, 边界, 精度, 单位…]。

- 错1 缺第1层正交拆: R 拆到 10 个并列项, 不是 A/B 两正交 → 结构丢失。
- 错2 层级混: X 与 X₁ 同层并列, 但 X 含 X₁ → 父子并列错。
- 错3 非正交: "单调性" 与 "A 大小" 重叠（单调性由 A 变化）→ 用同一指标判断, 应合并或重新划界。
- 错4 未递归到原子: X 停在非原子（未拆 X₁+X₂）→ 分解未完成。
- 判定: 负 → 按正案例重构。

## 正/负：已知 vs 待研究（数学）

- 正: "√2  هو irrational" 标 已知（一手: 经典证）; "Goldbach 对 n>10^18 成立" 标 待研究（未证, 不伪装已知）。
- 负: 把 "Goldbach 对所有 n 成立" 写作为已知事实 → 未证伪装已知, 红线。
