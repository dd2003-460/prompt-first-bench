# 阶段 04.5：最终复核与交接

## 操作流程

1. **从反方角度**检查全过程（不重新开展无边界研究）：挑战结论、主动找反例、评估错误风险与影响、给出替代方案。
2. 对照原始任务、01 空缺、02 证据、03 行动、04 结果，检查能否串成完整链条。
3. 列出：依据、薄弱点、未完成项、残余风险、最有价值的下一步。
4. 对书稿/代码/PDF 等产出核对**真实文件、编译结果、读者可见变化**。
5. 发现需要新资料或重新执行 → **明确回退阶段**，不把问题藏进最终总结。

## Reviewer 质检标准

- 原始任务是否全部得到回应；关键空缺、证据、行动、结果能否串成完整链条。
- 最终结论是否超出证据支持范围（不夸大）；未完成项和不确定性是否清楚。
- 交付物是否真实存在并经过必要验证；下一位使用者能否仅凭这些 Markdown 继续工作（可交接、可复现、可追溯）。

存在影响最终结论的缺口 → 必须 revise，`repair_stage` 写真正需要修复的阶段。
