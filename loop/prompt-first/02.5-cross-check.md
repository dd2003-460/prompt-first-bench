# 阶段 02.5：交叉核验与矛盾

## 操作流程

1. 逐项检查阶段 02 的关键主张、来源和观察时间。
2. 比较不同来源的定义、测量条件、样本、时间和利益关系。
3. 解释一致处和矛盾处；不能解释时保留不确定性，不强行收敛。
4. 检查网页 LLM 的结论是否被独立来源支持。
5. 形成可以交给行动分解阶段使用的证据边界。

## Reviewer 质检标准

- 关键结论是否真正经过独立来源比较；
- 矛盾是否有具体解释，而不是只写"基本一致"；
- 是否混淆理论规格、实测性能、当前价格和个人推断；
- 是否遗漏会改变结论的反例；
- 是否清楚标注仍未解决的问题。

如果需要补充新资料，repair_stage 写 02；如果资料充分但核验表达不完整，repair_stage 写 02.5。

## 操作示例（数学领域, 仅方法示范, 无任务信息）

### 正案例 1：小数展开不一致 → 解释（精度/截断）

**阶段 02 收集：**
```
- 来源 1：π = 3.14159265358979（15 位）
- 来源 2：π = 3.14159265358979323846（20 位）
```

**交叉核验：**
```
矛盾处：表面不一致（位数不同）。
解释：来源 1 截 15 位, 来源 2 20 位; 前 15 位一致 → 无实际矛盾, 精度不同。
处理：取更高精度来源, 标注精度; 不强行"平均"两值。
```

### 正案例 2：理论精确 vs 数值计算差异 → 解释（浮点 round-off）

**阶段 02 收集：**
```
- 来源 1（理论）：ζ(2) = π²/6 精确
- 来源 2（数值）：计算得 1.6449340668482262, 与 π²/6 差约 1e-16
```

**交叉核验：**
```
矛盾处：数值与理论精确差 1e-16。
解释：double 精度约 16 位 round-off; 差异属精度, 属"数值/实测" vs "理论精确"。
处理：区分理论精确 vs 数值近似; 用更高精度（mpmath dps=50）复核 → 一致。
```

### 正案例 3：已证明 vs 未证矛盾 → 解释（条件/版本）

**阶段 02 收集：**
```
- 来源 1："X 真"
- 来源 2："X 未证"
```

**交叉核验：**
```
矛盾处：来源 1 真 vs 来源 2 未证。
解释：来源 1 指"X 在条件 C 已证明"; 来源 2 指"X 无条件未证"; 一致。
处理：标注条件; 不强行收敛; 未证部分保留未伪装。
```

### 负案例：未解释矛盾 / 强行收敛

```
- 只写"两来源基本一致"无精度/条件检查 → 缺解释, 红线。
- 把数值近似与理论精确"平均"写成一个精确值 → 强行收敛, 红线。
- 把数值验证写成已证明 → 混淆类型, 红线。
```
