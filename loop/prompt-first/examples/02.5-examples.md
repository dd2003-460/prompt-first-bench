## 正案例：小数展开不一致 → 解释（精度/截断）

```
来源 1：π = 3.14159265358979      （15 位）
来源 2：π = 3.14159265358979323846（20 位）
```

```
矛盾：表面不一致
解释：来源 1 截 15 位、来源 2 取 20 位；前 15 位完全一致 → 无实际矛盾
处理：取更高精度来源并标注精度；不强行「平均」两值
```
