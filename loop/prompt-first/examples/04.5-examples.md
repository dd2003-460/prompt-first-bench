## 示例：ζ(2)=π²/6 的最终复核

```
原始任务：验证 Basel 问题（已证明 + 数值复核）

01 空缺回顾：定义与收敛条件[已完成] / 50 位数值复核[已完成]
             / 推导链可追溯[已完成] / 用户要更高精度[未完成—用户未提供]
02 证据回顾：已证明 Euler 1735 / 数值前 50 位一致，差 < 1e-50 / 边界 s=1 说明条件必要
03 行动回顾：步骤 1-3 全部完成
04 结果核对：命令与输出可复算，无失败项
结论边界：在 s>1 与 50 位精度内成立；更高精度未验证 → 不写成已证
回退判断：无需回退；未完成项属用户输入缺失，非流程缺陷
```

要点：链条（任务→空缺→证据→行动→结果）逐环对上；结论写清**成立范围**；未完成项标明归属。
