## 正案例：核验已证明事实（多独立来源 + 区分类型）

主张：「ζ(2) = π²/6」（Basel 问题）。

```
1. 一手来源：教科书/论文给出 ζ(2)=π²/6 及证明（Euler 1735）
   记录：类型=已证明、来源=一手、观察时间
2. 独立来源（数值）：mpmath 算 ζ(2) 与 π²/6 到 50 位 → 一致
   记录：类型=数值验证、精度=50 位、工具+版本
3. 区分标注：「已证明」≠「数值验证」；数值不替代证明，但独立支持
4. 易变事实类比：数学里「最新已知记录」（如最大 Mersenne prime）属易变——
   必须近日一手来源，资料 > 7 天即标未解决
```
