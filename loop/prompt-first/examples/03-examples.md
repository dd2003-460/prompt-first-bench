## 示例 1：验证 Basel 问题 ζ(2)=π²/6 — 行动分解

**阶段 02 证据：**
```
- 已证明：ζ(2)=π²/6（Euler 1735, 现代 Fourier 解析）, 条件 s>1 收敛
- 数值线索：Σ1/n² 与 π²/6 前 15 位一致
```

**行动分解：**
```
步骤 1：高精度数值复核
- 输入：已核验定义 ζ(2)=Σ_{n≥1} 1/n², 条件 s=2>1
- 动作：mpmath dps=50 计算 Σ1/n² 与 π²/6, 求差
- 依赖：无
- 预期产出：两数值 + 差
- 验收方式：|差| < 1e-40
- 并行：是（两计算可并行）
- 失败替代：换精度 / 换加速（Euler 加速）

步骤 2：符号推导链
- 输入：已核验条件（s>1 保证收敛）
- 动作：推导 ζ(2)=π²/6（Euler 方法 / Fourier 系列）
- 依赖：步骤 1 数值确认收敛
- 预期产出：推导链每步可追溯
- 验收方式：每步逻辑可追溯, 无跳
- 并行：否（依赖步骤 1）
- 失败替代：标注未证, 不伪装已证明

步骤 3：边界反例检查
- 输入：推导链 + 条件 s>1
- 动作：检查边界 s=1（harmonic 极缓慢）确认条件必要
- 依赖：步骤 2
- 预期产出：边界结论
- 验收方式：反例 s=1 确认条件必要
- 并行：否
- 失败替代：属边界不补造
```

## 示例 2：证明 √2 无理 — 行动分解

**阶段 02 证据：**
```
- 已核验：√2 定义, 有理 = p/q 整数比值
```

**行动分解：**
```
步骤 1：反证假设
- 输入：已核验定义
- 动作：假设 √2=p/q, gcd(p,q)=1
- 依赖：无
- 预期产出：假设 + 约定
- 验收方式：假设明确
- 并行：是
- 失败替代：属边界不补造

步骤 2：推导矛盾
- 输入：反证假设
- 动作：p²=2q² → p 偶 → p=2k → 2k²=q² → q 偶 → 无限 descent
- 依赖：步骤 1
- 预期产出：矛盾链
- 验收方式：每步可追溯
- 并行：否
- 失败替代：标注未证, 不伪装已证明

步骤 3：结论 + 边界
- 输入：矛盾链
- 动作：反证成立 → √2 无理; 边界 gcd 约定检查
- 依赖：步骤 2
- 预期产出：结论 + 边界
- 验收方式：结论属已证明范围, 不夸大
- 并行：否
- 失败替代：属边界不补造
```
