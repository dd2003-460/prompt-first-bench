## 示例：验证 ζ(2)=π²/6 的行动分解（节选两步）

```
步骤 1：高精度数值复核
  输入=ζ(2)=Σ1/n²、条件 s=2>1；动作=mpmath dps=50 算 Σ1/n² 与 π²/6 求差
  依赖=无；产出=两数值+差；验收=|差| < 1e-40；并行=是
  失败替代=换精度 / Euler 加速

步骤 2：符号推导链                     ← 依赖步骤 1 的收敛确认
  输入=已核验收敛条件；动作=推导 ζ(2)=π²/6（Euler / Fourier）
  产出=每步可追溯的推导链；验收=无跳步；并行=否
  失败替代=标注未证，不伪装已证明
```

要点：每步都写满 输入/动作/依赖/产出/验收/并行/失败替代 七项；依赖链单向无环。
