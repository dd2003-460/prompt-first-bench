## 正案例：结构化递归

目标：求 R = A/B 的最小值。

```
第1层  拆任务自身词：R → 分子 A、分母 B（正交、合起来完全定义 R）
第2层  递归 A：A = X·Y（正交、完全决定 A）
第3层  递归 X：X = X₁ + X₂；X₁、X₂ 不可再分 → 原子
第2层  递归 B：B = B₁·B₂；均可再分？→ 直到原子
停止   叶子 {X₁, X₂, Y, B₁, B₂} 全原子 → 分解完成
```

要点：每层只拆**一个**因素；拆分必须正交且覆盖；先拆任务自身词再递归；层级嵌套不并列。
