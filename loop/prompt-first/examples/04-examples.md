## 示例：数值核验执行记录

```
步骤 1（计划：确认 mpmath 可用，验收=dps 输出正常）
  命令：python -c "import mpmath as mp; print(mp.mp.dps)"
  输出：15；结果：通过；文件：无修改；观察：可用，默认 15 位

步骤 2（计划：50 位复核 ζ(2) 与 π²/6）
  命令：mp.mp.dps=50; print(mp.zeta(2)); print(mp.pi**2/6)
  输出：两行均为 1.644934066848226264071911774834817036373194211365
  结果：通过；观察：50 位一致，差 < 1e-50

步骤 3（边界）
  命令：dps=30; print(mp.zeta(1))
  结果：通过（属边界）；观察：s=1 调和级数极缓慢 → 条件 s>1 必要
```

要点：每条记录都含 **命令 / 输出 / 结果 / 文件改动 / 观察**，且逐项对照 03 的验收方式。
