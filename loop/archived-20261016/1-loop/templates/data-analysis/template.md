# 数据分析模板（预测导向）

> 面向预测结果准确性的数据分析分解模板。
> 核心要求：**预测准确性**
> 编号规范：R{轮次}-D{深度}-S{步骤}

---

## 模板定义

```markdown
### 数据分析分解模板

- **适用领域**: prediction-oriented data analysis
- **核心要求**: 预测准确性（模型在测试集上的表现）
- **输入**: 澄清结论（目标定义 + 数据约束 + 假设）
- **输出**: 数据分析计划（含子任务列表 + 每步验证标准）
- **分解模板 ID**: data-analysis-001
```

---

## 分解结构

```
R-D-S-1: 数据获取（搜索/读取/拉取数据）
R-D-S-2: 数据预处理（清洗、格式统一、缺失值处理）
R-D-S-3: 基线模型（简单模型先跑通）
R-D-S-4: 模型选择与训练（基于 S-3 基线性能选择）
R-D-S-5: 验证评估（独立测试集验证）
R-D-S-6: 结果解释（为什么准确/不准确）
```

### R-D-S-1: 数据获取

- **类型**: information-gathering
- **输入**: 澄清结论中的目标定义
- **输出**: 数据集（格式统一、可读取）
- **继续条件**:
  - [ ] 数据已获取
  - [ ] 数据格式可读取
  - [ ] 数据规模合理（不是空数据）
- **回退条件**:
  - [ ] 数据不足 → 补充搜索数据源
  - [ ] 数据格式不可读 → 问用户（"可用哪个数据？"）
- **继续输出**: [完整数据集 + 数据描述]
- **回退输出**: [缺失的数据清单 + 建议的数据源]

### R-D-S-2: 数据预处理

- **类型**: execution
- **输入**: 数据集（S-1 产出）
- **输出**: 干净数据集
- **继续条件**:
  - [ ] 缺失值已处理
  - [ ] 格式已统一
  - [ ] 异常值已标记
- **回退条件**:
  - [ ] 数据质量问题无法修复 → 回到 S-1 换数据源
  - [ ] 预处理引入偏差 → 回到 S-2 调整预处理
- **继续输出**: [干净数据集 + 预处理说明]
- **回退输出**: [数据质量问题清单 + 建议的替代方案]

### R-D-S-3: 基线模型

- **类型**: execution
- **输入**: 干净数据集（S-2 产出）
- **输出**: 基线性能指标
- **继续条件**:
  - [ ] 基线模型已训练
  - [ ] 基线性能指标已计算
- **回退条件**:
  - [ ] 基线模型失败 → 检查 S-2 预处理
  - [ ] 基线性能为 0 → 检查数据质量
- **继续输出**: [基线模型 + 性能指标]
- **回退输出**: [失败原因清单 + 建议的调试方向]

### R-D-S-4: 模型选择与训练

- **类型**: execution
- **输入**: 基线性能指标（S-3 产出）+ 干净数据集（S-2 产出）
- **输出**: 训练好的模型 + 训练集性能
- **继续条件**:
  - [ ] 模型已训练
  - [ ] 性能高于基线
- **回退条件**:
  - [ ] 性能低于基线 → 换方法或调参
  - [ ] 模型不收敛 → 检查数据和预处理
- **继续输出**: [训练好的模型 + 训练集性能]
- **回退输出**: [性能不达标的原因 + 建议的替代方法]

### R-D-S-5: 验证评估

- **类型**: verification
- **输入**: 训练好的模型（S-4 产出）
- **输出**: 验证报告
- **继续条件**:
  - [ ] 独立测试集性能已计算
  - [ ] 验证指标明确
- **回退条件**:
  - [ ] 验证结果不达标 → 回到 S-4 调整模型
  - [ ] 过拟合 → 调整正则化或换模型
- **继续输出**: [验证报告 + 测试集性能]
- **回退输出**: [验证失败的原因 + 建议的替代验证方法]

### R-D-S-6: 结果解释

- **类型**: execution + verification
- **输入**: 验证报告（S-5 产出）
- **输出**: 结果分析报告
- **继续条件**:
  - [ ] 有明确的分析结论
  - [ ] 结论有数据支持
- **回退条件**:
  - [ ] 结论不明确 → 回到 S-5 重新分析
  - [ ] 结论无数据支持 → 回到 S-4 调整模型
- **继续输出**: [结果分析报告 + 明确结论]
- **回退输出**: [分析失败的原因 + 建议的替代分析方法]

---

## 验证标准

| 步骤 | 验证方式 | 通过标准 |
|------|---------|---------|
| S-1 | 数据完整性检查 | 数据非空、格式可读、规模合理 |
| S-2 | 数据质量检查 | 无缺失值、格式统一、异常值已标记 |
| S-3 | 基线性能指标 | 性能指标已计算、模型已训练 |
| S-4 | 训练性能指标 | 性能高于基线、模型已训练 |
| S-5 | 验证报告 | 独立测试集性能已计算、指标明确 |
| S-6 | 结果分析报告 | 有明确结论、结论有数据支持 |

---

## 预测准确性阈值参考

| 任务类型 | 合理阈值 | 优秀阈值 |
|---------|---------|---------|
| 分类（2 类） | ≥ 0.75 | ≥ 0.90 |
| 分类（多类） | ≥ 0.60 | ≥ 0.80 |
| 回归 | ≥ 0.70 (R²) | ≥ 0.85 (R²) |
| 时间序列 | ≥ 0.70 (MAPE) | ≥ 0.85 (MAPE) |

> 阈值根据数据质量和任务复杂度调整。S-6 分析阶段必须说明采用的阈值和理由。
