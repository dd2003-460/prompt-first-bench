# 论文模板（Journal-Facing）

> 面向期刊发表的论文分解模板。
> 核心要求：**工作量 + 创新点**
> 编号规范：R{轮次}-D{深度}-S{步骤}

---

## 模板定义

```markdown
### 论文分解模板

- **适用领域**: journal-facing research
- **核心要求**: 工作量（对标顶刊）+ 创新点（方法修改/新发现）
- **输入**: 澄清结论（目标定义 + 约束 + 假设）
- **输出**: 论文计划（含子任务列表 + 每步验证标准）
- **分解模板 ID**: paper-001
```

---

## 分解结构

```
R-D-S-1: 问题定义（文献综述 → 找到空白 → 明确研究问题）
R-D-S-2: 方法选择（已有方法对比 → 确定方法 + 修改点 = 创新点）
R-D-S-3: 工作量执行（实验/推导/模拟 — 必须对标已发表论文）
R-D-S-4: 结果分析（数据/公式 → 图表/结论）
R-D-S-5: 论文写作（符合期刊格式要求）
```

### R-D-S-1: 问题定义

- **类型**: information-gathering
- **输入**: 澄清结论中的目标定义
- **输出**: 问题定义报告
- **继续条件**: 
  - [ ] 至少 5 篇对标论文已识别
  - [ ] 至少 2 个研究空白已标记
  - [ ] 至少 1 个明确的研究问题已定义
- **回退条件**:
  - [ ] 对标论文不足 → 补充搜索
  - [ ] 无法定义研究问题 → 问用户（"你更关注哪个方向？"）
- **继续输出**: [问题定义报告，包含研究问题 + 对标论文列表 + 空白分析]
- **回退输出**: [缺失的论文清单 + 建议的搜索关键词]

### R-D-S-2: 方法选择

- **类型**: information-gathering + clarification
- **输入**: 问题定义报告（S-1 产出）
- **输出**: 方法选择报告
- **继续条件**:
  - [ ] 明确的方法已选定
  - [ ] 明确的修改点/创新点已定义
  - [ ] 创新点与对标论文的差异已说明
- **回退条件**:
  - [ ] 找不到合适方法 → 问用户（"哪种修改方向更合适？"）
  - [ ] 创新点不够明确 → 回到 S-1 重新定义问题
- **继续输出**: [方法选择报告，包含选定方法 + 修改点 + 创新说明]
- **回退输出**: [可用方法清单 + 建议的创新方向]

### R-D-S-3: 工作量执行

- **类型**: execution
- **输入**: 方法选择报告（S-2 产出）+ 对标论文
- **输出**: 实验/推导/模拟结果
- **继续条件**:
  - [ ] 工作量对标已确认（对标 S-2 中标对论文的工作量）
  - [ ] 结果数据/公式已产出
- **回退条件**:
  - [ ] 工作量不够 → 补充实验/推导
  - [ ] 方法不可行 → 回到 S-2 换方法
- **继续输出**: [结果数据 + 初步分析]
- **回退输出**: [已完成的实验清单 + 缺失的实验清单]

### R-D-S-4: 结果分析

- **类型**: execution + verification
- **输入**: 结果数据（S-3 产出）
- **输出**: 结果分析报告
- **继续条件**:
  - [ ] 有明确的结果分析
  - [ ] 分析指向明确的结论
- **回退条件**:
  - [ ] 结果不清晰 → 回到 S-3 重新分析数据
  - [ ] 结果不支持任何结论 → 回到 S-2 换方法
- **继续输出**: [结果分析报告 + 明确结论]
- **回退输出**: [分析失败的原因 + 建议的替代分析方法]

### R-D-S-5: 论文写作

- **类型**: execution
- **输入**: 结果分析报告（S-4 产出）+ 期刊格式要求
- **输出**: 完整论文草稿
- **继续条件**:
  - [ ] 论文符合期刊格式
  - [ ] 内容覆盖 S-1 到 S-4 的所有产出
- **回退条件**:
  - [ ] 格式不达标 → 重写
  - [ ] 内容质量不足 → 回到 S-3/S-4 补充
- **继续输出**: [完整论文草稿]
- **回退输出**: [缺失的内容清单 + 质量不达标的具体说明]

---

## 验证标准

| 步骤 | 验证方式 | 通过标准 |
|------|---------|---------|
| S-1 | LLM review + 人工检查 | ≥5 篇对标论文，≥2 个空白，≥1 个研究问题 |
| S-2 | LLM review + 人工检查 | 明确的方法 + 明确的创新点 |
| S-3 | 实际运行结果 | 产出数据/公式，工作量对标确认 |
| S-4 | LLM review + 人工检查 | 有明确结论，分析逻辑完整 |
| S-5 | 格式检查 + LLM review | 符合期刊格式，内容完整 |

## 参考对标期刊

根据研究领域选择对标期刊：

| 领域 | 对标期刊 | 工作量参考 |
|------|---------|-----------|
| 理论物理 | PRD, JHEP, PRL | 推导完整 + 数值验证 |
| 计算物理 | PRB, COMPEL | 代码 + 数值结果 + 对比 |
| 机器学习 | NeurIPS, ICML, JMLR | 方法 + 实验 + 消融分析 |
| 数据科学 | JASA, JRSS | 方法 + 实证分析 + 鲁棒性 |

> 选择对标期刊时参考 S-1 文献综述的发现，选取该领域最相关的期刊。
