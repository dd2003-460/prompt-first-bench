# 写作模板（传播导向）

> 面向传播性的写作分解模板（非专业类）。
> 核心要求：**传播性**（非专业读者能理解、愿意传播）
> 编号规范：R{轮次}-D{深度}-S{步骤}

---

## 模板定义

```markdown
### 写作分解模板

- **适用领域**: communication-oriented writing
- **核心要求**: 传播性（受众覆盖 + 理解难度低 + 分享意愿高）
- **输入**: 澄清结论（目标定义 + 约束 + 受众定义）
- **输出**: 写作计划（含子任务列表 + 每步验证标准）
- **分解模板 ID**: writing-001
```

---

## 分解结构

```
R-D-S-1: 受众分析（写给谁看？他们已知的内容？）
R-D-S-2: 素材搜集（搜索所有可搜索的相关素材）
R-D-S-3: 结构规划（故事线/论证线，确保有"钩子"）
R-D-S-4: 初稿撰写
R-D-S-5: 可读性审查（非专业读者能否理解？）
R-D-S-6: 终稿输出
```

### R-D-S-1: 受众分析

- **类型**: clarification
- **输入**: 澄清结论中的目标定义
- **输出**: 受众分析报告
- **继续条件**:
  - [ ] 明确的受众描述已定义
  - [ ] 受众的知识水平已评估
  - [ ] 受众的传播渠道已识别
- **回退条件**:
  - [ ] 受众不明确 → 问用户（"这篇文章打算发给谁看？"）
  - [ ] 传播渠道不明确 → 默认策略：社交媒体（可搜索的）
- **继续输出**: [受众分析报告，包含受众描述 + 知识水平 + 传播渠道]
- **回退输出**: [建议的受众群体清单 + 传播渠道建议]

### R-D-S-2: 素材搜集

- **类型**: information-gathering
- **输入**: 受众分析报告（S-1 产出）+ 目标定义
- **输出**: 素材清单
- **继续条件**:
  - [ ] 素材覆盖所有必要话题
  - [ ] 素材来源多样化（不依赖单一来源）
- **回退条件**:
  - [ ] 素材不足 → 补充搜索
  - [ ] 素材质量差 → 换来源
- **继续输出**: [完整素材清单，包含来源 URL/文件路径]
- **回退输出**: [缺失的素材清单 + 建议的搜索方向]

### R-D-S-3: 结构规划

- **类型**: planning
- **输入**: 素材清单（S-2 产出）+ 受众分析（S-1 产出）
- **输出**: 结构大纲
- **继续条件**:
  - [ ] 完整的结构大纲已产出
  - [ ] 大纲包含明确的"钩子"（开头吸引读者）
  - [ ] 大纲结构适合受众（不超出知识水平）
- **回退条件**:
  - [ ] 结构不清晰 → 重新规划
  - [ ] 钩子不明确 → 问用户（"最想让人记住的点是什么？"）
- **继续输出**: [结构大纲 + 每节摘要 + 钩子说明]
- **回退输出**: [建议的结构选项 + 钩子建议]

### R-D-S-4: 初稿撰写

- **类型**: execution
- **输入**: 结构大纲（S-3 产出）+ 素材清单（S-2 产出）
- **输出**: 初稿
- **继续条件**:
  - [ ] 初稿完整（覆盖大纲所有章节）
  - [ ] 初稿语言适合受众
- **回退条件**:
  - [ ] 初稿质量差 → 重写
  - [ ] 初稿偏离受众 → 回到 S-3 调整结构
- **继续输出**: [完整初稿]
- **回退输出**: [缺失的章节清单 + 语言问题说明]

### R-D-S-5: 可读性审查

- **类型**: verification
- **输入**: 初稿（S-4 产出）
- **输出**: 审查报告
- **继续条件**:
  - [ ] 难懂处全部标记
  - [ ] 修改建议明确
- **回退条件**:
  - [ ] 审查不完整 → 重新审查
  - [ ] 审查发现结构性问题 → 回到 S-3 调整结构
- **继续输出**: [审查报告，包含难懂处标记 + 修改建议]
- **回退输出**: [审查失败的原因 + 建议的替代审查方法]

### R-D-S-6: 终稿输出

- **类型**: execution
- **输入**: 初稿（S-4 产出）+ 审查报告（S-5 产出）
- **输出**: 终稿
- **继续条件**:
  - [ ] 所有标记的难懂处已修改
  - [ ] 终稿符合传播标准
- **回退条件**:
  - [ ] 质量不达标 → 重写或简化
  - [ ] 传播性不足 → 问用户（"你期望的传播效果是什么？"）
- **继续输出**: [终稿]
- **回退输出**: [缺失的修改清单 + 质量不达标的具体说明]

---

## 验证标准

| 步骤 | 验证方式 | 通过标准 |
|------|---------|---------|
| S-1 | 人工检查 | 明确的受众 + 知识水平 + 传播渠道 |
| S-2 | LLM review | 素材覆盖 + 来源多样化 |
| S-3 | 人工检查 | 完整大纲 + 钩子 + 适合受众 |
| S-4 | 人工检查 | 初稿完整 + 语言适合 |
| S-5 | 人工检查 | 难懂处标记 + 修改建议 |
| S-6 | 人工检查 + LLM review | 终稿完整 + 传播标准满足 |

---

## 传播性检查清单

终稿发布前，检查以下项：

- [ ] 标题是否有吸引力？
- [ ] 开头是否有"钩子"（前 3 行抓住读者）？
- [ ] 专业术语是否有通俗解释？
- [ ] 故事线/论证线是否清晰？
- [ ] 结论是否有记忆点？
- [ ] 是否有可分享的引用句？
- [ ] 长度是否适合目标渠道？
- [ ] 非专业读者能否理解？

> 以上清单由 S-5 审查阶段执行，每个项必须有明确的是/否标记。
