# 编码模板（通用）

> 通用编码任务分解模板。
> 核心要求：**按具体需求（用户提供或澄清得出）**
> 编号规范：R{轮次}-D{深度}-S{步骤}

---

## 模板定义

```markdown
### 编码分解模板

- **适用领域**: general-purpose code
- **核心要求**: 按具体需求（由用户确认定义）
- **输入**: 澄清结论（目标定义 + 约束 + 需求规格）
- **输出**: 编码计划（含子任务列表 + 每步验证标准）
- **分解模板 ID**: code-001
```

---

## 分解结构

```
R-D-S-1: 需求澄清（输入/输出/边界）
R-D-S-2: 设计实现（方案选择 + 伪代码）
R-D-S-3: 编码实现
R-D-S-4: 测试验证
R-D-S-5: 文档补充
```

### R-D-S-1: 需求澄清

- **类型**: clarification
- **输入**: 澄清结论中的目标定义
- **输出**: 需求规格文档
- **继续条件**:
  - [ ] 输入格式已明确
  - [ ] 输出格式已明确
  - [ ] 边界条件已明确
  - [ ] 错误处理已定义
- **回退条件**:
  - [ ] 需求不明确 → 问用户（选择题格式）
  - [ ] 边界条件不清晰 → 默认策略：边界为空 + 不处理
- **继续输出**: [需求规格文档，包含输入/输出/边界/错误处理]
- **回退输出**: [缺失的需求清单 + 建议的默认值]

### R-D-S-2: 设计实现

- **类型**: planning
- **输入**: 需求规格文档（S-1 产出）
- **输出**: 设计方案 + 伪代码
- **继续条件**:
  - [ ] 设计方案已产出
  - [ ] 伪代码覆盖所有功能
- **回退条件**:
  - [ ] 方案不可行 → 问用户（"哪种方案更合适？"）
  - [ ] 伪代码不完整 → 补充
- **继续输出**: [设计方案 + 伪代码]
- **回退输出**: [设计失败的原因 + 建议的替代方案]

### R-D-S-3: 编码实现

- **类型**: execution
- **输入**: 设计方案 + 伪代码（S-2 产出）+ 需求规格（S-1 产出）
- **输出**: 可运行代码
- **继续条件**:
  - [ ] 代码已产出
  - [ ] 代码可运行
- **回退条件**:
  - [ ] 代码运行失败 → 调试
  - [ ] 代码不满足需求 → 回到 S-2 调整设计
- **继续输出**: [可运行代码]
- **回退输出**: [运行失败的错误清单 + 建议的调试方向]

### R-D-S-4: 测试验证

- **类型**: verification
- **输入**: 可运行代码（S-3 产出）+ 需求规格（S-1 产出）
- **输出**: 测试报告
- **继续条件**:
  - [ ] 测试已运行
  - [ ] 测试通过
- **回退条件**:
  - [ ] 测试不通过 → 回到 S-3 修复代码
  - [ ] 测试覆盖不足 → 补充测试
- **继续输出**: [测试报告 + 通过的测试用例]
- **回退输出**: [失败测试清单 + 修复建议]

### R-D-S-5: 文档补充

- **类型**: execution
- **输入**: 可运行代码（S-3 产出）+ 测试报告（S-4 产出）
- **输出**: 文档
- **继续条件**:
  - [ ] 文档覆盖关键逻辑
  - [ ] 文档格式正确
- **回退条件**:
  - [ ] 文档不完整 → 补充
  - [ ] 文档质量差 → 重写
- **继续输出**: [完整文档]
- **回退输出**: [缺失的文档清单 + 质量不达标的具体说明]

---

## 验证标准

| 步骤 | 验证方式 | 通过标准 |
|------|---------|---------|
| S-1 | 人工检查 | 输入/输出/边界/错误处理已明确 |
| S-2 | 人工检查 | 设计方案可行 + 伪代码覆盖所有功能 |
| S-3 | 代码运行 | 代码可运行无报错 |
| S-4 | 测试运行 | 所有测试通过 |
| S-5 | 人工检查 | 文档覆盖关键逻辑 |

---

## 默认策略

| 假设类型 | 默认策略 |
|---------|---------|
| 语言选择 | 项目已有语言 / 最普及语言 |
| 框架选择 | 项目已有框架 / 社区最流行 |
| 测试粒度 | 核心路径 + 边界条件 |
| 错误处理 | 最小化（记录错误 + 返回默认值） |
| 代码风格 | 项目已有风格 / PEP8 |
| 日志级别 | WARNING 及以上（不影响性能） |
