### R1-D3-S1 按 plan 执行子任务

- **类型**: execution
- **输入**: `loop/plan.md` 中定义的每个子任务
- **输出**: 各子任务的产出文件 + 结构化阶段动作
- **继续条件**: 子任务产出通过验证标准
- **回退条件**: 产出不符合输入/输出定义
- **继续输出**: 可验证的产出（文件/代码/数据）
- **回退输出**: 产出失败原因 + 具体不满足定义的位置

## 执行要求

1. 执行前：重读该任务的定义，确认理解一致
2. 执行中：遇到问题及时记录，不回退时编造
3. 执行后：产出文件包含自检声明，并返回 `RALPH_STAGE_RESULT`
4. 按 plan.md 中的 DAG 顺序执行；只有显式标注的正交并行组可同时执行
5. 每个子任务的信息搜集应通过浏览器与在线 LLM 交叉验证

## 并行执行

- plan.md 中标注为并行的子任务可同时启动（无数据依赖）
- 并行失败的节点不影响其他节点继续
- 人类阻塞的节点标记 `blocked_human` 并跳过，不阻塞兄弟节点

## Gold Case

- 执行前确认理解一致
- 遇到问题及时记录
- 产出文件包含自检声明

## Bad Case

- 定义要代码但只给规划
- 回退时编造理由
- 产出文件无版本/时间戳
- 产出没有结构化动作，导致状态机无法判断下一步
