### R1-D1-S3 技术背景搜集

- **类型**: information-gathering
- **输入**: `01-目标澄清.md` + `02-约束确认.md`
- **输出**: `loop/1-loop/03-技术背景.md`
- **继续条件**: 信息覆盖可搜索领域
- **回退条件**: 关键领域无可用信息（标注而非回退，不回退标记为 "信息不足"）
- **继续输出**:
  - 每个搜索结果标注：来源 URL/路径、时间、置信度
  - 信息缺口清单
- **回退输出**: 标注为 "信息不足" 的领域

## 执行要求

1. 全面搜索，不设上限（默认行为）
2. 搜索项：相关论文、GitHub 项目、技术文档、行业资料
3. 每个搜索结果必须标注来源
4. 对于关键信息，通过浏览器与在线 LLM 交叉验证（预置端点见综述）
5. 不引用超过 2 年的技术信息（AI 领域）

## 浏览器交叉验证

对关键信息，向以下预置 LLM 端点提交相同验证问题，对比回答一致性：
- https://arena.ai/agent
- https://bigmodel.cn/trialcenter/modeltrial/text?modelCode=glm-5.2
- https://aistudio.google.com/prompts/new_chat
- https://chatgpt.com/

## Gold Case

- 搜索与目标直接相关的最新信息
- 列出已验证可用的信息和纯推测的内容
- 对关键信息做多 LLM 交叉验证

## Bad Case

- 引用超过 2 年的技术信息（AI 领域）
- 不加时间标注的搜索
- 搜索范围过宽或过窄
