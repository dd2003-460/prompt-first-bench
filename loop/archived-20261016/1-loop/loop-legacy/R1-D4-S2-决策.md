### R1-D4-S2 决策

- **类型**: branch-check
- **输入**: `integrity-verify.md`
- **输出**: 决策结果 + `RALPH_STAGE_RESULT`
- **继续条件**: 置信度 ≥ 0.8 → 进入 2-loop
- **回退条件**: 置信度 < 0.5 → 新轮次 R2
- **继续输出**: 进入 2-loop 的指令 + 上下文
- **回退输出**: R2 分解建议 + R1 失败教训

## 执行要求

1. 基于整体验证的置信度做出决策
2. 决策依据透明，Commander 可复现判断
3. 回退时提供具体的新轮次分解建议
4. 记录失败教训，供 R2 使用
5. 计划修订不设固定次数上限；每次修订保留旧版本和 lineage

## Gold Case

- 决策依据透明，Commander 可复现判断

## Bad Case

- 跳过决策直接进下一步
