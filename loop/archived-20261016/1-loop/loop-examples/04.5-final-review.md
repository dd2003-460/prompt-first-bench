# 阶段 04.5：最终复核与交接

## 操作流程

1. 从反方角度检查全过程，不重新开展无边界研究。
2. 对照原始任务、阶段 01 空缺、阶段 02 证据、阶段 03 行动和阶段 04 结果。
3. 列出结论成立的依据、薄弱点、未完成项、残余风险和最有价值的下一步。
4. 对书稿、代码或 PDF 等具体产出，核对真实文件、编译结果和读者可见变化。
5. 如果发现需要新资料或重新执行，明确回退阶段，而不是把问题藏进最终总结。

## Reviewer 质检标准

- 原始任务是否全部得到回应；
- 关键空缺、证据、行动和结果是否能串成完整链条；
- 最终结论是否超出了证据支持范围；
- 未完成项和不确定性是否清楚；
- 交付物是否真实存在并经过必要验证；
- 下一位使用者能否仅凭这些 Markdown 继续工作。

存在会影响最终结论的缺口时必须 revise，并将 repair_stage 写为真正需要修复的阶段。

## 操作示例

### 示例：GPU 调研 — 最终复核

**原始任务：**
```
调研适合本地大模型推理的 GPU，预算 $2000 以内。
```

**阶段 01 空缺回顾：**
```
- [已完成] 各候选 GPU 的当前市场价格 → RTX 4090 $1,599
- [已完成] 各候选 GPU 的显存带宽具体数值 → 2112 GB/s
- [已完成] Apple M 系列芯片的 Metal 对主流框架的支持程度 → 支持，需 PyTorch >= 2.1
- [未完成] 用户现有电源/机箱的兼容性 → 用户未提供信息
```

**阶段 02 证据回顾：**
```
- RTX 4090：24GB GDDR6X，$1,599，CUDA 生态成熟，2112 GB/s
- RTX 4080：16GB GDDR6X，$1,199，CUDA 生态成熟，717 GB/s
- AMD 7900 XTX：24GB GDDR6，$999，ROCm 生态发展中，960 GB/s
- Apple M2 Max：192GB 统一内存，$3,199（超出预算）
```

**阶段 03 行动回顾：**
```
- 步骤 1-4 完成：测试环境搭建、框架安装、基准测试、成本效益分析
- 步骤 5 部分完成：Llama-3-8B 测试通过（使用量化模型）
- 步骤 6 未完成：Llama-3-70B 测试（显存不足）
```

**阶段 04 结果回顾：**
```
- RTX 4090：123.45 tokens/sec，显存占用 18.5/40 GB
- RTX 4080：89.23 tokens/sec，显存占用 12.1/16 GB
- AMD 7900 XTX：78.56 tokens/sec，显存占用 15.2/24 GB
- Apple M2 Max：65.43 tokens/sec，显存占用 8.5/192 GB
```

**最终结论：**
```
推荐：RTX 4090

依据：
1. 性能最高：123.45 tokens/sec，比 RTX 4080 高 38%
2. 显存充足：24GB，可运行 Llama-3-8B 和量化版 70B
3. 生态成熟：CUDA 生态完善，文档和社区支持好
4. 价格可接受：$1,599，在预算内

薄弱点：
1. 用户现有电源/机箱兼容性未知（需用户确认）
2. Llama-3-70B 未在实际硬件上测试（仅理论推算）
3. 量化模型性能损失约 5%（未量化模型性能更高但显存不足）

未完成项：
1. 用户现有电源/机箱兼容性确认
2. Llama-3-70B 实际测试（需 80GB 显存硬件）

残余风险：
1. RTX 4090 供货不稳定，可能延迟交付
2. 价格可能波动（已记录当前价格）
3. 用户现有硬件可能不兼容（需用户确认）

最有价值的下一步：
1. 用户确认现有电源/机箱兼容性
2. 如有 80GB 显存硬件，进行 Llama-3-70B 实际测试
3. 如有更高性能需求，考虑多卡方案（RTX 4090 x 2）
```

## 通用原则

### 复核原则

1. **完整链条**：从任务到结论的每一步都必须有证据支持
2. **诚实评估**：薄弱点和未完成项必须明确列出
3. **不夸大结论**：结论不能超出证据支持范围
4. **可交接**：下一位使用者能仅凭文档继续工作

### 反方检查原则

1. **挑战结论**：从反方角度质疑结论的合理性
2. **寻找反例**：主动寻找可能推翻结论的反例
3. **评估风险**：评估结论错误的风险和影响
4. **提出替代**：如果结论错误，替代方案是什么

### 交接原则

1. **文档完整**：所有阶段文档必须完整且一致
2. **可复现**：所有执行步骤必须可复现
3. **可追溯**：所有结论必须可追溯到证据
4. **可继续**：下一位使用者能继续工作
