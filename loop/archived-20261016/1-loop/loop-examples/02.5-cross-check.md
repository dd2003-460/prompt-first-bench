# 阶段 02.5：交叉核验与矛盾

## 操作流程

1. 逐项检查阶段 02 的关键主张、来源和观察时间。
2. 比较不同来源的定义、测量条件、样本、时间和利益关系。
3. 解释一致处和矛盾处；不能解释时保留不确定性，不强行收敛。
4. 检查网页 LLM 的结论是否被独立来源支持。
5. 形成可以交给行动分解阶段使用的证据边界。

## Reviewer 质检标准

- 关键结论是否真正经过独立来源比较；
- 矛盾是否有具体解释，而不是只写"基本一致"；
- 是否混淆理论规格、实测性能、当前价格和个人推断；
- 是否遗漏会改变结论的反例；
- 是否清楚标注仍未解决的问题。

如果需要补充新资料，repair_stage 写 02；如果资料充分但核验表达不完整，repair_stage 写 02.5。

## 操作示例

### 示例 1：价格矛盾处理

**阶段 02 收集的证据：**
```
- 来源 1（Amazon）：RTX 4090，$1,599，2024-01-15
- 来源 2（Newegg）：RTX 4090，$1,649，2024-01-15
- 来源 3（B&H Photo）：RTX 4090，$1,799，2024-01-10
```

**交叉核验：**
```
一致处：
- Amazon 和 Newegg 价格差异 < 5%，相互验证

矛盾处：
- B&H Photo 价格高出 10%+
- 可能原因：
  a) B&H 包含税费/运费
  b) B&H 库存较少，定价策略不同
  c) B&H 数据过期

处理方式：
- 检查 B&H 页面是否含税：是，$1,799 含税
- 换算后：$1,799 / 1.0888（纽约州税）≈ $1,652
- 与 Newegg 价格一致
- 结论：无实际矛盾，B&H 价格含税导致表面差异
```

### 示例 2：性能数据矛盾处理

**阶段 02 收集的证据：**
```
- 来源 1（NVIDIA 官方）：RTX 4090 理论算力 82.58 TFLOPS
- 来源 2（TechPowerUp）：RTX 4090 实测 FP32 约 75 TFLOPS
- 来源 3（AnandTech 评测）：RTX 4090 实测 FP32 约 73 TFLOOPS
```

**交叉核验：**
```
矛盾处：
- 理论算力（82.58 TFLOPS）vs 实测（73-75 TFLOPS）
- 差异约 10%

解释：
- 理论算力 = 峰值性能（理想条件）
- 实测性能 = 实际工作负载（有开销）
- 差异来源：
  a) 内存带宽限制
  b) 指令集效率
  c) 散热降频

处理方式：
- 明确区分"理论"和"实测"
- 使用实测数据作为决策依据
- 记录理论值作为上限参考
```

### 示例 3：软件支持矛盾处理

**阶段 02 收集的证据：**
```
- 来源 1（PyTorch 官方文档）：支持 Apple Silicon（Metal）
- 来源 2（GitHub Issue）：PyTorch 2.0 对 M2 Max 有 bug
- 来源 3（用户实测博客）：M2 Max 上 PyTorch 运行正常
```

**交叉核验：**
```
矛盾处：
- 官方说支持，但 GitHub Issue 说有 bug

解释：
- PyTorch 2.0 确实支持 Apple Silicon
- GitHub Issue #12345 报告了特定场景下的 bug（如大模型加载失败）
- 该 bug 在 PyTorch 2.1 中已修复
- 用户实测使用的是 PyTorch 2.1+

处理方式：
- 确认 PyTorch 版本要求：>= 2.1
- 记录 bug 历史和修复版本
- 结论：支持，但需要最新版本
```
