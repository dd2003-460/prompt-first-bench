# 阶段 04.5：最终复核与交接

## 操作流程

1. 从反方角度检查全过程，不重新开展无边界研究。
2. 对照原始任务、阶段 01 空缺、阶段 02 证据、阶段 03 行动和阶段 04 结果。
3. 列出结论成立的依据、薄弱点、未完成项、残余风险和最有价值的下一步。
4. 对书稿、代码或 PDF 等具体产出，核对真实文件、编译结果和读者可见变化。
5. 如果发现需要新资料或重新执行，明确回退阶段，而不是把问题藏进最终总结。

## Reviewer 质检标准

- 原始任务是否全部得到回应；
- 关键空缺、证据、行动和结果是否能串成完整链条；
- 最终结论是否超出了证据支持范围；
- 未完成项和不确定性是否清楚；
- 交付物是否真实存在并经过必要验证；
- 下一位使用者能否仅凭这些 Markdown 继续工作。

存在会影响最终结论的缺口时必须 revise，并将 repair_stage 写为真正需要修复的阶段。
