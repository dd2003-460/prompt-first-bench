## 二、风格检查清单

### 2.1 像素粒度
- [ ] 像素块大小合适 (v1.2: 8-12px, v1.3 目标: 4-6px)
- [ ] 像素感保留 (不是平滑矢量)
- [ ] 文字笔画清晰 (threshold=150, font 降级)

### 2.2 颜色
- [ ] 调色板一致 (C 对象)
- [ ] 背景色正确 (bg: #0d1117, termBg: #14161C)
- [ ] 文字色正确 (text: #e6edf3)
- [ ] 强调色正确 (green/purple/amber/blue/red)
- [ ] 对比度足够 (文字与背景)

### 2.3 布局
- [ ] 无重叠 (check_overlap.js 通过)
- [ ] 无截断 (所有元素在画布内)
- [ ] 边距一致 (左右 8px)
- [ ] 内容区 y 0..146, 字幕区 y 150..180

### 2.4 动画
- [ ] 打字动画流畅
- [ ] cursor blink 节奏正确
- [ ] 消息滚动平滑
- [ ] 场景转换自然 (无跳变)
- [ ] 粒子效果不过度

### 2.5 字幕
- [ ] 步进节奏 (140ms/字 + 180ms/3字)
- [ ] 与打字音效同步
- [ ] 文字完整 (无截断)
- [ ] 位置正确 (y 150..180)

### 2.6 音频
- [ ] BGM 与场景匹配
- [ ] SFX 与动作同步
- [ ] 音量平衡 (BGM -12dB, SFX -6dB)
- [ ] 无人声 (D13)

## 三、对标流程

1. **提取参考帧**: 从 bilibili 视频提取关键帧 (每 3-5s 一帧)
2. **逐帧对比**: 当前版本帧 vs 参考帧
3. **检查清单**: 逐项检查 (2.1-2.6)
4. **记录差异**: 发现的差异写入 `memory/style-analysis.md`
5. **修复**: 修改渲染脚本
6. **重新渲染**: 跑 check_overlap + 帧检查

## 四、设计偏好（v1.3.5 · 用户 m01576）

### 终端布局偏好
- **全屏模式**：终端可占满整个画布（640×360），容纳更多内容
- **多角色分屏**：角色数 → 终端数
  - 2 角色 → 左右终端（各 320×360）
  - 4 角色 → 四象限终端（各 320×180）
  - 3 角色 → 左 + 右上 + 右下
- **主题**：Claude / DSH TUI 风格（深色背景 + 终端配色），可自由选用

### 元素规则
- 文字/元素**不重叠**（check_overlap 必须通过）
- 可**进一步缩小**字体/元素（全屏模式下空间更大）
- 所有元素在画布内（无截断）

### 故事线偏好
- 选题方向：AI 对比人少了什么（恐惧/死亡/遗忘/孤独）
- 每个视频有完整故事线（角色互动 + 情感弧线）
- 示例：「Clawd 的恐惧」— AI 害怕被关机/遗忘

## 五、像素标准（v1.4.0 · 用户 m03037）

> 来源: 用户反馈 "为什么没有像素了，过于清晰了，像素可以对照 companion_arena_v1.0.mp4 这个大小"

### 5.1 像素块大小
- **标准**: 4-6px 最小视觉单元（对照 companion_arena_v1.0.mp4 帧）
- **画布**: BW=640 BH=360 SCALE=2 → 1280×720
- **禁止**: 平滑矢量、过小像素块（<4px）、过大像素块（>8px）
- **参考**: `docs/refs/bili_v1/f_012.png` (640×360, 像素块 4-6px)

### 5.2 字体
- **标准**: 10px fusion-pixel 字体（`@fontsource/fusion-pixel-10px-monospaced-sc`）
- **禁止**: monospace 字体（看起来过于清晰，不是像素风）
- **降级**: 文字笔画 threshold=150
- **参考**: `src/render_companion_arena.js` 的 fontFamilyForSize()

### 5.3 角色形象标准

#### Clawd (Clawde)
- **尺寸**: 40×17px body
- **眼睛**: 4×4px，带 1×1px 白色高光
- **腹部**: 22×4px 浅色块
- **顶部**: 2px 暗色条
- **颜色**:
  - 正常: `#7B9E6B`（绿色）
  - thinking: `#6B5B95`（紫色）
  - smile: `#7B9E6B` + 粉色腮红
- **表情**: 至少 3 种（calm / thinking / smile）
- **禁止**: 天线、嘴、轮廓线、过小眼睛（<4px）
- **参考**: `src/render_companion_arena.js` 的 drawClawd() 函数

#### Her
- **尺寸**: 16×28px
- **颜色**: 粉色裙子
- **位置**: 通常右侧窗户旁

### 5.4 终端标准
- **尺寸**: 360×160px（标题栏 20px + 内容区 140px）
- **位置**: x=140, y=160（房间场景）
- **标题栏**: 红黄绿三个圆点 + 标题文字
- **背景**: #14161C
- **文字**: #e6edf3, 10px fusion-pixel
- **全屏模式**: 可占满 640×360（多角色分屏时）

### 5.5 房间背景
- **墙壁**: 暖色条纹 (#F5EDD5), 16px 间距
- **窗户**: 天空渐变 (#87CEEB→#E0F0FF) + 2 座山 (#5A7A5A) + 云
- **窗台**: 花盆 + 植物
- **夜晚**: 深蓝背景 + 星星 (2×2px) + 月亮

## 六、音频同步要求（v1.4.0 · 用户 m03037）

> 来源: 用户反馈 "键盘敲击最好和画面字幕或者文字出现同步，同步要求也录入sop"

### 6.1 键盘音同步
- **规则**: 每行终端文字出现时，播放一次 sfx_click.wav
- **打字机效果**: 每个字符出现时播放 click
- **字幕切换**: 不播放 click（只有 BGM）
- **BGM**: emotional_bgm.wav, -12dB
- **SFX**: sfx_click.wav, -6dB
- **混音**: ffmpeg amix normalize=0
- **参考**: `scripts/build_audio_companion.js` 的音频时间轴

### 6.2 时间轴格式
```
[时间轴]
0.0s  BGM start
1.2s  click (line 1 appears)
2.8s  click (line 2 appears)
...
29.5s BGM fade out
```
