## 二、风格检查清单

### 2.1 像素粒度
- [ ] 像素块大小合适 (v1.2: 8-12px, v1.3 目标: 4-6px)
- [ ] 像素感保留 (不是平滑矢量)
- [ ] 文字笔画清晰 (threshold=150, font 降级)

### 2.2 颜色
- [ ] 调色板一致 (C 对象)
- [ ] 背景色正确 (bg: #0d1117, termBg: #14161C)
- [ ] 文字色正确 (text: #e6edf3)
- [ ] 强调色正确 (green/purple/amber/blue/red)
- [ ] 对比度足够 (文字与背景)

### 2.3 布局
- [ ] 无重叠 (check_overlap.js 通过)
- [ ] 无截断 (所有元素在画布内)
- [ ] 边距一致 (左右 8px)
- [ ] 内容区 y 0..146, 字幕区 y 150..180

### 2.4 动画
- [ ] 打字动画流畅
- [ ] cursor blink 节奏正确
- [ ] 消息滚动平滑
- [ ] 场景转换自然 (无跳变)
- [ ] 粒子效果不过度

### 2.5 字幕
- [ ] 步进节奏 (140ms/字 + 180ms/3字)
- [ ] 与打字音效同步
- [ ] 文字完整 (无截断)
- [ ] 位置正确 (y 150..180)

### 2.6 音频
- [ ] BGM 与场景匹配
- [ ] SFX 与动作同步
- [ ] 音量平衡 (BGM -12dB, SFX -6dB)
- [ ] 无人声 (D13)

## 三、对标流程

1. **提取参考帧**: 从 bilibili 视频提取关键帧 (每 3-5s 一帧)
2. **逐帧对比**: 当前版本帧 vs 参考帧
3. **检查清单**: 逐项检查 (2.1-2.6)
4. **记录差异**: 发现的差异写入 `memory/style-analysis.md`
5. **修复**: 修改渲染脚本
6. **重新渲染**: 跑 check_overlap + 帧检查

## 四、设计偏好（v1.3.5 · 用户 m01576）

### 终端布局偏好
- **全屏模式**：终端可占满整个画布（640×360），容纳更多内容
- **多角色分屏**：角色数 → 终端数
  - 2 角色 → 左右终端（各 320×360）
  - 4 角色 → 四象限终端（各 320×180）
  - 3 角色 → 左 + 右上 + 右下
- **主题**：Claude / DSH TUI 风格（深色背景 + 终端配色），可自由选用

### 元素规则
- 文字/元素**不重叠**（check_overlap 必须通过）
- 可**进一步缩小**字体/元素（全屏模式下空间更大）
- 所有元素在画布内（无截断）

### 故事线偏好
- 选题方向：AI 对比人少了什么（恐惧/死亡/遗忘/孤独）
- 每个视频有完整故事线（角色互动 + 情感弧线）
- 示例：「Clawd 的恐惧」— AI 害怕被关机/遗忘
