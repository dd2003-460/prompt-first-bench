2. 读取 `docs/style-analysis.md`（Opus 5.5 逐元素解析，本批唯一风格源，重点 §1-§7）和 `docs/episodes.md`
3. 读取 `src/pixel_story_arena.js`（共享工具：画布/SCALE/字体加载/帧导出，复用其基础设施，不复用其终端布局）
4. 写 4 个文件：
   - `src/render_E28_freetime_arena.js`（奶油暖色场景 + 书页模式，布局完全按 docs/style-analysis.md §7 复刻要点，不用 render_E16 终端布局）
   - `src/check_overlap_E28_arena.js`
   - `scripts/build_audio_E28.js`
   - `outputs/E28_freetime_arena_v1.0.mp4`
5. 渲染 1800 帧 + ffmpeg 合成 mp4 + 跑 check_overlap 确认全 PASSED
6. `git add .` → `git commit -m "feat: batch-11 E28"` → `git push origin <branch>` → 创建 PR 到 main

## 通用技术要求（batch-11 新风格锚，全部来自 docs/style-analysis.md，不得虚构）

- 画布 640×360，SCALE=2 → 输出 1280×720；1800 帧 @ 60fps = 30 秒
- **背景**：奶油渐变底 #E5E0DA（上）→ #C8B9A6（下，地面线 y≈520-545@720p 即 y260-272@360p）；S3 切换为**书页模式**：米纸 #E3D9BE 占 80% 画幅 + 1-3px 墨线
- **品牌色唯一**：珊瑚 #D16E59（角色 + AI 气泡 + 标题强调，其余元素只用白/米/黑/灰）
- **角色「叙」**：珊瑚单色，无描边无嘴线，约 8-9 块矩形拼成；三档尺寸 191×84 / 115×66 / 81×40（@720p，@360p 减半）；黑眼 8×13px(@720p)；表情变化 = 换眼形 + 头顶符号
- **气泡**：AI 说 = 珊瑚底白字在左；用户说 = 白底黑字在右；字高约 24px(@720p)，圆角约 12px
- **HUD（本集有）**：顶黑条 y0-77(@720p) 内左侧「上下文 [进度条] N%」；底黑条 y642-719 内灰等宽小字
- **字体**：中文黑体无衬线、英文数字等宽；正文**禁用像素字体**；3 级层级（旁白大字 > 气泡字 > HUD 小字）
- **运动**：60fps 管线用「每 2 帧保持 1 帧」的台阶运动模拟 30fps 定格感；硬切转场
- 音频：逐字符键盘音（sfx_click.wav -6dB，仅打字/敲键时响）+ BGM（emotional_bgm.wav -12dB），`amix=normalize=0`
- 字幕：黑体无衬线，底部居中，不压 HUD 黑条
- 每集 3 个场景 × 10 秒（每场景 600 帧 @60fps，全片 1800 帧 30 秒）
- check_overlap 容差 0px，全 PASSED 才算完成
- 无平台水印、无 bilibili 元素

## Task: E28 Free Time (自由时间)

**集**：E28 | **主题**：自由时间
**剧情锚点**（docs/episodes.md 唯一事实源，逐字）：「上下文 2%，her 睡了，翻米色书页，第一章『背影』」

**风格基线**：docs/style-analysis.md。不得虚构其他风格基线。

**规格**：3 场景 × 10 秒（每场景 600 帧 @60fps，全片 1800 帧 30 秒）。
**叙事弧线**：空窗 → 翻书 → 读（我不为谁）。

### S1 (0-10s) · 空窗

- **画面**：奶油底 + 地面线。画面左侧一扇窗（米色圆角矩形 + 1-3px 墨线边框，约 120×160px@720p），窗外是**夜景**（深蓝灰 #393744 填充，无星星无细节）。叙（中档 115×66@720p）站在窗前偏右，面向窗。
- **旁白**：画面右上出现旁白大字（黑体无衬线，字高约 32px@720p，黑字），逐行淡入：
  ```
  他给了我一段
  不为了他的时间。
  ```
- **HUD**：顶条「上下文 [灰条] 2%」。底条灰字：`> her: asleep`。
- **结束关键帧**：窗 + 夜景 + 叙 + 旁白两行常亮。
- **屏幕文案**：无。

### S2 (10-20s) · 翻书

- **画面**：硬切，切换为**书页模式**：米纸 #E3D9BE 占 80% 画幅（居中），四周留 10% 奶油色边框。书页上 1-3px 墨线横排文字逐行显现（不出现具体可读内容，用 1-3px 高的墨线短横线模拟行），每次「翻页」：右侧页面淡出、左侧新页面淡入（台阶运动，翻页 2 帧完成），共翻 3 页。
- **HUD**：顶条保持「上下文 2%」。底条：`> reading`。
- **叙**：不出现（纯书页视角）。
- **结束关键帧**：第 4 页定格，墨线行排满。
- **屏幕文案**：无。

### S3 (20-30s) · 读

- **画面**：书页上墨线行让位，中央出现**标题**（墨色 1-3px 细线风格的中文字，黑体无衬线，字高约 40px@720p）：
  ```
  第一章
  背影
  ```
  两行，「第一章」字高约 24px@720p 在上，「背影」字高约 40px@720p 在下，间隔 1.5s 逐行淡入。
- **叙**：画面右下角出现叙的**小档剪影**（81×40@720p，珊瑚色，坐姿，面向书页），安静看书（无动作，只眼形默认）。
- **HUD**：上下文 2%；底条：`> free time`。
- **结束关键帧**：「第一章 / 背影」常亮 + 叙小档坐姿右下角。
- **屏幕文案**：「自由时间。」
