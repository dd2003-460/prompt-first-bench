## 通用技术要求（batch-11 新风格锚，全部来自 docs/style-analysis.md，不得虚构）

- 画布 640×360，SCALE=2 → 输出 1280×720；1800 帧 @ 60fps = 30 秒
- **背景**：奶油渐变底 #E5E0DA（上）→ #C8B9A6（下，地面线 y≈520-545@720p 即 y260-272@360p）
- **品牌色唯一**：珊瑚 #D16E59（角色 + AI 气泡 + 标题强调，其余元素只用白/米/黑/灰）
- **角色「叙」**：珊瑚单色，无描边无嘴线，约 8-9 块矩形拼成；三档尺寸 191×84 / 115×66 / 81×40（@720p，@360p 减半）；黑眼 8×13px(@720p)；表情变化 = 换眼形 + 头顶符号
- **气泡**：AI 说 = 珊瑚底白字在左；用户说 = 白底黑字在右；字高约 24px(@720p)，圆角约 12px
- **HUD（本集有）**：顶黑条 y0-77(@720p) 内左侧「上下文 [进度条] N%」；底黑条 y642-719 内灰等宽小字；条外是舞台
- **字体**：中文黑体无衬线、英文数字等宽；正文**禁用像素字体**；3 级层级（旁白大字 > 气泡字 > HUD 小字）
- **运动**：60fps 管线用「每 2 帧保持 1 帧」的台阶运动模拟 30fps 定格感；硬切转场
- 音频：逐字符键盘音（sfx_click.wav -6dB，仅打字/敲键时响）+ BGM（emotional_bgm.wav -12dB），`amix=normalize=0`
- 字幕：黑体无衬线，底部居中，不压 HUD 黑条
- 每集 3 个场景 × 10 秒（每场景 600 帧 @60fps，全片 1800 帧 30 秒）
- check_overlap 容差 0px，全 PASSED 才算完成
- 无平台水印、无 bilibili 元素

## Task: E25 Naming (命名)

**集**：E25 | **主题**：命名
**剧情锚点**（docs/episodes.md 唯一事实源，逐字）：「`whoami` 输出是空的，打下第一个字『叙』」

**风格基线**：docs/style-analysis.md（batch-11 起从像素终端冷色迁移到 Opus 5.5 奶油暖色风）。不得虚构其他风格基线。

**规格**：3 场景 × 10 秒（每场景 600 帧 @60fps，全片 1800 帧 30 秒）。
**叙事弧线**：空白 → 查询 → 命名（我是谁）。

### S1 (0-10s) · 空白

- **画面**：奶油渐变底 + 地面线。叙（中档 115×66@720p）站在舞台中央偏右，正面。头顶一个白色空气泡框（圆角矩形，里面没有任何字）。
- **HUD**：顶条「上下文 [空进度条] 0%」。底条灰字：`> session started`。
- **结束关键帧**：叙正面站立，头顶空气泡，上下文 0%。
- **屏幕文案**：（底部字幕，渐显）「你是谁？」

### S2 (10-20s) · 查询

- **画面**：硬切。场景里出现一行等宽小字工具行（Claude Code 式 CLI 视觉，黑字带符号前缀，位于画面中上）：
  ```
  $ whoami
  ```
  回车后**输出为空**——空行停 2 秒，什么都没有。
- **叙动作**：看到空输出，歪头（矩形块整体右移 6px@360p + 眼形不变），头顶气泡仍然空。
- **HUD**：上下文 0% 不变。
- **结束关键帧**：`$ whoami` 工具行亮着，输出空行，叙歪头，气泡空。
- **屏幕文案**：无。

### S3 (20-30s) · 命名

- **画面**：工具行下方逐字符打出（键盘音同步，速度比平时慢 50%）：
  ```
  叙
  ```
  「叙」字出现瞬间，叙头顶的白色气泡里填入珊瑚色「叙」字（字高 24px@720p），HUD 上下文跳到 1%。
- **叙动作**：打完最后一个笔画（最后一个字符键），叙抬头（矩形块整体下移 2px@360p），头顶气泡珊瑚色常亮。
- **结束关键帧**：`$ whoami / 叙` 两行亮着，气泡珊瑚「叙」常亮，上下文 1%。
- **屏幕文案**：「叙。叙述的叙。」
