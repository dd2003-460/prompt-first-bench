# 阶段 01：目标分解、已知与空缺条件

## 1. 任务目标交付物定义

**核心交付物：**
一份针对 20 人混合办公团队的团队协作网盘选型报告，包含以下具体组成部分：
1. **3 个候选方案对比矩阵**：涵盖功能（版本管理、外链分享权限控制、离线同步）、成本、自托管能力。
2. **TCO（总拥有成本）估算**：基于 ≤$8/人/月 的预算约束，计算 20 人团队在 1 年/3 年周期内的总成本（含订阅费、潜在硬件/运维成本）。
3. **迁移风险评估**：从现有环境（假设通用 SMB 环境或无特定遗留系统，因未指定）迁移至各候选方案的风险点及缓解措施。
4. **推荐结论**：基于上述分析给出的首选方案及理由。

**非目标（Out of Scope）：**
- 不涉及代码仓库专用工具（如 GitLab/GitHub），仅聚焦于文件协作网盘。
- 不涉及本地 NAS 自建方案的详细硬件采购清单（除非作为自托管备选的一部分被纳入 TCO 对比）。
- 不涉及法律合规性深度审计（仅考虑基本的数据驻留和隐私政策）。

## 2. 因素分解（递归结构）

### 顶层影响因素（正交且覆盖完整）

| ID | 因素名称 | 描述 | 优先级 |
|----|----------|------|--------|
| F1 | **功能符合度** | 是否满足三大硬性需求：版本管理、外链分享权限控制、离线同步。 | High |
| F2 | **成本结构 (TCO)** | 订阅费用、隐藏费用、自托管硬件/运维成本，是否在 ≤$8/人/月 预算内。 | High |
| F3 | **自托管可行性** | 是否支持私有部署？部署复杂度？对 IT 维护能力的要求？ | Medium |
| F4 | **迁移风险** | 数据导入导出难度、客户端兼容性、用户习惯改变成本、停机时间。 | Medium |
| F5 | **安全与合规** | 端到端加密、SSO 支持、审计日志、数据驻留选项（影响信任度和长期可用性）。 | Low-Medium |

> **正交性检查**：F1 关注“能不能用”，F2 关注“贵不贵”，F3 关注“数据在哪里/谁控制”，F4 关注“换过去难不难”，F5 关注“安不安全”。各因素独立影响决策，无明显重叠。

---

### 递归分解：子因素与条件分类

#### F1: 功能符合度
*   **F1.1 版本管理**
    *   *子因素*: 文件级 vs 文件夹级版本历史；保留时长限制；冲突解决机制。
    *   *已知条件*: 用户明确要求“版本管理”。
    *   *可推导条件*: 大多数主流网盘（Nextcloud, Synology Drive, Dropbox Business）均具备基础版本管理。
    *   *空缺条件*: [待研究] 各候选方案的具体版本保留策略（如：免费版 vs 付费版保留多少天/多少个版本）。
*   **F1.2 外链分享权限控制**
    *   *子因素*: 链接有效期设置、密码保护、下载/编辑权限分离、访问次数限制、IP 白名单。
    *   *已知条件*: 用户明确要求“外链分享权限控制”。
    *   *可推导条件*: “权限控制”通常指细粒度控制（不仅仅是开/关）。
    *   *空缺条件*: [待研究] 各候选方案在 ≤$8/人/月 档位下是否开放所有高级分享权限（部分厂商将 IP 限制或访问次数限制放在更高价位）。
*   **F1.3 离线同步**
    *   *子因素*: 多平台客户端支持（Win/Mac/Linux/iOS/Android）；选择性同步（Selectively Sync）；带宽优化（增量同步 vs 全量重传）。
    *   *已知条件*: 混合办公意味着需要移动端和桌面端同步。
    *   *可推导条件*: 现代网盘标配。
    *   *空缺条件*: [待研究] Linux 客户端的支持程度（Nextcloud/Synology 通常较好，Dropbox 曾有原生 Linux 客户端但后转为 AppImage/第三方，需确认当前状态）。

#### F2: 成本结构 (TCO)
*   **F2.1 直接订阅成本**
    *   *子因素*: 单价 ($/user/month)、最低起购人数、年度预付折扣。
    *   *已知条件*: 预算 ≤ $8/user/month，人数 = 20。
    *   *可推导条件*: 月度总预算上限 = $160。年度总预算上限 = $1920。
    *   *空缺条件*: [待研究] 各候选方案针对 20 人规模的具体定价（是否有小团队优惠或阶梯价）。
*   **F2.2 自托管隐性成本 (若选择自托管路径)**
    *   *子因素*: 服务器硬件/云主机费用、初始部署工时、日常运维工时、备份存储额外费用。
    *   *已知条件*: 用户提到“数据可自托管备选”，暗示如果 SaaS 不满足需求或出于数据主权考虑，可能转向自托管。
    *   *可推导条件*: 自托管通常前期投入高，后期边际成本低。
    *   *空缺条件*: [待研究] 自托管 Nextcloud 或 Synology Drive 所需的最低硬件配置及云服务器市场均价（用于 TCO 对比）。

#### F3: 自托管可行性
*   **F3.1 软件许可与支持**
    *   *子因素*: 开源协议限制、商业支持购买必要性、社区活跃度。
    *   *已知条件*: 需评估是否真的需要“自托管”，还是仅作为 Plan B。
    *   *空缺条件*: [待研究] Nextcloud AIO (All-in-One) 的商业支持价格 vs 社区版免费支持的响应速度差异。
*   **F3.2 部署与维护复杂度**
    *   *子因素*: Docker/Kubernetes 依赖、数据库要求、升级中断风险。
    *   *空缺条件*: [待研究] 对于非专职 IT 人员，部署和维护 Nextcloud 的实际工作量估计。

#### F4: 迁移风险
*   **F4.1 数据迁移工具**
    *   *子因素*: 官方迁移助手、API 开放性、批量上传性能。
    *   *已知条件*: 来源未知（假设从 OneDrive/Dropbox/本地共享迁移）。
    *   *空缺条件*: [待研究] 各候选方案提供的官方迁移工具及其对常见来源（OneDrive, Google Drive, Dropbox）的支持情况。
*   **F4.2 客户端兼容性与体验**
    *   *子因素*: 旧版文件元数据保留、权限映射准确性、大文件传输稳定性。
    *   *空缺条件*: [待研究] 从其他网盘迁移时，原有分享链接是否会失效（通常都会，需通知外部联系人）。

#### F5: 安全与合规
*   **F5.1 身份认证集成**
    *   *子因素*: SSO (SAML/OIDC) 支持、MFA 强制开启。
    *   *空缺条件*: [待研究] 在 ≤$8/人/月 的价格档，是否包含 SSO 功能（许多厂商将 SSO 放在企业版高价档）。

## 3. 已知条件汇总 (Knowns)

1.  **团队规模**: 20 人。
2.  **工作模式**: 混合办公 (Hybrid)，意味着需要良好的远程访问和移动同步能力。
3.  **硬性功能需求**:
    *   版本管理 (Version Control)。
    *   外链分享权限控制 (External Link Sharing with Granular Permissions)。
    *   离线同步 (Offline Sync)。
4.  **预算约束**: ≤ $8 / person / month。
    *   月度总预算: $160。
    *   年度总预算: $1,920。
5.  **架构偏好**: 优先 SaaS，但必须有自托管备选方案 (Self-hosted Backup Option)。
6.  **交付要求**: 3 个候选对比 + TCO + 迁移风险。

## 5. 阶段 02 研究入口与路径

### 5.1 候选对象冻结集合 (Candidate Set Freeze)

基于行业常识和预算约束，初步锁定以下 **3 类典型代表** 作为阶段 02 的详细研究对象（具体品牌需在阶段 02 验证其当前市场地位）：

1.  **候选 A: 纯 SaaS 协作网盘 (Pure SaaS Collaboration)**
    *   *代表对象*: **Dropbox Business** 或 **Box Starter/Business**。
    *   *理由*: 市场主流，功能成熟，无需运维。
    *   *待验证属性*: 20 人定价、版本管理细节、Linux 客户端、SSO 支持。
2.  **候选 B: 开源自托管网盘 (Open Source Self-Hosted)**
    *   *代表对象*: **Nextcloud** (Community Edition 或 Paid Support)。
    *   *理由*: 完全满足自托管需求，功能丰富，社区活跃。
    *   *待验证属性*: 部署复杂度、云服务成本、商业支持价格、移动端体验。
3.  **候选 C: NAS 厂商生态网盘 (NAS Vendor Ecosystem)**
    *   *代表对象*: **Synology Drive** (配合 Synology NAS) 或 **Seafile** (Pro Edition)。
    *   *理由*: 介于 SaaS 和纯自建之间，提供硬件+软件捆绑，适合中小团队自托管。
    *   *待验证属性*: 最低硬件成本、软件授权费、云端同步服务可选性。

> **排除说明**: 
> - *Google Drive / OneDrive*: 虽然常用，但通常作为 Office 套件捆绑销售，单独拆分网盘功能的性价比和权限控制灵活性在本场景下不如专业网盘突出，且用户强调“自托管备选”，这两者自托管难度极大（需破解或逆向），故暂不作为主要候选，但在迁移源中需考虑。
> - *Turtl / Cryptomator*: 侧重加密而非协作，版本管理和多人实时协作较弱，排除。

### 5.2 具体研究动作 (Action Items for Stage 02)

#### Action 1: 核验候选 A (Dropbox Business / Box)
*   **目标网站**: dropbox.com/pricing, box.com/pricing
*   **搜索词**: "Dropbox Business pricing 20 users", "Dropbox version history limit business plan", "Dropbox linux client status 2024"
*   **关键字段提取**:
    *   每用户每月价格 (USD)。
    *   版本历史保留天数/数量。
    *   外链分享是否支持密码、过期时间、下载/编辑权限分离。
    *   Linux 客户端是否为官方原生支持。
    *   SSO (SAML) 是否包含在该价位。
*   **备用来源**: Gartner Peer Insights 评测, TechRadar 对比文章。

#### Action 2: 核验候选 B (Nextcloud)
*   **目标网站**: nextcloud.com/pricing, nextcloud.com/features
*   **搜索词**: "Nextcloud hosting cost estimate VPS", "Nextcloud version control features", "Nextcloud external share permissions granularity"
*   **关键字段提取**:
    *   社区版功能完整性确认。
    *   商业支持 (Business Support) 的人头价格。
    *   推荐的最小 VPS 配置 (CPU/RAM/Disk) 及 AWS/Linode 对应月租。
    *   移动端 App 评分与同步稳定性评价。
*   **备用来源**: Nextcloud Forum 用户反馈, DigitalOcean Marketplace Nextcloud 镜像文档。

#### Action 3: 核验候选 C (Synology Drive / Seafile)
*   **目标网站**: synology.com/drive, seafile.com/en/pricing.html
*   **搜索词**: "Synology Drive Standard license price", "Synology DS1522+ price 2024", "Seafile Pro pricing per user"
*   **关键字段提取**:
    *   Synology Drive 是免费随 NAS 附带还是需额外授权？(通常基础版免费，高级功能需 Plus 包，需核实)。
    *   最低入门级 NAS (支持 20 人并发) 的硬件市场价格。
    *   Seafile Pro 的订阅价格。
    *   两者在“外链分享权限控制”上的具体能力对比。

#### Action 4: TCO 建模参数搜集
*   **目标**: 获取云服务器基准价格。
*   **搜索词**: "AWS t3.medium price monthly", "Linode 4GB RAM price"
*   **用途**: 用于计算候选 B 的自托管 TCO。假设公式：`TCO_SelfHosted = (Hardware_Amortization + Cloud_Rent + Support_Fee + Labor_Estimate) / 20 users / 12 months`。

#### Action 5: 迁移风险资料搜集
*   **搜索词**: "Migrate OneDrive to Nextcloud tool", "Dropbox migration assistant limitations"
*   **重点**: 查找官方迁移工具文档，确认是否支持权限继承、是否支持断点续传、最大文件大小限制。

## 6. 矛盾处置与不确定性标注

*   **矛盾预设**: 若发现某 SaaS 厂商 (如 Dropbox) 在 ≤$8 档位不支持 SSO，而用户隐含需求是高安全性，则存在“功能-预算”矛盾。
    *   *处置策略*: 在阶段 02 中明确记录该矛盾，并在阶段 03 中建议“接受无 SSO 风险”或“增加预算”或“转向支持 SSO 的候选 (如 Box 或 Nextcloud 商业版)”。
*   **不确定性标注**: 
    *   所有价格均标注为 `[Price @ Date: YYYY-MM-DD]`，因为 SaaS 价格波动频繁。
    *   自托管运维成本标注为 `[Estimate: Range]`，因为取决于团队技术能力。
    *   Linux 客户端状态标注为 `[Status: Verified/Unverified]`，因为厂商常更新客户端策略。
