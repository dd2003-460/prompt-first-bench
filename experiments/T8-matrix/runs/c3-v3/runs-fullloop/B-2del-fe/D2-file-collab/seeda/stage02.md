## 4. 关键事实核验与风险评估

### 4.1 预算可行性分析
*   **坚果云**: ✅ 安全区。预计 < ¥15,000/年。
*   **Nextcloud**: ⚠️ 风险区。显性成本低，但隐性运维人力成本极易超支。若无专职IT，不推荐。
*   **阿里云盘/百度**: ✅ 安全区。预计 < ¥25,000/年。
*   **Synology NAS**: ✅ 安全区。首年 < ¥10,000，后续极低。

### 4.2 核心功能匹配度初筛
*   **版本管理 + 细粒度权限**:
    *   **最佳**: 坚果云 (SaaS便捷)、Synology (私有化灵活)。
    *   **次之**: Nextcloud (需配置)、阿里云盘 (功能偏弱)。
*   **离线可用**:
    *   **最佳**: Synology (本地局域网同步最快最稳)。
    *   **良好**: 坚果云 (云端同步稳定)。
    *   **一般**: Nextcloud (依赖服务器性能)、阿里云盘 (同步引擎较重)。

### 4.3 淘汰预警 (基于当前证据)
1.  **百度网盘企业版**: 虽在预算内，但其“版本管理”能力较弱，难以满足研发团队对“文档/代码版本回溯”的高要求。**建议标记为“备选-仅用于归档”，不作为核心协作工具推荐。**
2.  **Nextcloud (自建)**: 若团队无专职运维人员，其“隐性成本”可能导致实际TCO（总拥有成本）超出预算或占用过多研发资源。**建议标记为“高风险-需评估运维能力”。**

1.  **H1 (坚果云)**: 30人企业版的精确报价是多少？是否包含API接口费用（若需集成Git或其他工具）？
    *   *验证动作*: 联系坚果云销售获取正式报价单。
2.  **H2 (Synology)**: 现有办公网络带宽是否足以支撑30人同时通过公网访问NAS（若存在远程办公）？
    *   *验证动作*: 检查公司出口带宽，或测试异地访问速度。
3.  **H3 (权限定义)**: 团队定义的“细粒度权限”是否包含“单个文件对特定用户不可见”？
    *   *验证动作*: 与需求方确认权限矩阵的具体颗粒度。若需单文件隐藏，坚果云和阿里云盘可能不满足，需转向Synology或Nextcloud。
4.  **H4 (离线同步)**: 研发团队是否有频繁的离线工作场景（如出差、地铁通勤）？
    *   *验证动作*: 调研团队工作习惯。若离线场景极少，可降低对客户端离线能力的权重。
