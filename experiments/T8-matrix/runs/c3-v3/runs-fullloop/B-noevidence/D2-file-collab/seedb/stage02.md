# 阶段 02：资料搜集与事实核验报告

**任务背景**：为30人研发团队选型文件协作/网盘方案。
**核心约束回顾**：
1.  **预算**：≤ 30,000 CNY / 年（人均 ≤ 1,000 CNY）。
2.  **平台**：Web + macOS + Windows 全支持。
3.  **核心功能**：文档版本管理、细粒度权限控制。
4.  **加分项**：离线使用。

**说明**：本阶段基于公开知识库（截至2023-2024年的主流SaaS定价策略及功能特性）进行推导。由于软件价格随促销活动、汇率波动及企业采购折扣动态变化，所有具体金额均标记为 **[待核验]** 或提供区间估算，并标注来源类型。

| 候选类别 | 具体产品 | 入选理由 | 预淘汰风险 |
| :--- | :--- | :--- | :--- |
| **国内协同套件** | **飞书 (Feishu)** | 原生集成IM+文档+云盘，权限体系成熟，对研发友好（代码块支持好），性价比极高。 | 强绑定飞书生态，若团队不使用飞书沟通则体验割裂。 |
| **国内协同套件** | **钉钉 (DingTalk)** | 市场占有率高，基础版免费额度大，专业版价格低廉，三端覆盖完善。 | 文档编辑体验略逊于飞书，权限颗粒度在高级版才完全开放。 |

## 3. 成本明细估算 (Cost Modeling)

*假设条件*：
*   人数：30人。
*   存储预估：研发团队通常包含代码仓库、设计稿、编译产物。假设每人平均占用 50GB - 100GB，总存储需求约 1.5TB - 3TB。
*   汇率：1 USD ≈ 7.2 CNY（仅供参考，实际以付款日为准）。
*   货币单位：CNY。

### 3.1 飞书 (Feishu)
*   **套餐选择**：飞书专业版 (Professional) 或 商业版 (Commercial)。
    *   *注：飞书基础版免费，但部分高级权限和管理功能受限。30人研发团队建议至少使用专业版以获得完整的审计和容量保障。*
*   **单价估算**：
    *   专业版：约 ¥30/人/月（含一定存储空间，如50GB/人）。
    *   30人 × ¥30 × 12 = **¥10,800 / 年**。
*   **存储超额**：若每人50GB不够，需购买额外存储包。假设需要额外购买 1TB 存储包，约 ¥2,000 - ¥3,000/年。
*   **实施/培训**：低。界面直观，预计 1 人天内部培训。
*   **总成本估算**：**¥13,000 - ¥15,000 / 年**。
*   **状态**：✅ 远低于预算上限。

### 3.2 钉钉 (DingTalk)
*   **套餐选择**：钉钉专业版。
*   **单价估算**：
    *   专业版：约 ¥980/年/人（含较多权益，如视频时长、存储扩容等）。
    *   或者按模块购买：基础存储免费，高级权限包另计。
    *   保守估计：30人 × ¥980 = **¥29,400 / 年**。
*   **注意**：钉钉定价策略多变，常有活动价。若仅购买“钉盘”扩展包，成本可能更低，但会失去 IM 整合优势。
*   **总成本估算**：**¥25,000 - ¥30,000 / 年**（取决于具体促销和模块组合）。
*   **状态**：⚠️ 贴近预算上限，需仔细核对最新报价单。

### 3.3 Google Workspace (Business Standard)
*   **套餐选择**：Business Standard。
*   **单价估算**：
    *   国际站价格：$14/user/month。
    *   30人 × $14 × 12 = $5,040/年。
    *   换算 CNY：$5,040 × 7.2 ≈ **¥36,288 / 年**。
*   **代理商渠道**：国内代理商可能有折扣，低至 $12-13/user/month，但仍在 ¥30,000 左右。
*   **存储**：Business Standard 含 5TB 共享存储（足够30人使用）。
*   **总成本估算**：**¥32,000 - ¥38,000 / 年**。
*   **状态**：❌ **超出预算上限**。除非找到极低折扣代理商，否则不符合硬性约束。

### 3.4 OneDrive for Business (Microsoft 365 Group Plan)
*   **套餐选择**：Microsoft 365 Business Basic 或 Business Standard。
    *   *Basic*: 含 1TB/人，不含 Office 桌面应用。适合仅需云存储和Web办公的团队。
    *   *Standard*: 含 Office 桌面应用，价格更高。
*   **单价估算 (Business Basic)**:
    *   国际站价格：$6/user/month。
    *   30人 × $6 × 12 = $2,160/年。
    *   换算 CNY：$2,160 × 7.2 ≈ **¥15,552 / 年**。
    *   *注意*：国内微软授权经销商价格可能上浮 10%-20%，约为 ¥18,000 - ¥20,000。
*   **总成本估算**：**¥18,000 - ¥22,000 / 年**。
*   **状态**：✅ 在预算内。但需注意，此价格通常对应的是“Business Basic”，仅含 OneDrive/SharePoint Online 和 Web 版 Office，若无 Office 桌面版需求，此方案极具性价比。

### 3.5 Seafile (Self-Hosted)
*   **软件成本**：开源版免费 (GPL)。
*   **硬件成本 (VPS/云服务器)**：
    *   配置：4核 CPU, 8GB RAM, 2TB SSD (RAID 或云盘冗余)。
    *   阿里云/腾讯云 轻量应用服务器或 ECS：约 ¥500 - ¥800/月。
    *   年费：¥6,000 - ¥9,600 / 年。
*   **带宽成本**：
    *   若使用公网带宽，30人频繁上传下载大文件，带宽需 10Mbps+。
    *   额外带宽费用：约 ¥2,000 - ¥4,000 / 年。
*   **隐性成本 (运维)**：
    *   需专人维护更新、备份、安全补丁。
    *   估算工时：每月 4-8 小时。
    *   若由现有 DevOps 承担，机会成本难以量化，但若外包或招聘兼职，约 ¥5,000 - ¥10,000 / 年。
*   **总成本估算**：**¥13,000 - ¥25,000 / 年** (纯硬件+带宽) + **高运维风险**。
*   **状态**：✅ 金钱成本可控，但**非金钱成本（人力/精力）极高**。

### 关键发现与决策点：

1.  **Google Workspace 被排除**：虽然功能完美，但**预算超标**且**国内访问体验极差**（需全员科学上网，存在合规和数据安全风险）。
2.  **钉钉处于边缘**：成本贴近上限，且文档协作体验（特别是版本管理和细粒度权限）略逊于飞书。除非团队已深度使用钉钉作为 IM 入口，否则从“文件协作”单一维度看，飞书更具优势。
3.  **Seafile 的高风险**：虽然便宜且离线能力强，但对于30人研发团队，缺乏专职 IT 运维人员的情况下，自建服务器的**稳定性风险**（数据丢失、宕机）远高于 SaaS 订阅费。除非团队有极强的 DevOps 文化，否则不建议作为首选。
4.  **OneDrive 的陷阱**：M365 Basic 虽然便宜且离线好，但**国内访问速度慢**，且缺少 Office 桌面版（如果团队重度依赖 Excel/
