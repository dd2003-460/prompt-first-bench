# 阶段 02：资料搜集与证据清单

## 1. 执行摘要
本阶段针对阶段 01 识别的 **G1-G8** 空缺项，基于公开市场数据、官方文档及行业通用标准进行了系统性搜集。

**核心发现：**
1.  **预算约束极具挑战性**：人均 ¥83/月（¥1,000/年）的预算在主流企业级 SaaS 中处于极低区间。国际主流方案（M365, Google Workspace, Dropbox Business）的标准版均超预算或仅能覆盖基础存储，难以满足“细粒度权限+版本管理”的高级需求。
2.  **国产方案优势明显**：飞书、钉钉、腾讯文档/微云在同等预算下能提供更高的功能密度（尤其是文档协作和权限）。
3.  **“网盘”与“文档协作”需解耦评估**：纯网盘（如百度网盘企业版、阿里云盘）擅长存储但弱于文档版本管理和细粒度协同；办公套件（飞书、钉钉）擅长文档和权限但大文件存储能力相对较弱（通常有单文件大小限制）。鉴于研发团队既有代码/二进制又有文档，**推荐采用“主文档协作平台 + 辅助大文件传输通道”的组合策略**，或者选择支持大容量存储的综合型平台。

### G1: 各候选产品的最新定价模型 (P0 - 关键阻塞点)

**结论**：
*   **淘汰**：Dropbox Business (超预算)、Google Workspace/M365 (合规风险高，非首选，除非用户强制要求国际环境)、Nextcloud (运维成本不可控)。
*   **保留**：飞书、钉钉、腾讯系（微云/企业微信）、以及可能的垂直类研发网盘（如坚果云企业版，需进一步核实价格）。

### G2: "细粒度权限"的具体定义验证 (P0)

**定义标准**：能否实现 `文件夹A` 内 `文件B` 对 `用户C` 开放编辑，而对 `用户D` 开放只读，且 `用户E` 完全不可见？

| 产品 | 权限层级支持 | 细粒度程度 | 证据/说明 |
| :--- | :--- | :--- | :--- |
| **飞书** | 组织->部门->项目->文件夹->文件 | ⭐⭐⭐⭐⭐ (极高) | [公开知识/文档] 支持“协作者权限”细化到“可阅读/可评论/可编辑”。支持外部协作者隔离。支持文件夹继承权限，也可单独覆盖子文件权限。 |
| **钉钉** | 组织->部门->群聊/知识库节点 | ⭐⭐⭐⭐ (高) | [公开知识/文档] 钉盘支持共享文件夹权限（所有者/管理员/成员/访客）。Teambition 项目空间权限非常细致。但在纯文件层面，颗粒度略逊于飞书，更多依赖“知识库”结构。 |
| **腾讯微云/企微** | 企业->部门->个人 | ⭐⭐⭐ (中) | [待核验假设] 企业微信文件助手权限较基础，主要依赖群组共享。微云企业版支持共享空间权限，但跨部门的复杂 RBAC 配置不如飞书直观。 |
| **Dropbox** | Team->Shared Folder | ⭐⭐⭐ (中) | [公开知识] 基于 Shared Folders。可以设置 Folder 级别的权限（Admin/Editor/Viewer）。不支持单个文件的独立权限（除非移出文件夹单独分享）。缺乏复杂的 RBAC 角色系统。 |
| **Microsoft 365** | Site/Library/Folder/File | ⭐⭐⭐⭐⭐ (极高) | [公开知识] SharePoint 拥有最强大的 ACL 权限体系，支持 NTFS 级别的继承与阻断。但因合规问题已淘汰。 |

**结论**：
*   **飞书**和**钉钉**在国产方案中权限控制最佳。
*   **腾讯系**权限相对粗放，适合扁平化管理，不适合严格的研发保密分级。
*   **Dropbox** 虽然稳定，但其权限模型过于简单，无法满足“细粒度”这一 P0 需求（例如无法轻易实现同一文件夹内不同人不同权限而不破坏目录结构）。

### G3: "文档版本管理”的深度验证 (P0)

**定义标准**：是否支持在线文档的实时协作版本历史？是否支持二进制文件的历史快照回溯？是否支持 Diff 对比？

| 产品 | 在线文档版本 | 二进制文件版本 | Diff 对比能力 | 证据/说明 |
| :--- | :--- | :--- | :--- | :--- |
| **飞书** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ | [公开知识] 飞书文档（Docs/Sheets/Slides）具备极强的版本历史和回滚功能。支持查看谁在何时修改了哪一段。对于上传的 PDF/Office 文件，也提供历史版本下载，但无内置 Diff 工具（需借助第三方或导出对比）。 |
| **钉钉** | ⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐ | [公开知识] 钉钉文档（基于 WPS 内核或自研）支持版本历史。Teambition 中的文档协作较强。钉盘本身主要是文件同步，版本管理依赖底层存储，UI 展示不如飞书丰富。 |
| **腾讯微云** | ⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐ | [待核验假设] 腾讯文档支持版本历史。微云作为网盘，主要提供文件恢复（Recycle Bin）和历史版本下载，缺乏原生的文档内容级 Diff 视图。 |
| **Dropbox** | N/A (仅文件) | ⭐⭐⭐⭐⭐ | ⭐⭐ | [公开知识] Dropbox 以文件版本管理著称，保留期长（Standard 30天，Advanced 无限）。但它**不是**文档编辑器，无法进行文本级的 Track Changes。必须下载两个版本本地对比。 |

**结论**：
*   研发团队既需要“文档”（PRD, 设计稿说明）也需要“文件”（二进制, 日志）。
*   **飞书**在“文档版本管理”上具有压倒性优势（原生协同+版本历史+部分Diff）。
*   **Dropbox** 在“文件快照”上最强，但缺乏文档协作属性。
*   **建议**：若团队重视文档协作，飞书优于纯网盘。

### G4: 离线可用的具体机制 (P1)

| 产品 | 离线编辑 | 冲突解决 | 选择性同步 | 证据/说明 |

| **钉钉** | ✅ (客户端) | Last-write-wins 或提示 | ✅ | [公开知识] 钉钉桌面端支持离线缓存。文档离线编辑支持较好。 |

**结论**：所有保留候选均支持离线可用，此项不再是区分度高的指标，但 Dropbox 和微云在纯文件同步的稳定性上口碑更佳。

### G5: SSO/目录同步支持 (P1)

| 产品 | SSO 支持 (SAML/OIDC) | LDAP/AD 集成 | 证据/说明 |
| :--- | :--- | :--- | :--- |
| **飞书** | ✅ (专业版及以上) | ✅ | [公开知识] 支持 OIDC/SAML SSO。支持与主流 IdP 集成。 |
| **钉钉** | ✅ (专业版及以上) | ✅ | [公开知识] 支持 SSO，可对接企业 AD/LDAP。 |
| **腾讯微云** | ⚠️ 有限 | ❌/⚠️ | [待核验假设] 主要通过企业微信绑定组织架构，独立的 SSO 集成能力较弱，依赖企微生态。 |
| **Dropbox** | ✅ | ✅ | [公开知识] 企业版支持完整的 SSO 和 SCIM 用户同步。 |

**结论**：对于 30 人团队，SSO 不是绝对刚需（手动邀请即可），但若有统一身份认证需求，飞书和钉钉均满足。

### G6: 数据驻留地与合规资质 (P1)

| 产品 | 数据中心位置 | 等保/ISO 认证 | 风险评估 |
| :--- | :--- | :--- | :--- |
| **飞书** | 中国大陆 (腾讯云/火山引擎) | 等保三级, ISO27001 | ✅ 低风险。字节跳动旗下，合规性强。 |
| **钉钉** | 中国大陆 (阿里云) | 等保三级, ISO27001 | ✅ 低风险。阿里旗下，合规性强。 |
| **腾讯微云** | 中国大陆 (腾讯云) | 等保三级, ISO27001 | ✅ 低风险。腾讯旗下，合规性强。 |
| **Dropbox** | 境外 (美国为主) | SOC2, ISO27001 | ⚠️ 高风险。数据出境需符合《数据安全法》，研发敏感代码存境外存在法律隐患。 |
| **Google/M365** | 境外 | 国际认证 | ❌ 极高风险。国内直接访问困难，数据主权不明。 |

**结论**：出于合规和稳定性考虑，**强烈建议排除国际方案**，聚焦国产三巨头（字节、阿里、腾讯）。

### G7 & G8: 移动端与试用期 (P2)
*   **移动端**：飞书、钉钉、腾讯微云均有完善的 iOS/Android App，支持预览和基础编辑。
*   **试用期**：飞书、钉钉通常提供 14-30 天免费试用或永久免费版（功能受限）。便于 PoC。

## 3. 结构化证据清单 (Evidence List)

### 证据 E1: 飞书 (Feishu) 定价与功能
*   **事实**: 飞书专业版（Professional）支持最多 500 人，包含高级文档权限、无限版本历史（文档）、10TB 团队空间（基础包，可扩展）。
*   **来源**: 飞书官网价格页 (2023-2024 数据), 飞书帮助中心 "权限管理" 章节。
*   **状态**: **[待核验假设]** - 需确认当前促销价及 30 人具体折扣。
*   **关联空缺**: G1, G2, G3.

### 证据 E2: 钉钉 (DingTalk) 定价与功能
*   **事实**: 钉钉专业版提供 30TB 团队存储空间，支持知识库权限管理。基础版免费但存储和权限受限。
*   **来源**: 钉钉官网企业服务页面。
*   **状态**: **[待核验假设]** - 需确认专业版是否强制购买或可选组件。
*   **关联空缺**: G1, G2.

### 证据 E3: 腾讯微云/企业微信 定价与功能
*   **事实**: 腾讯微云企业版主打安全存储，支持外链管控。企业微信文件助手集成度高。
*   **来源**: 腾讯云官网，企业微信官网。
*   **状态**: **[待核验假设]** - 腾讯系产品定价透明度相对较低，常需销售报价。
*   **关联空缺**: G1, G2.

### 证据 E4: 国际方案合规风险
*   **事实**: 根据中国《网络安全法》及《数据出境安全评估办法》，重要数据和敏感个人信息出境需通过安全评估。研发团队源代码属于核心商业秘密，存储在境外云服务存在合规审查风险。
*   **来源**: 中国工信部/网信办公开法规解读。
*   **状态**: **[公开知识]** - 确凿事实。
*   **关联空缺**: G6.

### 证据 E5: 研发团队存储需求基准
*   **事实**: 一般软件研发团队，每人平均产生 20-50GB 的非代码资产（设计图、视频、临时构建包）。30 人团队年增量约 1.5-2TB。加上历史积累，初始容量建议预留 5TB+。
*   **来源**: IT 资产管理行业标准经验值。
*   **状态**: **[推导/假设]** - 需结合用户实际业务修正。
*   **关联空缺**: G1 (成本建模).
