## 2. 详细事实核验与成本测算 (对应 G2, G3, G5)

### 候选 C1: 飞书 (Feishu) - 会议室模块

*   **功能兼容性 (F)**:
    *   **三端支持**: ✅ 完美支持 Web, macOS, Windows, iOS, Android。
    *   **日历集成**: ✅ 原生支持双向同步 Outlook (通过 Microsoft 365 连接器) 和 Google Calendar (通过 Google Workspace 连接器)。这是其最大优势之一。
    *   **门禁联动**: ⚠️ 飞书本身不直接提供门禁硬件驱动，但开放平台 API 完善，可对接海康威视等主流门禁系统（需少量开发或中间件）。
*   **成本与商业模式 (C)**:
    *   **计费模型**: 按人头收费。
    *   **版本差异**:
        *   *免费版*: 限制较多（如存储、部分高级权限）。
        *   *商业版/标准版*: 通常包含高级日历功能和会议室管理。
    *   **价格估算**:
        *   飞书商业版/标准版价格通常在 **¥20 - ¥50 /人/月** 之间（取决于促销活动和企业规模折扣）。
        *   取中位数 **¥30/人/月** 计算：$30 \times 30 \text{人} \times 12 \text{月} = \mathbf{¥10,800 /年}$。
        *   *注*: 若仅开通会议室相关功能，有时可单独购买应用包，但通常随主套餐销售。此价格远低于 2 万预算上限。
*   **网络与合规 (G5/G7)**:
    *   ✅ 中国大陆节点，访问速度快，无需翻墙。
    *   ✅ 支持支付宝/微信支付，发票开具方便。
    *   ✅ 符合中国数据安全法。
*   **来源/标记**: [公开知识] 飞书官网定价页及过往企业采购案例。**待核验**: 当前最新的具体单价（可能随促销波动）。

### 候选 C2: 钉钉 (DingTalk) - 智能会议室

*   **功能兼容性 (F)**:
    *   **三端支持**: ✅ 完美支持。
    *   **日历集成**: ⚠️ **风险点**。钉钉原生深度绑定阿里系日历。虽然支持 ICS 导入导出，但实现与 Google Calendar/Outlook 的**实时双向自动同步**通常需要借助第三方连接器（如宜搭或第三方 ISV 插件），配置复杂度高于飞书。
    *   **门禁联动**: ✅ 钉钉生态内有大量门禁厂商（如海康、大华）的原生插件，开箱即用体验较好。
*   **成本与商业模式 (C)**:
    *   **计费模型**: 按专业版席位收费。
    *   **价格估算**:
        *   钉钉专业版价格约为 **¥9800 - ¥12800 /年**（全公司打包价，不限人数，但有上限，30人完全覆盖）。
        *   或者按高阶应用单独订阅，约 **¥2000 - ¥3000 /年**。
        *   总成本估算：**¥10,000 - ¥13,000 /年**。
*   **网络与合规 (G5/G7)**:
    *   ✅ 中国大陆节点，支付便利。
*   **来源/标记**: [公开知识] 钉钉官网专业版定价。**待核验**: 外部日历双向同步的具体稳定性及是否需要额外付费插件。

### 候选 C3: RoomGuru (代表国际垂直 VMS)

*   **功能兼容性 (F)**:
    *   **三端支持**: ✅ Web 为主，移动端通过 PWA 或 App。
    *   **日历集成**: ✅ 强项，原生支持 Google/Outlook 双向同步。
    *   **门禁联动**: ✅ 极强，拥有预置的 IoT 网关和 API 对接多种门禁品牌。
*   **成本与商业模式 (C)**:
    *   **计费模型**: 通常按“房间数”或“用户数”阶梯收费，且有起售门槛。
    *   **价格估算**:
        *   此类国际 SaaS 起步价通常较高。例如，5-10 间房间的入门方案可能在 **$50 - $100 /月** 甚至更高。
        *   换算人民币：$(50 \sim 100) \times 12 \times 7.2 \approx \mathbf{¥4,300 - ¥8,600 /年}$。
        *   *注意*: 若按 30 名用户授权收费，费用会急剧上升，可能超过预算。需确认是按 Room 还是 User 计费。多数 VMS 按 Room 计费，这对我们有利。
*   **网络与合规 (G5/G7)**:
    *   ❌ **重大阻塞点**: 服务器位于海外（美/欧）。在中国大陆直接访问速度慢或不稳定，**必须依赖 VPN 或代理**。
    *   ❌ **支付阻塞**: 不支持支付宝/微信，需 Visa/Mastercard 信用卡。
    *   ❌ **合规风险**: 数据出境问题，对于有严格合规要求的研发团队是减分项。
*   **来源/标记**: [公开知识] RoomGuru 官网 Pricing 页面结构。**待核验**: 具体的最低起售价及是否接受中国客户。

### 候选 C4: Calendly (Team Plan)

*   **功能兼容性 (F)**:
    *   **三端支持**: ✅ 优秀。
    *   **日历集成**: ✅ 完美支持 Google/Outlook 双向同步。
    *   **会议室管理**: ⚠️ **功能缺失**。Calendly 核心是“时间块预约”，虽然可以创建“会议室”资源，但它缺乏物理会议室的状态面板、门禁联动、复杂的权限管理（如谁可以取消谁的预定）以及利用率报表。它更适合预约“人”的时间，而非管理“物”的空间。
*   **成本与商业模式 (C)**:
    *   **价格估算**: Team 计划约 **$10 - $16 /user/month**。
    *   $16 \times 30 \times 12 \times 7.2 \approx \mathbf{¥41,472 /年}$。
    *   **结论**: **严重超预算**，且功能不完全匹配（缺少空间管理特性）。
*   **来源/标记**: [公开知识] Calendly 官网。**判定**: 淘汰。

### 候选 C5: Nextcloud Rooms (自托管)

*   **功能兼容性 (F)**:
    *   **三端支持**: ✅ 网页版好用，移动端 App 体验尚可。
    *   **日历集成**: ⚠️ **弱项**。Nextcloud 主要提供 CalDAV 服务。要实现与 Google/Outlook 的双向同步，需要用户在客户端手动添加 CalDAV 地址，或通过脚本桥接。这不是“开箱即用”的企业级双向同步体验，容易出错。
    *   **门禁联动**: ❌ 无原生支持，需自行开发 API 接口。
*   **成本与商业模式 (C)**:
    *   **软件费**: ¥0。
    *   **服务器费**: 一台 4核8G 的云服务器（阿里云/腾讯云）约 **¥200 - ¥400 /月**。年费 **¥2,400 - ¥4,800**。
    *   **隐性成本**: 需要 IT 人员维护升级、处理安全补丁、解决同步 Bug。对于 30 人研发团队，若没有专职 DevOps，这部分人力成本折算后远超 ¥20,000。
*   **来源/标记**: [公开知识] Nextcloud 官方文档及云服务价格。**判定**: 技术可行，但运维成本高，不作为首选推荐，仅作为极端成本控制下的备选。

## 3. 关键空缺填补与分析 (对应 G1-G7)

### G1 & G2: 候选列表与价格汇总

| 候选方案 | 预估年成本 (RMB) | 预算符合性 (≤2万) | 备注 |
| :--- | :--- | :--- | :--- |
| **飞书 (商业版)** | ~¥10,800 | ✅ 符合 | 性价比高，集成最顺滑 |
| **钉钉 (专业版)** | ~¥12,000 | ✅ 符合 | 门禁生态好，但外网日历集成稍弱 |
| **RoomGuru (国际)** | ~¥5,000 - ¥9,000 | ✅ 符合 (若按Room计) | 网络/支付/合规是大障碍 |
| **Calendly** | ~¥41,000+ | ❌ 超标 | 功能侧重不同，非空间管理工具 |
| **Nextcloud (自建)** | ~¥5,000 + 人力 | ⚠️ 显性低，隐性高 | 适合有强 IT 能力的团队 |

### G3: 日历集成深度验证

*   **飞书**: **High Confidence**。飞书明确宣传支持 Microsoft 365 和 Google Workspace 的深度连接，包括双向同步事件、忙闲状态。这是其作为国际化协同工具的核心卖点。
*   **钉钉**: **Medium Confidence**。钉钉支持 ICS 标准，但“双向实时同步”往往需要通过“钉钉连接平台”或第三方 ISV 应用实现。可能存在延迟或冲突处理不如原生平滑的问题。
*   **国际 SaaS**: **High Confidence**。RoomGuru 等专为全球市场设计，日历集成是其核心功能，双向同步非常稳定。

### G4: 门禁联动可行性

*   **飞书**: 需通过 API 对接。海康威视等厂商通常提供“飞书集成 SDK”或 Webhook 示例代码。开发难度：**Low-Medium**（需后端工程师配合，约 1-2 人天）。
*   **钉钉**: 生态内插件丰富，可直接在钉钉应用市场搜索“门禁”，选择兼容的品牌插件安装即可。开发难度：**Low**（配置为主）。
*   **国际 SaaS**: 通常提供标准 REST API 或 MQTT 协议。若使用国产门禁，可能需要编写简单的中间层转发请求。开发难度：**Medium**。

### G5: 网络可达性与支付

*   **国内 SaaS (飞书/钉钉)**: 无障碍。
*   **国际 SaaS**: 除非团队已习惯使用 VPN 且有外币信用卡，否则**强烈建议排除**。对于 30 人团队，要求所有人日常办公依赖 VPN 访问预约系统是巨大的效率损耗和管理负担。

## 5. 阶段 02 结论与建议

### 推荐路径
基于上述分析，**飞书 (Feishu)** 是最符合所有硬性约束且体验最优的方案。
1.  **预算**: ~1.1万/年，留有充足余量应对可能的加购或未来扩容。
2.  **集成**: 原生支持 Google Calendar 和 Outlook 双向同步，满足研发团队混合办公环境的需求。
3.  **门禁**: 可通过 API 低成本对接现有门禁系统。
4.  **体验**: 国内访问极速，无合规风险，员工无需额外培训（熟悉 IM 即可用）。

### 备选路径
**钉钉 (DingTalk)** 是强有力的备选，特别是如果团队已经在使用钉钉进行即时通讯。其主要劣势在于外部日历（Google/Outlook）的同步体验略逊于飞书，可能需要额外的配置或插件来保证稳定性。

### 淘汰理由总结
*   **Calendly**: 超出预算，且功能侧重于“人”的日程而非“房间”的管理，缺乏空间管理核心特性。
*   **国际垂直 SaaS (如 RoomGuru)**: 虽然功能强大且便宜，但**网络不可达**和**支付不便**构成了致命的使用障碍，不适合中国大陆的日常办公场景。
*   **自托管开源方案**: 隐形运维成本过高，且日历双向同步体验较差，不符合“低运维负担”的中型团队预期。
