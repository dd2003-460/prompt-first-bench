## 9. 给 Lead 的下一步建议

1. **优先修 rubric 形式，不是语义**：把"首行判定"改成"首个非围栏、非空行"或直接给 stage01 工件规定 H1 模板；否则同一份内容是否被代码围栏包裹会决定 0 分还是满分（Δ=1.0 的单点风险）。
2. **给"交叉引用 id"定规则**：id 锚定与"仅作为引用出现"目前是黑箱。建议 rubric 增加一行：`若 id 仅出现在引用/权重/前提括注中且无独立陈述 → verdict=fail 且 note「仅交叉引用」`（本轮即按此执行，r277 相反），或直接从条目清单剔除此类 id。
3. **复核 kappa 口径**：per-cell κ 在单边全 pass / 全 fail 的 cell 上不可定义（本轮 J1 有 1 个、J2 有 3 个 cell 为 NaN），建议以 pooled κ + 明确 n 为主口径。
4. **若要再升 conf**：用第二家非 Qwen 通道（如 Llama/Mistral/Claude）跑同一 36 cell，比较三家 κ；单家异源只能证明"不同家族解读不同"，不能证明"哪家对"。
