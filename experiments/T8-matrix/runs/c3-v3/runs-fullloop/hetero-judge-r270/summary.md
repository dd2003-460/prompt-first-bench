## 6. 结论与口径

1. **不建议据此升档 T8 conf。** 异源 judge 与本地同源 judge 的 J1 一致性接近零（κ = −0.030），J2 也只有弱一致（0.185）。两个判官之间的分歧主要是严格度差异，异源 judge 的 pass 率显著更低。
2. **r268 的 J2 S02 结论需要修正表述。** 异源 judge 的 S02 J2 整体偏低（11.3%），因此「S02 J2 不可靠」这一判断获得部分支持；但 r268 在 B-nofreeze/D1/S02 上 27/29 vs 本次 1/29，说明 r268 的 0.931 spread 是 **同源 judge 的不稳定性**，不是配置之间的稳定差异。
3. **rubric v3 对分解类工件（S01）效度不足。** J1 的 ① 测试对纯模型知识的分解文档全部判失败。在修订 rubric 或为工件类型设定不同的 ① 标准之前，S01 的 pass 率不应作为质量指标。
4. **G2 不能作为消融信号存在的证据**（口径问题，见 §5）。若要重新评估 G2，需要 opportunity set 口径和 spread 阈值的预注册。
