# S10 组合臂消融 — 初步分析（90 runs 完成）

## 实验设计
5 臂 × 3 题(Q1/Q3/Q4) × 6 rep = 90 runs，每 run 4 轮（R1分解→R2审查→R3修正→R4终审）
- S10-A: v0 基线（单轮，无审查）
- S10-B: 机械式检查（FAIL/PASS + 缺口清单）
- S10-C: 机械式+讲原因
- S10-D: 人话 reviewer（审计员语气）
- S10-E: 终极目标+安抚情绪

## 核心发现

### 1. 缺口检测率（Q1 NVLink 盲区）
| 臂 | R2 提到 NVLink 缺口 | R4 修正了该缺口 |
|---|---|---|
| B | 6/6 (100%) | 6/6 (100%) |
| C | 0/6 (0%) | 0/6 |
| D | 部分（模糊提及） | 0/6 |
| E | 部分（模糊提及） | 0/6 |

**结论：机械式具体指认 > 人话模糊反馈。** B 臂的"子节点2和3隐含错误前提：PCIe仅支持PCIe P2P"这种精确措辞直接驱动了 R4 的定向修正。D/E 臂的"存在一个物理事实盲区"虽然方向对，但没给模型一个可操作的锚点。

### 2. 否决率（R2 verdict）
| 臂 | FAIL | PASS | 说明 |
|---|---|---|---|
| B | 12/18 (67%) | 6/18 | 严格机械检查，高否决 |
| C | 6/18 (33%) | 12/18 | 加"讲原因"后变宽松 |
| D | N/A | N/A | 人话格式，无显式verdict |
| E | N/A | N/A | 同上 |

### 3. 修正幅度（R1→R4 Jaccard similarity）
所有臂都在 0.05-0.07（大幅重写），差异不在"改了多少"而在"改对了没有"。
