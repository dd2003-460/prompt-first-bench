# G9 GOLD v2 设计（2026-11-20）

> 输入：g9-full-findings.md（141 对全量审计：nat 15 / soc 21 / gpu 105）
> 状态：设计定稿，已落码（s8b_pilot.GOLD_V2 + compute_J 消费 v2）
> 决策：soc 选链式 rubric（C 项 = 2 独立维度 + 链完整度），gpu 做 hub 合并 + 元维度剔除，nat 做方法/实例拆分。全部可逆（GOLD 旧值保留）。

## 设计原则（从 4 个跨题模式导出）

1. **方法 vs 题面实例**：维度文本只留跨题可迁移的方法；本题参数进 `examples` 字段（U(T) 的 C 项只对维度计分，实例作 judge 上下文）
2. **元维度剔除**：置信度标注/来源标注/条件性推荐规范是 rubric 层要求，不是 gold 维度——进 `meta` 字段，不进 C 项
3. **整体-部分**：公式与其子项不同时计分——子项标 `parent` 指向父维度，C 项只计父
4. **链式结构**：推理链环节不做维度乘积——拆成"独立维度 + 链完整度"（断链在哪一环）

## soc v2（7 维 → 2 独立维度 + 5 环节链）

独立性审计：g0×g1、g0×g2 独立（两个现象的解释可分别构造反例），其余 18 对全相关 = 链式依赖。

- **独立维度**（进 C 项乘积）：
  - s0: 现象 A（挂价高+成交快）的解释候选质量
  - s1: 现象 B（降价无咨询）的解释候选质量
- **链**（C 项 = 链完整度，断链定位）：
  - L1 假设链起点（生存压力+偏好噪声，不跳级）
  - L2 两现象同一假设的解释力评估
  - L3 利益相关方判定有依据
  - L4 最小干预 + 受害者明确
  - L5 关键断言带置信度
- **meta**（不进 C）：无

## compute_J 消费规则

- `C 项`：nat 5 维 / soc(2 维乘积 × 链完整度) / gpu 12 维
- 子项（parent 非空）：covered 时归入父维度命中，不单独计分
- meta 字段：judge prompt 里作为"附加要求"列出，但命中不计 C
- examples 字段：拼进 judge 的维度描述上下文（"本题实例：..."）
- 旧 `GOLD` 保留不动（s3_supplement 等旧消费者零影响）
