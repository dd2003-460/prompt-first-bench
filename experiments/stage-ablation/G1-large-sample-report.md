## 6. 解读

1. **soc/nat 不对称**（0.957 vs 0.600）指向 reasoning-type deficit：同一套 prompt lever，soc 域靠参数化知识就够，nat 域需要多步定量推导链，断点在推导中间（pt3/pt4/pt5），不是知识缺失。
2. **A3 阴性结果的机制解释**：量纲纪律是"输出端检查规则"（写完答案后核对单位），但 pt3/pt4/pt5 的断点在"推导过程中间"——检查规则无法修复过程中已经走错的路径。这跟 S8B 的 self-judge flip 发现一致：模型对自身输出的额外审视倾向于把正确内容当噪声删掉，而不是纠错。
3. **A4 弱正向的机制解释**：few-shot 示范的是"怎么一步步推"而非"最后检查什么"，所以它作用于推导过程本身，能部分修复中间断点（pt3/pt4）。但 pt5（residence-time stale 判定）几乎不动——这个断点可能需要的是世界知识（缓存淘汰策略的具体实现细节），不是推理格式示范能解决的。
4. **G5 核心论点**：prompt 层干预对推理链断点的效果取决于 lever 作用的位置——输出端检查（A3）无效，过程示范（A4）有弱正向但受限于 n 和方差，且对知识型断点（pt5）仍然无效。这不是"prompt 工程没用"，而是"prompt 工程的作用边界在哪里"的精确测量。
