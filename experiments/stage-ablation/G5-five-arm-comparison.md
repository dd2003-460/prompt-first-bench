## 4. 关键发现

### 4.1 S8G 泛化性验证（本轮核心）

- **S8G-Q1 mean = 0.792 ≥ 0.70 ✓ PASS**（r1=0.843, r2=0.742）
- **S8G-Q4 mean = 0.738 ≥ 0.65 ✓ PASS**（r1=0.730, r2=0.747）
- S8G-Q5 5-rep mean = 0.798（历史轮次，作参照）
- A1-A4 patch 在 Q1/Q4 上泛化成立：不是只在 Q5（methodology 域）有效，跨域（GPU 规格 / 数据处理架构）同样把 S5 基线拉高。

### 4.2 S7V/S7F 基线定位

- S7F（hook 注入但无 patch）：mean 0.586，**低于 S5 裸流程（0.805）**——research_hook 当前形态（arXiv 查询词偏学术 + KNOWN_SITES 抓取前 300 字符）是负资产，注入的来源不含关键规格信息，反而干扰模型。
- S7V（S7F + two-pass 核验）：mean 0.630，比 S7F 高 0.044 但方差大（Q1=0.417 vs Q5=0.830）。two-pass 在 Q5 有效（核验帮助观点型答案收敛），在 Q1 无效（初稿的数字错误 pass2 也纠不过来，因为来源里根本没有正确数字）。
- **根因链**（与 HBM 类型系统错误一致）：hook 抓不到 datasheet 级信息 → 注入来源无 HBM2e/HBM3 区分 → 模型靠 prior 填 HBM3 → pass2 核验时来源不支持任何版本 → 要么保留错误要么删数字，无法修正。

### 4.3 五臂排序（按可用数据）

```
S5 (0.805) > S8G (0.776) > S1 (0.630) ≈ S7V (0.630) > S0 (0.615) > S7F (0.586)
```

注意：S8G 与 S5 的差异未做配对检验（不同题集、不同 n），不能断言 S8G < S5；S8G 的价值在于它是**纯 prompt patch 不改 harness** 就能达到的水平，且跨题稳定（Q1/Q4/Q5 三域均 ≥0.73）。

## 5. 局限声明

1. S7V/S7F 每题仅 n=1，无 CI，单 run 波动可吞掉臂间差异（S7V-Q1=0.417 可能是低分 outlier）。
2. S0/S1/S5 的 scores-v3.json 是 n=15 时代产物；expansion-r4 补到 n=30 后需重算（S5 还缺 10 runs）。
3. S8G-Q1/Q4 仅 n=2，mean 的 95% CI 约 ±0.15，PASS 判定置信度中等。
4. 所有臂共享同一 v3 judge；judge 对 methodology 型 gold 不注入 gold 文本（R-06 同族局限），M1 可能系统性偏高。
