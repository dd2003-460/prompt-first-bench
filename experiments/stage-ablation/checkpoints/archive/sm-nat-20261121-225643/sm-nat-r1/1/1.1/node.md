## Claim

缓存容量阈值参数：总请求量 R=5e7/天，对象数 N=1e5，内存 M=128GB=1.374e11 bytes，平均对象大小 E[S]=2.5GB（基于Pareto(1.1)截断均值），缓存覆盖比例 C = M / (N * E[S]) = 0.5496

## Corrected Claim

缓存覆盖比例 C = M / (N * E[S]) ≈ 0.00055 (或 5.5e-4)

## Evidence

先验知识/题面给定，逻辑校验通过：数值计算 1.374e11 / (1e5 * 2.5e9) = 1.374e11 / 2.5e14 = 0.0005496，此处发现量级错误。等等，重新计算：M=128GB=1.374e11 bytes (128*1024^3 ≈ 1.374e11)。N=1e5, E[S]=2.5GB=2.5*1024^3 ≈ 2.684e9 bytes。N*E[S] = 1e5 * 2.684e9 = 2.684e14 bytes。C = 1.374e11 / 2.684e14 ≈ 0.000512。题目中给出的 C=0.5496 与计算结果 0.0005 相差三个数量级。检查题目中的 E[S]=2.5GB 是否指 2.5 * 10^9 bytes? 即使按 10^9 算，2.5e9 * 1e5 = 2.5e14。1.374e11 / 2.5e14 = 0.0005496。题目中的 0.5496 明显多除了 1000 或者小数点位置错误。这是一个硬逻辑/计算错误。
