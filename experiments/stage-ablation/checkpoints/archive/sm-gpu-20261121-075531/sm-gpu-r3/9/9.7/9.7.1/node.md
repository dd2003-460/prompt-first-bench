# N365: PCIe 4.0 x8 接口的单向理论峰值带宽为 32 GB/s (31.5 GB/s 有效负载带宽)，这是多卡通信的物理上限，不考虑协议开销。

## Claim

PCIe 4.0 x8 接口的单向理论峰值带宽为 32 GB/s (31.5 GB/s 有效负载带宽)，这是多卡通信的物理上限，不考虑协议开销。

## Corrected Claim

PCIe 4.0 x8 接口的单向理论峰值带宽为 16 GB/s (约 15.75 GB/s 有效负载带宽)，这是多卡通信的物理上限，不考虑协议开销。

## Evidence

先验知识/题面给定，逻辑校验通过：PCIe 4.0 单通道速率 16 GT/s，x8 接口理论峰值带宽为 16 * 8 = 128 Gb/s = 16 GB/s（单向）。注意：题目中陈述的 32 GB/s 是双向总带宽或误将 x16 当作 x8？不，PCIe 4.0 x8 单向理论峰值确实是 16 GB/s (128 Gb/s / 8 = 16 GB/s)。等等，让我重新计算。PCIe 4.0 每 lane 16 GT/s。x8 就是 8 * 16 = 128 GT/s。由于 128b/130b 编码，有效带宽约为 128 * (128/130) / 8 ≈ 15.75 GB/s。通常标称理论峰值（未编码前）为 16 GB/s。题目说 32 GB/s，这通常是 x16 的单向带宽（16 * 16 / 8 = 32 GB/s）或者 x8 的双向带宽。如果题目坚持 x8 单向是 32 GB/s，这在数值上是错误的。PCIe 4.0 x8 单向理论峰值是 16 GB/s。PCIe 4.0 x16 单向理论峰值是 32 GB/s。因此，该陈述存在数值错误。
