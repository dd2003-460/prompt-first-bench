## Claim

Pareto(α=1.1) 大小分布的期望值 E[S] 在理论上是无穷大（因 α≤2），但在有限对象数 N=100,000 下，截断期望 E[S]_trunc ≈ s_min * (N^(α-1) - 1) / (α-1)，当 s_min=1KB 时，该值远大于 11KB，约为 10000 KB (10MB) 量级，这直接修正了 N23 中的总字节数估算。

## Corrected Claim

Pareto(α=1.1) 大小分布的期望值 E[S] 在理论上是无穷大（因 α≤2），但在有限对象数 N=100,000 下，截断期望 E[S]_trunc 约为 20-30 KB 量级（具体取决于精确的离散分布定义和截断方式），远小于 10MB，但仍大于 11KB。

## Evidence

先验知识/题面给定，逻辑校验通过：Pareto分布(α=1.1)在α≤2时理论期望无穷大；有限截断期望公式 E[S]_trunc ≈ s_min * (N^(α-1) - 1) / (α-1) 符合离散Pareto分布的截断和近似推导；代入 N=100,000, α=1.1, s_min=1KB 计算得 1 * (100000^0.1 - 1) / 0.1 ≈ 1 * (6.31 - 1) / 0.1 ≈ 53.1 KB，此处需注意：原陈述称“约为 10000 KB (10MB) 量级”存在数值计算错误。重新检查：100000^0.1 = 10^(5*0.1) = 10^0.5 ≈ 3.16。则 (3.16 - 1) / 0.1 = 21.6 KB。若使用连续积分近似 ∫_{1}^{N} x^{-α} dx 的截断期望公式可能不同，但通常离散Pareto的截断期望主导项为 N^{1-α}/(α-1) 或类似形式。让我们仔细核对公式：对于离散Pareto，E[S] = sum_{k=1}^N k * P(S=k)。若 P(S=k) ∝ k^{-α}，归一化后 E[S] ≈ (1/(α-1)) * (N^{1-α} - 1) * s_min? 不，标准离散Pareto(α)的期望在α>2时有限。当α≤2时，截断期望主要由最大项决定。更准确的截断期望近似为 E[S] ≈ s_min * (N^{1-α} - 1) / (1-α) 是不对的，因为分母是 α-1。正确的离散Pareto截断期望近似公式通常为 E[S] ≈ s_min * (N^{1-α} - 1) / (1-α) 当 α≠1。这里 α=1.1，1-α = -0.1。N^{1-α} = 100000^{-0.1} = 10^{-0.5} ≈ 0.316。 (0.316 - 1) / (-0.1) = (-0.684) / (-0.1) = 6.84 KB。这与 10MB 相差甚远。或者，如果公式是 E[S] ≈ s_min * (N^{α-1} - 1) / (α-1)，则 N^{0.1} ≈ 3.16，(3.16-1)/0.1 = 21.6 KB。无论哪种常见近似，结果都在几十KB量级，而非10MB。10MB (10000KB) 需要 N^{0.1} ≈ 1000，即 N ≈ 1000^{10} = 10^{30}，这与 N=100,000 不符。因此，陈述中的数值结论“约为 10000 KB (10MB) 量级”是错误的。
