## Corrected Claim

计算Pareto(β=0.9)分布下，排名区间 [90001, 100000] 的累积请求概率精确值：P_tail = (90000^{-0.9} - 100000^{-0.9}) / (1 - 100000^{-0.9})，数值约为 3.4e-6。

## Evidence

先验知识/题面给定，逻辑校验通过：Pareto分布尾部概率公式正确，数值计算量级合理（90000^-0.9 ≈ 0.000215, 100000^-0.9 ≈ 0.000158, 差值≈0.000057, 分母≈1, 结果≈0.000057? 等等，重新计算：90000^-0.9 = exp(-0.9*ln(90000)) ≈ exp(-0.9*11.4079) ≈ exp(-10.267) ≈ 3.48e-5; 100000^-0.9 = exp(-0.9*11.5129) ≈ exp(-10.3616) ≈ 3.14e-5. 差值 ≈ 3.4e-6. 这远小于0.1168。让我再仔细检查Pareto分布的定义。通常Pareto分布的CDF是 F(x) = 1 - (x_m/x)^α for x >= x_m. 如果x_m=1, α=0.9, 则P(X > k) = k^-α. P(90000 < X <= 100000) = P(X > 90000) - P(X > 100000) = 90000^-0.9 - 100000^-0.9. 这个值非常小，约为3.4e-6。题目中给出的公式是 (90000^{-0.9} - 100000^{-0.9}) / (1 - 100000^{-0.9})，分母接近1，所以结果应该也是约3.4e-6。但是题目说数值约为0.1168。这明显是错误的。0.1168大约是11.68%，这对于排名90001-100000的尾部概率来说太大了。通常Pareto分布的尾部概率随排名增加而迅速下降。例如，P(X > 100) = 100^-0.9 ≈ 0.0126. P(X > 1000) = 1000^-0.9 ≈ 0.00126. P(X > 10000) = 10000^-0.9 ≈ 0.000126. P(X > 90000) ≈ 3.48e-5. 所以区间[90001, 100000]的概率应该是3.48e-5 - 3.14e-5 = 3.4e-6。题目中的0.1168是错误的。
