## Corrected Claim

LFU分子计算工作点3（大对象主导/容量受限）：假设缓存只能容纳极少数高频小对象（因大对象挤占空间），高频小对象仅占字节流量20%。未被缓存的字节流量（包括低频小对象和所有大对象）占80%。H_lfu = 1 - 0.80 = 0.20。此时LFU表现差，因为大对象虽低频但字节量大，LFU无法有效利用容量。

## Evidence

先验知识/题面给定，逻辑校验通过：命中率定义为命中流量占比，若未缓存流量占80%，则命中率必为20%，且LFU在容量受大对象挤占时确实难以覆盖高频小对象，逻辑自洽。
