## Claim

RX 9000 系列 (假设 32GB, 1100 GB/s, $1100) 的理论 Decode 吞吐与成本效益：INT4 权重 (13.5GB) 下理论吞吐 = 1100 / 13.5 ≈ 81.5 tokens/s。考虑 ROCm 效率 0.8 (假设优化后)，实际 ≈ 65.2 tokens/s。单位成本 = $1100 / 65.2 ≈ $16.87/token/s，低于 RTX 4090 ($21.43) 和 RTX 5090 (预计 $2000/132.7*0.95≈$15.75，若 5090 效率更高则 5090 占优)。
