# N171: 低热度对象（λ_i < 50 req/day）在 LRU 缓存中的平均驻留时间 T_resident 的解析表达式为 T_resident = C / (R *

- **status**: degraded

## Claim

低热度对象（λ_i < 50 req/day）在 LRU 缓存中的平均驻留时间 T_resident 的解析表达式为 T_resident = C / (R * s_i) * (1/β_eff)，其中 C=128GB，R=50,000,000 次/天，s_i 为对象大小，β_eff 为有效热度指数（在 Pareto(β=0.9) 下需通过积分 ∫_{λ_min}^{50} λ^{-1} dF(λ) 计算）；当 s_i=50KB 时，T_resident ≈ 128GB / (50,000,000 * 50KB) * (1/0.9) ≈ 5.69 天，与 5.0 天的估计值差异需通过 β_eff 的精确计算修正。

## Corrected Claim

低热度对象在 LRU 缓存中的平均驻留时间 T_resident 无法仅通过 C/(R*s_i) 简单解析得出，需基于具体访问模型（如 Markov 链或排队论）模拟计算；原公式量纲正确但物理机制描述不准确，建议移除具体解析表达式，仅保留定性结论：低热度对象驻留时间较短，具体数值需通过仿真或更复杂的解析模型确定。

## Evidence

[质询]公式 T_resident = C / (R * s_i) * (1/β_eff) 在物理量纲和逻辑上存在严重缺陷：1. 量纲错误：C/(R*s_i) 的单位是 (Byte) / ((1/Day) * Byte) = Day，这代表的是缓存总容量相对于总请求带宽的周转时间，而非特定对象的驻留时间。2. 逻辑矛盾：该公式计算出的 T_resident 与对象大小 s_i 成反比，意味着小对象驻留时间更长，这与 LRU 缓存中“小对象因占用空间少而更容易被保留”的直觉相符，但公式中 R 是总请求率，未体现对象 i 的特定热度 λ_i 对驱逐概率的影响。3. 数值巧合：5.69 天的结果主要源于 C/(R*s_i) 的计算，而 (1/β_eff) 仅作为修正因子，这种解析形式缺乏标准的缓存理论支持（通常驻留时间与热度 λ_i 和缓存大小 C 有关，而非简单的总请求率倒数）。 | 先验知识/题面给定，逻辑校验未通过：公式量纲虽为时间，但物理意义不明，且将总请求率 R 直接用于计算单对象驻留时间缺乏理论依据，属于经验事实且逻辑存疑。
