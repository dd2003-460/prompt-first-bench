Intel Gaudi 3 单卡方案的 3 年 TCO 约为 $29,988（基于给定参数计算）。由于 RTX 5090 的完整 3 年 TCO（含电费、维护等）未在陈述中完整列出，无法直接得出 8.5 倍的精确倍数结论，但 Gaudi 3 的 TCO 显著高于 RTX 5090 方案，其成本劣势仅在高并发多用户服务场景下可能通过 Batch Size 优势部分抵消。
