## Claim

L4 与 A10 在 7x24 运行、电价 $0.15/kWh 下的年度电力成本差异量化：ΔP = (150W - 72W) = 78W = 0.078 kW；ΔC_power_year = 0.078 kW * 8760 h * $0.15/kWh ≈ $102.6 USD/year；3 年 TCO 电力差异约为 $307.8 USD，远小于硬件价差 ($800+ USD)，因此电力成本不足以抵消 A10 的更高硬件成本，A10 在 TCO 上劣于 L4，除非 A10 吞吐量优势带来的时间价值 > $307.8/3年。
