## Claim

A100/H100 服务器级噪音源定位：噪音主要来源于服务器前置/后置的高转速轴流风扇（通常 6-8 个，转速 5000-8000 RPM），在满载时单服务器噪音可达 70-80 dB(A)；这与消费级 GPU 的涡轮风扇噪音频谱不同，低频成分更多，隔音难度更大。
