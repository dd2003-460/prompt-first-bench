## Claim

信任维护成本 C_trust 的边际差异 ΔC_trust = C_trust_high - C_trust_low，其中 C_trust_high 对应高信号卖家（低纠纷率），C_trust_low 对应低信号卖家；需计算 ΔC_trust 是否小于高挂价带来的额外佣金收入 ΔRevenue，以判断平台是否通过降低信任成本来维持高溢价均衡。

## Corrected Claim

在特定平台经济模型中，若高信号卖家（低纠纷率）的信任维护成本显著低于低信号卖家，且该成本差异（ΔC_trust）小于高挂价带来的额外佣金收入（ΔRevenue），则平台可能通过降低信任成本来维持高溢价均衡。
