## 一句话结论

**两个杠杆在 n=3 pilot 上都没跑出净正效应，但失败模式不同**：persona 是"零效应+轻微幻觉上升"（与 `2311.10054`、S8A 一致方向），掩码重建是"负效应+成本 2-3 倍"——且负效应集中在它理论上最该生效的维度（假设链起点、置信度标注）。这给 T-PR-13 "掩码重建翻正自校验符号"的判决加了第一个本地反例证据。

## 预测判决

- **P1 (A2 > A0)**：**不成立**。两域都 ≤ A0，soc 域显著为负。
- **P2 (A1 ≈ A0)**：**基本成立**。两域差值都在 ±0.05 内（n=3 下无法区分真零效应和小负效应），与 `2311.10054` 大样本零效应和 S8A 本地先例同向。附带观察：A1 在 nat 上 hallucination flags 从 3.0 降到 1.0——persona 没提升覆盖但压了编造，这是 S8A 没测过的侧面。
- **P3 (soc 上 A2-A0 ≥ nat 上 A2-A0)**：**反向成立**。soc −0.238 < nat −0.056。"社会域必须带二级层"在行为层**没获得支持**——至少对掩码重建这个杠杆，二级层的结构化锚点没帮上忙，反而更伤。

## 失败机制（judge reasons 里读出来的，不是猜的）

1. **A2/soc-r1 丢了"置信度标注"**（pt7=0：通篇未标置信度）——掩码重建流程占满了输出结构，把原 prompt 里的标注要求挤掉了。**杠杆之间抢同一块注意力预算**，这是组合消融的直接证据。
2. **A2/soc-r1 假设链起点偏移**（pt1=0：归结为"禀赋效应"而非"生存压力定向+偏好噪声随机"）——重建阶段让模型把注意力放在"内部一致性"上，弱化了框架要求的特定理论视角。
3. **A0/nat-r3 的低分是裸基线自身的方差**（推导逻辑错误被判 0 分）——说明 nat 题对 27b 偏难，A0 的 0.444 均值被一个坏 run 拉低，nat 域的 arm 间对比信噪比差于 soc 域。

## 对"组合看非独立部分"的回答（成璐 2026-11-08 问题）

本实验第一次给出了**组件非独立的直接测量**：三个臂共享同一个基础 prompt 骨架（标注要求/口径检查/防编造指令），A1 和 A2 各自往里塞流程时：
- 单独看：A1 ≈ 中性，A2 = 负
- 机制看：A2 的负效应来自**挤占标注行为**（pt7 缺失只在 A2 出现）——即 A2 与"标注习惯"组件负交互，与"推理质量"组件无交互
- 推论：pfb 的组件 Δ 测量（现有 S0-S8M 体系）测的是**边际效应**，而这里测到的是**交互项**。要完整回答"最终有多少非独立部分"，需要 2^k 全因子设计而不是加法消融——当前 k=3（persona/掩码/标注）就是 8 臂，可跑；k=5 就 32 臂，成本开始不划算。**建议交互项测量只挑有先验怀疑配对的组件做**（如 A2×标注、A1×发散前段），不做全因子。
