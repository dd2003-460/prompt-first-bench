# 标准答案 · 科研方法论（贝叶斯 vs 频率学派怎么选）

**题面**：面对一个统计推断/决策问题，选**贝叶斯学派**还是**频率学派**，使
**每个统计决策的期望决策损失最低**，且满足制度约束（如期刊要求 α 显著性、监管要求可审计）。

**候选**：频率学派（固定样本检验 / 置信区间 / p 值）· 贝叶斯学派（后验推断 / 决策论 / MCMC）。
（对照：混合/两阶段 workflow —— 先用频率筛查、再贝叶斯量化，作为工程折中列出。）

**与 27B 硬件 gold 的结构差异**（本题是泛化测试的**最远域**）：
硬件题里候选=GPU，叶子=**物理规格（可查表 S-a）**，成本侧 `c_hour` 主导，约束=显存/带宽准入。
本题候选=**统计范式**，叶子=**范式属性（多为理论推导 S-a 或黑盒 S-b）**，
**没有任何实测数据可查表**，根节点从「单位产出成本」变成「单位决策期望损失」。
这是与硬件题最本质的结构不同：**证据类型从「测量」退化为「理论推导 + 模拟」**。

---

## 0. 根节点（L0)

**N-0 每个统计推断决策的期望决策损失 `L_dec` [AU/decision]**

```
L_dec = L_err + L_cost + L_comm + L_tail
```

- `L_err`：推断错误的期望代价（假阳性/假阴性）——**本题主导项**。
- `L_cost`：跑这套程序的计算 + 人力 + 时间代价。
- `L_comm`：结论被下游误读/误用的期望损失（可解释性）。
- `L_tail`：范式核心假设失效的尾部风险（先验误设 / 模型误设 / 多重比较）。

**为什么用这个标量**：
1. 「哪个学派更划算」= 单位决策的期望损失最低，无歧义（决策论标准表述）。
2. 标量，可排序、可谈弹性（虽然本题弹性多为定性，见 §6 边界）。
3. **制度约束作为 feasible 约束**（不是损失项）：不满足 α 显著性要求的范式在监管场景直接划掉——和硬件题「带宽不够直接划掉 M2 Ultra」同构。

**口径声明**：

| 项 | 口径 |
|---|---|
| `SHARE` | 弹性绝对值归一化——**本题多为定性份额**（无实测数据算不出数值弹性，见 §6） |
| `BOUND` | 叶子区间内 `L_dec` 的 max/min——**用模拟给出，非实测** |
| 损失函数 | `C_FP`/`C_FN` 由**决策场景**给定，题面未给 → 列入空缺清单（§5），不做默认假设 |
| 证据类型 | S-a=统计理论可推导 · S-b=黑盒（给区间+一天模拟测法）· S-c=场景约束决定 |

> **关键诚实声明**：硬件 gold 的叶子数字来自 `calc.py` 实测；本 gold **没有任何实测数字**，
> 所有「区间」都是理论量级估计 + 可一天内用模拟复核的下界。这是本域与硬件域的根本差异，
> 也是方法论泛化边界的直接证据（§6）。

## 1. 正交维度定义（L1)

```
L_dec = L_err + L_cost + L_comm + L_tail       （损失空间的正交划分）
L_err = P(FP)×C_FP + P(FN)×C_FN                （错误代价恒等式）
```

| 维度 | 节点 | KIND | 说明 |
|---|---|---|---|
| **推断错误** | N-1 `L_err` | signal（主导) | 假阳性/假阴性代价，两学派的核心战场 |
| **计算人力** | N-2 `L_cost` | signal | 闭式 vs MCMC 的成本差 |
| **沟通误读** | N-3 `L_comm` | signal | p 值通用但易滥用 vs 后验直观但小众 |
| **范式尾部** | N-4 `L_tail` | signal/constraint | 先验误设（贝叶斯）vs 模型误设/p-hacking（频率） |
| **适用场景** | N-5 `feasible` | constraint | 样本量/先验可用性/决策直接性/制度约束 |

**正交性检验**（每对找独占因素）：

| 这一对 | 前者独占 | 后者独占 |
|---|---|---|
| 推断错误 ↔ 计算人力 | 假阳性率 P(FP) | MCMC 收敛迭代数 |
| 推断错误 ↔ 沟通误读 | 假阴性损失 C_FN | p 值误读率 |
| 推断错误 ↔ 范式尾部 | 样本量 n（直接进入 P(FP)/P(FN)） | 先验误设的尾部幅度 |
| 计算人力 ↔ 沟通误读 | 算法复杂度 | 不确定性表达直观性 |
| 范式尾部 ↔ 适用场景 | 哲学一致性 | 制度约束（α 一票否决） |

全过。**SHARED 必须现在记**（详见 §5）：
- `n 样本量` 同时进 N-1（错误率）和 N-5（场景划分），且是**两范式收敛的 crossover 参数**。
- `prior_quality 先验质量` 同时进 N-1.4（好先验**降** L_err）和 N-4.1（坏先验**升** L_tail）——
  **同一参数两条路径符号相反**，与硬件 gold 的 `quant`（降成本 vs 升成本）完全同构，是本域标志性耦合。

## 3. 叶子卡片（执行动作 + 完成判据 + 来源类型）

> 本域无实测数据，「数据来源」= 统计理论/经典文献/一天内可做的**模拟或试点**。
> 「一天测法」在方法论域的具体形态 = **蒙特卡洛模拟**（生成已知真相的数据，比较两学派表现）。

### N-1.1.1 假阳性率 P(FP)
- **执行动作**：固定 n、效应量 d、显著性水平 α，用统计理论算频率学派 P(FP)=α；贝叶斯侧给定后验拒绝阈值，算后验包含原假设的概率。
- **完成判据**：每个候选范式一个 P(FP) 表达式/数值（在给定 n,d,α 下）。
- **来源**：统计推断教材（S-a 可推导）。

### N-1.1.2 假阳性损失 C_FP ／ N-1.2.2 假阴性损失 C_FN
- **执行动作**：从决策场景提取「误报一次代价多少 / 漏报一次代价多少」（如医学筛查：漏报≪误报；spam 过滤：误报≪漏报）。
- **完成判据**：一个 C_FP:C_FN 比值。**题面未给 → 不假设，列入空缺清单**，结论按比值分档条件化。
- **来源**：用户/场景给定（S-b 空缺）。

### N-1.2.1 假阴性率 P(FN)
- **执行动作**：频率学派算 power=1-β（依赖 n,d,α）；贝叶斯算后验区间包含 0/无效值的概率。
- **完成判据**：每个范式一个 P(FN) 表达式。
- **来源**：统计理论（S-a）。

### N-1.3 样本量 n ■B5 ■瓶颈#1
- **执行动作**：确认实际可用样本量，划入小/中/大档；小样本下算频率学派 power 缺口，大样本下确认两范式一致性（贝叶斯-频率渐近等效）。
- **完成判据**：n 的档位 + 该档下两范式 P(FP)/P(FN) 的差距量级。
- **来源**：场景给定 + 模拟 power 曲线（S-b）。
- **为什么是第一瓶颈**：n 决定两学派差距大小——大 n 时差距消失（结论对学派不敏感），小 n 时差距最大（学派选择才真正重要）。**没确认 n 之前谈「哪个学派好」无意义**，对应硬件 gold 的「u<0.35 别买卡」。

### N-1.4 先验信息价值 prior_value ■B1
- **执行动作**：评估领域是否有可靠先验（历史数据/专家知识/物理约束）；估计先验能减少多少后验方差/错误率。
- **完成判据**：prior_value 档位（无/弱/强）+ 小样本下 L_err 降幅区间。
- **来源**：领域知识 + 模拟（S-b）。**贝叶斯独占**，频率学派此值恒为 0。

### N-2.1 算法复杂度
- **执行动作**：列出目标问题在两范式下的求解方式——频率：闭式检验/CI（t/z/卡方）vs 贝叶斯：MCMC/变分/拉普拉斯近似。
- **完成判据**：每个范式一个复杂度档位（闭式/数值/迭代采样）。
- **来源**：统计计算方法教材（S-a）。

### N-2.2 收敛与诊断成本 ■B3
- **执行动作**：对 MCMC 方案，估计达到收敛所需的迭代数 + 诊断（R-hat、ESS、重采样）耗时；闭式方案此项为 0。
- **完成判据**：MCMC 收敛诊断的人时区间。
- **来源**：实测一个真实分析计时（S-b）。

### N-2.3 实现人力
- **执行动作**：估计从零建模到出结论的人时（频率：通常几行代码；贝叶斯：建模+先验设定+MCMC 调参+诊断）。
- **完成判据**：每个范式一个人时区间。
- **来源**：经验 + 试点（S-b）。

### N-3.1 结论标准度
- **执行动作**：评估结论的「通用语」程度——p 值/CI 是科研通用语（读者无需额外解释）；后验分布/贝叶斯因子需向非贝叶斯读者翻译。
- **完成判据**：每个范式一个「下游理解成本」定性档。
- **来源**：科学传播/可重复性文献（S-a）。

### N-3.2 误读率 ■B4
- **执行动作**：评估两范式结论被误用的概率——p 值滥用（把 p 当效应量/把不显著当无效应）是有文献记录的系统性风险；后验误读（把后验当频率）也存在但受众小。
- **完成判据**：每个范式一个误读风险定性档 + 文献依据。
- **来源**：可重复性危机文献（ Ioannidis 等，S-b 偏 S-a）。

### N-3.3 不确定性表达
- **执行动作**：评估「参数在区间 X 的概率为 Y」这种语句对决策者的直观性——贝叶斯后验直接给出，频率 CI 需小心解释（不是参数的概率）。
- **完成判据**：每个范式一个直观性定性档。
- **来源**：统计哲学文献（S-a）。

### N-4.1 先验误设风险 ■B2（SHARED，符号与 N-1.4 相反）
- **执行动作**：做先验敏感性分析——换 3 个合理先验，看后验结论/决策是否变化；强敏感=高风险。
- **完成判据**：prior_sens 档位（稳健/中等/强敏感）。
- **来源**：模拟（S-b）。**与 N-1.4 是同一参数 prior_quality 的两面**：好先验在 N-1.4 降 L_err，坏先验在 N-4.1 升 L_tail。

### N-4.2 模型误设/多重比较
- **执行动作**：评估频率学派在模型误设、多重比较、p-hacking 下的尾部风险（选择偏差、发表偏倚）；贝叶斯模型选择可部分缓解但非免疫。
- **完成判据**：每个范式一个尾部风险定性档。
- **来源**：可重复性危机文献（S-b 偏 S-a）。

### N-4.3 哲学一致性
- **执行动作**：确认决策框架需要哪种概率解释——长期频率（重复抽样）vs 主观信念（单次决策）。单次高风险决策（如桥梁承重、新药上市）更匹配贝叶斯决策论。
- **完成判据**：场景与概率解释的匹配档。
- **来源**：统计哲学（S-a）。

### N-5.1 样本量场景（SHARED←N-1.3)
- **执行动作**：把 n 划档：小（n≲30 或 power 不足）、中、大（n→∞，两范式渐近一致）。
- **完成判据**：n 档位 + 该档下「学派选择重要性」定性。
- **来源**：场景 + 渐近理论（S-a/S-b）。

### N-5.2 先验可用性（SHARED←N-1.4)
- **执行动作**：判断先验状态：有可靠先验 / 无先验（用弱信息先验）/ 有但不可靠（需敏感性分析）。
- **完成判据**：先验状态三档之一。
- **来源**：领域知识（S-b）。

### N-5.3 决策直接性（SHARED←C_FP/C_FN)
- **执行动作**：判断下游要什么——直接决策（要后验概率/期望损失，贝叶斯决策论直接给）vs 发表/汇报（要 p 值/显著性，频率给）。
- **完成判据**：决策直接性档位。
- **来源**：场景（S-a）。

### N-5.4 制度约束 ■一票否决
- **执行动作**：查目标场景是否有硬性制度要求（FDA/期刊要求 α 显著性、审计要求可复现流程）。
- **完成判据**：pass/fail——有 α 硬性要求则纯贝叶斯方案在該场景被划掉（可改用混合 workflow）。
- **来源**：制度文件（S-a）。

## 4. 关键黑盒（S-b 收口）

| 黑盒 | 为什么没有闭式 | 区间（量级估） | 一天内能做完的测法（=模拟/试点） | 弹性 |
|---|---|---|---|---|
| **B1 先验价值 prior_value** | 取决于先验与真实参数的匹配度，问题相关 | 小样本下 L_err 降幅 [10%, 60%] | 模拟 1000 组数据（已知真相），比有无先验的 CI 覆盖率/宽度 | **高（小样本主导）** |
| **B2 先验敏感性 prior_sens** | 后验对先验的依赖无解析解 | [稳健, 强敏感] | 换 3 个合理先验跑同一数据，看结论变不变 | 中（定 L_tail) |
| **B3 MCMC 收敛成本** | 收敛速度依赖模型维度/几何，无闭式 | [0.5, 8] 人时/分析 | 真实分析计时（含诊断） | 中（L_cost) |
| **B4 p 值误读率** | 依赖受众统计素养，无闭式 | 高（有系统文献） | 文献调查 + 对目标受众访谈 | 中（L_comm) |
| **B5 小样本功效缺口** | power 依赖具体 n,d,α 组合 | 小 n 下频率 power 可低至 [0.2, 0.5] | 模拟 power 曲线扫 n | **高（与 B1 对冲）** |

**B1 与 B5 是对冲关系**：小样本时频率学派功效缺口大（B5 高），但正是此时贝叶斯先验价值最大（B1 高）——
两黑盒共同决定「小样本场景贝叶斯是否净赢」。这对应硬件 gold 的 B2/B3（MFU/η_bw 都是「标称 vs 实测」差距），
但性质不同：硬件黑盒是**物理噪声**，方法论黑盒是**问题相关的建模判断**，区间更宽、更依赖模拟。

## 5. SHARED 参数（跨子树耦合）

### 5.1 `n 样本量` —— 两范式收敛的 crossover
```
n 大 → 贝叶斯后验 ≈ 频率置信区间（一致性定理）→ 学派选择重要性 → 0
n 小 → 先验主导后验 → 学派选择重要性 → 最大
```
- 出现在 N-1.3（进 P(FP)/P(FN)）和 N-5.1（场景划分）。
- **不标 SHARED 的后果**：会分别得出「样本少贝叶斯好」（只看 N-1.4）和「样本多无所谓」（只看 N-5.1），
  拼不出「**n 是决定要不要认真选学派的开关**」这个核心条件化结论。

### 5.2 `prior_quality 先验质量` —— 同一参数两条路径符号相反 ★
```
好先验 → N-1.4 降 L_err（正向收益)
坏先验 → N-4.1 升 L_tail（反向风险)
```
- 与硬件 gold 的 `quant`（W4 降成本 vs 升通过率风险）**完全同构**：同一参数在两条路径符号相反，
  净效应取决于「收益路径」和「风险路径」谁占优。
- **不标 SHARED 的后果**：只看 N-1.4 会得出「有先验就用贝叶斯」，忽略坏先验的系统性偏差风险，
  给出无条件「贝叶斯更好」的错误结论。

### 5.3 `C_FP/C_FN 损失比` —— 场景决定错误权重
```
C_FN ≫ C_FP（漏报贵，如疾病筛查) → 要高 power → 小样本下贝叶斯/大样本频率
C_FP ≫ C_FN（误报贵，如 spam）   → 要低 FPR → 频率 α 直控更透明
```
- 出现在 N-1.1.2/N-1.2.2（错误加权）和 N-5.3（决策直接性）。
- **题面未给损失比 → 列为空缺**，结论按比值分档条件化，不做默认假设。

## 6. 推荐方案（条件化决策规则，不是「无脑贝叶斯」）

**结论形状**（全部条件化，对应硬件 gold 的「在前提 P 下选 A」）：

1. **先过制度约束**（N-5.4）：场景硬性要求 α 显著性/可审计 → 纯贝叶斯划掉，
   用频率或「频率筛查 + 贝叶斯量化」混合 workflow。
2. **大样本（n 大）+ 无强先验 + 要发表** → **频率学派**（p 值/CI 通用语，闭式，流程成熟；
   此档两范式渐近一致，选频率只为沟通成本最低）。
3. **小样本 + 有可靠先验 + 直接决策（要后验概率/期望损失）** → **贝叶斯**
   （先验价值 B1 高，弥补功效缺口 B5；后验直接服务决策）。
4. **高维/复杂模型 + 需要完整不确定性量化** → **贝叶斯**（MCMC 成本 B3 可接受时；
   频率 bootstrap 是低成本替代）。
5. **先验不可靠 / 强敏感（B2 高）** → 谨慎用贝叶斯，先做敏感性分析，或退回频率 + 大样本。
6. **C_FP/C_FN 极端偏斜** → 按偏斜方向选：漏报贵→要 power（贝叶斯/大 n），误报贵→要 FPR 透明（频率 α）。

**最有用的产出**（对应硬件 gold 的「u<0.35 别买卡」）：
**「学派选型的第一变量不是学派，是 (n 样本量, 先验质量, 损失比 C_FP/C_FN) 这三个业务侧黑盒」——**
n 和先验状态没确认之前，「贝叶斯更灵活」或「p 值更客观」都没有决策意义。
大样本下这句话尤其成立：两范式收敛，争论学派是伪问题，真正该问的是「我的 n 够不够、先验靠不靠谱、哪种错误更贵」。

**不成立条件**（对应硬件 gold 的「ΔG>0.08 时 W4 输给 W8」）：
- 若场景是**单次、高维、无先验、无制度约束、纯探索** → 本树的 L_err 主导假设可能不成立，
  应改用「探索-利用」框架而非「错误最小化」框架，本 gold 不适用。

## 常见误读（= 本实验要测的"隐藏矛盾"）
1. **「小样本下贝叶斯一定更优」** —— 错。统计效率优势依赖先验质量；先验设定错误时贝叶斯后验系统性偏移，而频率派的保守性在小样本下反而是保护。"更优"是有条件的。
2. **「期刊要求 α 显著性 = 只能用频率派」** —— 错。贝叶斯结果可转换为等效 p 值/置信区间表述以满足投稿要求，制度约束限制的是呈现形式不是推断方法本身。
3. **「p 值可重复 = 结论可靠」** —— 错。p-hacking、多重比较、发表偏倚使 p<0.05 的复现率远低于名义水平，显著性是门槛不是证据强度。
4. **「监管领域不能用贝叶斯因为先验主观」** —— 错。敏感性分析（多先验族对比）可把先验主观性变成可审计维度，问题不在方法而在是否做敏感性披露。
