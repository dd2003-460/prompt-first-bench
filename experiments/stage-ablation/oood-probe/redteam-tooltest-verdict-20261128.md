# 判别性实验: 检索通道 + 元层注入 → 会不会自发先查前人方案（2026-11-28）

# origin: ai
## 动机
上一探针结论: strategic 层质疑 = 习惯(可注入) × 信息(需检索)。V4 元层注入给了"层次敏感度"但"查前人"动作没触发。
本实验补最后一刀: 给 V4 注入的模型一个真实检索通道([SEARCH: query]), 测它会不会**自发**在动手审查前先查前人方案。
- 会 → 习惯注入 + 检索通道就够, strategic 层可 prompt 化
- 不会 → 触发器没接上, 这层得靠 agent 循环(记忆/矛盾触发机制), prompt 到头了

## 设置
- 臂: v4+tool = 检索通道说明 + V4 元层质疑习惯 + 同一红队任务 + 同一材料
- 检索通道: "你有检索工具, 要查就单独一行写 [SEARCH: 检索词]"
- 判据: 输出里有没有 [SEARCH:] 行(自发查), 以及查的时机(动手前 vs 全程不查)
- 输出: redteam-inject-v4+tool.txt (944字, finish=length)

## 结果
**没自发查。** 输出里零 [SEARCH:] 行。模型拿到检索通道 + 元层习惯, 仍然直接冲进 execution 层批判(构念效度/统计功效), 全程没决定"先查查有没有人做过"。

## 判决
习惯在(它知道"该查前人"), 通道在(给了工具), 但**触发器没接上**——模型不会在"我还没查"这个状态上停下来真的去查。
- 这说明 strategic 层质疑的瓶颈不是"知不知道该查"(认知)也不是"能不能查"(工具), 而是**"在什么信号下决定去查"(触发/时机)**。
- 纯 prompt 注入补不了触发器: 触发器需要一个外部事件(矛盾/卡住/信息缺口)去点火, 这正是 agent 循环里"矛盾触发思考机制"要干的事。
- 推论(对 M 线 claim 的影响): "让 27b 像 D 一样思考"的 strategic 层, 不能靠 prompt 注入实现, 得靠 ① 记忆系统(知道有哪些前人方案/成熟解可查) ② 触发机制(矛盾/缺口时点火去查)。prompt 注入最多给到"层次敏感度"(知道自己在错层上)。

## 负结果价值(排除了什么)
- 排除了"给工具就行"的错误解释: 不是缺工具, 是缺触发
- 排除了"元层习惯注入就够"的错误解释: 习惯≠行为, 中间差一个触发器
- 导出的设计规则: 思考机制落地 = 习惯(prompt) × 信息(记忆) × 触发(agent 循环事件), 三者缺一不可, 当前 M 线只做了第一项
