

# 实验设计审查意见

## 一、根本性问题：实验测的不是它声称要测的东西

**实验声称的目标**是让 27b "表现出 D 式思考"（爬层/统一覆盖/量化落地/类比审计/判据瓶颈），但实际测量的全部是**输出文本的表面统计特征**：

- `flip`：judge 做二分类，判断 claim 里的机制词是否属于题目域
- `form`：正则匹配"三要素≥2"的节点占比
- 域偏移率：词表命中计数比
- 量化 claim 密度：含数字/公式的节点占比

这些指标共同的问题是：**它们测量的是"输出长什么样"，而不是"模型在想什么"。** 一个完全不具备相应思考能力的模型，只要学会了在正确位置插入域内词汇、凑够三要素格式、避免使用黑名单词，就能让所有指标同时改善。实验自己已经意识到这一点（"form 升 align 平 = 形式模仿 → 判负"），但整个测量体系里**没有任何一个指标能区分"真的在统一覆盖地思考"和"学会了在输出里写一句'存在统一形式：X÷Y'"**。

这不是"指标不够好"的问题，而是**构念效度（construct validity）的根本缺失**。实验无法回答"注入是否改变了模型的思考过程"，只能回答"注入是否改变了输出的表面分布"。

## 二、判据与要测的东西结构性错位

预注册判据的核心是 `align = flip × form`。这个乘积结构有两个致命问题：

1. **flip 是二分类（0/1）**。任何一个 rep 里 judge 判错一次域身份，该 rep 的 align 直接归零，无论 form 多高。这使得主指标对单次噪声极度敏感，3 个 rep 取均值后信噪比很差。
2. **它奖励的是"域内词汇 + 格式合规"的组合**，而不是任何意义上的"思考质量"。一个模型如果只是在 cyclone 域里多说了几次"角动量""潜热"，并且把每个节点拆成"参数变化 + 因果说明 + 影响量"三段，align 就会上升——但这和"统一覆盖思考"没有任何逻辑关系。

更关键的是：**实验想验证的是"T1+T2 注入是否让模型获得了 D 式思考"，但判据里完全没有测量 D 式思考的其他三个维度（爬层、类比审计、判据瓶颈）**。即使 T1+T2 完美生效，实验也只能说"代价模型和统一覆盖的表面指标改善了"，无法对"D 式思考落地"做任何整体判断。

## 三、对照设计不足以支撑因果推断

| 缺陷 | 具体表现 |
|---|---|
| **无安慰剂对照** | 没有"注入一段等长但无关的文本"的 V0' 臂。V1 比 V0 多了约 200 字指令 + prompt 结构变化（插在 P1H_INDEX 尾部和 P1_L1_SKELETON 目标函数段后），任何额外 token 都可能改变输出分布。没有这个对照，无法排除"仅仅是 prompt 变长了/结构变了"的解释。 |
| **样本量不对称** | V0 气象只有 1 rep（复用旧数据）+ 补跑 2 reps = 3 reps；V1 每域 3 reps。但 V0 的 1 rep 来自不同时间、不同运行条件，混入后引入不可控的批次效应。 |
| **无随机化** | 同一模型串行跑不同域，域的顺序（cyclone → mining → hw）固定。如果模型有状态漂移或 warm-up 效应，域顺序和注入效果混淆。 |
| **单变量控制名存实亡** | 声称"唯一变量 = 注入文本，harness 零改动"，但注入位置改变了 prompt 的信息结构（在"节点来源标记"之后、"本轮要分解的父节点"之前插入了一段操作指令），这不仅是"加了文字"，而是**改变了模型接收指令的顺序和注意力分配**。 |

## 四、统计功效与方差估计方法错误

- M2a 方差探针报告的是**跨臂方差**（6 个不同配置之间的差异），而非**rep 间方差**（同一配置重复运行的波动）。用跨臂方差来估计"3 reps 够不够"是方法错误——跨臂方差天然大于 rep 间方差，会高估噪声、低估功效。
- 每个条件 3 reps，对于检测中等效应量（Cohen's d ≈ 0.5）的配对比较，power 大约在 0.3-0.4 左右，远低于常规的 0.8。实验没有做正式的 power analysis，只是看了
