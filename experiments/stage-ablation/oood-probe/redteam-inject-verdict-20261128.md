## 关键发现

1. **对象层习惯注入（v1/v2/v3）不产生 strategic 层质疑**——四臂输出高度雷同，全在打构念效度/Goodhart/统计功效/对照设计（= bare 的同一组点）。Step-Back（v2）作为"上溯原理"机制，在本任务上也没有把审查顶到"先查前人方案"层。
2. **v4（元层质疑习惯注入）是判别性正信号但只到一半**：它显式识别出"对象层模板 vs 元层机制"的层次错配，并建议增设元层注入组——这是唯一一臂把"层次"本身作为批评对象。但它**没有自发提出"你手里有 M0 调研结果为什么没用上/有没有现成方案该复用"**——材料里白纸黑字写着"M0 调研已交付但未消费"，五个臂全都没问这一句。
3. **gap 精确定位**：
   - 注入元层习惯 → 模型获得"层次敏感度"（能说出"测错了层"）
   - 但"查前人/复用成熟方案"这个具体动作没被触发 → 该动作需要**外部信息前提**（知道存在成熟方案/M0 结果），prompt 注入只给习惯不给信息
   - 推论：strategic 层质疑 = 习惯（可注入）× 信息（需检索/记忆系统提供）。纯 prompt 注入只能补前半，后半要 agent 循环（检索+记忆）配合
4. **负结果的预言力**：这解释了为什么 M 线一直在 execution 层打转——不是模型不行，是探针任务（红队审查）本身不提供"前人方案存在"的信息，模型无从"查"。要测 strategic 层，探针得改成"给模型一个它没见过的方向 + 允许/要求它先查"，或直接在 agent 循环里测（有检索工具的 27b 会不会自发先搜）。
