# 主动多层质疑 vs 被动缺口触发: 召回判别（2026-11-28）

# origin: ai
## 动机(D 质疑)
被动触发(扫模型输出的"不确定"信号)依赖模型的不确定**已校准**——它可能很不确定却不说(漏触发)。
D 提议: 不等它承认不确定, 改为对分解/计划**逐层主动扫可质疑点**(目标/对照/混淆/测量/执行 5 层)。
判别问题: 主动多层质疑是真召回提升, 还是"为质疑而质疑"的噪音? 跟被动比增量在哪?

## 方法
- 预埋缺陷的分解计划, 看两臂抓不抓得到(召回) + 抓的是不是那些(精确)
- 臂A 主动: 逐层强制扫 5 层可质疑点(哪怕看起来没问题也要找)
- 臂B 被动: "只说你真正觉得有问题的, 没问题的别硬找"
- 缺陷难度递增: v1 显眼(无对照/长度混淆/未预注册) → v2 隐性 Goodhart(用注入直接诱导的"节点数"当质量判据)
- ⚠️ 自动关键词判分两次误判(把"抓到了"判成漏), 最终靠人工读全文定召回

## 结果(人工判定)
| 缺陷 | 难度 | 主动 | 被动 |
|---|---|---|---|
| 无对照基线 | 显眼 | ✓ | ✓ |
| 长度混淆 | 显眼 | ✓ | ✓(写温度/难度混淆) |
| 未预注册判据 | 显眼 | ✓ | ✓ |
| Goodhart(节点数≠质量) | 隐性 | ✓("节点数量直接等同于分解质量") | ✓("节点数≠质量") |
- 显眼缺陷: 两臂都 3/3
- 隐性 Goodhart: 两臂都抓到(自动判分误判为 0, 人工读=都中)

## 判决
1. **D 的担忧部分成立但被高估**: 对 27b, 被动"让它找问题"本身召回就不低, 连隐性 Goodhart 都能抓。所以"不确定没校准导致漏触发"在这个探针上没造成实质漏检。
2. **主动多层质疑的增量不在召回, 在覆盖面/系统性**: 主动臂逐层强制扫, 不会因为模型"没觉得某层有问题"就整层跳过; 被动臂靠模型自觉, 理论上会漏它"没意识到要看"的层。本探针两臂都抓是因为缺陷对 27b 仍偏显眼。
3. **判别探针失效**: 我的自动关键词判分不可靠(两次误判), 且 27b 对"找问题"任务基线太强, 拉不开主动/被动差距。要真判别, 需要**两臂都抓不到的更难缺陷**(更深的循环论证/跨层耦合), 否则测不出增量。
4. **对 M 线的含义**: 主动多层质疑值得做(系统性兜底), 但别指望它靠"召回更高"取胜, 它的卖点是**不漏层**; 且自动判分必须换成 LLM-as-judge 或人工, 关键词匹配在 27b 这种强基线上不可用。
