- [△] **RTX 4090 (24GB) 的显存带宽约为 1008 GB/s (注意：原陈述中384 GB/s有误，应为GDDR6X规格下的实际带宽，若指FP16带宽需换算，但通常标称显存带宽为~1 TB/s级别，此处原事实中的384GB/s数值本身疑似错误，可能是混淆了其他指标或旧卡数据，但根据判定规则，若无明确矛盾来源证明其‘错误’而是‘缺失’，则主要问题是价格缺失。然而，仔细检查RTX 4090规格：24GB GDDR6X, 384-bit bus, 21 Gbps -> 24*1024/8 * 21 = 6348 MB/s? 不对。RTX 4090 显存位宽384bit，频率21Gbps。带宽 = 384 * 21 / 8 = 1008 GB/s。原陈述写的是 384 GB/s，这显然是错误的数量级或单位混淆（可能把位宽当成了带宽？或者参考了非常旧的显存？）。这是一个硬逻辑/事实错误吗？是的，RTX 4090 的显存带宽是 1008 GB/s，而不是 384 GB/s。384是位宽(bit)。因此，该节点包含明显的事实性错误（量纲/数值错误）。

重新评估第一步逻辑校验：
陈述称“显存带宽 (384 GB/s)”。
RTX 4090 显存位宽为 384-bit。
显存频率为 21 Gbps (有效)。
带宽 = (384 bit / 8 bits per byte) * 21 GB/s = 48 * 21 = 1008 GB/s。
陈述中的 384 GB/s 与标准规格严重不符，属于内部矛盾或违背基本硬件常识（将位宽误作带宽，或数值错误）。
因此 logic_ok 应为 false，或者至少存在硬错误。
根据判定规则：failed: 仅当该陈述与参考来源明确矛盾，或存在硬逻辑错误（量纲错/内部矛盾）时才判 failed。
