## 归因判断（三轴第 3 轴 · 贡献独立性）

**判据**（idea #23）：S8 vs S5 的 Δ 若集中在 O6 → 质询是独立维度；若分散在 M1/M4/O6 → 伪正交，"组合"一词在论文里不能用。

**本轮证据**：Δ 分散（M1 +0.284 / M4 −0.350 / O6 新增 0.876）。初步判断 = **质询是有代价的机制**：
- 收益侧：M1（质询修正事实锚点）+ O6（框架外矛盾发现）
- 代价侧：M4（质询轮次消耗生成预算，覆盖面收窄）
- 净效应题目依赖：事实断言题 M1 增益占主导（值得付 M4 代价）；启发题 O6 增益占主导（M4 本非目标）→ 与 #24 任务类型分域合流

**置信度**：中（n=3 复验完成，见下节）。Δ 分散模式在 n=3 下方向全部一致 → 论文 claim 定为"质询是有代价的重分配机制而非独立能力"。这本身是可发表的结果（有代价的 trade-off 比免费午餐更有信息量）。

**结果：假设被否定。** 两个方向都没赢——

1. **Q5 反例没被找回**：原以为发散探索能缓解开放题的 M1 损失（S8 在 Q5 上 M1 比 S5 低 0.13），实际长版 M1 掉得更狠（0.533→0.333）。发散前段没有帮模型"想得更全"，反而稀释了后续质询的注意力。
2. **Q1 也没白赚**：事实题上加发散段，M1 微跌、O6 明显跌（矛盾发现从满分掉到 0.792）——多出来的视角扫描产生了更多候选主张，但质询环节没有相应扩展，矛盾覆盖反而漏了。
3. **唯一稳定增益是 M4**（+0.183）：发散段让输出更长更结构化（out 7346→7927 chars），口径检查声明变多。但这正是 #23 判据里的"伪正交"信号——M4 涨是长度副产物，不是独立能力。

**局限**：self-judge（B-face 已确认系统性偏高 ~0.14，但方向性结论在 B-face 下也稳）；n=3；Q1/Q5 各一道代表两类题型，单题代表性有限。

### B-face 重打（qwen2.5-7b 独立 judge）— 结论翻转

用 qwen2.5-7b（LM Studio @1234，半跨族）对 S8+S8L 全部 12 份输出重打 M1/M4/O6。结果：**self-judge 的核心叙事被推翻**。

| 指标 | Self Δ(S8L−S8) | B-face Δ(S8L−S8) | 方向一致？ |
|------|---------------|-----------------|-----------|
| Q1 M1 | −0.041 | −0.122 | ✓ 一致（事实题微跌） |
| Q1 M4 | +0.167 | **0.000** | ✗ 伪正交消失 |
| Q1 O6 | −0.208 | **+0.250** | ✗ **完全翻转** |
| Q5 M1 | −0.200 | **+0.283** | ✗ **完全翻转** |
| Q5 M4 | +0.200 | **0.000** | ✗ 伪正交消失 |
| Q5 O6 | 0.000 | +0.125 | ~ 接近 |

三个发现：

1. **M4 的"涨"是纯长度副产物**——self-judge 给 +0.17~0.20，B-face 给 0.000。两个 judge 看同一份输出，一个看到"覆盖更广"一个没看到，说明 self-judge 被输出量带偏。#23 判据里的伪正交信号在独立 judge 下不成立。
2. **Q5 M1 翻转让 #24 的第一轮结论要修正**——self-judge 说开放题事实准确性掉了 0.200（"发散稀释注意力"），B-face 说反而涨了 0.283（0.650→0.933）。自由发散前段让模型在开放题上更准确地引用了事实，不是更少。"注意力稀释"叙事是 self-judge 的系统性偏差。
3. **Q1 O6 也翻转**——self-judge 说矛盾发现能力掉了 0.208，B-face 说涨了 0.250。grep 验证：S8C-Q1-r1 是三臂中唯一命中 gold #1（"14倍"误读）的，S8/S8L 都漏了。发散段确实帮模型找到了更多隐藏矛盾。

**修正后的第一轮结论**：不是"假设被否定"，而是"self-judge 系统性低估了 S8L 的收益"。真实图景（B-face）：自由发散前段对开放题有正向效果（M1+0.283, O6+0.125），对事实题 M1 微跌（−0.122）但 O6 也涨（+0.250）。代价 = prompt +178 chars、生成时间增加。#24 路由条件从"当前形态不成立"修正为"方向可能成立，需 S8C 约束化模板对照确认结构效应"。

**局限**：B-face 仍是半跨族（qwen2.5-7b 与 27b 同属 Qwen 架构）；O6 有 3/12 JSON 解析失败（qwen2.5-7b 输出不稳定），有效样本 n=9；n=3 单题代表性有限。真跨族需 ego-browser 网页 LLM。
