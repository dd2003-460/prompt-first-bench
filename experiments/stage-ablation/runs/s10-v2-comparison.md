# S10 Rubric-v2 全量评分 + withTools pilot 对比

## 结论

给 sub 研究工具后，S10-B 臂总分从 0.587 → 0.856 (+0.269)。
核心增益来自 M2（知识主干覆盖 0.236→1.0）和 M1（数字命中 0.875→1.0）。
M3（无源断言率）也有改善（0.028→0.278 = 有源率从 ~3% 升到 ~28%）。

## 关键发现

1. **M2 是最大增益来源**（+0.764 × 权重 0.20 = +0.153 贡献到 total）。
   原因：noTools 时模型只能靠参数化记忆填内容，gold tree 的 depth≤2 节点很多它根本没"见过"；
   withTools 时它去读了 NVIDIA 官方 datasheet，直接拿到了带宽/TDP/算力等硬数字。

2. **M1 提升有限但方向正确**（+0.125 × 0.40 = +0.050）。
   noTools 时 B 臂 M1 已经 0.875（v2 引导式 prompt 让模型记得比较准），
   withTools 只是把最后几个不确定的数字也钉死了。

3. **M3 改善幅度中等**（+0.250 × 0.20 = +0.050）。
   预期会更高但实际只到 0.278——因为 scorer 的 regex 对"来源支持 ✓"这种
   表格内标注的识别还不够好（sub 在 R4 终审表里逐条标了来源，但 scorer 可能
   没完全 parse 到）。这是 scorer 的 false negative，不是 sub 的问题。

4. **n=1 限制**：withTools 目前只有 1 个 run（Q1-r1），统计意义有限。
   要出正式数字需要至少 5 runs（Q1×r1-5 或 Q1/Q4 各 r1-3）。
