# T-L4-AUDIT：L4 0/21 归因审计（M1-M4 反向覆盖 + embedding 校准 + oracle-parent）

> origin: ai · 2026-11-25 · 来源：ego-browser 与 ChatGPT 的交叉验证对话（`ai-dialogue-chatgpt-l4-challenge-20261125.md`）
> 触发：D 22:36 问"pfb 究竟能提升到什么程度"，我答"质量/覆盖结构性封顶 ~0.5-0.6，L4 结论层 0/21 硬墙"。对话指出该判断有归因漏洞——**0/21 未必是模型推理深度墙**，可能是测量/类型/上游机制的假性上限。本设计把"模型深度上限"从断言降为待证假设，给出最便宜的判别实验。

## 为什么做（归因漏洞）

我的原判断把「L4 0/21」+「修复率 3.7%」直接归因为模型能力上限。对话拆出三个竞争性解释，我之前都没排除：

- **H1（能力）**：模型有效推理深度不足，推不出 L4 结论。
- **H2（上游）**：模型有能力，但状态机的分解/调度/上下文传递/节点接口没把它带到推导入口。
- **H3（测量）**：模型已产出足够内容，但 gold/judge 的评分结构识别不到——**embedding 相似度阈值从未对"等价改写"校准过**，0/21 可能部分是"阈值太高+改写不匹配"。

对话最关键的重构：我的 gold 是**贡献因子树（结论型节点）**，agent 生成的是**研究计划树（任务型节点）**。拿结论树去评研究计划树，会系统性低分——"评估 RAID6 容量损耗"这个研究节点可能正确覆盖了 gold 因子，但 embedding 到不了阈值。所以 **L4 0/21 至少有三种失败**：发现失败（没找到因子）、识别失败（找到了但没过阈值）、类型失败（结论 vs 任务节点不匹配）。

## 实验 1（最便宜，不重跑）：Gold-to-Agent 反向覆盖审计（M1-M4）

**目的**：把"6 个上游机制"缩到 2-3 个，直接定位 0/21 是哪类失败。
**数据**：已有的 719-r1/r2 + 300-r1/r3 的 agent 树 JSON + gold 的 21 个结论节点。**不生成任何东西，纯分析已有数据。**

Step 1：对每个 gold 结论节点，在完整 agent 输出里（不只叶子，含所有节点/描述/关系/总结）找语义最接近的 3 个 agent 节点。
Step 2：盲审分类（不用 embedding 分数定标签）：
- **M1** 已表达 gold 结论
- **M2** 有关键机制但未成完整结论
- **M3** 识别了相关方向但未形成结论
- **M4** 完全没涉及

Step 3：诊断矩阵：
| 结果 | 解释 |
|---|---|
| M1 多、judge 判 0 | **judge 测量故障**（H3 坐实） |
| M2 多、M1 少 | 结论形成/节点粒度问题 |
| M3 多、M2/M1 少 | 深化与结论生成问题（H2 深度饥饿） |
| M4 多且对应 L3 不存在 | 上游发现/分支调度问题（H2 预算分配） |
| M4 多但对应 L3 已存在 | L3→L4 局部展开问题 |

Step 4（顺手）：embedding 阈值校准。对 21 个 gold 节点各造 3 个语义等价改写 + 2 个 hard negative（结论不同但高度相似），共 105 样本，测 TPR(τ)/FPR(τ)，选满足可接受误判率的 τ。**正样本必须保留原结论的适用条件，不能把有条件结论改写成无条件。**

**判读**：
- 若 M1 占比高（≥30%）而 judge 判 0 → H3 主导，0/21 是测量假象，"结构性封顶"判断需大幅下调，上限其实更高。
- 若 M2/M3 主导 → H2 主导（结论形成/深化瓶颈），修复环 + 深度预留是正确杠杆。
- 若 M4 主导且 L3 缺失 → 上游发现/调度问题，预算分配是杠杆。
- 若 M4 主导且 L3 存在 → 局部 L3→L4 展开问题。

## 实验 2（次便宜）：Oracle-parent 三条件（控制父节点措辞泄漏）

对话指出我原方案（只喂 L3 claim）不干净——claim 本身可能含一半因果链。改三条件：
- **O1 No-parent**：原始问题 + 公共背景 + 公共证据，不给 gold L3。测独立发现能力。
- **O2 Parent-claim-only**：O1 + gold L3 一句话 claim（不给推导/证据选择/中间变量）。测"给正确上游方向后能否完成 L4"。
- **O3 Parent-neutralized**：O1 + 独立改写的中性 L3（只留研究对象+边界条件，去掉因果方向/机制/关键变量/结论暗示）。防措辞泄漏。

比较：Δ_parent=Q(O2)-Q(O1)，Δ_neutral=Q(O3)-Q(O1)。
- O2 高 O3 低 → 父节点语义泄漏（O2 的成功是补全填空）。
- O2 高 O3 高 → 上游定位真有用，不依赖具体措辞（H2 坐实）。
- O1 高 → 模型本身能做，上游机制更可疑。
- 三者都低 → 局部推导能力不足（H1 增强），但仍需排除任务不可解/证据不足。

**控制**：允许所有组用相同公共原始证据，只禁 gold 特有推导链+证据选择（否则测的是无证据猜测）。需独立标注者检查 O3 输入能否反推 L4 方向。

## 实验 3（贵，最后）：Depth-reserved 预算预留

保持原状态机，强制预留预算给 L3→L4 推导，禁止预算全被浅层扩展吃掉。测预算分配是否是深度饥饿主因。

## 优先级与成本

1. **实验 1（M1-M4 审计 + 校准）**：纯分析已有数据，0 次新 LLM run，最便宜，最先做。**这一步就能把"模型深度上限"从断言变成有/无证据的假设。**
2. 实验 2（O1/O2/O3）：需新模型调用但不动状态机，中等成本。
3. 实验 3（Depth-reserved）：需改状态机预算分配逻辑，最贵，且与 T-PR-17/T-REPAIR-1 都改 SM → 必须串行排后。
