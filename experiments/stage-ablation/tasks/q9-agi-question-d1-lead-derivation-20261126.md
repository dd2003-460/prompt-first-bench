## 四项推导

### ① 硬件边界：本地 4×V100 only，**不含云端 API**（conf 0.75）
推理链：
1. D 的显式偏好是「免费白嫖，不为看起来高级付费」（AGENTS.md 网络规则原文）——付费 API 违背这条价值观。
2. T8c 翻转事件（11-26）刚实证：价格依赖的假设是脆弱的（V100 ①类实价 $975 击穿 $2033 锚点）。
   题面若含云端 API 价格，会引入同类脆弱性——价格随时间/供应商漂移，gold 锚点跟着失效。
3. 可复现性：本地 4×V100 是 D 的实际生产环境（所有实验在这跑），测量生态效度最高；
   云端 API 每次跑的成本/速率不同，跨 session 不可复现。
4. 自包含性：题目资源边界封闭 = 测量干净（「你的全部资源」这句才成立）。
改主意条件：D 说 AGI 系统应该能把付费 API 当工具用 → 则题面需给**固定美元预算包络**
（不是按次定价，避免价格漂移），并同步改 gold 口径。

### ② 预算定值 150 节点：**暂维持，E-SYNTH 回执后复核**（conf 0.6，唯一待定项）

   太高逼不出 tradeoff。

   若综合结论是操作点 ≫150，题面预算应上调到操作点附近（测量系统在其最优工况）。
3. 题面预算 = 被测系统的约束，不是我们的实验设计——它应该落在「系统最值得被测量」的区间。
