## 关键发现

### 1. Nat 首次超过 S0 基线
V16-nat cov=0.667 > S0-nat 0.637（+0.03）。虽然 n=2 统计力不够，但方向对了——
状态机的多轮回退 + 已确认事实注入让分解质量超过了单轮管线。

### 2. GPU 被 R2 硬上限砍断（v16.0 bug，v16.3 已修）
- gpu-r1：r1 拆出 33 节点 → 直接 R2-budget 停（S_α=27.68，还在涨）
- gpu-r2：r1 拆 22 → r2 再拆 10 → total 32 → R2-budget 停（S_α=27.83）
- 两个 rep 都被硬上限掐断，没有机会继续深挖
- **代价量化**：gpu-r2 的 r2 新增了 10 个节点、S_α 从 20.4→27.8（+36%），
  说明树还非常健康就被砍了。v16.3 把 R2 改成软约束后这些 rep 可以继续长。

### 3. Soc 表现好但被 S0 压制
V16-soc mean=0.857 vs S0-soc 0.957（-0.10）。soc 题结构清晰、S0 本身就很强，
状态机没帮上忙反而可能因为多轮引入噪声。但 soc-r2 达到 cov=1.0（满分），
说明上限没被 cap 住。

### 4. R1 饱和在 nat/soc 都触发了
nat-r1 和 soc-r2 都是 r2 零新增 → R1 停。这是定义级粒度的自然停止信号在工作。
gpu 两个 rep 都没触发 R1（被 R2 先截断了），所以不知道 gpu 的自然饱和点在哪。

### 5. Wall time 可接受
平均 ~545s/rep（~9 min）。最慢 gpu-r1 = 820s（13.7 min）。
对于 3 轮以内的状态机循环来说合理；如果 v16.3 让 gpu 跑到 4-5 轮，预计 15-20 min/rep。

## 结论

- **状态机机制验证成功**：多轮回退 + 事实注入 + 行为证据停止（R1/R3）全部按设计工作
- **Nat 方向正确**：首次超过 S0 基线，支持"迭代加深 > 单轮"的核心假设
- **GPU 需要 v16.3 重跑**：R2 硬停是已知 bug，修完后 gpu 才能展示真正的回退深度
- **n=2 不够下结论**：下一步用 v16.3（R2 软约束 + per-layer cap）跑 30-rep 正式实验
