# T0/T1/T2 措辞梯度实验设计

> origin: ai · 2026-11-07 · 方向来源：arena T-PR-06（gap survives as Cartesian product, conf 0.58）
> 代码：`ablation_harness.py`（arms T0/T1/T2）+ `runs/t0t1t2-score.py`（快速指标）

## 要回答的问题

S5（完整六阶段流程 prompt，~6.6k input tokens）≫ S0（裸问，~153 tokens）。
**增益来自「结构本身」还是「token 剂量」？** 如果主要是剂量，那么一个紧凑的 400 token 结构化指令块（T2）应该能复现大部分增益；如果是结构本身（多阶段文件里的具体规则内容），T2 会明显弱于 S5。

## 三臂定义

| 臂 | 输入规模 | 内容 | 对标已有臂 |
|----|---------|------|-----------|
| T0 | ~90 chars | 裸问 + 缺口标注要求 | ≈ S0（更短，去掉背景句） |
| T1 | ~140 chars | 单句软启发式（拆因素/区分标称实测/缺口明说） | ≈ S6 压缩版 |
| T2 | ~430 chars | 五步分析要求 + 输出要求 + 约束重复 2× | ≈ S5 的紧凑指令化（无多阶段文件） |

参考锚点（已有数据，gate-fixed rubric-v3 评分，来自 T17-stage-ablation-final-report.md）：
- ConInstruct 文献锚点：纯措辞变化 ~2.5% 性能差
- FIND 文献锚点：结构化提示最大 ~64% 相对提升
- 我们 v1（S5 vs S0）：~86.7% 相对提升（同族 27b judge）

## 变量控制

- temp=0.1 + per-rep seed（与 S6/S7 系列一致，保证 rep 独立性）
- 无联网钩子（T0-T2 都是纯推理臂，research_hook 只挂 S2+/S7 系）
- 题面完全复用 QUESTIONS 字典（Q1-Q5 同一题源）
- max_tokens=8000 统一

## 指标（两层）

**第一层（机器可检，t0t1t2-score.py，跑完即出）**：
1. `out_tokens` — 输出剂量
2. `gap_per_ktok` — 每千 output token 的缺口标记数（[待核验]/不确定/记不清/查不到...）→ 测「诚实标注行为」是否被激活
3. `struct_hits` / `has_struct` — 分析结构词频（拆解/分解/主导项/口径/标称...）→ 测「结构化思维」是否被激活

**第二层（质量，走 arena 异族 judge，首跑结果出来后派）**：
rubric-v3 全维度打分（M1-M5/C1-C3），与 S0/S5 已有分数同口径对比。
理由：第一层只能测行为激活，测不了答案质量；而本实验的核心问题（结构 vs 剂量）最终要落在质量差上。

## 预期判读表

| 观察 | 结论 |
|------|------|
| T2 ≈ S5（质量分差 < 10%）且 T2 ≫ T0 | 剂量/紧凑指令足够 → 多阶段文件的增量价值小，prompt 可以大幅瘦身 |
| T2 > T0 但 T2 ≪ S5 | 结构内容本身有独立价值 → 多阶段文件不可压缩成指令块 |
| T1 ≈ T2 | 单句启发式和完整指令块等效 → 模型对指令细节不敏感，persona 触发就够 |
| T0 ≈ T1 ≈ T2（都接近） | 措辞梯度无效 → 增益主要来自联网来源注入（S2+ 才有 hook），需重设对照 |
| gap_rate 随臂单调升但质量不升 | 诚实标注是表面行为，不等于真查证 |
