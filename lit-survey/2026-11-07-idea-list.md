## E. 先查后拆的机制（2026-11-07 下午调研中间产物）

19. **「先查后拆」减少幻觉的机制** ❓ 未决——四种候选：
    - A: Attention allocation（分步→短 context→token 级幻觉率降）
    - B: Self-verification loop（R4 终审提供纠错机会）
    - C: Source grounding（R3 强制引用=行为约束非认知机制）
    - D: 都不对——改变幻觉分布而非总量，净效果取决于 rubric
    - **反方证据**：arXiv:2506.17088 "CoT Obscures Hallucination Cues"（CoT 让幻觉更难检测）；arXiv:2607.20492 "PhantomFill"（结构化 required fields → 10/13 models 100% fabrication）；arXiv:2608.09942 "Serial-Depth Bottleneck"（CoT 串行深度有上限）
    - **正方证据**：我们的 S5 vs S0 +0.235 (n=30, p=5.8e-08)；withTools pilot M2 0.236→1.0
    - **与 §C12 分隔符实验的关系**：如果机制是 A（attention），那"时间维度分隔符"（R1/R2/R3/R4 阶段标记）和"空间维度分隔符"（话题分隔）应该是同一族干预，可合并为一个实验
    - **可证伪实验设计**（待 sub 讨论后定）：跑 S5-noR4（去掉终审）vs S5-full vs S0，如果 Δ(S5-full, S0) ≈ Δ(S5-noR4, S0) 则 B 不成立；如果 noR4 比 full 差很多则 B 是主因
    - **M1 tolerance 抓不住系统性错误**：io.net "14x" = NVLink bidirectional / PCIe unidirectional 口径混用，单个数字在 ±10% 内但方法论错。需要加 M1b "单位/口径一致性" 检查（或让 judge 判"这个数字的测量条件是否跟 gold 一致"）
    - 📦 部分被 pfb stage-ablation 吸收（2026-11-07）→ S5 vs S0 结果已落盘 `pfb/experiments/stage-ablation/RESULTS-FINAL.md`（Δ=+0.252, M5/M6 贡献全部增益）。机制归因（A/B/C/D 哪个是主因）仍 ❓ 未决，需 S5-noR4 消融才能判定。

20. **"活人感" = 预测误差最优水平** ❓ 未验证假说
    - 幽默 = d(形式通道, 内容通道) 的 inverted-U（已讨论）
    - 活人感可能是同一个函数：太可预测=无聊，太不可预测=不信任，刚好超出预期但在合理范围=活人感
    - 如果成立：persona-warmth hook 触发条件可以量化为"当前输出预测熵 < 阈值 X"
    - 可证伪：给同一段技术内容加不同水平的"意外元素"（一个冷知识/一个类比/一个自嘲），测用户感知"活人感"评分是否呈 inverted-U

21. **压低自信的触发条件 = 错误回退开销，不是领域前沿度** ❓ 未验证假说（成璐 2026-11-07 提出）
    - **现象锚点**：模型在高频区（童话/常见物理定律）显得博学可靠，在低频区（前沿/复杂计算）是编造——同一套生成机制，高频=回忆、低频=拼凑，而模型自己分不出此刻站在哪个区。这是元认知失败点，不是"有时傻有时聪明"。
    - **核心主张**：不该按"领域是否前沿"压自信（模型判断不了自己在回忆还是猜），该按**错误回退开销**（外部可观测，不需自省）：
      - `该不该提醒 = f(错误成本, 验证成本)`
      - 错误成本高 + 验证便宜（能 grep / 查 arXiv）→ 强制标来源 + 压低自信 + 触发查证
      - 错误成本高 + 验证也贵 → 更要提醒，但外包 arena
      - 错误成本低（闲聊/头脑风暴）→ 正常输出；压了反而把活人感压没（接 §20 倒 U 左边：免责声明机器人）
    - **与 source-trace 的关系**：标来源有效是因为逼模型区分"刚查到的 vs 权重里的"。自信度是果，来源标记是因——因可控，果跟着走。真正干预点是让来源显式化，不是直接调自信参数。
    - **可证伪实验**（接 E3 双轨评分）：同一批 run，一组 prompt 注入"按回退开销分级标注来源+conf"，一组不注入，测 M1（数字命中）和 M3（无源断言率）差异。若注入组 M1↑ 且 M3↓，支持"来源显式化 > 自信压制"。
    - **风险**：若"回退开销"本身需要模型自评，又落回元认知失败——需由 Lead/hook 按任务类型外部指定开销档位，不让模型自己判。

22. **矛盾检测的三级级联（先验 → ICL → 构造）** ❓ 未验证假说（成璐 2026-11-07 提出）
    - **现象锚点**：无 query 时（模型没主动检索），口径/条件矛盾的发现能力完全取决于权重里有没有存过该域的测量协议——"14x 错了"不是逻辑矛盾（前提不矛盾，是前提选错了），是语义层不一致，纯推理推不出来。qqbot 观察确认：无 query 的矛盾洞察 ≈ 先验检索。
    - **核心主张**：不是"放弃先验靠 ICL"，而是置信度驱动的级联：
      - L1（免费）：权重先验 + 形式结构检查（文本内定义链比对，不需要领域知识）
      - L2（中等）：L1 低置信度 → 触发 ICL 召回（从锚定案例库/检索结果加载该域口径模板）
      - L3（高成本）：连"该查什么"都不知道 → decomp 画地图 + arena 构造新先验
    - **关键设计**：L1 的输出必须带置信度标签，低置信度自动升级。"裸数字不合格"规则的作用 = 把 L1 的语义判断降级为字符串结构比对（先验外化到生成阶段）。
    - **与现有臂的关系**：S5 = 全量 L2（强制检索）；D1 = 纯 L1（纯先验，但管道天然产出"未验证"标记 = 意外的 L1 置信度标签）。C-face 结果暗示最优臂可能是"L1 快速过 → 低置信度节点才触发 L2"的级联臂，尚未跑过。
    - **可证伪实验**（B-face 后候选消融）：S5-cascade（先验快筛 + 条件检索）vs S5-full（全量检索）vs D1（纯先验），测 M1/M3/M5 + 总 token 开销。若 cascade 在 M1 上 ≈ full 且开销显著更低，支持级联架构。
    - **风险**：L1→L2 的升级阈值怎么定？如果阈值太松 = 退化回全量检索（白搭）；太紧 = 漏检。可能需要按域调参，或者用 rubric-v3 O3 的 p̃（模型发现率）做自适应阈值。
    - **短 prompt 激发变体（成璐 2026-11-07 提出）**：L1 触发器不需要完整规则文本，只需一句可触发提示（如"比较两个数字前，写出各自的测量层级"）+ 一个格式要求（"关键数字后括号写测量条件"）。完整规则是教学用的，内化后一句话就够。可证伪实验升级为三方对比：S5-cascade-shortprompt vs S5-full vs D1，测 M1/M3/M5 + 总 token 开销。若 shortprompt ≈ full 且开销显著低 → 直接进生产路径替代当前 02.5 长段落。

23. **多模型讨论校验臂（S8-discuss）+ 矛盾发现度量维度** ❓ 未验证假说（成璐 2026-11-07 提出，"校验不用模型自己，强调跟其他模型讨论，不用着急给答案，多搜索，多找矛盾，梳理完整再写回到 decomp 节点"）
    - **现象锚点**：E3 双轨评分显示所有臂的事后修正 Δ 在 ±0.022 以内——"自己检查自己"几乎不产生增量。02.5 的对抗核验条款纸面很强，但执行时是同一个 27b 在同一上下文里扮演质疑者，自我怀疑深度天然有限。异族 judge 目前只在打分端用（S10），生成端的交叉讨论完全空白。
    - **核心主张**：增量的来源是**独立性**，不是检查次数。架构 = A 模型生成 → B/C/D 质询（不同 persona：较真的/怀疑论的/领域专家）→ A 修改 → 写回 decomp 节点。矛盾成为分解树的一等公民：新发现的矛盾点要么推翻某节点（触发回退 repair_stage），要么长成新分支（= "发现新东西"）。
    - **配套设计**：
      - ① 校验+回退做成每阶段出口门禁（轻量版：口径回溯 + 来源标签抽查），而非一次性中间阶段；不过就回退到对应阶段。
      - ② rubric 加 O6 维度：矛盾发现数/质量（当前 M1 只把矛盾检测当子项，没有独立度量"通过找矛盾发现了多少原问题没覆盖的东西"）。
      - ③ 外部事实验证补硬事实源（datasheet/数据库级），research_hook 目前只有 arXiv 一条腿。
      - ④ 先修 research_hook 的 bing 垃圾源 bug（S5 Q1 三 rep 全污染），否则新臂继承同样污染。
    - **与现有臂的关系**：S5 = 单模型全流程 + 强制检索；D1 = 纯先验；S8-discuss = 多模型讨论 + 条件检索。与 #22 级联正交（#22 管"查不查"的路由，本条管"谁来判断"的独立性）。
    - **可证伪实验**：S8-discuss vs S5-full vs D1，测 M1/M3/O6（矛盾发现）+ token 开销。若 S8-discuss 在 O6 上显著领先且 M1 不掉，支持"独立性 > 检查次数"。
    - **前置调研**（已完成 2026-11-07，落盘 `pfb/research/multi-model-verification-survey.md`）：核心发现——① Martingale Curse：同质 agent 辩论 ≤ 多数投票，质询者必须跨家族；② debate 效应可反号（critique-induced degradation，开放任务上有害、有锚点任务上有效）；③ 预注册实验显示 MAD 对论文反馈无增益 → 主指标应押 O6（矛盾发现）而非 M1；④ 三篇独立工作收敛到"按置信度条件触发讨论"→ 与 #22 级联同构，臂名改为 S8-cascade-discuss；⑤ test-time scaling 有 plateau，轮次从 1 开始不加预设。设计含义 6 条见 survey §5。
