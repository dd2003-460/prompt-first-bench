19. **「先查后拆」减少幻觉的机制** ❓ 未决——四种候选：
    - A: Attention allocation（分步→短 context→token 级幻觉率降）
    - B: Self-verification loop（R4 终审提供纠错机会）
    - C: Source grounding（R3 强制引用=行为约束非认知机制）
    - D: 都不对——改变幻觉分布而非总量，净效果取决于 rubric
    - **反方证据**：arXiv:2506.17088 "CoT Obscures Hallucination Cues"（CoT 让幻觉更难检测）；arXiv:2607.20492 "PhantomFill"（结构化 required fields → 10/13 models 100% fabrication）；arXiv:2608.09942 "Serial-Depth Bottleneck"（CoT 串行深度有上限）
    - **正方证据**：我们的 S5 vs S0 +0.235 (n=30, p=5.8e-08)；withTools pilot M2 0.236→1.0
    - **与 §C12 分隔符实验的关系**：如果机制是 A（attention），那"时间维度分隔符"（R1/R2/R3/R4 阶段标记）和"空间维度分隔符"（话题分隔）应该是同一族干预，可合并为一个实验
    - **可证伪实验设计**（待 sub 讨论后定）：跑 S5-noR4（去掉终审）vs S5-full vs S0，如果 Δ(S5-full, S0) ≈ Δ(S5-noR4, S0) 则 B 不成立；如果 noR4 比 full 差很多则 B 是主因
    - **M1 tolerance 抓不住系统性错误**：io.net "14x" = NVLink bidirectional / PCIe unidirectional 口径混用，单个数字在 ±10% 内但方法论错。需要加 M1b "单位/口径一致性" 检查（或让 judge 判"这个数字的测量条件是否跟 gold 一致"）
    - 📦 部分被 pfb stage-ablation 吸收（2026-11-07）→ S5 vs S0 结果已落盘 `pfb/experiments/stage-ablation/RESULTS-FINAL.md`（Δ=+0.252, M5/M6 贡献全部增益）。机制归因（A/B/C/D 哪个是主因）仍 ❓ 未决，需 S5-noR4 消融才能判定。

21. **压低自信的触发条件 = 错误回退开销，不是领域前沿度** ❓ 未验证假说（成璐 2026-11-07 提出）
    - **现象锚点**：模型在高频区（童话/常见物理定律）显得博学可靠，在低频区（前沿/复杂计算）是编造——同一套生成机制，高频=回忆、低频=拼凑，而模型自己分不出此刻站在哪个区。这是元认知失败点，不是"有时傻有时聪明"。
    - **核心主张**：不该按"领域是否前沿"压自信（模型判断不了自己在回忆还是猜），该按**错误回退开销**（外部可观测，不需自省）：
      - `该不该提醒 = f(错误成本, 验证成本)`
      - 错误成本高 + 验证便宜（能 grep / 查 arXiv）→ 强制标来源 + 压低自信 + 触发查证
      - 错误成本高 + 验证也贵 → 更要提醒，但外包 arena
      - 错误成本低（闲聊/头脑风暴）→ 正常输出；压了反而把活人感压没（接 §20 倒 U 左边：免责声明机器人）
    - **与 source-trace 的关系**：标来源有效是因为逼模型区分"刚查到的 vs 权重里的"。自信度是果，来源标记是因——因可控，果跟着走。真正干预点是让来源显式化，不是直接调自信参数。
    - **可证伪实验**（接 E3 双轨评分）：同一批 run，一组 prompt 注入"按回退开销分级标注来源+conf"，一组不注入，测 M1（数字命中）和 M3（无源断言率）差异。若注入组 M1↑ 且 M3↓，支持"来源显式化 > 自信压制"。
    - **风险**：若"回退开销"本身需要模型自评，又落回元认知失败——需由 Lead/hook 按任务类型外部指定开销档位，不让模型自己判。

22. **矛盾检测的三级级联（先验 → ICL → 构造）** ❓ 未验证假说（成璐 2026-11-07 提出）
    - **现象锚点**：无 query 时（模型没主动检索），口径/条件矛盾的发现能力完全取决于权重里有没有存过该域的测量协议——"14x 错了"不是逻辑矛盾（前提不矛盾，是前提选错了），是语义层不一致，纯推理推不出来。qqbot 观察确认：无 query 的矛盾洞察 ≈ 先验检索。
    - **核心主张**：不是"放弃先验靠 ICL"，而是置信度驱动的级联：
      - L1（免费）：权重先验 + 形式结构检查（文本内定义链比对，不需要领域知识）
      - L2（中等）：L1 低置信度 → 触发 ICL 召回（从锚定案例库/检索结果加载该域口径模板）
      - L3（高成本）：连"该查什么"都不知道 → decomp 画地图 + arena 构造新先验
    - **关键设计**：L1 的输出必须带置信度标签，低置信度自动升级。"裸数字不合格"规则的作用 = 把 L1 的语义判断降级为字符串结构比对（先验外化到生成阶段）。
    - **与现有臂的关系**：S5 = 全量 L2（强制检索）；D1 = 纯 L1（纯先验，但管道天然产出"未验证"标记 = 意外的 L1 置信度标签）。C-face 结果暗示最优臂可能是"L1 快速过 → 低置信度节点才触发 L2"的级联臂，尚未跑过。
    - **可证伪实验**（B-face 后候选消融）：S5-cascade（先验快筛 + 条件检索）vs S5-full（全量检索）vs D1（纯先验），测 M1/M3/M5 + 总 token 开销。若 cascade 在 M1 上 ≈ full 且开销显著更低，支持级联架构。
    - **风险**：L1→L2 的升级阈值怎么定？如果阈值太松 = 退化回全量检索（白搭）；太紧 = 漏检。可能需要按域调参，或者用 rubric-v3 O3 的 p̃（模型发现率）做自适应阈值。
    - **短 prompt 激发变体（成璐 2026-11-07 提出）**：L1 触发器不需要完整规则文本，只需一句可触发提示（如"比较两个数字前，写出各自的测量层级"）+ 一个格式要求（"关键数字后括号写测量条件"）。完整规则是教学用的，内化后一句话就够。可证伪实验升级为三方对比：S5-cascade-shortprompt vs S5-full vs D1，测 M1/M3/M5 + 总 token 开销。若 shortprompt ≈ full 且开销显著低 → 直接进生产路径替代当前 02.5 长段落。

24. **长短 prompt 按任务类型分域：事实断言型 vs 启发型，指令独立放置**（成璐 2026-11-07 晚提出）
    - **现象锚点**：T53b（runs-t53b/t53b-report.md）短prompt T2+hook ≈ S5-full 质量、成本减半，但增益结构不对称——M1 事实断言 +0.226（短触发器把幻觉压得更狠），M4 覆盖度 -0.167（广度换准确）。同一个短prompt 在"要准"和"要全/要新"两类目标上表现相反。
    - **核心主张**：长短不是全局开关，是**任务类型的函数**——
      - **事实断言型**（有可查证锚点：数字/规格/对比/口径）→ 短prompt + hook 足够，甚至更好（M1↑、成本低）。生产 pf 的 L1 档走这条。
      - **启发型**（需要新维度、矛盾发现、框架外洞察）→ 必须长prompt（完整分解指导 + 质询轮次），因为 M4/O6 这类广度指标靠 token 剂量买不来，靠结构买。S8-cascade-discuss 天然属于这条。
    - **反例警示**（为什么不能混在一个 prompt 里）：把"大胆思考小心求证"和"查不到就承认查不到"塞进同一段，模型会把两者当同一优先级的约束，实际行为是向保守端坍缩（T53 no-hook 的 M5 -0.287 就是这个症状——没有外部锚点时，纪律性指令把探索也一起压死了）。两条指令的适用条件不同，必须**独立放置**：事实断言段只挂纪律约束，启发段只挂探索授权，各管各的上下文。
    - **与 #22/#23 的关系**：#22 级联管"查不查"（L1/L2 路由），本条管"用哪套指令"（事实/启发分域）；#23 S8 是启发型的完整实现。三者正交，可组合：事实断言型走 L1 短prompt，启发型走 S8 长prompt + 质询。
    - **撞车扫描（2026-11-07 晚，成璐问"自适应是不是很多人做"）**：是——test-time compute 自适应分配已拥挤（Learning When to Think 2608.20256 / Thinking Hard Not Smart 2608.07968 / CIRCE 2610.41089 / SuCo 2606.17687 / Active RAG budget 2607.24010 / Claim-Level Reliability 2608.11994，详见 novelty-scan §自适应路由撞车扫描）。共同范式 = 同一行为调剂量、难度/置信度触发、无贡献测量。本条差异 = 换行为（指令集分域）+ 任务类型触发 + 贡献独立性测量。"自适应"不能当 novelty，卖点在叠加结构。
    - **可证伪实验**：同一批题（Q1-Q5 偏事实断言，另造 2 道启发型题如"这个方案还有什么没被考虑到的失败模式"），四臂对比：短prompt×事实题 / 长prompt×事实题 / 短prompt×启发题 / 长prompt×启发题。预测：事实题上短≥长（M1），启发题上长≫短（O6/M4）。若交叉成立 → 生产 pf 按题型路由指令集。
    - **第一轮实测（2026-11-07，S8L vs S8，Q1+Q5 n=3）**：self-judge 说"假设被否定"（M1−0.121/O6−0.104/M4+0.183），**但 B-face（qwen2.5-7b 独立 judge）重打后结论翻转**：M4 Δ=0.000（伪正交消失）、Q5 M1 Δ=+0.283（self 说 −0.200，实际是涨的）、Q1 O6 Δ=+0.250（self 说 −0.208，实际也是涨的）。真实图景：自由发散前段对开放题有正向效果（M1+O6 都涨），对事实题 M1 微跌但 O6 也涨。#24 路由条件从"当前形态不成立"修正为"方向可能成立"。**教训**：self-judge 系统性低估长输出的收益（被输出量带偏），关键结论必须过独立 judge。详见 runs/s8-report.md §S8L + §B-face 重打。
    - **滚雪球调研（2026-11-07，arXiv 两轮 54 篇，筛出 12 篇直接相关）**：学界**没有**"自由发散 vs 约束化探索"在质询任务上的 head-to-head。最接近的三篇：① Beyond the Hivemind (2608.02618) 确认无约束打不开多样性，解法是 persona anchoring（结构化）；② PRISM (2602.21317) 主张多样性来自结构化认知路径而非同路径重复；③ DriftBench (2604.28031) 解释了"先发散再聚焦"为什么 drift——发散引入的新视角在后续被当作同等优先级候选，稀释原始焦点。另有 Another Turn (2509.06770) 预测 vague steering 无效、targeted steering 才有增益——与 S8L 实测一致。**novelty 定位**：prompt 层"质询 × 结构化探索"交叉点无直接撞车。**第二轮设计**：把"列 5 个视角"换成三维度封闭模板（失败模式 ≥2 / 边界条件 ≥2 / 反例搜索 ≥1），预期 O6 恢复 + M1 不降。详见 research/s8l-constrained-exploration-survey.md。

### #27 "信息搜集+校验贡献函数"滚雪球调研（origin: ai · 成璐指令"滚雪球调研吧"）

- **问题**：有没有完整的"信息搜集 × 校验"合成贡献函数（可优化的统一目标）？
- **结论（2026-11-07 晚，3 轮 arXiv 23 篇去重 `/tmp/arxiv-grpo{,2,3}.json`）**：**不存在，且被明确宣布为开放问题**。Proof-Carrying Cognition (2609.09776) 原文："the field's binding constraint is the verification gap: no scalable, incorruptible reward for reasoning outside formal domains."
- **最接近组件（全是单侧的）**：
  - SearchGym (2601.14615)：环境保真度——reward 不被模拟/快照噪声污染（防 corrupted reward）。
  - Beyond Outcome Rewards (2608.12764)：步级自蒸馏做 credit assignment（轨迹内哪一步贡献了什么；OPSD 扩展）。
  - GroundedPRM (2510.14942)：树引导 + 保真度感知的过程奖励（防 PRM 自身幻觉）。
  - UnifiedPlayers (2609.20089)：planner×verifier 联合适应（防静态 verifier 跟不上新失败模式 / self-consistency 强化共享错误）。
  - MARCH (2603.24579)：多智能体强化自检（reward = 质疑是否命中真实错误，不是是否找到矛盾——后者会奖励凭空找茬）。
- **空档**：无人把"搜集质量 × 校验质量"合成为一个贡献函数。**pfb 的贡献独立性测量 = 这个函数的离散 prompt 层版本**（每个组件 Δ 落到哪个 metric 维度）；RL 系在梯度里做（不可分解），我们在 prompt 层做（可消融）——结构性优势再次成立。
- **✅ 滚雪球核验完成（2026-11-07 深夜，T-PR-11 @ paradigm-routing main 822e0bd）**：arena agent 对 5 个已知节点 + 4 组穷尽 query 做了引用链追踪，产出 `research/search-verify-contribution-function.md`（231 行）。判决升级：**乘积型贡献函数不存在——伪合成 2 例（SSPO 嵌套方向×幅度、UnifiedPlayers 加权和）+ 单侧 4 例；且"搜集质量"这一侧连可计算定义都没有**。三假说：A reward 污染成立(0.85，SearchGym corrupted-reward 原文 + PCC N^(1/ρ²) 惩罚)、B credit assignment 未解决成立(0.85)、C 试过但失败证据不足(0.45)。对外材料可用更强表述："没人做，且做不了（一侧无 ground truth + 双重未定义量相乘），所以我们换做法——测量而非优化"。§4.4 有可直接引用的定位段落。局限自报：6 篇中仅 1 篇到公式级，其余摘要级（若正文藏有未写进摘要的乘积项会漏判）。
- **GPO/GRPO 对抗训练机制澄清（成璐问 3）**：逻辑矛盾识别 ≠ 对抗训练学出来的——基本逻辑范式是预训练遗产，RL 只调"可靠调用"的权重；对抗成分训的是**对证据的校验行为**（搜什么/何时停/如何引用），reward 设计决定训出"命中真错"还是"凭空找茬"。prompt 质询 = 调用已有检测能力；RL 对抗 = 重塑调用策略。互补关系。注：未找到名为"GPO 对抗训练"的具体论文 [待核验]，按 GRPO 系解读。

### #28 S9-audit：证据元数据审计 arm（origin: human 成璐提出四维度 · ai 编码为 prompt）

### #29 prompt 内部等价类合并（origin: human 成璐指出"反事实推理相当于结构化发散假设" · ai 落盘）

- **触发**：成璐问"这些 prompt 什么是等价的，例如反事实推理，相当于结构化发散假设吗，似乎也能验证筛选和排除"，随后指出我用"反事实/翻转/投影"一堆术语把简单事说复杂了。
- **核心观察（人话版）**：检验一个结论靠不靠谱 = 故意把它往坏了想，看它会不会塌。S8 质询者 B（"假设这个结论是错的，找出最可能错在哪"）、质询者 E（列隐含前提查互斥）、S8C 第零轮三维度（失败模式/边界条件/反例搜索）——全是同一个动作的不同问法：找让结论变假的条件。我之前把它们当不同设计还编术语区分，是我绕晕了。
- **推论 1（重复消耗）**：当前 S8C 实际做了两遍同一件事——第零轮列失败模式 + 质询轮 B/E 再找一遍漏洞。这解释了为什么 S8C 比 S8L 更伤事实题 M1（B-face Q1: −0.233 vs −0.122）：重复的找漏洞消耗叠加，注意力预算被摊薄。
- **推论 2（你说的"验证筛选和排除"）**：找漏洞不只是生成候选，还能做剪枝——用"翻转后结论是否依然成立"去淘汰伪脆弱点（翻转了也没事的 = 不是真弱点），给质询轮一份已筛过的清单而非原始候选堆。这把操作从"发散"升级成"发散+剪枝"。
- **可证伪预测**：若把 S8C 第零轮与质询轮的重复部分合并（探索段只做初筛、质询段只深挖筛出的点），M1 代价应下降而 O6 保持。当前证据是语义分析（prompt 文本层面），未验证模型执行时是否真把它们当同一件事做——需跑一臂对照或外包 arena 核验概念等价性。
- **下一步方向**：合并重叠 > 加新花样。先画一张"每个指令片段实际做什么动作"的映射表，标出重复对，再决定砍哪边。

| arm | 片段 | 实际动作 | 与谁重叠 |
|---|---|---|---|
| S8 | 质询B | 反事实：找让结论变假的条件 | — |
| S8 | 质询C | 反例搜索（实证版） | — |
| S8 | 质询D | 逻辑审计（推理跳跃/无来源） | 独立维度，不重复 |
| S8 | 质询E | 前提枚举+边界条件 | — |

### #34 压缩项连续性原则 + 外生离散信息豁免（2026-11-12，D 指示）

**原话**："你把压缩k复杂度的也说一下，不一定要非常简单的理论结构（有可能时间复杂度爆炸），但是能连续的就可以上变量，离散和不同的显卡这没法压缩（市场随机出的，难道还能在中间插值造吗）的外信息就没关系了"

**解读**：
1. **连续性优先于简洁性**——目标函数里的量要连续可微（可以上变量、可以做优化），时间复杂度高一点没关系（O(n²) 甚至更高都可接受）。→ 落地：redundancy_score 去掉 cap 200 截断，全量 pair 均值。
2. **外生离散信息豁免**——不同显卡的规格、市场价格这类"查表得到的离散事实"不可插值（"市场随机出的，难道还能在中间插值造吗"），不存在近义变体刷分空间，不该进压缩/惩罚项。→ 现状 [待设计]：NodeRecord 加 exogenous-fact 标签，redundancy 只对 derived 节点算；等 r9 基线出来再切口径。
3. **β 标定**（配套动作）：实测 n=117 full-pair mean Jaccard=0.0146，旧 β=0.3 罚项仅 0.51（structural 97 的 0.5%，形同虚设）→ β=3.0 罚项 ≈5.1（5%）。

**落点**：`research/sm-thinking-sop.md` Decision 14；代码 `s5_state_machine.py`（redundancy_score 全量化 + ObjectiveConfig.redundancy_penalty_beta=3.0）。

## #40 (2026-11-12, D 提出)
**压缩阶梯与 K 复杂度：为什么 decomp 树是好压缩形式**
D 的直觉链：数值→变量→函数族→向量空间，按 K 复杂度压缩一般遇不到极端时间复杂度爆炸。
我的回应要点：
1. 链条成立（代数/分析一直在做），但断点在"找到压缩形式"本身——K 最短描述不可判定，NP-hard 搜索。
2. 准确表述应为分布性陈述："在自然分布（低描述复杂性）对象上平均情况好"，非普适存在性陈述。
3. 压缩-展开税：批量线性操作省，随机点访问不一定省；对应状态机的 per-round checkpoint 设计。
4. 若一切压缩都便宜 → P vs NP 坍塌，故不存在通用廉价压缩机制；结论是结构敏感性的。
5. 落点：cost(T) 本质 = 树的 K 复杂度 + 展开税；Decision 19 逼模型先找短描述再枚举。
