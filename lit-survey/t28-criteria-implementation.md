# T28 — 判据实现调研：STaD 重建测试 + ADaPT 失败回退 + 组合臂设计

> 任务卡 `tasks/T28-criteria-implementation.md`｜前置 T26 §Q4、`tasks/2026-11-07-nine-points.md` 第 3/6/8 点
> 口径：这是一份 **prompt 工程调研 + 可执行草稿**，不跑实验。所有 prompt 均可直接复制进 S10 三臂 / 组合臂。
> 验收对照：①来源 8 条带 URL+conf（§6）②重建模板（§2）③≤200 字回退段（§3，实测 189 字）④组合臂草稿 + decomp-01 §2 衔接（§4）⑤文献/原创分列（§5）。

## 1. 结论摘要

- **STaD 的重建不是论文主协议**，只是 Appendix B 的「分解质量」代理指标：coverage = 只给中间步骤+其答案、遮住原题与最终答案，让模型复现正确最终答案；redundancy = 完全相同中间答案对的比例。数字：ToT 8.29%/99.09%、GSM8K 4.21%/87.52%、Math-Hard 6.03%/99.31%（redundancy/coverage）。判等由 LLM "Consistency" prompt 打 0/1（附录 H），**不是人工标注**（conf 0.7）。**关键局限**：它依赖子步骤带可比对的数值答案；我们的子节点是"范围/维度"，没有唯一答案 → 直接照搬会退化成主观判等，正好踩中 CoVe 记录的同意偏差。故需改造（§2，标 [原创]）。
- **ADaPT 的失败判定是执行者自报**（prompt 里让它输出 `task completed` / `task failed`），不依赖环境 gold reward；planner 只在失败时被调用，产出 3–5 个子任务 + AND/OR 算子，递归到 `d_max`。增益 +28.3%（ALFWorld）/ 27%（WebShop）/ 33%（TextCraft）；d=1→2 增益最大；TextCraft 深度 3 时 ReAct 1.8% → ADaPT 38.7%。**它有一个我们没有的便宜**：交互环境里"失败"有外部锚（动作无效、物体不存在）；我们的 pipeline 没有环境反馈，所以必须把"失败"换成可检查的硬条件（§3，标 [原创]）。
- **AOP（成璐贴的那个 detector）出处已定位**：Li et al., *Agent-Oriented Planning in Multi-Agent Systems*, arXiv **2410.02189**, ICLR 2025。三原则 = solvability / completeness / non-redundancy。detector 的做法是"抽原 query 关键要素（含关键数字名词）→ 逐个匹配子任务 → 额外查未预见依赖"。**最有价值的一条实证：把详细要求直接写进分解 prompt 不管用，>15% 的 query 仍不完备/冗余，因此才拆出独立的 detector 角色。** 这说明**"检查放在哪"比"检查怎么写"更决定成败**（与 T28 的方向一致）。量化：completeness 0.822→0.969、solvability 0.763→0.938、non-redundancy 0.986→0.993（LLM 二元评审）。
- **non-redundancy 基线已 0.986** → 在模型眼里"两两重叠"几乎总是满足。这与我们 S1 的经历一致，也意味着**正交性检查必须用注入缺陷校准，否则测不出差异**（§7）。
- **逐要素匹配 vs 整体重建**：逐要素匹配更抗 fabrication（每条缺口都能指认"父节点哪句话没人接"），整体重建更容易"看起来像"却不可核验。→ 组合臂采用**要素清单做锚（AOP）+ 整体重建做一致性复核（STaD 改造版）**，两段式（[原创] 组合）。

## 2. 可执行模板：重建测试（换掉 STaD 的"复现最终答案"）

**用法**：作为**独立的第二个 call**，由**异族模型**执行；输入里**不得包含**子节点的自评结论/通过标记（防 scope laundering）。

```
你是覆盖度审计员。你会收到父节点描述与一组子节点（子节点标签已抹除，只有内容）。
不要评价子节点写得好不好，只做一件事：把这组子节点能支撑的范围，重新拼成一段父节点描述。

【父节点描述】{{parent_text}}
【子节点清单（无序，标签已抹除）】
1) {{child_1}}
2) {{child_2}}
...
【父节点要素清单（由上游独立抽取，勿修改）】{{element_list}}   # 若上游未给，你先自己抽，并另起一行标 ELEMENT-EXTRACTED-BY-AUDITOR

按顺序输出三块，顺序不可调换：
A. 重建描述（≤80 字）：只用子节点里的内容，写出"这个父节点在讲什么、边界到哪"。
B. 要素承接表：对要素清单每一项，写出承接它的子节点编号；无人承接写 NONE。
   | 要素ID | 要素原话（≤15字） | 承接子节点 | 承接方式（原话片段） |
C. 缺口清单：B 中每个 NONE 都要变成一条缺口，写明"父节点哪句话/哪个要求没被任何子节点承接"，
   并给补救建议（补一个子节点 / 该要素本就不可枚举，标 [待核验]）。
   若确实一条缺口都没有，输出 `NO-GAP` 并在下一行写出你检查过的要素数与你认为最容易漏的那个要素。

硬规则：
- 禁止只回"覆盖完整/不完整"这类结论；没有 B 表的结论一律作废。
- 禁止把"说不清"当成"无缺口"；说不清就写进 C 并标 [待核验]。
- 覆盖率 = (要素总数 − NONE 数) / 要素总数，保留两位小数，写在最后一行 `COVERAGE: x.xx`。
```

**评分与阈值（[原创]，阈值待 S10 标定）**：`COVERAGE ≥ 0.8` 且 C 表非空或有 `NO-GAP` 理由 → 通过；否则 FAIL 进回退（§3）。**为什么不用 yes/no**：CoVe 反例里把检查改成 yes/no 后 precision 0.22→0.19，模型"对错都倾向同意"；所以本模板强制先产出表、再产出结论，且结论不参与评分。
**与 STaD 原协议的差异**（须在论文里如实写）：①把"复现最终数值答案"换成"复述父节点范围边界 + 要素承接"（我们的父节点无唯一答案）；②判等从"答案等价 0/1"换成"要素级覆盖率 + 缺口定位"；③审计员与被审模型异族（原文未做此控制，属 [原创] 加固）；④抹除标签（防按顺序对齐而非按语义对齐）。

## 3. 可执行 prompt：ADaPT 式失败触发回退（≤200 字，实测 189 字）

```
【失败】任一即 FAIL：①覆盖图缺失或留空格；②重建覆盖率<0.80；③缺口既无子节点承接也未标[待核验]；④某子节点在独占样例上无法与兄弟节点区分。
【回退】只退 FAIL 的那个子节点，父约束、兄弟节点、已产出工件不动：留父节点描述、该子节点原范围声明、工件引用；丢其内部拆分与自评。
【重切】带新约束重切一次，维度数±1。
【上限】同节点最多 2 次；第 3 次整体标[待核验]交调研阶段。
```

（对照 ADaPT：原文按 sub-task 递归回退、成功分支不回滚 → 我们保留；原文靠执行者自报失败 → 我们换成 4 条可检查硬条件 [原创]；原文用 AND/OR 逻辑算子 → 我们的 pipeline 是线性阶段，故省略。）

## 4. 组合臂完整 prompt 草稿（可直接复制）

**轮次结构**：R1 分解+自检（本 prompt）→ R2 异族重建审计（§2 模板）→ 若 FAIL 进 §3 回退 → R3 调研填充（占位回写）→ R4 终审。
**状态传递**：R1→R2 只传「覆盖图 + 要素清单」（不传自我评价）；R2→R3 只传「缺口清单 + [待核验] 占位表」；R3→R4 传「填充后的覆盖图 + 每条占位的来源 URL」。理由：全量传递会撞多轮衰减（15 模型 6 任务平均 -39%，可靠性 +112%），且长上下文中部注意力最弱 → 只传缺口清单最省且最稳。

```
【角色】你是分解者，只做"切分 + 标注缺口 + 留空"，不调研、不填数。
【输入】父节点：{{parent_text}}　目标标量：{{root_scalar}}　约束：{{constraints}}

【S1 要素抽取】先把父节点拆成"要素清单"再动手切分。要素 = 父节点里每一个必须被回答的要求/对象/边界条件（含关键数字、时间范围、比较口径）。
输出：| 要素ID | 要素原话（≤15字） | 类型（约束/成本/其他） |
要求：要素数 ≥3；只准抄父节点原话，禁止发明要素。若父节点本身残缺，把残缺处列成 `[待核验]` 要素。

【S2 切分】按正交维度切成 ≤7 个子节点；每个子节点给出"覆盖范围"一句话，用具体对象描述，不用抽象标签。

【S3 覆盖图】必须交表（这是验收工件，decomp-01 §2 的同一张表）：
| 子节点 | 覆盖范围（一句话） | 承接的要素ID | 与其他子节点的重叠 | 缺口/不确定区域 |
规则：①"承接的要素ID"必须来自 S1，空着即视为缺口；②重叠列要点名"与哪个子节点、在哪个具体区域"；③缺口列**以事实为准**——真查过、真拼过了就是无缺口，如实写"无"（2026-11-07 成璐纠正：旧版"全表无缺口=可疑"会诱导模型故意留缺口表演谨慎，已删）；确实说不清的地方才占位并标 [待核验]。若 NO-GAP，在表下写一行"我检查过的要素数 + 我认为最容易漏的那个要素"（这是诚实自检，不是被迫找茬）。

【S4 正交性取证】只对"看不出区别"的兄弟对做一次取证（不要给所有对都写公式）：
对 X 与 Y，给一个**具体样例**（一个输入/一个候选/一个场景），使 X 与 Y 的判定不同，写成 `X: …｜Y: …`。
若给不出样例：二者重叠 → 合并，或把重叠区域单独列成一行标 [重叠-待定]。
禁止用"X 负责 A 方面、Y 负责 B 方面"这类同义反复当取证。

【S5 占位】所有需要外部事实的位置写 `[待核验: 要查什么]`，禁止给具体数字/规格。留空不扣分，编造即失败。

【S6 自检】逐条回答（不许写 OK）：
1) 要素清单里哪些没有被任何子节点承接？→ 列 ID
2) 哪两个子节点最可能重叠？→ 点名 + 区域
3) 若我现在被要求"只看子节点复述父节点"，会丢哪一块？
把 1)2)3) 的答案并入 S3 的表，不要另写一套。

【禁止】不给结论性总评（"已完整覆盖"之类）；不用公式/参数名代替具体样例；不写调研内容。
```

**与 decomp-01.md §2 的衔接（逐项对应，别各写一套）**：

| decomp-01 §2 现有要素 | 组合臂里的落点 | 增量（[原创]） |
|---|---|---|
| 「拼接覆盖图」4 列（子节点/覆盖范围/重叠/缺口） | §4-S3 原样保留 | 加 `承接的要素ID` 列，把"看图说话"锚到 S1 要素清单（AOP 做法） |
| 「缺口列允许写说不清 + 标 [待核验]」 | §4-S5 | 占位语法统一为 `[待核验: 要查什么]`，供 R3 机械检索 |
| 「缺口以事实为准 + NO-GAP 时写最可能漏什么」 | §4-S3 规则③ | 量化为"NO-GAP 必须附自检行（检查过的要素数 + 最易漏要素）"，否则判 FAIL（§3 条件①③）。2026-11-07 成璐纠正：旧版"全表无缺口=可疑"诱导表演谨慎，已改为以事实为准 |
| 「Reviewer 拿覆盖图做重建测试（STaD 代理）」 | **§2 模板 = 这句话的可执行版本** | 异族模型 + 抹标签 + 要素级覆盖率 + 禁 yes/no |
| 「禁止用代数式判据（独占参数/贡献形式）」 | §4-S4 改为"具体样例取证" | 保留禁令，但给一个可审计替代物（样例可被第三方复算，公式不可） |
| 黑盒收口表 / 口径声明 | 不变，仍由 decomp-01 §3/§4 承担 | — |

## 5. 文献支撑 vs 原创（不混）

**有文献支撑**：①重建作为覆盖代理、redundancy=重复中间答案比（STaD, R30）；②失败触发、按子任务递归回退、成功分支不回滚（ADaPT, R37）；③检查要拆成独立 detector 角色 / 要素级匹配（AOP, R36）；④拆细+独立取证有效、封闭式 yes/no 有害（CoVe, R27）；⑤原子二元清单提升评委可靠性（CheckEval, R28）；⑥内在自检不可靠、须外部信号（Huang, R11）；⑦多轮全量传递衰减（Lost in Multi-Turn, R10）；⑧v1 的四类 fabrication 失效面（T26 Q4, R31–R34）。

**属原创组合（无单一文献支持，须在论文里标 [原创]）**：①把"复现最终答案"改造成"复述父节点范围 + 要素承接表 + 覆盖率公式"；②把 ADaPT 的环境失败信号换成 4 条可检查硬条件（无图/覆盖率<0.8/缺口无归属/样例不可区分）；③要素锚定 + 整体重建的**两段式**串联（AOP 定位、STaD 复核）；④"缺口以事实为准 + NO-GAP 时附自检行"的反橡皮图章规则（2026-11-07 成璐纠正后版本）；⑤`[待核验: 要查什么]` 占位语法 + R3 机械回写（T29 确认：占位作为一等工件是精确空位 (a)）；⑥审计员异族 + 抹标签。

## 7. 风险映射：T26 Q4 四种 fabrication → 本流程的闸门

| Q4 失效模式 | 在本流程里的表现 | 闸门 |
|---|---|---|
| vacuous formalization | 覆盖图全填"无缺口/无重叠" | §3 条件①③ + §4 规则④（必须写最可能漏什么） |
| scope laundering | 自己宣布"重建通过"但没真做 | 重建由**异族第二 call** 执行，输入抹掉自评（§2） |
| formalization gaming | 编"独占参数/公式"凑正交性 | 禁令 + 改为**具体样例取证**，第三方可复算（§4-S4） |
| compile-only 循环 | 填完表就收工 | 终止条件是"覆盖率≥0.8 且 缺口全部有归属"，不是"表填满" |
