# 多模型/多 prompt 校验的独立提升效果 — 调研（2026-11-07）

origin: ai | 触发：成璐"着重调研不同 prompt 校验要求独立的提升效果，先调研"（idea-list #23 前置调研）
方法：arXiv API 直查（本轮工具输出，来源①），15 组查询 ~130 条命中，人工筛相关子集。未做网页 LLM 交叉验证。

## 一句话结论

**"加一个别的模型来检查"不是免费的增益——它什么时候有用、什么时候有害，取决于三个变量：质询者是否真正独立（错误不相关）、任务是否有可证伪锚点、以及讨论会不会把对的改错。** 文献里正面和负面证据几乎对半，但负面证据更具体、更可操作。对我们 S8-discuss 臂的设计含义直接写在 §5。

## §1 核心发现（按对我们的价值排序）

### 1.1 "Martingale Curse"：同质 agent 辩论 ≤ 多数投票（2603.06801, 2026-03）
标准 MAD 无法把信念正确性提升到多数投票之上——因为同一模型的多个实例共享训练分布，错误高度相关。这是"独立性 > 检查次数"的最硬理论支撑：**N 个同族模型讨论 ≈ 1 个模型看 N 遍自己的答案**。解法是异构（不同家族/不同训练路线的模型）。
→ **S8-discuss 必须用跨家族质询者（如 27b + GPT/Claude/Gemini 级），不能是 27b 分身。**

### 1.2 辩论效应可以反号：critique-induced degradation（2606.02866, 2026-06）
数据清洗任务上，debate 在全部四个模型上**降低**生成质量（-1.6 到 -15.5pp），机制 = 批评本身诱导了退化（被质询方倾向于迎合质询方，即使质询方错了）。条件依赖：有明确对错标准时 debate 有效，开放判断任务上有害。
→ **我们的科研事实核查属于"有可证伪锚点"的任务，理论上落在 debate 有效区；但 O6（矛盾发现）维度可能部分落在开放区，需要分开测。**

### 1.3 预注册实验：MAD 对论文反馈无增益（2607.14713, 2026-07）
44 篇经济学 meta-analysis 的作者盲评自己论文的三份 AI 报告：单次前沿模型 vs 两种 multi-agent debate 配置 → **debate 没赢**。预注册 + identity-masked + within-paper 设计，证据强度高。
→ 提醒我们：S8-discuss 如果只在 M1（数字命中）上测，很可能复现"无增益"；真正的增量假设应该押在 O6（矛盾发现/新分支）上——这正是现有 benchmark 都不测的维度。

### 1.4 第二模型何时帮忙（2610.01471, 2026-10）
"When Does a Second Model Help? Cross-Model Review in LLM Verification"——直接研究跨模型 review 的条件。结论文档化了我们需要的决策表：context 传递方式、重复次数、角色结构各自的影响。（摘要层信息，细节需读全文 [待核验]）

### 1.5 Self-preference bias 是双向的（2410.21819 / 2604.22891 / 2608.18091）
judge 偏袒自己家族的输出已成定论（多篇量化），2608.18091 补充：self-label 和 other-label 都会引入偏差，不只是"认亲"。
→ **打分端沿用异族 judge 是对的；生成端的质询者同样要避开与生成者同家族，否则"讨论"退化成自我欣赏。**

### 1.6 问题漂移（2502.19559, 2025-02）
MAD 在长推理链任务上失效的机制之一 = 讨论过程中话题偏离原问题（problem drift）。轮次越多漂移越严重。
→ **S8-discuss 需要每轮开头重述原始问题 + 当前节点断言，防漂移。这正好和"写回 decomp 节点"设计兼容——decomp 树就是防漂移的锚。**

### 1.7 安全面：adversarial error propagation（2609.39146, 2026-09）
MAD 的纠错通道同时是攻击通道——一个被污染的 agent 可以把错误传染给其他 agent。
→ 本地实验风险低（都是自己的模型），但如果质询者接入外部 API 且其上下文被注入，需要意识到这个面。

### 1.8 自适应路由方向（ARMOR-MAD 2606.13197 / iMAD 2511.11306 / HCP-MAD 2604.09679）
三篇独立工作收敛到同一结论：**固定全流程 debate 浪费算力且放大相关错误，应该按难度/置信度条件触发**。这和我们 idea-list #22 的级联路由完全同构——两个独立线索指向同一个架构：L1 快筛 → 低置信才升级讨论。
→ **#22 和 #23 应该合并成一个臂设计：cascade-discuss（低置信节点才触发跨模型讨论），而不是全量讨论。**

## §3 自校正的边界（为什么"自己检查自己"不行）

| arXiv | 要点 |
|---|---|
| 2310.01798 | "LLMs Cannot Self-Correct Reasoning Yet"——无外部信息时自校正无效甚至有害（经典引用） |
| 2402.08115 | 自我验证在 reasoning/planning 上的系统性局限 |
| 2512.02389 | 合成错误注入也 eliciting 不出自校正 |
| 2406.15673 | 反方：内在自校正能力存在，但需要特定条件（外部反馈/检索） |
| 2606.21724 (DISC) | 把验证问题输出当噪声测量做结构化迭代——naive correction 会伤及已正确的答案 |

这组文献和 E3 结果（事后修正 Δ±0.022）互相印证：**自校正要起作用，必须引入外部信息（检索/异族模型），纯内部反思≈零增量。**

## §5 对 S8-discuss 臂设计的直接含义（综合 §1-§4）

1. **质询者必须跨家族**（1.1/1.5）：27b 生成 + 至少一个非 Qwen 系质询者。本地资源约束下：LM Studio 上有 GLM-4.7-Flash、Qwen 系之外还有 Heretic 35B——GLM 可当第一个异族质询者。
2. **不全量讨论，按置信度触发**（1.8 × #22）：arm 名改为 S8-cascade-discuss——L1 自检（口径回溯+来源标签）→ 低置信节点才发质询包给异族模型 → 回复写回 decomp 节点。这样同时测 #22 的路由和 #23 的独立性。
3. **每轮重述锚点**（1.6）：质询 prompt 必须包含原始问题 + 当前节点断言原文 + 该断言的来源标签，防止讨论漂移到泛泛而谈。
4. **主指标押 O6 不押 M1**（1.3）：预期 M1 上与 S5 打平或略低（讨论有迎合风险），O6（矛盾发现数/新分支数）显著领先才算成功。若 O6 也不领先 → 整个多模型讨论方向在本任务域证伪，及时止损。
5. **质询者 persona 分化**（已有基础：S6/S7 的 persona 措辞实验）：较真的（找逻辑漏洞）/ 怀疑论的（默认所有数字存疑直到给出测量条件）/ 领域专家（用领域协议审口径）。单质询者 vs 三角色是第二个消融轴。
6. **预算控制**：test-time scaling 有 plateau（2505.20522），讨论轮次从 1 轮开始，不预设 3 轮——先看 1 轮的 O6 增量再决定加不加。
