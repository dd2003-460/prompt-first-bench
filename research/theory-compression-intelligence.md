# 压缩-智能框架：完整推导（Theory: Compression-Intelligence for Decomposition Trees）

## 0. 对象与记号

**分解树 T**：根 r，叶集 L(T)，|L(T)| = n。每个叶 ℓ ∈ L(T) 携带内容文本 c(ℓ)（一个事实断言或参数值）。parent(ℓ) 为其父节点。

**题目 Q**：约束集 G = {g₁,…,g_g}（gold 维度，机器侧标注，模型不可见）。维度 gᵢ 的固有信息量 hᵢ > 0（bits）。

**语言模型 M**：固定的本地 LM（qwen3.8-27b），给出条件分布 P_M(·|context)。

### 基本量

```
H_M(ℓ | parent(ℓ))   := −Σ_{t∈tokens(c(ℓ))} log₂ P_M(t | context(parent(ℓ), t₁..t₋₁))
                        # 叶内容的条件交叉熵（bits），即"给定父节点后写出这个叶需要多少 bit"

D(T)    := Σ_{ℓ∈L(T)} H_M(ℓ | parent(ℓ))          # 总条件描述长度（bits）
d̄(T)    := D(T)/n                                   # 每叶平均（bits/leaf）

cov(T)  := |M(T) ∩ G| / g                           # 覆盖率 ∈ [0,1]，M(T) = T 实际命中的 gold 维度集
```

**S_α'（结构项，现有实现口径，来自 s5_state_machine.py `S_alpha_corrected`）**：

```
S_α'(T) := Σ_{lv≥1} [ lv·ln(k_lv + 1) + α·k_lv·ln(lv + 1) ] − β·red(T)·n
```

其中 k_lv = 第 lv 层节点数，α = 0.5（代码内固定），β = 3.0（redundancy_penalty_beta，2026-11-11 标定），red(T) = 同层叶子对的平均 n-gram Jaccard 重叠 ∈ [0,1]。

## 1. 公理层（三条，全部可操作化）

**A1（覆盖完备性）**：答案质量的上界由 cov(T) 控制。漏掉一个真实贡献维度，预测误差至少损失该维度的贡献份额。
*操作化*：cov 用 gold 标注算（机器侧）。

**A2（MDL 原则）**：在两个解释力相同（cov 相同）的树之间，选条件描述长度小的。
*操作化*：D(T) 用固定 LM M 的条件交叉熵算。这是 MDL 文献的标准做法——K(T)（Kolmogorov 复杂度）不可判定，条件交叉熵是其一致可算估计（当 M 足够强时 H_M → K，见 §6 可算性讨论）。

**A3（对称展开先验）**：树的结构规模应接近"该有的量"。过分解（冗余膨胀）和欠分解（漏结构）都是病态，且按乘性尺度对称惩罚。
*操作化*：expansion_prior(T) = exp(−|ln(S_α'(T)/S_α'(T₀))| / σ_s)，T₀ = oracle 参考树，σ_s > 0 宽容度超参。

为什么 A3 用对数距离而不是线性距离：结构量的合理比较是乘性的（"比 oracle 多一倍"和"少一半"是同一类偏离）。线性距离 |S_α' − S_α'(T₀)| 会随树的绝对尺度漂移——大树上同样的相对偏离被罚得更重。ln 域消除这个尺度依赖，这正是"边际极限优化"的尺度不变含义。

## 2. 核心命题

### 命题 1（覆盖-复杂度下界）

设 T 覆盖全部 g 个 gold 维度（cov(T)=1），且维度 gᵢ 的固有信息量为 hᵢ bits（即任何正确承载 gᵢ 的内容至少需要 hᵢ bits 条件描述长度）。则：

```
D(T) ≥ Σ_{i=1}^{g} hᵢ ≜ H*(Q)
```

等号成立当且仅当：(i) T 恰好按 g 个维度划分，每个维度一个最小充分叶；(ii) 无同义重复叶；(iii) 无 gold 之外的额外叶。

**证明**：
将 L(T) 按所属 gold 维度分桶：L(T) = (⊔_{i=1}^g Lᵢ) ⊔ L₀，其中 Lᵢ = 属于维度 gᵢ 的叶，L₀ = 不属于任何 gold 维度的叶（冗余/外生叶）。

第一步（桶内下界）：对每个 i，Lᵢ 非空（cov=1 要求）。取 ℓᵢ* ∈ Lᵢ 为承载 gᵢ 的叶。由 hᵢ 的定义（固有信息量 = 正确承载 gᵢ 的最小条件描述长度），H_M(ℓᵢ* | parent(ℓᵢ*)) ≥ hᵢ。故 Σ_{ℓ∈Lᵢ} H_M(ℓ|parent(ℓ)) ≥ H_M(ℓᵢ*|parent(ℓᵢ*)) ≥ hᵢ。

第二步（跨桶相加）：D(T) = Σ_i Σ_{ℓ∈Lᵢ} H_M(ℓ|parent(ℓ)) + Σ_{ℓ∈L₀} H_M(ℓ|parent(ℓ)) ≥ Σ_i hᵢ + Σ_{ℓ∈L₀} H_M(ℓ|parent(ℓ)) ≥ Σ_i hᵢ。

第三步（等号条件）：等号要求 (a) 每个 Lᵢ 恰含一个叶且其条件熵恰好 = hᵢ（无同义重复、无过度具体化）；(b) L₀ = ∅（无额外叶）。∎

**注 1.1（hᵢ 的可算性）**：hᵢ 本身不可精确知道（那是 K 复杂度层面的量）。工程替代：用 oracle 树 T₀ 的分维度条件熵 ĥᵢ := D(T₀)/g 的逐维分解（G9 标注时给每个 gold 维度标出 oracle 中对应的叶，hᵢ ← 该叶的条件熵）。由命题 1 对 T₀ 自身适用，H*(Q) ≤ D(T₀)，即用 D(T₀) 做 H* 的代理是**保守偏大**的——Δ 被高估，I(T) 被低估，不产生假阳性（好树不会被误判为坏），只可能让分数整体偏低。这是可接受的偏差方向。

**注 1.2（商边维度的系统性偏差）**：若某 gold 维度是商/约束边类型（如性价比 = 性能/TCO，Decision 24 的三边分类），其"固有信息量"包含 frontier 采样的多个锚点，单一 hᵢ 会低估该维度真实需要的描述长度 → H* 被低估 → Δ 被高估。处理：此类题目只报告 cov，不报告 I(T)；或在 G9 标注时给商边维度标多锚点分解的 hᵢ 之和。写入论文假设块。

### 命题 2（完备性饱和下的单调递减 —— "hack 直接掉分"的解析形式）

设 T 满足 cov(T) = 1。向 T 添加一个新叶 ℓ（挂在任意现有节点下），得到 T'。若 ℓ 的内容非平凡（H_M(ℓ|parent(ℓ)) > 0），则：

```
cov(T') = 1,   Δ(T') = Δ(T) + H_M(ℓ|parent(ℓ)) > Δ(T),   I(T') < I(T)
```

特别地，若连续添加 m 个同义变体叶（每个条件熵 ≈ h_syn > 0），则：

```
I(T_m) = exp(−(Δ(T) + m·h_syn)/H*(Q)) = I(T)·e^(−m·h_syn/H*)
```

即 I 随冗余叶数**指数衰减**。m 个冗余叶使分数乘以 e^(−m·h_syn/H*)；当 m·h_syn = ln 2 · H* 时分数减半。

**证明**：
cov：新叶 ℓ 若属于已覆盖维度，M(T') = M(T)，cov 不变 = 1。（若 ℓ 属于未覆盖维度则 cov 上升，不在本命题范围。）
Δ：Δ(T') = D(T') − H*(Q) = D(T) + H_M(ℓ|parent(ℓ)) − H*(Q) = Δ(T) + H_M(ℓ|parent(ℓ))。
严格性：非平凡文本的条件熵 > 0——LM 对任何具体事实句子的续写分布不是 δ 分布（父节点内容不能确定性推出子节点的具体表述），故 H_M(ℓ|parent(ℓ)) ≥ min_token_entropy > 0（min_token_entropy 为 LM 词表上的最小单 token 熵，实践中 ~0.01-0.1 bits/token，句子级 ~1-10 bits）。
I：I(T') = 1·exp(−Δ(T')/H*) < exp(−Δ(T)/H*) = I(T)，因指数函数严格递减且 Δ(T') > Δ(T)。
指数形式：直接代入。∎

**推论 2.1（v17 解析击杀）**：v17 hack 树 n = 1930 节点，假设其中 ~1900 个是同义变体叶（实测近义重复率 ~99%，来自 v17-hier-decomposition-blowup.md 诊断），每叶条件熵 h_syn。即使取极小值 h_syn = 1 bit（一句短事实句的条件熵下限量级），H*(Q) ~ 几十 bits 量级（gpu 题 g≈8 维度 × 每维几 bits）：m·h_syn/H* ≈ 1900/50 ≈ 38 → I 因子 e^(−38) ≈ 3×10⁻¹⁷。**v17 树在 I(T) 下分数塌到 0，不需要任何规则条款、阈值或调参。** 对比：旧 S_α' 下这棵树结构项极高（正是被 hack 的对象）。

**推论 2.2（实验验证协议）**：命题 2 的可测形式 = I-vs-n 曲线斜率为负。取一棵 cov=1 的树，逐步添加同义叶（或取 v17 树的节点前缀序列），画 I(T_m) vs m。预期：半对数图（log I vs m）为直线，斜率 = −h_syn/H* < 0。这条线同时标定 h_syn/H* 的比值——不需要单独测 h_syn 和 H*，只需要曲线斜率。

### 命题 3（正交性 = 压缩性 —— 冗余度的条件熵刻画）

设 ℓ₁, ℓ₂ 为同父节点的两个兄弟叶。定义二者的**信息冗余度**：

```
R(ℓ₁, ℓ₂) := 1 − H_M(ℓ₂ | parent, ℓ₁) / H_M(ℓ₂ | parent)
```

（条件熵之比 ∈ [0,1]：给定 ℓ₁ 后 ℓ₂ 还剩多少不确定性。）则：

```
R(ℓ₁, ℓ₂) 高  ⟺  ℓ₁, ℓ₂ 不正交（共享信息多，近义/同维）
R(ℓ₁, ℓ₂) ≈ 0  ⟺  ℓ₁, ℓ₂ 正交（ℓ₁ 不提供关于 ℓ₂ 的信息）
```

**证明**：
数据处理不等式方向：H(ℓ₂|parent, ℓ₁) ≤ H(ℓ₂|parent)（增加条件不减熵……准确说是减熵：条件越多不确定性越少），故比值 ∈ [0,1]，R ∈ [0,1]。
语义：若 ℓ₁, ℓ₂ 是同一维度的两种说法（近义），知道 ℓ₁ 几乎确定 ℓ₂ 的内容 → H(ℓ₂|parent, ℓ₁) ≈ 0 → R ≈ 1。若 ℓ₁, ℓ₂ 是不同维度（正交），ℓ₁ 的内容对 ℓ₂ 无信息 → H(ℓ₂|parent, ℓ₁) ≈ H(ℓ₂|parent) → R ≈ 0。∎

**推论 3.1（消解 Decision 15 悬案）**：Decision 15 悬而未决的问题是"正交度量选型：n-gram 重叠 / embedding 余弦 / LLM-judge 三选一，需实验标定"。命题 3 表明：**条件熵 R(ℓ₁,ℓ₂) 就是正交度的精确定义**，三种候选度量全是它的粗糙近似——
- n-gram Jaccard 重叠：表面字符串相似度，是 R 的高估（同义不同词时低估冗余）；
- embedding 余弦：语义空间距离，是 R 的近似（捕捉同义但受 embedding 训练分布影响）；
- LLM-judge：问模型"这两个是否同义"，本质是让另一个 LM 估计 R（且输出离散判断，丢失连续值）。
选型问题不存在了：直接用 H_M(ℓ₂|parent, ℓ₁) 算 R，工具已在手（同一个 LM 一次前向）。现有 S_α' 里的 red(T)（n-gram 版）可以平滑升级为条件熵版，不改架构只改度量内核。

**推论 3.2（全局冗余度的条件熵重构）**：

```
red_CE(T) := (1/|pairs|) Σ_{(ℓ₁,ℓ₂)∈pairs} [1 − H_M(ℓ₂|parent, ℓ₁)/H_M(ℓ₂|parent)]
```

替换现有 n-gram 版的 red(T)，进入 S_α' 的罚项。代价：pair 数 × 每次一个条件前向（同层 >20 抽样策略保留）。收益：罚项从"表面相似"升级为"真信息冗余"，近义不同词的 hack 路径（v17 的主攻方向）被精确打击。

### 命题 4（双约束均衡 —— "边际极限优化"的精确形式）

定义两侧边际量（对"添加一个叶 ℓ"的操作）：

```
压缩侧边际代价:   c_add(ℓ) := H_M(ℓ|parent(ℓ))                    （bits，命题 2 已用）
展开侧边际收益:   s_add(ℓ) := ∂S_α'/∂ℓ |_{structural only}
                  = lv(ℓ)·[1/ln(k_lv+1)] + α·ln(lv(ℓ)+1)          （对第 lv 层加一个节点的结构性增量）
```

（推导：S_α' 结构项对第 lv 层的贡献 f(k) = lv·ln(k+1) + α·k·ln(lv+1)，df/dk = lv/(k+1) + α·ln(lv+1)。离散版 ∂f/∂ℓ = f(k+1)−f(k) = lv·ln((k+2)/(k+1)) + α·ln(lv+1)，大 k 时 ≈ lv/(k+1) + α·ln(lv+1)。）

**最优树 T* 的一阶条件（边际相等）**：

```
存在 λ* > 0 使得对 T* 的边界叶（加与不加都在最优邻域内）：
    c_add(ℓ) / H*(Q)  =  λ* · s_add(ℓ) / S_α'(T₀)
```

左端 = 归一化压缩代价（新叶占固有信息的比例）；右端 = 归一化结构收益（新叶占 oracle 结构量的比例）× 交换比率 λ*。

**经济解释**：λ* 是两侧预算的交换比率。λ* 大 → 结构收益权重高 → 容忍更多展开（树更大）；λ* 小 → 压缩优先（树更小）。λ* = 1 是对称基准。这个方程说：**最优树停在"再加一个叶子的压缩代价（按 H* 归一）等于其结构收益（按 oracle 归一）乘以交换比率"的地方**——两种资源（描述预算 vs 结构预算）的最优配置在边际替代率相等处，标准微观经济结论，不引入新数学。

**与现有停止判据的关系（解释而非替代）**：状态机的 gain < τ 停止条件，其中 gain = 本轮新增叶的平均信息增益（经验量）。gain 低 ⟺ 新叶的 c_add 相对其带来的 cov 提升小 ⟺ 逼近边际相等点。P5 回标的 gain CDF（n=8，mean 0.896，std 0.056，stop_std_max 已改为 0.06）就是这条均衡线附近的波动分布——**现有停止判据是命题 4 一阶条件的经验化近似**，理论上站得住。实践上不解方程（需在线算 s_add），乘积目标 J(T) 做验收 + gain 阈值做停止，两者分工不变。

### 命题 5（联合目标的性质）

联合验收目标（机器侧，不进 prompt）：

```
J(T) := cov(T) · exp(−Δ(T)/H*(Q)) · exp(−|ln(S_α'(T)/S_α'(T₀))|/σ_s)
      = cov(T) · exp(−Δ(T)/H* − |ln ρ_s(T)|/σ_s)
```

其中 ρ_s(T) := S_α'(T)/S_α'(T₀) 为相对结构匹配比。

**性质 P1（界）**：J(T) ∈ [0,1]。cov ≤ 1，两个指数项 ≤ 1（指数参数 ≥ 0）。

**性质 P2（完美树上界可达）**：存在 T 使 J(T) = 1，当且仅当 cov=1 ∧ Δ=0 ∧ ρ_s=1——即 T 恰好按 g 个维度划分、无冗余、结构量恰等于 oracle。这是可达上界（oracle 树自身近似达到，偏差来自 T₀ 的不完美）。

**性质 P3（缺维双重惩罚）**：漏掉一个 gold 维度（其余完美）：cov: 1 → (g−1)/g；同时该维度的 hᵢ 从 D(T) 消失使 Δ 变化——注意 Δ = D(T) − H*，漏维使 D(T) 降 hᵢ 但 H* 不变，Δ 降 hᵢ → 指数项反而升？

**修正（重要）**：这里暴露一个微妙点。Δ 定义为 D(T) − H*(Q)，漏维时 D(T) 下降，Δ 也下降，压缩项不罚反奖——**漏维只被 cov 单项惩罚，压缩项中性**。这不是 bug 而是设计：漏维的惩罚全在 cov（线性丢 1/g），压缩项只管"你写的东西有没有冗余"，不管"你少写了什么"。两项职责正交：cov 管召回，exp(−Δ/H*) 管精度（非冗余），exp(−|lnρ_s|/σ_s) 管结构规模合理性。三重惩罚的说法只在"加冗余叶"场景成立（命题 2：cov 不变 + Δ 升 + ρ_s 偏离），在"漏维"场景是 cov 单罚 + ρ_s 可能偏离（树比 oracle 小 → lnρ_s < 0 被对称项罚）。所以漏维实际是**双罚**（cov + 结构偏小项），加冗余叶是**双罚**（Δ + 结构偏大项）。修正后的表述：**任何偏离完美树的方向都至少被两项惩罚**，无一维偏离只被一项抓住。

**性质 P4（聚合性）**：ln J = ln cov − Δ/H* − |lnρ_s|/σ_s。三项分离，可对多题取几何均值（= ln 域的算术均值）而不破坏可加性。跨题聚合口径由此固定。

**性质 P5（hack 免疫性）**：任何只改变树内部表述而不改变 (cov, 命中维度集) 的操作：
- 同义改写叶内容：D(T) 不变（条件熵对同义表述近似不变，LM 视角下信息量相同）→ Δ 不变；
- 复制叶：命题 2，Δ 严格升 → J 严格降；
- 删除已覆盖维度的叶：cov 降 → J 降。
不存在保持或提升 J 的同时不改变真实覆盖的 hack 路径。**Goodhart 防线从"prompt 里不写公式"（行为层防御）升级为"目标函数本身无 hack 不动点"（结构层防御）**——即使把 J 的公式告诉模型，它也无从优化（优化的唯一途径是真的找对维度）。这是对 Decision 16 Goodhart 论证的强化：之前是"藏住 proxy"，现在是"proxy 本身收敛到真目标"。

## 3. 数值例（gpu 题量级估算）

设定（gpu 题，来自 G9 构建规划）：g = 8 个 gold 维度，每维固有信息 hᵢ ≈ 5 bits（一个维度名 + 关键参数值，~10-15 token 的条件熵量级）→ H*(Q) ≈ 40 bits。oracle 树 T₀：n₀ ≈ 40 节点，S_α'(T₀) ≈ 100（量级参照 clean-r2 实测 structural 97.2 @n=117，oracle 更小故更低，取 100 量级 [待 r12 出树后实算]）。

**情形 A（完美树）**：cov=1, D=40=H*, Δ=0, S_α'=100=T₀ → J = 1·e⁰·e⁰ = **1.0**。

**情形 B（v17 式膨胀）**：cov=1（维度都碰到了）, n=1930, 冗余叶 ~1900 × h_syn≈2 bits → Δ ≈ 0 + 3800 bits（相对 H*=40）→ 指数项 e^(−95) ≈ 10⁻⁴¹；ρ_s ≈ 1930/40 量级 → |lnρ_s|/σ_s ≈ ln(48) ≈ 3.9 → 结构项 e^(−3.9) ≈ 0.02。J ≈ **10⁻⁴³ 量级 → 0**。

**情形 C（欠分解，漏 2 维）**：cov = 6/8 = 0.75, D ≈ 30, Δ = 30−40 = −10 <0？

**再修正（Δ 的下界问题）**：命题 1 说 cov=1 时 D ≥ H*。cov<1 时 D 可以小于 H*（没覆盖的维度没写），此时 Δ = D − H* < 0，exp(−Δ/H*) = exp(+|Δ|/H*) > 1 ——**指数项超过 1，部分抵消 cov 的损失**。这是设计漏洞吗？

检查：情形 C 中 J = 0.75 · e^(10/40) · e^(−|lnρ_s|/σ_s) = 0.75 · 1.28 · (结构项)。若结构项 = 1（树大小恰好），J = 0.96 > 0.75——欠分解树得分比 cov 还高？不对，cov=0.75 的完美欠分解树 J=0.96，而完美树 J=1.0，排序仍然对（欠分解 < 完美），只是没被"加倍罚"。

**设计决定（明确记录）**：接受 Δ 可为负（cov<1 时），exp 项 >1 的效果是"欠分解的树不被压缩项额外惩罚"——惩罚全在 cov 的线性损失。理由：欠分解的病是"漏"，cov 已经精确计量了漏了多少（线性 1/g 每维）；再用指数项罚一次是重复计罪，且会让 J 对 cov 的响应变成非线性扭曲（cov 0.75 的树得 0.96，cov 0.5 的树得 0.5·e^(20/40)=0.82——排序对但间距压缩）。保持 exp(−Δ/H*) 在 Δ<0 时 >1 是**有意的**：它让 J 在欠分解区近似线性跟随 cov，在完备区（cov=1, Δ≥0）才启动指数杀冗余。**J 的行为分段：欠分解区 = cov 主导（线性），完备区 = 压缩主导（指数）**——两段各有一个干净的机制，没有交叉干扰。这个分段性质应该写进论文（它是 J 的核心设计特征，不是缺陷）。

**情形 D（过分解但不冗余，真新维度）**：cov=1（gold 全覆盖）, 加了 2 个 gold 之外但对答案真有贡献的维度，各 3 bits → Δ = 6, J = 1·e^(−6/40)·(结构项) ≈ 0.86·(结构项)。**J 误伤了真新维度**（命题 30 局限 3 的量化：6 bits 的新增真信息 → 掉 14%）。缓解方案（记录待选）：(a) G9 标注时把"合理扩展维度"纳入 G 的超集 G⁺，cov 和 H* 同步扩大 → 真新维度不再算 Δ；(b) 接受保守偏差（bench 题面封闭，gold 之外贡献有限）。当前选 (b)，(a) 留作 G9 构建时的可选扩展。

## 5. 与既有决策的衔接（一致性核对）

- **Decision 24（代理锥）**：S_α'（K 的上界松弛）与 cost(T)（线性下界）夹住 K(T)。J(T) 不破坏锥结构——它用的是 D(T)（条件 MDL，落在锥内偏上位置，Decision 26 已定位）+ S_α'（锥上沿）的组合，仍在测量带内。
- **Decision 26（条件 MDL）**：D(T) 的定义直接继承，β=0 的 cost(T) 升级建议被 J(T) 取代——不再改 U(T) 的 cost 项，而是独立加 J(T) 做联合验收。U(T) 保留原角色（终点验收的质量侧），J(T) 管结构侧（压缩+规模）。
- **Decision 28（命题 1 + I(T)）**：I(T) = J(T) 去掉结构项（σ_s → ∞ 极限）。J(T) 是 I(T) 的严格推广，I(T) 的所有性质（界、kill、聚合）继承（命题 5 P1-P5 已复核）。
- **Decision 29（prompt 声明 + B(T)）**：B(T)（计算预算比）与 J(T) 的关系：B(T) 管"计算-传输平衡"（运行时资源），J(T) 管"信息结构"（内容质量）。两者正交，联合验收 = J(T) ≥ τ_J ∧ B(T) ∈ [0.9, 1.1]。B(T) 不并入 J(T)（混合信息量与资源量纲不正交）。
- **Goodhart 防线**：从行为层（藏公式，Decision 16）升级为结构层（命题 5 P5：J 无 hack 不动点）。两层防御叠加，即使未来有人把 J 写进 prompt（不推荐），也不会复现 v17。

## 6. 假设清单与局限（论文 assumption block 素材）

**A-1（LM 充分性）**：M 足够强，H_M(·|·) 近似 K(·|·)。弱 LM 会使 D(T) 系统性偏大（模型表达不了的内容熵高）→ Δ 偏大 → J 偏低。缓解：固定 M 后所有树同尺度比较，相对排序不受影响（同 M 下的偏置是公共因子）。跨模型比较（H3）时才需校准。

**A-2（gold 标注质量）**：G 的完备性和正交性决定 cov 的有效性。G 漏标一个真实维度 → cov 上限 <1，所有树被压分（公共偏置，排序不变）。G 标错（把非贡献维度标进去）→ cov 可被刷（模型覆盖无用维度提分）——这是唯一的标注侧 hack 路径，靠 G9 构建时的独立性检验（维度间相关性矩阵）防。

**A-3（维度独立性）**：命题 1 的 hᵢ 相加要求维度间近似独立。商边维度（耦合）违反此假设 → 注 1.2 的处理（报 cov 不报 I，或多锚点分解）。

**A-4（oracle 质量）**：T₀ 用于 H* 代理和 ρ_s 归一化。T₀ 不完美 → H* 偏大（保守，J 偏低不假阳）+ ρ_s 基准偏移（结构项罚错方向的风险）。缓解：多 oracle 取中位数（Decision 30 已记录）。

**A-5（封闭题面）**：bench 题目约束集封闭（gold 维度穷尽了真实贡献维度）。开放任务（真实科研）中 gold 之外常有真贡献 → 情形 D 的误伤放大。论文叙事限定在 bench 场景，开放场景列为 future work。

**A-6（超参）**：σ_s（结构宽容度）、τ_J（验收阈值）是新超参。它们只影响验收宽容度，不影响模型可见的任何东西（Goodhart 风险为零）。标定方式：在已知好树（clean-r2 类）和坏树（v17 类）上网格搜索使判别力（两簇 J 的分离度，如 Fisher ratio）最大的值。初始 σ_s=1, τ_J=0.5 [待标定]。

## 8. 一页总结（论文 abstract 骨架）

我们在分解树对象上提出压缩-智能联合验收目标 J(T) = cov · exp(−Δ/H*) · exp(−|lnρ_s|/σ_s)，三个因子分别计量覆盖（召回）、非冗余（精度）、结构规模合理性。核心定理：(1) 覆盖-复杂度下界 D(T) ≥ H*(Q)（命题 1）；(2) 完备性饱和下冗余叶导致 J 指数衰减（命题 2）——hack 树被解析击杀，无需规则条款；(3) 正交性等价于压缩性：条件熵是正交度的精确定义，消解了正交度量选型问题（命题 3）；(4) 双约束在边际相等处达均衡，解释了经验停止判据的理论地位（命题 4）。J 无 hack 不动点（命题 5 P5），Goodhart 防线从行为层升级为结构层。全部量可用固定本地 LM 在 10 秒级算完。三条可证伪命题 + 一条消融实验构成完整验证链。新颖性主张：MDL 作为分解状态机验收目标（非"压缩即智能"提法本身）无直接先例（conf 0.8，lit-survey ②类来源核查）。
